Path A — MassNavigation（Formation / HAN / 10k）

右键 Command → MassNavigationLocalCommandInputSystem → 每个选中 actor 一条 MassNavigationMoveOrderArgs → NavGroup 编队执行。

Path B — RtsDemoMod / 通用 GAS

右键 Command mapping → InputOrderMappingSystem → moveTo order → GAS OrderBuffer，不经 MassNav ingestion。

① 选玩家（Local Player SSOT）

本地玩家不是运行时 UI 点选，而是地图加载时通过 Launch Context 绑定到 ECS 实体，再每帧由 resolver 维护。

Startup 配置
Phase: 地图加载前 · 一次性
入口GameEngine.LoadStartupMap() 输入MergedConfig.StartupSelectedPlayerId + StartupMapId 输出MapLaunchContext { SelectedPlayerId } 文件src/Core/Engine/GameEngine.cs · src/Core/Map/MapLaunchContext.cs
Participant 绑定
Phase: MapLoaded / entity spawn 后
系统ParticipantBindingResolver.Resolve() 输入MapConfig.Players[] + spawn 索引 + LaunchContext 输出LocalPlayerId, LocalPlayerEntity, PlayerEntityLookup 组件玩家代表实体上写 PlayerIdentity · PlayerOwner · Team 文件src/Core/Gameplay/Teams/ParticipantBindingResolver.cs
发布到 GlobalContext
Phase: Session focus
服务键CoreServiceKeys.LocalPlayerId · LocalPlayerEntity · MapLaunchContext 下游框选的 owner、MassNav 本地命令、Order 的 playerId 都从这里读
每帧重解析
Phase: InputCollection
系统LocalPlayerEntityResolverSystem 作用Lookup 变化时刷新 LocalPlayerEntity，避免 stale 引用 文件src/Core/Input/Systems/LocalPlayerEntityResolverSystem.cs
MassNav 额外绑定（地图 focus 时）
Mod runtime · MassNavigation map
系统MassNavigationRuntime.BindLocalSelectionOwner() 写入本地玩家实体上的 SelectionDragState；Primary view → LivePrimary 文件src/Core/MassNavigation/Runtime/MassNavigationRuntime.cs

② 框选部队（Screen-space box selection）

左键拖拽走 Confirm action（默认 Select），不是右键 Command。正式选中集合写入 SelectionSetKeys.LivePrimary。

原始输入 → 冻结快照
Visual: InputRuntimeSystem · Fixed: AuthoritativeInputSnapshotSystem
Confirm左键按下/拖拽/释放 → PointerInteractionSnapshot.Confirm Ground射线落点 → AuthoritativeGroundPointerHelper → GroundWorldCm 文件InputRuntimeSystem.cs · PointerInteractionSnapshotReader.cs
拖拽状态机
Phase: InputCollection · CurrentSelectionApplySystem
OwnerLocalPlayerEntity（必须 alive） 状态SelectionDragState on owner: StartScreen, CurrentScreen, Active 抑制瞄准时 InputOrderMappingSystem.IsAiming → 跳过框选 释放屏幕矩形 → ApplyBoxSelection()
Hit test → 正式 Selection
Query: VisualTransform + CullState + SelectionSelectableTag
投影IScreenProjector 把单位 VisualTransform 投到屏幕空间 过滤SelectionEligibility + TargetRelationFilter（只选可命令友军等） 写入SelectionRuntime.ReplaceSelection(owner, LivePrimary, hits[]) 结构Selection container + SelectionMember* relation entities 文件CurrentSelectionApplySystem.cs · SelectionRuntime.cs

③ 右键下单（Ground move command）

共享前提：右键映射到 InteractionActionBindings.CommandActionId（默认 "Command"），同时需要 AuthoritativeGroundPointerHelper.TryRead() 得到地面世界坐标 WorldCmInt2。

Path B — RtsDemoMod / InputOrderMappingSystem

RtsLocalOrderSourceSystem 装配 mapping
GameStart · input_order_mappings.json
Command 映射requireSelection: true, selectionType: Position 路由priority 0 → moveTo GAS order
InputOrderMappingSystem.Update
Phase: InputCollection
注意瞄准时同一 Command 被当 cancel（与 move 语义冲突 · #503） 输出OrderQueue → OrderBuffer → GAS moveTo 执行链
已知基建债 #503：MassNav 的 MassNavigationLocalCommandInputSystem 与瞄准态的 InputOrderMappingSystem 都直接读 raw Command，缺少 context-scoped semantic intent 层；瞄准时右键可能同时 cancel 和 submit move。
