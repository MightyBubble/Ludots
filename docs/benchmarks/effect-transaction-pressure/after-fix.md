# Effect 事务规模退化修复：实测结果

基线：`81a1b5f543`，Release/net9.0/x64。

## 结果

| 场景 | 修复前 10k | 修复后 10k | 结论 |
|---|---:|---:|---|
| 持续效果未到周期 | 42.672 ms | 0.239 ms median / 0.244 ms P95 | 从 O(n²) 恢复为近线性，零帧分配 |
| 状态事务直接 stage/read/commit | 928.110 ms（参考微基准） | 1.826 ms median / 1.876 ms P95 | Entity 索引不再重复扫描 |
| 同 tick 到期（无标签） | 256.366 ms | 28.908 ms median | 清理路径显著下降，仍受图执行和实体销毁成本影响 |
| 同 tick 到期（含标签） | 未覆盖 | 45.458 ms median / 54.753 ms P95 | 标签撤销、监听器、容器清理语义通过 |
| 监听器注册（2 万个目标实体） | 未覆盖 | 1.638 ms median / 1.753 ms P95 | 去除注册校验的平方级重扫 |

`waiting` 的 10k 性能断言为小于 16.667 ms；修复前对照运行得到 23.320 ms，因此会失败，修复后为 0.239 ms。

## 语义验证

- 事务状态索引：容量边界、重复写、回滚复用、实体版本复用。
- 生命周期：周期执行、到期清理、标签撤销、监听器移除、通知顺序。
- 分片：周期属性变化和到期通知顺序与一次执行一致。
- 既有事务、挂接、分配约束：`61/61` 通过。

证据：`final-core-regression.log`、`final-regression-2.log`、`index-regression.log`。

## 范围

本修复针对 GAS 生命周期事务的跨实体定位退化。10k GpuSkinned 的整机渲染帧率仍需在可持续运行的桌面进程中单独验收；本次独立进程已确认新调色板布局加载为 `1024x192`，但未完成稳定 FPS 采样。
