## 4. 场景

1. 打开启动器：120 间还能进的短剧在，八间划掉的家族大杂烩没有可复制的启动命令。
2. 点「伤害钳在上下限里」：字幕讲这一刀被钳住，详情说示意条从多少掉到多少，不把它说成结算出来的伤。
3. 作者给查询图只填图号、不填函数名：编译当场拒绝，不会等到运行期才炸。
4. 维护者打开解决方案：能看见两份薄契约程序集；合同页第一行仍是「修复中」。
