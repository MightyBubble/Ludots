TEST PYRAMID

测试分层 L0–L5

从静态架构守护到端到端证据录制，每层有明确的职责与运行时机。

L0

架构守护

依赖方向、分层约束、命名与注册契约的静态守护。最快失败，守门第一关。

ArchitectureTests · *ArchitectureGuardTests
L1

核心单元

无 World 依赖的纯逻辑单元测试：时间流、数学、容器、规则集。

TimeFlowCoreTests · GasTests（纯逻辑部分）
L2

子系统集成

单 World 内的子系统级集成：GAS 战斗、3C、存档、Mod 加载。

GasTests · ThreeCTests · PersistenceTests
L3

表现与适配器契约

表现层与平台适配器契约：Performer 管线、Raylib/Web/CEF 适配、Web UI 数据面。

PresentationTests · RaylibAdapterTests · WebUi*Tests · Ui*Tests · BrowserCefTests
L4

Showcase 验收

与注册表 acceptanceTest 字段一一配对的场景验收测试，验证 showcase 行为契约。

*AcceptanceTests（GasTests/Production 等）
L5

端到端证据

真实 launcher 启动 + 确定性回放录制，产出六件套证据归档到仓库。

cli launch <binding> --record artifacts/acceptance/<dir>

EVIDENCE KIT

验收六件套

一次 --record 录制产出一组确定性证据，人读战报、机读签名、眼见截图。

battle-report.md

战报：场景意图、确定性输入、动作脚本、预期结果、逐帧时间线与结论裁决。

summary.json

机器可读摘要：场景、适配器、root mods、关键计数与 normalized_signature 跨适配器一致性签名。

trace.jsonl

逐 tick 轨迹：固定时钟 1/60s 下的确定性回放记录，用于差异定位。

path.mmd

Mermaid 流程图：场景动作脚本的分支路径（成功 / 失败分支）。

screens/*.png

关键帧截图：start、after_click、marker_live、marker_expired 与 timeline 拼图。

visible-checklist.md

可见性核对单：每个关键帧「应该看到什么」的人工核对清单。
