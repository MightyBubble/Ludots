GETTING STARTED

上手

先选一条路：你要改引擎、写 Mod，还是只想把可玩包发给别人。 命令写在下面；完整合同仍以正式文档为准。

作者：弱网也能跑

本机要装 .NET 9 SDK。包还原走仓库自带离线源，规范路径不必访问 nuget.org。

  1. 安装 .NET 9 SDK（唯一硬前置）。
  2. 克隆仓库后执行一键脚本：离线还原 + 构建 + 启动示例。
  3. 换成官方验收场景时，把示例改成 binding 名即可。
./scripts/dev-up.sh
.\scripts\dev-up.ps1
./scripts/dev-up.sh resolve camera_acceptance --adapter raylib
快速开始 → 零环境契约 → 环境与构建 →

玩家：零安装开玩

玩家机不需要 .NET SDK。作者先打出自包含包，对方解压后点 Play 即可。

  1. 在开发机用发行脚本打出带 RID 的玩家包。
  2. 包内已含自包含 App、启动器与预编译 Mod。
  3. Windows 用 Play.cmd；Linux / macOS 用 Play.sh。
.\scripts\publish-player-build.ps1 -Mods ExampleMod -RuntimeIdentifier win-x64
./scripts/publish-player-build.sh --mods ExampleMod --rid linux-x64
玩家发行链 → Showcase 画廊 →
别绕路：正式入口是 launcher / dev-up；直接跑 src/Apps/... 只适合适配器级调试。GUI 启动器与 Web 适配器才需要 Node.js； Raylib CLI 主路径不需要。Cef / Ultralight 特例首次构建会访问 nuget.org，之后走缓存。
