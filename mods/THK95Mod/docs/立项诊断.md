## 2. 赛道标配

历史模拟大战略 SLG 的标配角度是桌游、体量、热点三项。桌游是规则深度的生命线；体量是武将、城池、事件、剧本的堆料；热点是历史题材认知锚点，信长用战国、三国志用三国。

## 3. 七角度打分

| 角度 | 档位 | 说明 |
| --- | --- | --- |
| 桌游 | 3 | 大战略规则是核心，尚不及信长级打磨 |
| 运动 | 2 | 即时制需基础操作，非卖点 |
| 美学 | 3 | 1995 现代东亚冷峻美学，差异化 |

| 玩具 | 2 | 势力博弈涌现，非沙盒自由 |
| 热点 | 3 | 三国母题，但它是本赛道标配 |

## 4. 公式计算

本次诊断发现公式修正：热点杠杆 P 需受标配约束，热点在赛道是标配时不贡献杠杆。

```
P = hot >= 3 且 stdHot == 0 且 content >= 11 ? hot - 2 : 0
```

计算过程：

```
总投入   T = 3+2+3+2+3+2+3 = 18
标配投入 TG = 3+3+3 = 9      桌游、体量、热点三项
红海度   H = 9/18 = 0.50
偏离杠杆 L = 1               来自美学
热点杠杆 P = 0               三国题材是本赛道标配，不贡献
有机杠杆 O = 1               同步度档位 3
总杠杆   Leverage = 1+0+1 = 2
```

## 5. 判定

红海度 0.50，蓝海；总杠杆 2；立项通过，但杠杆偏薄。

## 6. 命门

立项押注最集中的单一杠杆是美学，即 1995 现代转写。它的失效条件是：这个转写沦为换皮，美学会滑到平档，偏离杠杆归零，立项滑向蓝海无杠杆。

## 7. 公式回填

热点杠杆受 stdHot 约束的修正，应回填到 docjin 诊断公式。
