# 221 石脂年产出

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/220_Rule/221_石脂年产出.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 石脂每年产出一次，秋季统一结算进账。

## 2. 设计意图

- 用年产出驱动季节节拍，让战争与经营有节奏取舍。
- 约束 [石脂开采](211_石脂开采.md)。

## 3. 机制说明

- 判定条件：秋季到来时触发结算。
- 结算方式：按预期产量统一产出石脂进账。
- 状态变化：结算后预期产量重置进入下一年累积。

## 4. 边界与例外

- 平日不产出石脂，只累积预期产量。
