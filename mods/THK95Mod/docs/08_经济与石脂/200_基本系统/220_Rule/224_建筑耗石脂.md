# 224 建筑耗石脂

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/220_Rule/224_建筑耗石脂.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 建建筑消耗石脂，制造部队不耗任何资源只耗时间。

## 2. 设计意图

- 让石脂成为建设的硬通货，与造兵的时间成本区分。
- 约束 [工业](213_工业.md) 与建设。

## 3. 机制说明

- 建筑：消耗石脂解锁科技与提升效率。
- 造兵：只耗时间，春耕减半。
- 状态变化：石脂消耗影响后续建设与贸易。

## 4. 边界与例外

- 石脂不足则无法建建筑。
