# 222 预期产量

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/220_Rule/222_预期产量.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 平日石脂以预期产量累积，秋季按预期结算。

## 2. 设计意图

- 让玩家在秋季前经营产区，提升预期，而非即时产出。
- 约束 [石脂开采](211_石脂开采.md)。

## 3. 机制说明

- 判定条件：产区控制与经营状态。
- 结算方式：预期产量越高，秋季结算越多。
- 状态变化：经营调整改变预期产量。

## 4. 边界与例外

- 产区失控则预期产量归零。
