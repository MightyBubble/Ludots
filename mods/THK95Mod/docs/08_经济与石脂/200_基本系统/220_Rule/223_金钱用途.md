# 223 金钱用途

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/220_Rule/223_金钱用途.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 金钱只用于交易政治关系与赏赐，不参与任何生产。

## 2. 设计意图

- 让金钱成为关系货币，而非生产资料，与石脂分工。
- 约束 [贸易](212_贸易.md) 与经济循环。

## 3. 机制说明

- 金钱用途：交易政治关系、赏赐英雄与集团。
- 金钱不能购买生产、不能直接造兵或建筑。

## 4. 边界与例外

- 建筑与造兵不消耗金钱，分别耗石脂与时间。
