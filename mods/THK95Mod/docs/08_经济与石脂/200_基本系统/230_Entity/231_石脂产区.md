# 231 石脂产区

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/230_Entity/231_石脂产区.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 产出石脂的矿区据点，核心地缘资源来源。

## 2. 核心属性

- 预期产量与产区状态。

## 3. 生命周期

- 创建：开局或占领矿区产生。
- 变更：经营提升预期产量，失控归零。
- 销毁：矿区被毁。

## 4. 职责边界

- 负责：累积石脂预期产量。
- 不负责：石脂结算由年产出规则定义。

## 5. 关联

- 作为据点（模块 06）的一种类型。

## 6. 持有 Behavior

- 无。
