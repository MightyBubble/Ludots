# 213 工业

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/210_Pattern/213_工业.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家发展工业，产铁与建设能力的体验原子。

## 2. 体验目标

- 玩家应感受到工业是军备与建设的基础。
- 若此 Pattern 缺失，铁资源失去产出载体。

## 3. 涉及要素

- Rule: [建筑耗石脂](224_建筑耗石脂.md)
- Entity: [工厂](232_工厂.md)
- Action: [加工](252_加工.md)

## 4. 对系统的要求

- 系统必须提供铁产出与建筑建设消耗石脂的结算。
- 系统不应让工业脱离石脂消耗。
