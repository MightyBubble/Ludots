# 211 石脂开采

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/210_Pattern/211_石脂开采.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家控制石脂产区，积累预期产量，等待秋季结算的体验原子。

## 2. 体验目标

- 玩家应感受到石脂是地缘命脉，控制产区即控制话语权。
- 若此 Pattern 缺失，核心资源失去地缘意义。

## 3. 涉及要素

- Rule: [石脂年产出](221_石脂年产出.md)、[预期产量](222_预期产量.md)
- Entity: [石脂产区](231_石脂产区.md)、[仓库](234_仓库.md)
- Action: [开采](251_开采.md)

## 4. 对系统的要求

- 系统必须提供预期产量累积与秋季统一结算。
- 系统不应让石脂持续产出，破坏季节节拍。
