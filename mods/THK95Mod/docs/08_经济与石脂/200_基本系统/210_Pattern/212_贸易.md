# 212 贸易

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/210_Pattern/212_贸易.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家交易资源与石脂，换取关系或短缺物资的体验原子。

## 2. 体验目标

- 玩家应感受到贸易是经济与关系的桥梁。
- 若此 Pattern 缺失，资源只能自产自用。

## 3. 涉及要素

- Rule: [金钱用途](223_金钱用途.md)
- Entity: [市场](233_市场.md)
- Action: [贸易](253_贸易.md)

## 4. 对系统的要求

- 系统必须提供石脂贸易与资源交换入口。
- 系统不应让贸易脱离关系网络。
