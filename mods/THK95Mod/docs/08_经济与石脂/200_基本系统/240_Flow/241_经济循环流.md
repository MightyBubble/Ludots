# 241 经济循环流

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/200_基本系统/240_Flow/241_经济循环流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 循环流

## 1. 设计目标

- 组合训练开采、加工、贸易与消费的经济循环。
- 由 Pattern [石脂开采](211_石脂开采.md)、[工业](213_工业.md)、[贸易](212_贸易.md) 组成。
- 学习曲线阶段：练习。

## 2. 前置条件

### 2a. 局面状态

- 势力控制石脂产区或工厂。

### 2b. 玩家认知

- 玩家已理解石脂年产出与金钱用途。

## 3. 节拍序列

1. **开采** (Pattern: [石脂开采](211_石脂开采.md)) — 设计角色：引入
   - 暴露：预期产量
   - 决策：经营哪个产区
   - 压力源：秋季结算临近

2. **加工** (Pattern: [工业](213_工业.md)) — 设计角色：发展
   - 暴露：铁产出与建筑耗石脂
   - 决策：石脂投向建设还是储备
   - 压力源：石脂有限

3. **贸易** (Pattern: [贸易](212_贸易.md)) — 设计角色：高潮
   - 暴露：交易与关系机会
   - 决策：石脂换关系还是换资源
   - 压力源：关系网络的时效

## 4. 失败教学

- 石脂枯竭或产区失控：强化地缘资源保护。

## 5. 达成验证

- 玩家能自主完成开采到贸易的循环，并解释石脂与金钱的分工。
