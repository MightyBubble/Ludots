# 300 经济与石脂交互表现

- Canonical Path: `mods/THK95Mod/docs/08_经济与石脂/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家看清石脂预期产量、年产出结算与金钱用途，做出开采与贸易判断。
- 避免玩家忽略秋季结算时间与金钱不能生产的限制。

## 2. 入口与信息架构

- 入口：底栏资源条，或据点经济面板。
- 页面结构：资源条、预期产量、秋季结算倒计时、市场、仓库。
- 回看入口：底栏资源条常驻。

## 3. 核心操作路径

- 路径 A：查看预期产量 → 经营产区 → 等待秋季结算 → 查看进账。
- 路径 B：打开市场 → 贸易 → 确认 → 查看关系与库存变化。

## 4. 关键流程时序

1. 预期产量累积 → 资源条显示。
2. 秋季结算 → 石脂进账，预期重置。
3. 石脂消耗 → 建建筑或贸易。

异常时序：产区失控 → 预期产量归零提示 → 夺回产区。

## 5. 关键节点信息需求

- 预期产量与秋季结算倒计时必须前置显示。
- 石脂储量与消耗去向必须可见。
- 金钱不能生产的限制必须明确。

## 6. 提示、警示与阻断反馈

- 普通提示：结算进账、产量提升。
- 风险警示：产区将失控、石脂将耗尽。
- 硬阻断：石脂不足时建建筑置灰。

## 7. 状态反馈与可回看性

- 执行中：预期累积、加工进度可见。
- 完成后：结算、贸易在日志留痕。
- 历史记录：开采、贸易、赏赐事件写入日志。

- 金钱用途限制是否清晰。
