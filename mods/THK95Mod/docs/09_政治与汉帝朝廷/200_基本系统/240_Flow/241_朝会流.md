# 241 朝会流

- Canonical Path: `mods/THK95Mod/docs/09_政治与汉帝朝廷/200_基本系统/240_Flow/241_朝会流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 循环流

## 1. 设计目标

- 组合训练上表、投票与颁诏的政治流程。
- 由 Pattern [朝会](211_朝会.md)、[诏令](213_诏令.md) 组成。
- 学习曲线阶段：组合。

## 2. 前置条件

### 2a. 局面状态

- 势力拥有朝会席位。

### 2b. 玩家认知

- 玩家已理解席位与贡赋。

## 3. 节拍序列

1. **上表** (Pattern: [朝会](211_朝会.md)) — 设计角色：引入
   - 暴露：可提案的议题
   - 决策：提案加恩还是加罪
   - 压力源：对手也在提案

2. **投票** (Pattern: [朝会](211_朝会.md)) — 设计角色：发展
   - 暴露：各势力席位权重
   - 决策：拉票还是弃权
   - 压力源：席位不足

3. **颁诏** (Pattern: [诏令](213_诏令.md)) — 设计角色：释放
   - 暴露：诏令生效效果
   - 决策：如何利用或应对
   - 压力源：被加罪的风险

## 4. 失败教学

- 提案被否决或遭加罪：强化席位经营与拉票。

## 5. 达成验证

- 玩家能自主完成一次朝会提案到颁诏，并解释席位与贡赋的作用。
