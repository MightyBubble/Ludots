# 254 拥立

- Canonical Path: `mods/THK95Mod/docs/09_政治与汉帝朝廷/200_基本系统/250_Action/254_拥立.md`
- Document Type: GDD / Action
- Upstream: `00_索引.md`

## 1. 操作定义

- 玩家拥立汉帝或新帝，挟天子以令诸侯。

## 2. 前置条件

- 势力具备足够实力与名分。

## 3. 操作输入

- 选择拥立对象并确认。

## 4. 执行结果

- 获得挟天子政治红利，可能触发天下反应。

## 5. 失败与反馈

- 拥立触发天下反应，确认时提示风险。
