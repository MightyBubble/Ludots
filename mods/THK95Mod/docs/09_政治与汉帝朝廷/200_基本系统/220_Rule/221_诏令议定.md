# 221 诏令议定

- Canonical Path: `mods/THK95Mod/docs/09_政治与汉帝朝廷/200_基本系统/220_Rule/221_诏令议定.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 朝会召开时，各势力上表议题，按席位投票议定诏令。

## 2. 设计意图

- 让席位决定政治话语权，诏令成为合法的加恩与加罪工具。
- 约束 [朝会](211_朝会.md) 与 [诏令](213_诏令.md)。

## 3. 机制说明

- 判定条件：朝会周期到来时。
- 结算方式：上表议题，按席位权重投票，票多者诏令颁行。
- 状态变化：诏令生效，给目标势力加恩或加罪。

## 4. 边界与例外

- 无席位势力不能投票。
