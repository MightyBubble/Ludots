# 222 石脂贡赋换席位

- Canonical Path: `mods/THK95Mod/docs/09_政治与汉帝朝廷/200_基本系统/220_Rule/222_石脂贡赋换席位.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 势力交石脂贡赋换取或维持朝会席位，席位决定投票权。

## 2. 设计意图

- 用石脂贡赋把经济与政治绑定，对标沙丘香料税。
- 约束 [朝会](211_朝会.md) 的席位。

## 3. 机制说明

- 判定条件：势力是否持续交贡赋。
- 结算方式：交贡赋则席位保持，欠贡则席位缩减。
- 状态变化：席位变化影响投票权与政治地位。

## 4. 边界与例外

- 欠贡过久可能失去席位。
