# 213 诏令

- Canonical Path: `mods/THK95Mod/docs/09_政治与汉帝朝廷/200_基本系统/210_Pattern/213_诏令.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 朝会议定的诏令，对势力施加加恩或加罪的体验原子。

## 2. 体验目标

- 玩家应感受到诏令是政治武器的威力。
- 若此 Pattern 缺失，朝会投票无产出。

## 3. 涉及要素

- Rule: [诏令议定](221_诏令议定.md)
- Entity: [诏令](234_诏令.md)
- Action: [上表](251_上表.md)

## 4. 对系统的要求

- 系统必须提供诏令生效与势力影响结算。
- 系统不应让诏令脱离朝会投票。
