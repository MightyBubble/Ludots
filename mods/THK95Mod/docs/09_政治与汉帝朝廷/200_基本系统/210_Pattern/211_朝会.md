# 211 朝会

- Canonical Path: `mods/THK95Mod/docs/09_政治与汉帝朝廷/200_基本系统/210_Pattern/211_朝会.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 朝廷定期召开朝会，各势力上表议定诏令的体验原子。

## 2. 体验目标

- 玩家应感受到名分政治与席位的价值。
- 若此 Pattern 缺失，政治退化为外交数值。

## 3. 涉及要素

- Rule: [诏令议定](221_诏令议定.md)、[石脂贡赋换席位](222_石脂贡赋换席位.md)
- Entity: [朝廷](232_朝廷.md)、[席位](233_席位.md)
- Action: [上表](251_上表.md)、[投票](252_投票.md)

## 4. 对系统的要求

- 系统必须提供朝会周期与诏令投票结算。
- 系统不应让无席位势力参与投票。
