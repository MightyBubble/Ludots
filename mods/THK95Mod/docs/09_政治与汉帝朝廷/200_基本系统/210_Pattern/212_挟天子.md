# 212 挟天子

- Canonical Path: `mods/THK95Mod/docs/09_政治与汉帝朝廷/200_基本系统/210_Pattern/212_挟天子.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 势力控制汉帝，借天子名义号令天下的体验原子。

## 2. 体验目标

- 玩家应感受到挟天子的政治红利与风险。
- 若此 Pattern 缺失，汉帝沦为背景板。

## 3. 涉及要素

- Rule: [诏令议定](221_诏令议定.md)
- Entity: [汉帝](231_汉帝.md)
- Action: [拥立](254_拥立.md)

## 4. 对系统的要求

- 系统必须提供挟天子带来的诏令主导权。
- 系统不应让挟天子无代价。
