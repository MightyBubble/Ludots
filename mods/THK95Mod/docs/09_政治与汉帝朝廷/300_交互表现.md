# 300 政治与汉帝朝廷交互表现

- Canonical Path: `mods/THK95Mod/docs/09_政治与汉帝朝廷/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家看清席位、朝会与诏令，做出上表、投票与贡赋判断。
- 避免玩家忽略席位权重与欠贡风险。

## 2. 入口与信息架构

- 入口：势力面板的政治页，或朝会弹窗。
- 页面结构：席位列表、贡赋状态、朝会倒计时、议题与投票区。
- 回看入口：政治页常驻可查。

## 3. 核心操作路径

- 路径 A：查看席位 → 交贡赋 → 维持席位 → 朝会投票。
- 路径 B：朝会召开 → 上表议题 → 拉票 → 颁诏 → 查看效果。

## 4. 关键流程时序

1. 朝会倒计时 → 政治页提示。
2. 朝会召开 → 上表与投票。
3. 诏令颁行 → 加恩或加罪反馈。

异常时序：欠贡 → 席位缩减提示 → 补贡赋恢复。

## 5. 关键节点信息需求

- 席位权重与贡赋状态必须前置显示。
- 朝会倒计时与议题必须可见。
- 诏令目标与效果必须明确。

## 6. 提示、警示与阻断反馈

- 普通提示：朝会召开、诏令颁行。
- 风险警示：欠贡失席位、被加罪。
- 硬阻断：无席位时上表投票置灰。

## 7. 状态反馈与可回看性

- 执行中：投票进行、贡赋状态可见。
- 完成后：诏令效果在日志留痕。
- 历史记录：上表、投票、贡赋、拥立事件写入日志。
