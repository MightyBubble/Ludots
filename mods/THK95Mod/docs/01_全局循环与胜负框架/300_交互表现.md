# 300 全局循环与胜负框架交互表现

- Canonical Path: `mods/THK95Mod/docs/01_全局循环与胜负框架/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家一眼看清势力现状、季节节拍与三条胜利路径的进度，从而做出经营、扩张与冲刺的判断。
- 避免玩家漏看季节切换、补给圈断裂与胜利进度被对手抢跑的常见误判。

## 2. 入口与信息架构

- 入口：游戏主界面即战略地图，本模块是常驻层，无需额外入口。
- 页面结构：
  - 主视区：节点制地图，据点、补给线、部队与势力色块。
  - 顶栏：当前季节与年份，时间控制（暂停/常速/加速）。
  - 侧栏：当前选中据点的详情与操作。
  - 底栏：资源条（兵、粮、铁、石脂）与金钱。
  - 胜利面板：三条胜利路径的进度对比。
- 回看入口：胜利面板常驻可展开，事件日志保留季节切换与结算记录。

## 3. 核心操作路径

- 路径 A：玩家在战略地图上选中据点 → 预览据点状态 → 下达经营或动员指令 → 执行 → 在侧栏回看结果。
- 路径 B：时间推进中季节切换 → 顶栏季节高亮提示 → 玩家调整生产与出兵计划 → 秋季结算时底栏石脂进账可见。

## 4. 关键流程时序

1. 季节推进 → 顶栏季节刷新，春耕/秋收高亮。
2. 玩家依据季节调整指令。
3. 秋季石脂结算 → 底栏石脂与日志同时更新。
4. 胜利进度变化 → 胜利面板刷新，落后路径风险提示。

异常时序：补给圈断裂 → 地图补给线变红 → 受影响部队标记警告 → 玩家修复或撤军，回到可继续状态。

## 5. 关键节点信息需求

- 当前季节与距下一季节的时间，必须常驻顶栏。
- 石脂预期产量与秋季结算倒计时，必须前置显示，不能等结算后才让玩家知情。
- 三条胜利路径各自进度与对手对比，必须在胜利面板可见。

## 6. 提示、警示与阻断反馈

- 普通提示：季节切换、石脂结算、胜利进度更新。
- 风险警示：补给圈即将断裂、胜利路径被对手抢跑、春耕期间出兵效率减半。
- 硬阻断：无补给圈覆盖时部队无法释放技能，界面明确告知断补给原因与修复方式。

## 7. 状态反馈与可回看性

- 执行中：生产队列、部队移动、折跃部署的进度在侧栏与地图可见。
- 完成后：石脂进账、据点归属变化、胜利进度在日志与胜利面板留下记录。
- 历史记录：事件日志保留季节切换、结算、胜负进度变更痕迹。

## 9. 验收关注点

- 玩家第一次进入时，能否在数秒内读出当前季节与资源状态。
- 是否存在必须靠记忆才能避免的误判，例如忘记秋收结算时间。
- 补给圈断裂是否转化为可行动提示，而非抽象报错。
