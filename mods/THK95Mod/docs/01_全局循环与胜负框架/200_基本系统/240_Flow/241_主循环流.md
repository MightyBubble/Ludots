# 241 主循环流

- Canonical Path: `mods/THK95Mod/docs/01_全局循环与胜负框架/200_基本系统/240_Flow/241_主循环流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 循环流

## 1. 设计目标

- 组合训练势力经营、资源积累、扩张与胜利判定的完整循环。
- 涉及规则：[胜负判定](221_胜负判定.md)、[春夏秋冬循环](222_春夏秋冬循环.md)。
- 由 Pattern [势力经营](211_势力经营.md) 与 [统一天下](212_统一天下.md) 组成，资源与扩张节拍引用下游模块。
- 学习曲线阶段：引入 → 练习 → 组合 → 精通，贯穿整局。

## 2. 前置条件

### 2a. 局面状态

- 玩家已选定一方势力并完成开局。

### 2b. 玩家认知

- 玩家已理解据点、补给线与势力阶段的基本概念。

## 3. 节拍序列

1. **经营** (Pattern: [势力经营](211_势力经营.md)) — 设计角色：引入
   - 暴露：势力的关系网与人口集团现状
   - 决策：如何分配经营重心
   - 压力源：春夏秋冬的季节节拍

2. **资源积累** (Pattern: 经济模块) — 设计角色：发展
   - 暴露：石脂预期产量与金钱用途
   - 决策：资源投向建设还是关系
   - 压力源：秋季石脂结算临近

3. **扩张** (Pattern: 军事模块) — 设计角色：高潮
   - 暴露：补给线与据点攻防
   - 决策：出兵方向与时机
   - 压力源：补给圈覆盖与春耕造兵减半

4. **胜利判定** (Pattern: [统一天下](212_统一天下.md)) — 设计角色：释放
   - 暴露：三条胜利路径进度
   - 决策：集中冲刺哪条路径
   - 压力源：其他势力的竞争

## 4. 失败教学

- 势力灭亡：反向强化关系与补给的重要性。
- 路径进度被对手抢先：强化多路径并行与取舍意识。

## 5. 达成验证

- 玩家能自主完成经营到胜利的完整循环，并能解释四季节拍对决策的影响。
