# 222 春夏秋冬循环

- Document Type: GDD / Rule

## 1. 规则陈述

- 时间按春夏秋冬四季循环，春耕造兵效率减半，秋季石脂统一产出结算。

## 2. 设计意图

- 四季循环是节奏骨架，让战争与经营有季节性的取舍节拍。
- 约束 [势力经营](211_势力经营.md) 的节奏与石脂经济的周期。

## 3. 机制说明

- 春：春耕季节，部队生产队列效率减半。
- 夏：作战季节，补给圈正常覆盖。
- 秋：收获季节，石脂统一产出结算。
- 冬：休整季节，具体限制待细化。
- 状态变化：季节推进影响生产与产出节拍。

## 4. 边界与例外

- 石脂年产出只在秋季结算，平日仅累积预期产量。
- 四季循环对全部势力统一生效，不因势力差异而改变。
