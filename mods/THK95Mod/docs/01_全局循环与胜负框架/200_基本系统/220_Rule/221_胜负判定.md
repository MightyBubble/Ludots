# 221 胜负判定

## 1. 规则陈述

- 三条胜利路径：军事统一、政治主导、经济垄断，达成任一路径即统一天下。

## 2. 设计意图

- 多路径让不同势力形态都能取胜：军阀走军事、财团走经济、挟天子者走政治。
- 约束 [统一天下](212_统一天下.md) 与 [势力经营](211_势力经营.md) 的终局导向。

## 3. 机制说明

- 军事统一：消灭或吞并其余全部势力。
- 政治主导：挟天子，主导朝会取得合法霸权。
- 经济垄断：垄断石脂与财团命脉。
- 状态变化：达成条件后天下进入结算，宣告胜利。

## 4. 边界与例外

- 三条路径可并行推进，最终以先达成者判定。
- 若势力灭亡，其路径进度作废。
