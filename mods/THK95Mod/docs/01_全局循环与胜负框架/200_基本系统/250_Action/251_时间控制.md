# 251 时间控制

- Canonical Path: `mods/THK95Mod/docs/01_全局循环与胜负框架/200_基本系统/250_Action/251_时间控制.md`
- Document Type: GDD / Action
- Upstream: `00_索引.md`

## 1. 操作定义

- 玩家对即时推进的时间进行暂停、加速、减速控制。

## 2. 前置条件

- 游戏处于进行中，非结算状态。

## 3. 操作输入

- 选择时间流速：暂停、常速、加速。

## 4. 执行结果

- 系统按所选流速推进 [时间](231_时间.md)，驱动 [春夏秋冬循环](222_春夏秋冬循环.md)。

## 5. 失败与反馈

- 结算或特殊事件期间不可调速，界面给出明确提示。
