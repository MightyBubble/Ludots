# 232 天下

- Canonical Path: `mods/THK95Mod/docs/01_全局循环与胜负框架/200_基本系统/230_Entity/232_天下.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 整局游戏的顶层容器，持有地图、势力与胜负状态。

## 2. 核心属性

- 势力列表：所有存活势力。
- 胜负状态：未分胜负或已分胜负及胜者。

## 3. 生命周期

- 创建：开局时初始化地图与势力。
- 变更：势力兴亡、路径进度更新。
- 销毁：任一胜利路径达成时进入结算。

## 4. 职责边界

- 负责：追踪势力存亡与胜负状态。
- 不负责：势力内部结构由势力模块定义，地图拓扑由地图模块定义。

## 5. 关联

- 引用势力（模块 02）。
- 引用地图与补给线（模块 06）。
- 被 [胜负判定](221_胜负判定.md) 消费。

## 6. 持有 Behavior

- 无。
