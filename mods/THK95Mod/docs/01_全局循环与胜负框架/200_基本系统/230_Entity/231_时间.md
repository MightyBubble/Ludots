# 231 时间

- Canonical Path: `mods/THK95Mod/docs/01_全局循环与胜负框架/200_基本系统/230_Entity/231_时间.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 全局统一的季节与年份时钟，驱动春夏秋冬循环。

## 2. 核心属性

- 当前季节：春夏秋冬四态之一。
- 当前年份：整数递增。

## 3. 生命周期

- 创建：开局时从某一季节与年份开始。
- 变更：随实时推进，季节按春夏秋冬轮转，年随四季完成递增。
- 销毁：游戏结束。

## 4. 职责边界

- 负责：推进季节与年份，向全系统广播季节变化。
- 不负责：具体季节效果由 [春夏秋冬循环](222_春夏秋冬循环.md) 规则消费，不在此处定义。

## 5. 关联

- 被 [春夏秋冬循环](222_春夏秋冬循环.md) 消费。
- 被经济模块、军事模块的季节效果引用。

## 6. 持有 Behavior

- 无。
