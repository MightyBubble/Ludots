# 211 势力经营

- Canonical Path: `mods/THK95Mod/docs/01_全局循环与胜负框架/200_基本系统/210_Pattern/211_势力经营.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家经营一方现代势力，在节点制地图上积累关系、资源与军力，走向统一的宏观体验原子。

## 2. 体验目标

- 玩家应感受到「运筹一个现代势力从边缘走向统一」的持久掌控感与取舍决策。
- 若此 Pattern 缺失，玩家失去长线经营的目标感，游戏退化为散点操作。

## 3. 涉及要素

- Rule: [胜负判定](221_胜负判定.md)、[春夏秋冬循环](222_春夏秋冬循环.md)
- Entity: 势力（模块 02）、[时间](231_时间.md)、[天下](232_天下.md)
- Action: [时间推进](251_时间推进.md)
- Behavior: 无，势力经营是宏观体验，能力在英雄与人口集团模块定义

## 4. 对系统的要求

- 系统必须提供势力状态、时间推进、资源与关系结算的能力。
- 系统不应把势力经营写成单一按钮流程；具体经营动作属于下游模块的 Action。
