# 212 统一天下

- Canonical Path: `mods/THK95Mod/docs/01_全局循环与胜负框架/200_基本系统/210_Pattern/212_统一天下.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家达成任一胜利路径，统一天下的终极体验原子。

## 2. 体验目标

- 玩家应感受到从割据到统一的史诗感与大局观满足。
- 若此 Pattern 缺失，游戏没有终局，长线经营失去意义。

## 3. 涉及要素

- Rule: [胜负判定](221_胜负判定.md)
- Entity: [天下](232_天下.md)
- Action: 无，统一是结果而非操作
- Behavior: 无

## 4. 对系统的要求

- 系统必须持续追踪各势力状态，并在达成条件时触发胜负结算。
- 系统不应把统一写成单一数值阈值；三条胜利路径需分别判定。
