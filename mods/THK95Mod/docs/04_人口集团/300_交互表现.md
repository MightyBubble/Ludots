# 300 人口集团交互表现

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家看清三类集团的控制投影、专项能力与生产队列，做出动员与经营判断。
- 避免玩家忽略关系对控制投影的影响与集团立场的风险。

## 2. 入口与信息架构

- 入口：据点面板或势力面板的集团列表。
- 页面结构：集团列表、控制投影条、专项能力、生产队列、集团立场。
- 回看入口：集团列表常驻可查。

## 3. 核心操作路径

- 路径 A：打开集团列表 → 查看控制投影 → 动员或征税 → 确认 → 查看队列变化。
- 路径 B：查看氏族实例 → 迁徙 → 选择目标据点 → 确认。

## 4. 关键流程时序

1. 选中集团 → 控制投影与专项能力展开。
2. 判断关系与立场 → 动员或安抚。
3. 队列或立场更新 → 反馈。

异常时序：控制投影不足动员 → 提示关系缺口 → 转向经营关系。

## 5. 关键节点信息需求

- 控制投影与关系来源必须前置显示。
- 专项能力与生产队列必须可见。
- 集团立场变化必须提示，避免反抗。

## 6. 提示、警示与阻断反馈

- 普通提示：队列完成、产出结算。
- 风险警示：立场下降、控制投影流失。
- 硬阻断：关系不足时动员置灰并提示缺口。

## 7. 状态反馈与可回看性

- 执行中：队列进度、迁徙路径可见。
- 完成后：产出、立场变化在日志留痕。
- 历史记录：动员、征税、迁徙事件写入日志。

- 集团反抗风险是否在操作前充分暴露。
