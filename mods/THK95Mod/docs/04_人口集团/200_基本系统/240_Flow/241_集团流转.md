# 241 集团流转

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/240_Flow/241_集团流转.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 循环流

## 1. 设计目标

- 组合训练集团经营、动员、征税与迁徙的完整流程。
- 由 Pattern [集团经营](211_集团经营.md) 组成。
- 学习曲线阶段：练习。

## 2. 前置条件

### 2a. 局面状态

- 势力拥有多类人口集团，需要调配资源与军力。

### 2b. 玩家认知

- 玩家已理解控制投影与专项能力。

## 3. 节拍序列

1. **维系关系** (Pattern: [集团经营](211_集团经营.md)) — 设计角色：发展
   - 暴露：各集团控制投影现状
   - 决策：经营哪类集团的关系
   - 压力源：关系衰减

2. **调度产能** (Pattern: [集团经营](211_集团经营.md)) — 设计角色：高潮
   - 暴露：生产队列与专项能力
   - 决策：人口投入建设还是制造
   - 压力源：春耕减半与石脂消耗

3. **调整分布** (Pattern: [集团经营](211_集团经营.md)) — 设计角色：释放
   - 暴露：据点人口分布
   - 决策：动员、征税或迁徙
   - 压力源：战乱与补给

## 4. 失败教学

- 关系破裂导致集团失控：强化控制投影的价值。

## 5. 达成验证

- 玩家能自主完成关系维系到产能调度的循环，并解释三类集团的控制差异。
