# 211 集团经营

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/210_Pattern/211_集团经营.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家经营军阀、财团、平民三类人口集团，维系控制投影的体验原子。

## 2. 体验目标

- 玩家应感受到人口是势力的血肉，关系决定能调动多少力量。
- 若此 Pattern 缺失，人口退化为资源数字。

## 3. 涉及要素

- Rule: [控制投影](221_控制投影.md)、[专项能力](222_专项能力.md)、[生产队列](223_生产队列.md)
- Entity: [军阀集团](231_军阀集团.md)、[财团](232_财团.md)、[平民](233_平民.md)
- Action: [动员](251_动员.md)、[征税](252_征税.md)、[安抚](253_安抚.md)
- Behavior: [集团立场](261_集团立场.md)

## 4. 对系统的要求

- 系统必须提供集团控制投影的实时结算与专项能力队列。
- 系统不应让集团控制脱离关系网络，纯靠数值占有。
