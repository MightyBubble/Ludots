# 222 专项能力

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/220_Rule/222_专项能力.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 一个人口单位只持有一项专项能力，不同种类人口产出的资源不同。

## 2. 设计意图

- 让人口有明确分工，避免万能单位。
- 约束 [集团经营](211_集团经营.md) 的分工。

## 3. 机制说明

- 判定条件：人口单位分配专项能力后，仅在该能力上产出。
- 结算方式：不同集团类型产出不同资源，军阀产军力，财团产资源，平民产粮。
- 状态变化：迁徙或转化时专项能力随之改变。

## 4. 边界与例外

- 联姻可转化人口类型，专项能力随之转化。
