# 221 控制投影

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/220_Rule/221_控制投影.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 军阀由头目个人控制，君主靠私交影响；财团由士族控制，君主靠士人关系动用；平民直属君主。

## 2. 设计意图

- 让势力对集团的控制力取决于关系，而非纯占领。
- 约束 [集团经营](211_集团经营.md) 的核心。

## 3. 机制说明

- 军阀：头目与君主私交决定控制投影，关系高则能调动其军力。
- 财团：君主与士人关系决定能否动用财团资源与单位。
- 平民：直属，无中间层。
- 状态变化：关系变化直接改变集团控制投影。

## 4. 边界与例外

- 门阀财团默认不投入资源给君主，除非关系到位且签订协议。
