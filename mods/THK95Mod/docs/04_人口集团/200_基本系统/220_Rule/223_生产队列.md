# 223 生产队列

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/220_Rule/223_生产队列.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 多一个人口单位多一个生产队列，用于建设建筑与制造部队。

## 2. 设计意图

- 让人口数量直接对应生产能力，颗粒度大而清晰。
- 约束 [集团经营](211_集团经营.md) 的产能。

## 3. 机制说明

- 判定条件：人口单位可用于建设或制造。
- 结算方式：每人口单位一个队列，春耕季节部队生产效率减半。
- 状态变化：人口增减直接影响队列数量。

## 4. 边界与例外

- 建筑消耗石脂，制造部队不耗资源只耗时间。
