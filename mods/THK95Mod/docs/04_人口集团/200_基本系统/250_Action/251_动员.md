# 251 动员

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/250_Action/251_动员.md`
- Document Type: GDD / Action
- Upstream: `00_索引.md`

## 1. 操作定义

- 玩家调动人口集团投入军力生产或建设队列。

## 2. 前置条件

- 集团控制投影足够，有可动员人口。

## 3. 操作输入

- 选择集团与动员方向。

## 4. 执行结果

- 人口进入生产队列，产出部队或建筑。

## 5. 失败与反馈

- 控制投影不足时动员受限，提示关系缺口。
