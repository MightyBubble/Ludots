# 254 迁徙

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/250_Action/254_迁徙.md`
- Document Type: GDD / Action
- Upstream: `00_索引.md`

## 1. 操作定义

- 玩家把人口集团从一据点迁往另一据点。

## 2. 前置条件

- 目标据点可容纳人口，补给线连通。

## 3. 操作输入

- 选择迁徙人口与目标据点。

## 4. 执行结果

- 人口在目标据点落点，专项能力与产出随之转移。

## 5. 失败与反馈

- 目标不可达或超上限时提示原因。
