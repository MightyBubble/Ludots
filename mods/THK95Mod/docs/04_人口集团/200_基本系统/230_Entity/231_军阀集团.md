# 231 军阀集团

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/230_Entity/231_军阀集团.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 军事集团，由头目个人控制，君主靠与头目的私交影响。

## 2. 核心属性

- 头目：控制本集团的英雄。
- 万户数：人口规模。
- 控制投影：由头目与君主关系决定。

## 3. 生命周期

- 创建：势力扩张或收编时产生。
- 变更：头目关系变化改变控制投影。
- 销毁：集团瓦解或灭亡。

## 4. 职责边界

- 负责：生产部队与军力。
- 不负责：资源产出主要不归军阀。

## 5. 关联

- 引用英雄头目（模块 03）。
- 被军事模块消费。

## 6. 持有 Behavior

- [集团立场](261_集团立场.md)。
