# 232 财团

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/230_Entity/232_财团.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 经济集团，由士族控制，君主靠与士人的关系动用其力量。

## 2. 核心属性

- 士族：控制本财团的士人群体。
- 万户数：人口规模。
- 资源产出：兵粮铁石脂中的经济资源。

## 3. 生命周期

- 创建：势力扩张或收编时产生。
- 变更：士人关系变化决定动用程度。
- 销毁：财团破产或灭亡。

## 4. 职责边界

- 负责：产出经济资源与工业能力。
- 不负责：默认不投入资源给君主，除非关系与协议到位。

## 5. 关联

- 引用士人英雄（模块 03）。
- 被经济模块消费。
