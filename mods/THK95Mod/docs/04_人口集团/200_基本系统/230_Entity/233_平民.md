# 233 平民

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/230_Entity/233_平民.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 直属君主的基层人口，无中间层。

## 2. 核心属性

- 万户数：人口规模。
- 产出：粮等基础物资。

## 3. 生命周期

- 创建：开局或扩张时产生。
- 变更：征税、迁徙改变规模与分布。
- 销毁：战乱或迁徙。

## 4. 职责边界

- 负责：基础物资产出与直辖人口。
- 不负责：不参与军力与工业。

## 5. 关联

- 被经济模块消费。
- 受势力总文决定直辖上限。
