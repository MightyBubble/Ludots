# 261 集团立场

- Canonical Path: `mods/THK95Mod/docs/04_人口集团/200_基本系统/260_Behavior/261_集团立场.md`
- Document Type: GDD / Behavior
- Upstream: `00_索引.md`

## 1. 能力定义

- 人口集团对君主势力的支持、中立或反抗倾向。

## 2. 适用对象

- [军阀集团](231_军阀集团.md)、[财团](232_财团.md)、[平民](233_平民.md)、[氏族实例](235_氏族实例.md)。

## 3. 激活与效果

- 激活条件：集团存在时持续生效。
- 效果：支持则产出与控制投影提升，反抗则产出下降或叛离。

## 4. 约束

- 受控制投影、征税、安抚与关系事件影响。

## 5. 与其他 Behavior 的关系

- 与英雄的 [忠诚](261_忠诚.md) 相互影响。

## 6. 授予与剥夺

- 默认持有，随立场变化。
