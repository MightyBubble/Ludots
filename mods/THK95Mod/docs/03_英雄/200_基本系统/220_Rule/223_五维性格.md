# 223 五维性格

- Canonical Path: `mods/THK95Mod/docs/03_英雄/200_基本系统/220_Rule/223_五维性格.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 英雄性格分五维，十分制 0 到 10，配五行五德。

## 2. 设计意图

- 用性格决定英雄的忠诚、道德、勇气、权谋与容人，驱动关系与行为。
- 约束 [英雄养成](211_英雄养成.md) 与关系网络。

## 3. 机制说明

- 贞，土，忠诚。
- 诚，火，道德高度。
- 胆，木，勇气与冲动。
- 变，水，权谋变通、应变识破。
- 器，金，忍耐力、容人肚量。
- 状态变化：性格影响英雄在关系与事件中的表现。

## 4. 边界与例外

- 十分制上限 10，性格可随事件缓慢演变。
