# 222 文武韬

- Canonical Path: `mods/THK95Mod/docs/03_英雄/200_基本系统/220_Rule/222_文武韬.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 英雄能力分文、武、韬三值，百分制 0 到 100。

## 2. 设计意图

- 用三项能力对应治理、战斗、谋略，构成势力能力的输入。
- 约束 [英雄养成](211_英雄养成.md) 与势力总文武韬。

## 3. 机制说明

- 文：治理能力，对应内政。
- 武：战斗能力，对应军事。
- 韬：谋略能力，对应计谋与政策。
- 状态变化：就任官职时按放大倍数贡献给势力。

## 4. 边界与例外

- 百分制上限 100，成长受事件与培养约束。
