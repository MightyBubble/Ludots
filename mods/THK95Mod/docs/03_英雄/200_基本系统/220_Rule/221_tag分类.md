# 221 tag 分类

- Canonical Path: `mods/THK95Mod/docs/03_英雄/200_基本系统/220_Rule/221_tag分类.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 英雄与人口集团共享 tag 空间，tag 分地域、身份、门第三类。

## 2. 设计意图

- 用共享 tag 让关系自动涌现，而非手工配置。
- 约束 [英雄登场](212_英雄登场.md) 与关系推导。

## 3. 机制说明

- 地域 tag：颍川、河东等，决定同乡。
- 身份 tag：士人、流民、武人、富商等，决定同阶层。
- 门第 tag：大族等，决定同族。
- 状态变化：tag 重合在关系网络模块推导关系。

## 4. 边界与例外

- 一个英雄可持有多个 tag。
- 例：荀彧为颍川、士人、大族，关羽为河东、流民、武人。
