# 262 结党

- Canonical Path: `mods/THK95Mod/docs/03_英雄/200_基本系统/260_Behavior/262_结党.md`
- Document Type: GDD / Behavior
- Upstream: `00_索引.md`

## 1. 能力定义

- 英雄与同 tag 或同派系英雄形成政治同盟的倾向。

## 2. 适用对象

- [英雄](231_英雄.md)。

## 3. 激活与效果

- 激活条件：同 tag 英雄共处时触发。
- 效果：同派系英雄关系自动升温，形成朋党。

## 4. 约束

- 受 tag 重合与性格影响。

## 5. 与其他 Behavior 的关系

- 与 [忠诚](261_忠诚.md) 相互作用，结党可能影响忠诚对象。

## 6. 授予与剥夺

- 默认持有，随派系关系变化。
