# 261 忠诚

- Canonical Path: `mods/THK95Mod/docs/03_英雄/200_基本系统/260_Behavior/261_忠诚.md`
- Document Type: GDD / Behavior
- Upstream: `00_索引.md`

## 1. 能力定义

- 英雄对势力或君主的忠诚倾向，由性格贞决定。

## 2. 适用对象

- [英雄](231_英雄.md)。

## 3. 激活与效果

- 激活条件：英雄属于某势力时持续生效。
- 效果：忠诚高则不易叛离，忠诚低则易被笼络或叛变。

## 4. 约束

- 随关系与事件变化，受性格贞影响。

## 5. 与其他 Behavior 的关系

- 与 [结党](262_结党.md) 相互影响。

## 6. 授予与剥夺

- 默认持有，随忠诚度变化生效或失效。
