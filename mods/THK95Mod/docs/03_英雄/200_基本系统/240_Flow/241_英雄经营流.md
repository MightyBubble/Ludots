# 241 英雄经营流

- Canonical Path: `mods/THK95Mod/docs/03_英雄/200_基本系统/240_Flow/241_英雄经营流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 循环流

## 1. 设计目标

- 组合训练英雄招募、培养与任用的完整流程。
- 由 Pattern [英雄登场](212_英雄登场.md) 与 [英雄养成](211_英雄养成.md) 组成。
- 学习曲线阶段：练习。

## 2. 前置条件

### 2a. 局面状态

- 势力有官职空缺或需要特定能力英雄。

### 2b. 玩家认知

- 玩家已理解 tag、文武韬与五维性格。

## 3. 节拍序列

1. **招募** (Pattern: [英雄登场](212_英雄登场.md)) — 设计角色：引入
   - 暴露：英雄的 tag 与能力
   - 决策：是否笼络该英雄
   - 压力源：其他势力也在争夺

2. **培养** (Pattern: [英雄养成](211_英雄养成.md)) — 设计角色：发展
   - 暴露：能力与性格的成长空间
   - 决策：培养方向
   - 压力源：培养资源有限

3. **任用** (Pattern: [英雄养成](211_英雄养成.md)) — 设计角色：高潮
   - 暴露：官职放大倍数
   - 决策：安置到哪个官职
   - 压力源：官位数量有限

## 4. 失败教学

- 笼络失败或英雄流放：强化关系与性格的考量。

## 5. 达成验证

- 玩家能自主完成招募到任用的流程，并解释 tag 与能力对任用的影响。
