# 211 英雄养成

- Canonical Path: `mods/THK95Mod/docs/03_英雄/200_基本系统/210_Pattern/211_英雄养成.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家培养英雄能力与性格，使其在势力中发挥更大作用的体验原子。

## 2. 体验目标

- 玩家应感受到人才成长的回报与武将养成的投入感。
- 若此 Pattern 缺失，英雄沦为静态数值卡。

## 3. 涉及要素

- Rule: [文武韬](222_文武韬.md)、[五维性格](223_五维性格.md)
- Entity: [英雄](231_英雄.md)
- Action: [调动](251_调动.md)、[笼络](252_笼络.md)
- Behavior: [忠诚](261_忠诚.md)

## 4. 对系统的要求

- 系统必须提供英雄成长与性格演变的入口。
- 系统不应让英雄成长脱离关系与事件，纯刷数值。
