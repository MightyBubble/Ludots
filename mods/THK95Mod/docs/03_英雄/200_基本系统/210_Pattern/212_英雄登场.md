# 212 英雄登场

- Canonical Path: `mods/THK95Mod/docs/03_英雄/200_基本系统/210_Pattern/212_英雄登场.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 新英雄加入势力的登场体验原子。

## 2. 体验目标

- 玩家应感受到名将加入的惊喜与势力壮大的实感。
- 若此 Pattern 缺失，英雄加入沦为列表增员。

## 3. 涉及要素

- Rule: [tag 分类](221_tag分类.md)
- Entity: [英雄](231_英雄.md)
- Action: [笼络](252_笼络.md)
- Behavior: [结党](262_结党.md)

## 4. 对系统的要求

- 系统必须展示英雄的 tag、能力与可能的关系关联。
- 系统不应让英雄登场无任何关系与派系背景。
