# 300 军事交互表现

- Canonical Path: `mods/THK95Mod/docs/07_军事/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家看清六兵种、补给圈、驻军池与攻城双维度，做出动员与作战判断。
- 避免玩家忽略断补给、驻军上限与攻城兵种配合。

## 2. 入口与信息架构

- 入口：据点面板的军事页，或地图上的部队。
- 页面结构：兵种列表、训练队列、驻军池、补给圈范围、攻城面板。
- 回看入口：军事页常驻可查。

## 3. 核心操作路径

- 路径 A：打开军事页 → 选兵种训练 → 确认 → 查看队列。
- 路径 B：选中部队 → 出兵 → 攻城 → 选削耐久或耗驻军 → 确认。

## 4. 关键流程时序

1. 选中据点 → 驻军池与训练队列展开。
2. 判断补给圈与城等级 → 训练或折跃。
3. 攻城时 → 耐久与驻军双线进度显示。

异常时序：部队超补给圈 → 技能禁用与掉血提示 → 修复补给或撤军。

## 5. 关键节点信息需求

- 补给圈范围与断补给状态必须前置显示。
- 驻军上限与城等级关系必须可见。
- 攻城时耐久与驻军双线进度必须并排显示。

## 6. 提示、警示与阻断反馈

- 普通提示：训练完成、折跃部署。
- 风险警示：超补给圈、飞弹车脆弱、驻军将耗尽。
- 硬阻断：超圈时技能置灰，攻城兵种不匹配时提示。

## 7. 状态反馈与可回看性

- 执行中：训练队列、部队移动、攻城进度可见。
- 完成后：破城、折跃在日志留痕。
- 历史记录：动员、出兵、攻城事件写入日志。
