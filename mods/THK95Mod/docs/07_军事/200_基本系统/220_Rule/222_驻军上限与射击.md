# 222 驻军上限与射击

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/220_Rule/222_驻军上限与射击.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 驻军有上限，由城等级决定，城等级由建筑等级决定；驻军数量决定可射击目标数。

## 2. 设计意图

- 让城等级与驻军挂钩，驻军既是守备也是火力。
- 约束 [动员](211_动员.md) 与 [攻城](213_攻城.md)。

## 3. 机制说明

- 上限：城等级决定驻军池容量。
- 射击：驻军可对外射击，数量决定同时射击的目标数。
- 状态变化：城等级随建筑等级提升，驻军上限随之提升。

## 4. 边界与例外

- 驻军可被折跃消耗，降低城内守备。
