# 225 折跃部署

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/220_Rule/225_折跃部署.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 城池可消耗驻军池，把驻军快速部署到己方补给圈内任意位置。

## 2. 设计意图

- 让驻军池成为战略储备，可快速转成野战兵力。
- 约束 [动员](211_动员.md) 与 [作战](212_作战.md)。

## 3. 机制说明

- 判定条件：目标位置在己方补给圈内。
- 结算方式：消耗驻军池，在目标位置生成野战部队。
- 状态变化：驻军减少，城内守备下降。

## 4. 边界与例外

- 折跃受驻军池余量限制。
