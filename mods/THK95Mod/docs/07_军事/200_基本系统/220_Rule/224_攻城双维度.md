# 224 攻城双维度

- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 攻城分耐久与驻军两维度，不同兵种分别作用于不同维度。

## 2. 设计意图

- 让攻城需兵种配合，耐久是城防，驻军是城内兵力。
- 约束 [攻城](213_攻城.md)。

## 3. 机制说明

- 耐久维度：飞弹车远程消耗，爆破车近战消耗。
- 驻军维度：步兵巷战消耗，直升机远程消耗，空投艇空降火并。
- 坦克野外五五开但无法进城。
- 状态变化：耐久或驻军任一归零，据点易主。

## 4. 边界与例外

- 步兵是唯一可巷战消耗驻军的兵种。
