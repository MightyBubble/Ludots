# 221 兵种训练

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/220_Rule/221_兵种训练.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 训练分两种：消耗时间产野战部队到门口，或产驻军兵力值存城里。

## 2. 设计意图

- 让部队有野战与驻军两种形态，驻军可守城可折跃。
- 约束 [动员](211_动员.md)。

## 3. 机制说明

- 野战部队：训练完成直接到据点门口，可出征。
- 驻军：训练完成转化为兵力值，存于城池驻军池。
- 状态变化：春耕季节部队生产效率减半，造兵不耗资源只耗时间。

## 4. 边界与例外

- 建筑耗石脂，制造部队不耗任何资源。
