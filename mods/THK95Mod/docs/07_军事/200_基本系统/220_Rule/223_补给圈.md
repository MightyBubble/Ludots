# 223 补给圈

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/220_Rule/223_补给圈.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 所有部队需补给圈覆盖，超圈无法释放技能且逐渐损失生命值。

## 2. 设计意图

- 用补给圈约束远征深度，补给线成为战略目标。
- 约束 [作战](212_作战.md)。

## 3. 机制说明

- 判定条件：部队是否在己方补给圈内。
- 结算方式：超圈则技能禁用，生命逐渐下降。
- 状态变化：补给圈随据点与补给线连通变化。

## 4. 边界与例外

- 补给圈由己方据点沿连通补给线投射。
