# 242 攻城流

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/240_Flow/242_攻城流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 线性流

## 1. 设计目标

- 组合训练削耐久与耗驻军两条攻城线的配合流程。
- 由 Pattern [攻城](213_攻城.md) 组成。
- 学习曲线阶段：精通。

## 2. 前置条件

### 2a. 局面状态

- 部队已抵达敌方据点，具备攻城兵种。

### 2b. 玩家认知

- 玩家已理解六兵种的攻城方式。

## 3. 节拍序列

1. **削耐久** (Pattern: [攻城](213_攻城.md)) — 设计角色：发展
   - 暴露：飞弹车远程与爆破车近战的选择
   - 决策：昂贵远程还是便宜近战
   - 压力源：飞弹车脆弱易被反击

2. **耗驻军** (Pattern: [攻城](213_攻城.md)) — 设计角色：高潮
   - 暴露：步兵巷战、直升机远程、空投艇空降
   - 决策：正面巷战还是绕城空降
   - 压力源：驻军射击目标数

3. **破城** (Pattern: [攻城](213_攻城.md)) — 设计角色：释放
   - 暴露：耐久或驻军归零
   - 决策：发起总攻
   - 压力源：守军折跃反扑

## 4. 失败教学

- 单兵种攻城被反制：强化双维度配合。

## 5. 达成验证

- 玩家能自主完成一次攻城，并解释各兵种的攻城分工。
