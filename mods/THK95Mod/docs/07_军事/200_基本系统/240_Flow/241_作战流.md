# 241 作战流

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/240_Flow/241_作战流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 线性流

## 1. 设计目标

- 组合训练动员、出兵、野战与攻城的完整作战流程。
- 由 Pattern [动员](211_动员.md)、[作战](212_作战.md)、[攻城](213_攻城.md) 组成。
- 学习曲线阶段：组合。

## 2. 前置条件

### 2a. 局面状态

- 势力有可出征部队与目标据点。

### 2b. 玩家认知

- 玩家已理解兵种、补给圈与攻城双维度。

## 3. 节拍序列

1. **动员** (Pattern: [动员](211_动员.md)) — 设计角色：引入
   - 暴露：兵种训练与驻军池
   - 决策：训练野战还是驻军
   - 压力源：春耕减半

2. **出征** (Pattern: [作战](212_作战.md)) — 设计角色：发展
   - 暴露：补给圈范围
   - 决策：沿哪条补给线推进
   - 压力源：断补给风险

3. **攻城** (Pattern: [攻城](213_攻城.md)) — 设计角色：高潮
   - 暴露：耐久与驻军两维度
   - 决策：削耐久还是耗驻军
   - 压力源：驻军射击与守军反击

## 4. 失败教学

- 断补给或攻城兵种不足：强化补给与兵种配合。

## 5. 达成验证

- 玩家能自主完成动员到攻城的流程，并解释攻城双维度。
