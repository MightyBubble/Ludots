# 211 动员

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/210_Pattern/211_动员.md`

- Upstream: `00_索引.md`

## 1. 定义

- 玩家训练部队、积累驻军，备战出征的体验原子。

## 2. 体验目标

- 玩家应感受到春耕秋收节奏下的军备取舍。
- 若此 Pattern 缺失，部队可无限暴兵，失去季节节拍。

## 3. 涉及要素

- Rule: [兵种训练](221_兵种训练.md)、[驻军上限与射击](222_驻军上限与射击.md)
- Entity: [部队](231_部队.md)、[驻军池](233_驻军池.md)
- Action: [训练](251_训练.md)、[折跃](253_折跃.md)

## 4. 对系统的要求

- 系统必须提供野战部队与驻军两种训练形态。
- 系统不应让春耕造兵不减半。
