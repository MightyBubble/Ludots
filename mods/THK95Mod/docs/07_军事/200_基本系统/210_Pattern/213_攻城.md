# 213 攻城

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/210_Pattern/213_攻城.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家组织部队攻占敌方据点，削耐久与耗驻军的体验原子。

## 2. 体验目标

- 玩家应感受到攻城需兵种配合，耐久与驻军双线并进。
- 若此 Pattern 缺失，攻城退化为单一输出。

## 3. 涉及要素

- Rule: [攻城双维度](224_攻城双维度.md)、[驻军上限与射击](222_驻军上限与射击.md)
- Entity: [兵种](232_兵种.md)、[驻军池](233_驻军池.md)
- Action: [攻城](254_攻城.md)

## 4. 对系统的要求

- 系统必须分别结算耐久与驻军两条攻城线。
- 系统不应让单兵种通吃所有攻城方式。
