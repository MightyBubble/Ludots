# 212 作战

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/210_Pattern/212_作战.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家指挥部队在野外与敌方部队交战的体验原子。

## 2. 体验目标

- 玩家应感受到兵种克制与补给圈约束下的战术决策。
- 若此 Pattern 缺失，野战退化为数值碰撞。

## 3. 涉及要素

- Rule: [补给圈](223_补给圈.md)
- Entity: [部队](231_部队.md)、[兵种](232_兵种.md)
- Action: [出兵](252_出兵.md)、[释放技能](255_释放技能.md)

## 4. 对系统的要求

- 系统必须提供补给圈覆盖判定与技能释放限制。
- 系统不应让超圈部队正常作战。
