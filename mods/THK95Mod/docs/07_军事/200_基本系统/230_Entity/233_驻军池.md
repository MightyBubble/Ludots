# 233 驻军池

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/230_Entity/233_驻军池.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 城池内的抽象兵力值，代表守备与折跃储备。

## 2. 核心属性

- 驻军数量与上限。
- 可射击目标数。

## 3. 生命周期

- 创建：训练驻军时累积。
- 变更：折跃消耗、巷战损失。
- 销毁：城破或清零。

## 4. 职责边界

- 负责：承载守备兵力与折跃储备。
- 不负责：上限由城等级决定。

## 5. 关联

- 受 [驻军上限与射击](222_驻军上限与射击.md) 约束。
- 被 [折跃部署](225_折跃部署.md) 消耗。

## 6. 持有 Behavior

- 无。
