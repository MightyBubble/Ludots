# 232 兵种

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/230_Entity/232_兵种.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 部队的构成单位，六种：步兵、坦克、直升机、飞弹车、爆破车、空投飞艇。

## 2. 核心属性

- 攻城方式：消耗驻军或消耗耐久。
- 成本与特性：造价、速度、防护。

## 3. 生命周期

- 创建：训练产生。
- 变更：升级或改造。
- 销毁：被歼灭。

## 4. 职责边界

- 负责：定义各自的攻城方式与野战能力。
- 不负责：补给由补给圈规则约束。

## 5. 关联

- 被 [部队](231_部队.md) 使用。
- 攻城方式由 [攻城双维度](224_攻城双维度.md) 结算。

## 6. 持有 Behavior

- 无。
