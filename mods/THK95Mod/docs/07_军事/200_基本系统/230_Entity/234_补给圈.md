# 234 补给圈

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/230_Entity/234_补给圈.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 由己方据点沿连通补给线投射的供应范围。

## 2. 核心属性

- 覆盖范围与覆盖状态。

## 3. 生命周期

- 创建：据点控制且补给线连通时产生。
- 变更：补给线切断或修复改变覆盖。
- 销毁：据点失控。

## 4. 职责边界

- 负责：承载补给覆盖判定。
- 不负责：部队补给惩罚由补给圈规则定义。

## 5. 关联

- 依赖据点与补给线（模块 06）。
- 被 [补给圈](223_补给圈.md) 规则消费。

## 6. 持有 Behavior

- 无。
