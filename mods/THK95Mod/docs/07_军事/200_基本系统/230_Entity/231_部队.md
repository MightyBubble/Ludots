# 231 部队

- Canonical Path: `mods/THK95Mod/docs/07_军事/200_基本系统/230_Entity/231_部队.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 可出征的野战单位，由兵种构成。

## 2. 核心属性

- 兵种与数量。
- 生命值与补给状态。

## 3. 生命周期

- 创建：训练完成或折跃产生。
- 变更：作战、移动、补给。
- 销毁：被歼灭或解散。

## 4. 职责边界

- 负责：承载兵种、数量与补给状态。
- 不负责：兵种能力由兵种定义。

## 5. 关联

- 由 [兵种](232_兵种.md) 构成。
- 受 [补给圈](234_补给圈.md) 约束。

## 6. 持有 Behavior

- 英雄可持有 [英雄强化兵种](261_英雄强化兵种.md)。
