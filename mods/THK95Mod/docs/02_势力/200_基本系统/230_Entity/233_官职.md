# 233 官职

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/230_Entity/233_官职.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 私人团队中的官职席位，主公固定，另有若干下属席位。

## 2. 核心属性

- 放大倍数：该官职对文武韬的放大权重。
- 在位英雄：当前就任该官职的英雄。

## 3. 生命周期

- 创建：势力进入某阶段时生成对应数量的官职。
- 变更：任命或罢免英雄改变在位英雄。
- 销毁：阶段变化或势力灭亡时移除。

## 4. 职责边界

- 负责：持有放大倍数与在位英雄。
- 不负责：英雄属性由英雄模块定义。

## 5. 关联

- 引用英雄（模块 03）。
- 被 [官职放大](223_官职放大.md) 消费。

## 6. 持有 Behavior

- 无。
