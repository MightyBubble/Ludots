# 231 势力

- Upstream: `00_索引.md`

## 1. 定义

- 君主领导的政治实体，是英雄与人口集团的容器。

## 2. 核心属性

- 阶段：草牧霸制帝之一。
- 私人团队：主公加若干官职席位。
- 总文武韬：由官职放大规则计算得出。

## 3. 生命周期

- 创建：开局选定势力时创建。
- 变更：晋升、僭越、任命英雄时改变阶段与能力。
- 销毁：势力灭亡时移除。

## 4. 职责边界

- 负责：持有阶段、私人团队与总文武韬。
- 不负责：英雄属性由英雄模块定义，人口集团由人口集团模块定义。

## 5. 关联

- 引用英雄（模块 03）、人口集团（模块 04）。
- 被 [官职放大](223_官职放大.md) 计算，被 [天下](232_天下.md) 追踪。

## 6. 持有 Behavior

- 无。
