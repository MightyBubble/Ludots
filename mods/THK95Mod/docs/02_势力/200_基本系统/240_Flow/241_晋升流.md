# 241 晋升流

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/240_Flow/241_晋升流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 线性流

## 1. 设计目标

- 组合训练任务推进、阶段晋升与天下反应的名分成长流程。
- 由 Pattern [势力晋升](211_势力晋升.md) 与 [僭越](212_僭越.md) 组成。
- 学习曲线阶段：练习。

## 2. 前置条件

### 2a. 局面状态

- 势力处于某阶段，尚未达成更高阶段。

### 2b. 玩家认知

- 玩家已理解官位数量与总文武韬的关系。

## 3. 节拍序列

1. **积累功业** (Pattern: [势力晋升](211_势力晋升.md)) — 设计角色：发展
   - 暴露：当前阶段的必要与可选任务
   - 决策：优先完成哪项任务
   - 压力源：对手势力也在晋升

2. **抉择晋升或僭越** (Pattern: [势力晋升](211_势力晋升.md) / [僭越](212_僭越.md)) — 设计角色：转折
   - 暴露：名正言顺与僭越的代价对比
   - 决策：完成任务晋升还是冒险僭越
   - 压力源：天下反应的潜在风险

3. **阶段跃升** (Pattern: [势力晋升](211_势力晋升.md)) — 设计角色：释放
   - 暴露：新官位数量与政策规模
   - 决策：重新分配私人团队
   - 压力源：新阶段的更大责任

## 4. 失败教学

- 僭越引发讨伐联盟：强化名分的价值。

## 5. 达成验证

- 玩家能自主完成一次晋升，并解释僭越的代价与时机。
