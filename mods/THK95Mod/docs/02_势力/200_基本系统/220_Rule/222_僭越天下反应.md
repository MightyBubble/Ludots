# 222 僭越天下反应

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/220_Rule/222_僭越天下反应.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 僭越称公称王称帝时，天下各势力与人口集团产生负面反应。

## 2. 设计意图

- 让名分有代价，约束 [僭越](212_僭越.md) 成为高风险高回报的选择。

## 3. 机制说明

- 判定条件：发生僭越时触发。
- 结算方式：周边势力关系下降，可能组建讨伐联盟；同派系集团立场动摇。
- 状态变化：关系等级与集团立场按天下反应下降。

## 4. 边界与例外

- 若势力实力足够强，可承受反应代价强行僭越。
- 名正言顺晋升不触发此规则。
