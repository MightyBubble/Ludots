# 223 官职放大

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/220_Rule/223_官职放大.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 官职有属性放大倍数，势力总文武韬等于各官职英雄属性乘放大倍数之和。

## 2. 设计意图

- 让私人团队构成势力能力，官职位置决定英雄贡献的权重。
- 约束 [势力晋升](211_势力晋升.md) 的能力成长。

## 3. 机制说明

- 判定条件：英雄就任官职时按官职放大倍数计算贡献。
- 结算方式：总文决定直辖平民人口上限，总武决定统筹部队数量上限，总韬决定势力政策总 cost。
- 状态变化：任命或罢免英雄时，总文武韬重算。

## 4. 边界与例外

- 主公为固定席位，不计入官位数量。
- 草创阶段官位数量最少，随阶段晋升增加。
