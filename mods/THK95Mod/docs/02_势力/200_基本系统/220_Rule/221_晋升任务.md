# 221 晋升任务

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/220_Rule/221_晋升任务.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 每个阶段设必要任务与可选任务，完成必要任务方可名正言顺晋升。

## 2. 设计意图

- 用任务门槛把阶段成长绑定到实质功业，而非单纯时间或数值。
- 约束 [势力晋升](211_势力晋升.md) 的成长节奏。

## 3. 机制说明

- 必要任务：晋升的硬门槛，必须全部完成。
- 可选任务：提供额外收益或加速，非硬门槛。
- 状态变化：完成任务后阶段解锁，官位数量与政策规模随之变化。

## 4. 边界与例外

- 未完成必要任务仍可走 [僭越](212_僭越.md) 路径，但触发天下反应。
