# 212 僭越

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/210_Pattern/212_僭越.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 未满足晋升任务而直接僭越称公称王称帝，引天下反应的冒险体验原子。

## 2. 体验目标

- 玩家应感受到孤注一掷的冒险与代价的刺激。
- 若此 Pattern 缺失，名分失去约束，阶段晋升流于形式。

## 3. 涉及要素

- Rule: [僭越天下反应](222_僭越天下反应.md)
- Entity: [势力](231_势力.md)、[阶段](232_阶段.md)
- Action: [僭越](252_僭越.md)
- Behavior: 无

## 4. 对系统的要求

- 系统必须提供僭越后的天下反应结算，如关系恶化、外部势力讨伐。
- 系统不应让僭越无代价成功。
