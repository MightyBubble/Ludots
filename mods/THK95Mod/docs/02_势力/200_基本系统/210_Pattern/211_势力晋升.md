# 211 势力晋升

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/210_Pattern/211_势力晋升.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 势力从草创到称帝，逐阶段名正言顺成长的体验原子。

## 2. 体验目标

- 玩家应感受到势力由弱到强的成长感与名分确立的庄重感。
- 若此 Pattern 缺失，势力成长退化为数值堆叠。

## 3. 涉及要素

- Rule: [晋升任务](221_晋升任务.md)、[官职放大](223_官职放大.md)
- Entity: [势力](231_势力.md)、[阶段](232_阶段.md)、[官职](233_官职.md)
- Action: [晋升](251_晋升.md)、[任命官职](253_任命官职.md)
- Behavior: 无

## 4. 对系统的要求

- 系统必须提供阶段任务追踪、官位数量变化、总文武韬重算。
- 系统不应把晋升写成无门槛的按钮，晋升需满足任务或承担僭越代价。
