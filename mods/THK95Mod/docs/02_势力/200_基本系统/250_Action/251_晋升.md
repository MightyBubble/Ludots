# 251 晋升

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/250_Action/251_晋升.md`
- Document Type: GDD / Action
- Upstream: `00_索引.md`

## 1. 操作定义

- 玩家在完成必要任务后，宣布势力晋升到下一阶段。

## 2. 前置条件

- 完成当前阶段的全部必要任务。

## 3. 操作输入

- 选择晋升并确认。

## 4. 执行结果

- 势力进入下一阶段，官位数量增加，总文武韬容量提升。

## 5. 失败与反馈

- 必要任务未完成时不可晋升，界面列出缺口任务。
