# 253 任命官职

- Canonical Path: `mods/THK95Mod/docs/02_势力/200_基本系统/250_Action/253_任命官职.md`
- Document Type: GDD / Action
- Upstream: `00_索引.md`

## 1. 操作定义

- 玩家把英雄任命到私人团队的官职席位。

## 2. 前置条件

- 有空缺官职，且有可任命的英雄。

## 3. 操作输入

- 选择官职与英雄。

## 4. 执行结果

- 英雄就任官职，总文武韬按放大倍数重算。

## 5. 失败与反馈

- 英雄不符合官职要求时不可任命，提示所需属性。
