# 300 势力交互表现

- Canonical Path: `mods/THK95Mod/docs/02_势力/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家看清势力阶段、晋升任务与私人团队能力，做出晋升与任命的判断。
- 避免玩家忽略晋升任务缺口与僭越代价。

## 2. 入口与信息架构

- 入口：主界面势力面板。
- 页面结构：阶段条、任务列表、私人团队官职槽、总文武韬数值、政策容量。
- 回看入口：势力面板常驻可展开。

## 3. 核心操作路径

- 路径 A：打开势力面板 → 查看任务缺口 → 完成 → 晋升 → 查看新阶段官位。
- 路径 B：查看官职槽 → 任命英雄 → 确认总文武韬重算 → 回看政策容量变化。

## 4. 关键流程时序

1. 任务完成 → 任务列表勾选。
2. 玩家晋升 → 阶段条推进，官位槽增加。
3. 总文武韬重算 → 政策容量与人口部队上限刷新。

异常时序：僭越确认 → 弹出天下反应预警 → 玩家确认或取消。

## 5. 关键节点信息需求

- 当前阶段与晋升任务缺口必须前置显示。
- 官职放大倍数与英雄属性贡献必须可见。
- 僭越的天下反应代价必须在确认前明确提示。

## 6. 提示、警示与阻断反馈

- 普通提示：任务进度、官位新增。
- 风险警示：僭越引发讨伐联盟、关系下降。
- 硬阻断：必要任务未完成时晋升按钮置灰并列出缺口。

## 7. 状态反馈与可回看性

- 执行中：任务进度在面板实时更新。
- 完成后：阶段跃升、总文武韬变化在日志留痕。
- 历史记录：晋升与僭越事件写入事件日志。

- 玩家能否在数秒内读出阶段与任务缺口。
- 僭越代价是否在确认前充分暴露。
