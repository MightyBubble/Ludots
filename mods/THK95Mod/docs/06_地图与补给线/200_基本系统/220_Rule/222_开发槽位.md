# 222 开发槽位

- Canonical Path: `mods/THK95Mod/docs/06_地图与补给线/200_基本系统/220_Rule/222_开发槽位.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 据点有特定开发槽位，可建建筑，建筑位置不重要，都在城池内部。

## 2. 设计意图

- 让建设抽象化，聚焦科技解锁与效率提升，而非摆位置。
- 约束建设与城等级。

## 3. 机制说明

- 判定条件：据点有空槽位且消耗石脂。
- 结算方式：建筑只解锁科技与提升生产效率。
- 状态变化：建筑等级决定城等级，城等级决定驻军上限。

## 4. 边界与例外

- 建筑位置不影响功能，只占据槽位。
