# 221 补给线连通切断

- Canonical Path: `mods/THK95Mod/docs/06_地图与补给线/200_基本系统/220_Rule/221_补给线连通切断.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 部队需补给圈覆盖，补给线可被切断，超圈部队无法放技能且逐渐掉血。

## 2. 设计意图

- 让补给线成为战略目标，切断补给是重要战术。
- 约束 [补给](212_补给.md) 与 [扩张](211_扩张.md)。

## 3. 机制说明

- 判定条件：部队是否在己方补给圈内。
- 结算方式：超圈则技能禁用，生命逐渐损失。
- 状态变化：补给线被切断后，下游据点失去覆盖。

## 4. 边界与例外

- 补给圈由己方据点沿连通补给线投射。
