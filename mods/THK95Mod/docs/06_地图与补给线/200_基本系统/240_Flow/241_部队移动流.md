# 241 部队移动流

- Canonical Path: `mods/THK95Mod/docs/06_地图与补给线/200_基本系统/240_Flow/241_部队移动流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 线性流

## 1. 设计目标

- 组合训练部队沿补给线移动与补给圈维持的流程。
- 由 Pattern [扩张](211_扩张.md) 与 [补给](212_补给.md) 组成。
- 学习曲线阶段：练习。

## 2. 前置条件

### 2a. 局面状态

- 部队需从一据点到另一据点。

### 2b. 玩家认知

- 玩家已理解补给圈与补给线。

## 3. 节拍序列

1. **出发** (Pattern: [补给](212_补给.md)) — 设计角色：引入
   - 暴露：补给圈覆盖范围
   - 决策：走哪条补给线
   - 压力源：补给圈边界

2. **移动** (Pattern: [扩张](211_扩张.md)) — 设计角色：发展
   - 暴露：沿途据点与补给线状态
   - 决策：是否途中占领
   - 压力源：补给线可能被切断

3. **抵达** (Pattern: [扩张](211_扩张.md)) — 设计角色：释放
   - 暴露：目标据点守备
   - 决策：攻城还是绕行
   - 压力源：断补给风险

## 4. 失败教学

- 补给线被切断导致部队超圈掉血：强化后勤价值。

## 5. 达成验证

- 玩家能自主完成沿补给线移动，并解释断补给的后果。
