# 232 槽位

- Canonical Path: `mods/THK95Mod/docs/06_地图与补给线/200_基本系统/230_Entity/232_槽位.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 据点内的开发地槽位，用于建建筑。

## 2. 核心属性

- 是否占用，占用建筑。

## 3. 生命周期

- 创建：据点生成时产生。
- 变更：建建筑占用，拆建筑释放。
- 销毁：据点销毁。

## 4. 职责边界

- 负责：承载建筑。
- 不负责：建筑功能由建筑定义。

## 5. 关联

- 被 [建筑](233_建筑.md) 占用。

## 6. 持有 Behavior

- 无。
