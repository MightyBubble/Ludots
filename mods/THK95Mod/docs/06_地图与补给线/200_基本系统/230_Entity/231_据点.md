# 231 据点

- Canonical Path: `mods/THK95Mod/docs/06_地图与补给线/200_基本系统/230_Entity/231_据点.md`
- Document Type: GDD / Entity
- Upstream: `00_索引.md`

## 1. 定义

- 节点制地图上的落点，含城市、县城、要塞、矿区、坞堡。

## 2. 核心属性

- 据点类型与等级。
- 槽位列表与建筑等级。
- 驻军池与补给圈。

## 3. 生命周期

- 创建：开局或扩张时产生。
- 变更：占领、建建筑、城等级变化。
- 销毁：被摧毁或放弃。

## 4. 职责边界

- 负责：承载槽位、建筑、驻军与补给圈。
- 不负责：据点归属的控制投影由人口集团模块定义。

## 5. 关联

- 被 [补给线](234_补给线.md) 连接。
- 被军事、经济模块消费。

## 6. 持有 Behavior

- 无。
