## 1. 定义

- 玩家沿补给线占领据点，扩大势力版图的体验原子。

## 2. 体验目标

- 玩家应感受到沿补给线蚕食领土的战略推进感。
- 若此 Pattern 缺失，扩张退化为点列占领。

## 3. 涉及要素

- Rule: [补给线连通切断](221_补给线连通切断.md)
- Entity: [据点](231_据点.md)、[补给线](234_补给线.md)
- Action: [占领据点](251_占领据点.md)

## 4. 对系统的要求

- 系统必须提供补给线连通的据点占领判定。
- 系统不应允许脱离补给线的孤岛占领。
