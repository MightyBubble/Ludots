# 212 补给

- Canonical Path: `mods/THK95Mod/docs/06_地图与补给线/200_基本系统/210_Pattern/212_补给.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家维系部队补给圈覆盖，保障远征能力的体验原子。

## 2. 体验目标

- 玩家应感受到补给是战争的生命线，断补给的恐惧与守补给的算计。
- 若此 Pattern 缺失，部队可无脑深入，战争失去后勤维度。

## 3. 涉及要素

- Rule: [补给线连通切断](221_补给线连通切断.md)
- Entity: [补给线](234_补给线.md)
- Action: [修补给线](253_修补给线.md)、[切断补给线](254_切断补给线.md)

## 4. 对系统的要求

- 系统必须提供补给圈覆盖判定与断补给惩罚。
- 系统不应让超圈部队正常作战。
