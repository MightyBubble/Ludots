# 300 地图与补给线交互表现

- Canonical Path: `mods/THK95Mod/docs/06_地图与补给线/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家看清节点地图、补给线与据点槽位，做出扩张、建设与切断判断。
- 避免玩家忽略断补给与城等级上限。

## 2. 入口与信息架构

- 入口：主界面战略地图。
- 页面结构：节点地图、补给线着色、据点详情、槽位与建筑列表、补给圈范围。
- 回看入口：据点详情常驻可查。

## 3. 核心操作路径

- 路径 A：选中据点 → 查看槽位 → 建建筑 → 确认 → 查看城等级变化。
- 路径 B：选中补给线 → 切断或修复 → 确认 → 查看覆盖变化。

## 4. 关键流程时序

1. 选中据点 → 槽位与建筑展开。
2. 判断石脂与城等级 → 建建筑。
3. 补给圈与城等级更新 → 反馈。

异常时序：补给线切断 → 地图变红 → 部队超圈警告 → 修复或撤军。

## 5. 关键节点信息需求

- 补给圈范围与断补给状态必须前置显示。
- 槽位占用与建筑等级必须可见。
- 城等级决定驻军上限，必须提示。

## 6. 提示、警示与阻断反馈

- 普通提示：建筑建成、补给线修复。
- 风险警示：补给线将被切断、部队超圈。
- 硬阻断：槽位已满或石脂不足时建建筑置灰。

## 7. 状态反馈与可回看性

- 执行中：建筑建设、补给线状态可见。
- 完成后：城等级、覆盖变化在日志留痕。
- 历史记录：占领、建设、切断事件写入日志。

- 城等级与驻军上限的关系是否清晰。
