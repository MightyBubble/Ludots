# 211 关系经营

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/200_基本系统/210_Pattern/211_关系经营.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家经营英雄间、集团间关系，扩大势力控制投影的体验原子。

## 2. 体验目标

- 玩家应感受到关系是权力的真正来源，关系经营与军事经营同等重要。
- 若此 Pattern 缺失，势力控制退化为纯占领。

## 3. 涉及要素

- Rule: [tag 重合推导](221_tag重合推导.md)、[关系进位制](222_关系进位制.md)、[协议](223_协议.md)、[联姻转化](224_联姻转化.md)
- Entity: [关系](231_关系.md)
- Action: [笼络](251_笼络.md)、[联姻](252_联姻.md)、[签约](255_签约.md)
- Behavior: [亲近](261_亲近.md)、[敌对](263_敌对.md)

## 4. 对系统的要求

- 系统必须提供 tag 推导、关系进位与协议的实时结算。
- 系统不应让关系经营脱离 tag 与协议，纯刷好感度。
