# 225 内政外交同构

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/200_基本系统/220_Rule/225_内政外交同构.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 与内部人口集团和与外部势力签约，使用同一套协议机制。

## 2. 设计意图

- 让内政与外交共享协议结构，减少重复系统。
- 约束 [关系经营](211_关系经营.md) 的统一性。

## 3. 机制说明

- 内政：与门阀财团签协议调动其力量。
- 外交：与外部势力签协议获取支持或委托。
- 状态变化：两者共用关系进位与协议结算。

## 4. 边界与例外

- 内政协议对象是人口集团，外交协议对象是外部势力，但机制同构。
