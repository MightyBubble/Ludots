# 221 tag 重合推导

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/200_基本系统/220_Rule/221_tag重合推导.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 英雄与人口集团共享 tag，重合自动推导关系：地域同乡、身份同阶层、门第同族。

## 2. 设计意图

- 让关系自动涌现，而非手工配置，同 tag 派系交往有关联反应。
- 约束 [关系经营](211_关系经营.md) 的底层。

## 3. 机制说明

- 地域 tag 重合：同乡。
- 身份 tag 重合：同阶层。
- 门第 tag 重合：同族。
- 状态变化：例荀彧与荀攸共享颍川、士人、大族，自动映射同族；关羽与某富商共享河东，映射同乡。

## 4. 边界与例外

- 同 tag 派系的交往事件产生关联反应，一地分支得失影响同 tag 其他分支。
