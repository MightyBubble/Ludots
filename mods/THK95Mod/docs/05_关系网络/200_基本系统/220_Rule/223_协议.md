# 223 协议

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/200_基本系统/220_Rule/223_协议.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 君主与门阀财团或外部势力签订协议，完成任务后加深关系，正向循环。

## 2. 设计意图

- 让财团力量通过协议被调动，而非无偿投入。
- 约束 [关系经营](211_关系经营.md) 的资源交换。

## 3. 机制说明

- 协议类型：战争委托、夺取钱财、击杀指定目标等。
- 结算方式：完成任务则关系进位，未完成则关系受损。
- 状态变化：协议达成可联姻，进一步转化人口类型。

## 4. 边界与例外

- 门阀财团默认不投入资源，协议是调动其力量的唯一途径。
