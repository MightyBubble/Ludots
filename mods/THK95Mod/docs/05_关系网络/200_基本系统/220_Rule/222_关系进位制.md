# 222 关系进位制

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/200_基本系统/220_Rule/222_关系进位制.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 关系由等级与等级内进度组成，五等级负二到正二，进度满百分百进位。

## 2. 设计意图

- 用进位制表达关系的质变门槛，而非线性数值。
- 约束 [关系经营](211_关系经营.md) 的度量。

## 3. 机制说明

- 等级：负二、负一、零、正一、正二五档。
- 进度：等级内 0 到 100，满则进位到下一等级。
- 状态变化：例关系正一，进度 60，表示离正二还差 40。

## 4. 边界与例外

- 关系下降同理退位，进度跌破 0 则降一等级。
