# 224 联姻转化

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/200_基本系统/220_Rule/224_联姻转化.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 联姻后可将人口集团转化为己方类型，改变其控制投影与专项能力。

## 2. 设计意图

- 让联姻成为关系经营的终极手段，实现集团质变。
- 约束 [关系经营](211_关系经营.md) 的深度。

## 3. 机制说明

- 判定条件：关系达到足够等级后联姻。
- 结算方式：目标人口集团转化类型，如财团转为直属或军阀。
- 状态变化：控制投影与专项能力随之转化。

## 4. 边界与例外

- 联姻需消耗关系与资源，且有政治风险。
