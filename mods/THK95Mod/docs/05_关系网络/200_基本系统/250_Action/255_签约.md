# 255 签约

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/200_基本系统/250_Action/255_签约.md`
- Document Type: GDD / Action
- Upstream: `00_索引.md`

## 1. 操作定义

- 玩家与门阀财团或外部势力签订协议，委托任务以换关系。

## 2. 前置条件

- 目标愿意签约，关系达到基础档位。

## 3. 操作输入

- 选择协议类型与条款。

## 4. 执行结果

- 协议生效，完成任务后关系进位。

## 5. 失败与反馈

- 协议未完成时关系受损，提示后果。
