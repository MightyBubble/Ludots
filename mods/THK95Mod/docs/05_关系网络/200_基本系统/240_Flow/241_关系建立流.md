# 241 关系建立流

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/200_基本系统/240_Flow/241_关系建立流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 线性流

## 1. 设计目标

- 组合训练关系从结识到深化或破裂的完整流程。
- 由 Pattern [关系经营](211_关系经营.md) 组成。
- 学习曲线阶段：练习。

## 2. 前置条件

### 2a. 局面状态

- 存在可经营关系的英雄或集团。

### 2b. 玩家认知

- 玩家已理解 tag 推导与进位制。

## 3. 节拍序列

1. **结识** (Pattern: [关系经营](211_关系经营.md)) — 设计角色：引入
   - 暴露：tag 重合自动推导的初始关系
   - 决策：是否投入经营
   - 压力源：关系会衰减

2. **交往** (Pattern: [关系经营](211_关系经营.md)) — 设计角色：发展
   - 暴露：笼络与协议的机会
   - 决策：经营方式与投入
   - 压力源：协议未完成的代价

3. **深化或破裂** (Pattern: [关系经营](211_关系经营.md)) — 设计角色：高潮
   - 暴露：进位或退位的关键节点
   - 决策：联姻转化还是离间
   - 压力源：对手的离间

## 4. 失败教学

- 协议失败或离间：强化关系维护与 tag 的考量。

## 5. 达成验证

- 玩家能自主完成结识到深化的流程，并解释进位制与协议的作用。
