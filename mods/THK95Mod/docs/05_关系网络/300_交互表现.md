# 300 关系网络交互表现

- Canonical Path: `mods/THK95Mod/docs/05_关系网络/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家看清三类关系、进位制等级与协议机会，做出笼络、签约与联姻的判断。
- 避免玩家忽略 tag 推导的自动关系与同派系关联反应。

## 2. 入口与信息架构

- 入口：势力面板的关系页，或英雄详情的关系列表。
- 页面结构：关系列表、等级与进度条、tag 重合提示、协议入口、联姻入口。
- 回看入口：关系页常驻可查。

## 3. 核心操作路径

- 路径 A：打开关系页 → 查看 tag 推导的自动关系 → 笼络 → 确认 → 查看进位。
- 路径 B：查看协议机会 → 签约 → 完成任务 → 关系进位 → 正向循环。

## 4. 关键流程时序

1. 选中主体 → 关系列表展开，tag 重合高亮。
2. 判断等级与进度 → 笼络或签约。
3. 关系进位或退位 → 反馈与关联反应。

异常时序：签约未完成 → 关系受损提示 → 补救或放弃。

## 5. 关键节点信息需求

- tag 重合推导的自动关系必须高亮。
- 进位制等级与进度必须可见。
- 同派系关联反应必须提示，避免连锁。

## 6. 提示、警示与阻断反馈

- 普通提示：关系进位、协议完成。
- 风险警示：关系衰减、协议失败、离间反噬。
- 硬阻断：关系不足时签约或联姻置灰。

## 7. 状态反馈与可回看性

- 执行中：协议进度、笼络效果可见。
- 完成后：关系变化在日志留痕。
- 历史记录：签约、联姻、离间事件写入日志。

- 玩家能否数秒内读懂 tag 推导的自动关系。
- 协议失败与关联反应的代价是否充分暴露。
