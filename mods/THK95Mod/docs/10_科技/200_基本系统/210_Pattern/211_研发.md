# 211 研发

- Canonical Path: `mods/THK95Mod/docs/10_科技/200_基本系统/210_Pattern/211_研发.md`
- Document Type: GDD / Pattern
- Upstream: `00_索引.md`

## 1. 定义

- 玩家研究科技项，解锁能力的体验原子。

## 2. 体验目标

- 玩家应感受到科技成长的规划感与解锁的回报。
- 若此 Pattern 缺失，能力成长退化为数值。

## 3. 涉及要素

- Rule: [科技树](221_科技树.md)
- Entity: [科技项](231_科技项.md)
- Action: [研究](251_研究.md)、[应用](252_应用.md)

## 4. 对系统的要求

- 系统必须提供科技树解锁与研究结算。
- 系统不应让科技脱离建筑解锁。
