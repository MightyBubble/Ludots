# 241 研发流

- Canonical Path: `mods/THK95Mod/docs/10_科技/200_基本系统/240_Flow/241_研发流.md`
- Document Type: GDD / Flow
- Upstream: `00_索引.md`
- Flow Type: 线性流

## 1. 设计目标

- 组合训练建建筑解锁、研究与应用科技的流程。
- 由 Pattern [研发](211_研发.md) 组成。
- 学习曲线阶段：练习。

## 2. 前置条件

### 2a. 局面状态

- 势力已建对应建筑，解锁科技项。

### 2b. 玩家认知

- 玩家已理解三线科技树。

## 3. 节拍序列

1. **解锁** (Pattern: [研发](211_研发.md)) — 设计角色：引入
   - 暴露：建筑解锁的科技项
   - 决策：优先建哪种建筑
   - 压力源：石脂消耗

2. **研究** (Pattern: [研发](211_研发.md)) — 设计角色：发展
   - 暴露：科技效果与成本
   - 决策：研究哪条线
   - 压力源：时间与竞争

3. **应用** (Pattern: [研发](211_研发.md)) — 设计角色：释放
   - 暴露：科技生效范围
   - 决策：如何把科技转化为战力
   - 压力源：对手科技进度

## 4. 失败教学

- 科技落后：强化建筑解锁与规划。

## 5. 达成验证

- 玩家能自主完成解锁到应用的流程，并解释三线科技的取舍。
