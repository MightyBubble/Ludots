# 221 科技树

- Canonical Path: `mods/THK95Mod/docs/10_科技/200_基本系统/220_Rule/221_科技树.md`
- Document Type: GDD / Rule
- Upstream: `00_索引.md`

## 1. 规则陈述

- 科技分军事、经济、信息三线，科技项由建筑解锁。

## 2. 设计意图

- 用三线科技树区分成长方向，建筑解锁绑定建设。
- 约束 [研发](211_研发.md)。

## 3. 机制说明

- 军事线：兵种与战力。
- 经济线：资源与效率。
- 信息线：情报与通讯。
- 状态变化：建建筑解锁科技项，研究后能力生效。

## 4. 边界与例外

- 未解锁的科技不可研究。
