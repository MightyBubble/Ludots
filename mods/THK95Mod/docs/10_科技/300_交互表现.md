# 300 科技交互表现

- Canonical Path: `mods/THK95Mod/docs/10_科技/300_交互表现.md`
- Document Type: PRD / Module Interaction UX
- Upstream: `200_基本系统/00_索引.md`

## 1. UX 目标

- 让玩家看清三线科技树与建筑解锁关系，做出研发规划。
- 避免玩家忽略科技需建筑解锁的前置。

## 2. 入口与信息架构

- 入口：势力面板的科技页。
- 页面结构：三线科技树、解锁状态、研究队列、应用入口。
- 回看入口：科技页常驻可查。

## 3. 核心操作路径

- 路径 A：查看科技树 → 确认建筑解锁 → 研究 → 应用。
- 路径 B：建建筑 → 解锁科技 → 研究 → 查看效果。

## 4. 关键流程时序

1. 建建筑 → 科技解锁提示。
2. 选科技研究 → 队列推进。
3. 研究完成 → 应用 → 效果反馈。

异常时序：研究未解锁科技 → 提示需先建对应建筑。

## 5. 关键节点信息需求

- 科技解锁的建筑前置必须前置显示。
- 三线科技效果必须可见。
- 研究队列与进度必须显示。

## 6. 提示、警示与阻断反馈

- 普通提示：科技解锁、研究完成。
- 风险警示：对手科技领先。
- 硬阻断：未解锁科技时研究置灰。

## 7. 状态反馈与可回看性

- 执行中：研究队列进度可见。
- 完成后：科技生效在日志留痕。
- 历史记录：解锁、研究、应用事件写入日志。

## 8. 线框索引

- 尚未展开 `320_交互线框`，待功能交付期补科技树面板线框。

## 9. 验收关注点

- 玩家能否数秒内读懂建筑解锁科技的前置。
- 三线科技的取舍是否清晰。
