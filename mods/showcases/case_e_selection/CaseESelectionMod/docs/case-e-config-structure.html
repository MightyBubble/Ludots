Case E · 配置结构修订（落地合同）

框选：矩形单源 · 一张命中函数 · 预览/已选中同面

本文是 Case E 框选链路的现行配置合同。相对旧宪法 HTML，修正：矩形只留起角 + 活指针；命中只配一张纯函数，拖拽调度与松手 Trigger 都调用它； 函数彼此等价，差别只在返回类型（命中函数返回名单），不再把「Query」当成特殊 kind； 候选入参是集合 key（最早宪法），不是默认全图扫人。

和旧文档的关系：旧 case-e-config-report.html 保留对照；以本文为准。标 缺口 的是引擎还没对齐本合同、必须先补的基建。

00第一性：函数等价，不是 Kind 动物园

合同立场 合同 + 缺口：现网 GraphKind

可复用的图体都是函数：有入参、有返回。Score 返回分、Validation 返回是否通过、命中函数返回名单——同一套调用模型，不靠「Query 是一种 kind」制造特权通道。
边沿动作（按下/抬起）仍是带事件入口的 Trigger 图；那是调度宿主，不是另一种「函数物种」。宿主调函数；函数不调宿主。
boxing context 用 whileActive.graph 挂存活期命中函数；禁止再发明 continuousQuery 或第二套 Query 专用字段。
命中函数 · 引脚合同（对齐最早宪法 §05②，不是现网图头字段名）
入参 · 候选collection key框之前就有的名单（如 case_e.selectable）。不是「每次拿全部 entity」。全图扫描若出现，只能是某个函数体内部的实现选择，不是命中合同的默认入参。
入参 · 矩形四个 float起角 x/y + 活角 x/y。调用方接线：起角=按下写入的单一 map var；活角=指针屏幕位置 helper（拖拽当帧 / 松手 payload）。
返回TargetList / 实体名单当前矩形 ∩ 候选。现网：命中图内 DispatchCollectionEvent 自己写预览集（如 case_e.box_hover）；调度只 Execute，禁止 GraphReturnWriter / outputs[] 代写。目标模型仍可按返回类型物化，但不得再把「调用方偷写」当成现网合同。
现网缺口：图文档顶层只有 outputs[]（出参公示），没有对等的图级入参表；入参被写死在节点 imm / 读属性里。调用方在 profile 挂载处看不到引脚。补齐方向：函数登记声明入参类型 + 返回类型；挂载/Invoke 只传函数 id 与值边，不再靠 kind=Query 开后门。

08基建缺口清单

必须先补，再改 Case E 资产装成目标合同
函数等价Core可调用体统一为函数；用返回类型区分。现网已：continuous 不强制 Query；InvokeGraph 可调 Query 并拷回名单。仍缺：图级入参表、字段改名、全面废 GraphKind 特权语义。
图级入参表作者面与 outputs 对等的入参声明；调用方可见、可接线。禁止长期靠节点 imm 藏入参。
宿主调函数op现网：InvokeGraph 可调 TriggerGraph 或 Query，名单拷回宿主。命名仍可演进为 InvokeFunc。
存活期调度whileActive挂命中函数 id；图内 DispatchCollectionEvent 写预览集；不要求 kind=Query。
