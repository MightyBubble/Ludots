# 东亚 · 陆海分路

在大约 64 公里的东亚棋盘上，亲自下两道移动令：黄块走陆，蓝块走海。

这条演示**只讲走路**：同一套导航三角网里，陆地一层、海上一层，黄块和蓝块用不同的走路档案，各查各的层。不是沿路网、河网那种节点图走。

国界色、格子归属、过境面板不在这里——那是 `field_east_asia_country` 的事，跟陆海分路无关。

## 开局你看见什么

1. 中国境内一支陆军（黄块）。
2. 黄海海面一艘船（蓝块）。

导航三角网和走性贴图默认关掉。要看调试层，用 `preset:east_asia_navmesh_debug_raylib`，按 `N` / `T`。

## 启动

```powershell
.\scripts\run-mod-launcher.cmd cli launch 'preset:east_asia_borders_land_sea_raylib'
```

## 操作

- 左键点黄块或蓝块
- 右键点地面下达移动

黄块用陆地走路档案，只在陆地那层三角网上走，不会下海抄近路。蓝块用海上走路档案，只在海上那层三角网上走，不会上岸穿陆。

## 玩家验收

```gherkin
Feature: 东亚陆海分路

  Scenario: 陆军走陆地层、船走海上层
    Given 玩家进入东亚陆海演示
    And 棋盘上看见一支黄块陆军、一艘蓝块船
    When 玩家点选黄块并右键点向内陆另一处
    Then 黄块沿陆地三角网走，不下海
    When 玩家点选蓝块并右键点向另一处海面
    Then 蓝块沿海面三角网走，不上岸
    When 玩家把蓝块的目标点到内陆
    Then 船在海上那一层找不到路，不会穿陆过去

  Scenario: 船停在作者写的黄海开局点
    Given 玩家进入东亚陆海演示
    When 开局后不另下命令
    Then 蓝块仍在黄海附近，不会被空闲编队拽到陆军旁边
```

黄块蓝块看起来多大，写在展示绑定里，不写在走路档案里。
