# 东亚国界 · 陆海分路

在大约 64 公里的东亚棋盘上，先看清国界色，再亲自下两道移动令：黄块走陆，蓝块走海。走进另一个国家，左上角会报过境。

中国境内另有省级示意区。过境面板报的是国家；省界用来查“这块地属于哪一层”，不是第二套贴花。

## 开局你看见什么

1. 地形上铺着国界色（投影贴花，不是调试格子）。
2. 中国境内一支陆军（黄块）。
3. 黄海海面一艘船（蓝块）。
4. 左上角过境面板：阶段、国家代码、进入次数。

导航三角网和走性贴图默认关掉。要看调试层，用 `preset:east_asia_navmesh_debug_raylib`，按 `N` / `T`。

## 启动

```powershell
.\scripts\run-mod-launcher.cmd cli launch 'preset:east_asia_borders_land_sea_raylib'
```

## 操作

- 左键点黄块或蓝块
- 右键点地面下达移动

黄块只走陆网，不会下海抄近路。蓝块只走海网，不会上岸穿陆。

## 国界两级

| 级 | 玩家看见 | 数据 |
| --- | --- | --- |
| 国家 | 整图国界色贴花 | Natural Earth `admin_0`，层 `ownership.east_asia.country` |
| 省 | 不另画贴花；开局点落在中国某省示意区上 | 26 个中国省级占位矩形，层 `ownership.east_asia.admin`；省先挂到片区，片区再挂到 `country.china` |

郡级没有。省界是示意框，不是正式行政区划线。一条链是：省 → 片区 → 中国。

## 玩家验收

```gherkin
Feature: 东亚陆海分路与国界过境

  Scenario: 陆军走陆、船走海
    Given 玩家进入东亚国界陆海演示
    And 棋盘上看见国界色、一支黄块陆军、一艘蓝块船
    When 玩家点选黄块并右键点向内陆另一处
    Then 黄块沿陆地走，不下海
    When 玩家点选蓝块并右键点向另一处海面
    Then 蓝块沿海面走，不上岸
    When 玩家把蓝块的目标点到内陆
    Then 船找不到可走的海路，不会穿陆过去

  Scenario: 走进另一个国家
    Given 黄块当前在中国境内
    When 单位进入韩国境内
    Then 左上角过境面板的国家代码变成 3
    And 进入次数至少加一
    When 单位再进入日本境内
    Then 国家代码变成 2
    And 进入次数再加一

  Scenario: 中国境内能查到省
    Given 黄块开局在中国境内
    Then 同一位置也能查到一个省级示意区
    And 该省先属于一个片区，片区再属于中国
```

内河沿河网走还要等节点图主棋盘，这条演示不做。

黄块蓝块看起来多大，写在展示绑定里，不写在走路档案里。
