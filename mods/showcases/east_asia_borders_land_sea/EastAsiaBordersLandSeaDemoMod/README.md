# 东亚国界 · 陆海分路

在大约 64 公里的东亚棋盘上，先看清国界色，再亲自下两道移动令：黄块走陆，蓝块走海。走进另一个国家，左上角会报过境。

这条演示的重点是：同一套导航三角网里，陆地一层、海上一层，黄块和蓝块用不同的走路档案，各查各的层。不是沿路网、河网那种节点图走。

归属只挂**国家**一层。省界是另一条独立展示（`field_east_asia_admin`），不叠进本图。

## 开局你看见什么

1. 地形上铺着国界色（投影贴花，不是调试格子）。
2. 中国境内一支陆军（黄块）。
3. 黄海海面一艘船（蓝块）。
4. 左上角过境面板：阶段、国家代码、进入次数。

导航三角网和走性贴图默认关掉。要看调试层，用 `preset:east_asia_navmesh_debug_raylib`，按 `N` / `T`。

## 启动

```powershell
.\scripts\run-mod-launcher.cmd cli launch 'preset:east_asia_borders_land_sea_raylib'
```

## 操作

- 左键点黄块或蓝块
- 右键点地面下达移动

黄块用陆地走路档案，只在陆地那层三角网上走，不会下海抄近路。蓝块用海上走路档案，只在海上那层三角网上走，不会上岸穿陆。

## 国界数据

玩家看见的是整图国界色贴花；格子归属层是 `ownership.east_asia.country`（Natural Earth `admin_0`）。郡级、省级不进本图。国↔省对齐若需要，走离线烘焙脚本，不进引擎核心。标准合同见 [MapField 离散归属 SSOT](../../../../gitbook/architecture/mapfield-discreteid-ssot.md)。

## 玩家验收

```gherkin
Feature: 东亚陆海分路与国界过境

  Scenario: 陆军走陆地层、船走海上层
    Given 玩家进入东亚国界陆海演示
    And 棋盘上看见国界色、一支黄块陆军、一艘蓝块船
    When 玩家点选黄块并右键点向内陆另一处
    Then 黄块沿陆地三角网走，不下海
    When 玩家点选蓝块并右键点向另一处海面
    Then 蓝块沿海面三角网走，不上岸
    When 玩家把蓝块的目标点到内陆
    Then 船在海上那一层找不到路，不会穿陆过去

  Scenario: 走进另一个国家
    Given 黄块当前在中国境内
    When 单位进入韩国境内
    Then 左上角过境面板的国家代码变成 3
    And 进入次数至少加一
    When 单位再进入日本境内
    Then 国家代码变成 2
    And 进入次数再加一

  Scenario: 本图只有国家归属层
    Given 玩家进入东亚国界陆海演示
    Then 棋盘启用的归属层只有国家层
    And 开局黄块落在中国境内
```

黄块蓝块看起来多大，写在展示绑定里，不写在走路档案里。
