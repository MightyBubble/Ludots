# Dynamic NavMesh Hex Open World 64x64

Playable HexGrid open-world battlefield (`nav_bake_open_world_64x64_hex`): 16384 coarse graph nodes over 4096 authored Hex data chunks, a sliding 4x4 resident NavMesh window, hotspot wall edits, and visible runtime dirty tile updates.

## Launch

```text
.\scripts\run-mod-launcher.cmd cli launch preset:nav_bake_open_world_64x64_hex_raylib
```
