# Dynamic NavMesh RTS Fortress

Playable RTS battlefield (`nav_bake_dynamic_rts`): 8x8 nav chunks, central gate, side routes, selected squad, goal flag.

## Launch

```text
.\scripts\run-mod-launcher.cmd cli launch preset:nav_bake_showcase_raylib
```

This opens the unified construction lab. Use the RTS/Open World controls in the overlay panel to switch maps.
