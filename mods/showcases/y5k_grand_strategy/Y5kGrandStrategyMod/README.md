# y5k 大战略示例

新玩家一局：补给告急 → 攻防双路径 → 接管俘获 → 任命主官 → 谋略与技能。

## 九宫格指认

| 位置 | 控件 |
|---|---|
| 右上 | 小地图 |
| 左上 | 活动/任务 + 时间控制 |
| 左中 | 实体信息 |
| 右中 | 生产 / 实体列表（Tab） |
| 上中 | 视图过滤 + 通知 |
| 下中 | 命令栏 |
| 正中 | 3D 世界 |

## 启动

依赖底座：`StrategicDomainMod`、`UiRegionsMod`，以及既有通用面板能力。

```text
scripts/run-mod-launcher.cmd cli launch --preset y5k_grand_strategy_raylib
```

本 Mod 只放内容与装配，不实现通用运行时。
