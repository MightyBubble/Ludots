# 说人话（shuorenhua）

面向用户的中文文档、状态同步、公开说明写完或改完前，用本 skill 清掉模板感、表演腔和语域漂移。

## Rules

- 按 `SKILL.md` 固定顺序：判场景 → protected spans → Tier → 档位 → scope → 改写 → 回读。
- 保事实、术语、责任主体；不增删数字与主体动作关系。
- Ludots 的 `gitbook/` 正式文档、showcase 设计说明、门户说明、PR/Issue 面向人的段落默认走 `docs` 或对应 Scene Pack。
- 代码、命令、路径、接口名、报错原文不改。
- 默认只给单一推荐版本；用户要「先标问题」时切 annotation mode。

## Outputs

改写后的正文，或 annotation mode 下的问题清单。细节见 `SKILL.md` 与 `references/`。
