# Effekseer Runtime

Ludots' native emitter bridge is built against Effekseer 1.80.6 (`tag 1806`).

- Project: <https://github.com/effekseer/Effekseer>
- Source package: `EffekseerForCpp1.80.6.zip`
- SHA-256: `B0004A4961F549AA44031956196388AA07125AAA7E2A364670F03A3602727C70`
- License: MIT

The native bridge does not expose Effekseer as an engine-level asset category. It is a Raylib adapter implementation for concrete emitter asset kinds.
