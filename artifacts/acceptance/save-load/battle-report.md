# 存档读档战报（玩家主循环）

## 场景

岸线小地图上的「巡逻兵」：挪 → 存 → 再挪 → 读档归位。

## 主循环证据（合同测试）

`SaveLoadShowcaseAcceptanceTests.PatrolMoveSaveMoveLoad_ReturnsToSavedPoint`

1. 巡逻兵出生 (1000,2000)
2. 往东挪一步 → (1400,2000)
3. 经 SavePanelMod 写入 `manual/showcase`
4. 再挪远 → (2200,2200)
5. 读档 → 回到 (1400,2000)

额外：无存档重置回到出厂；弄坏档拒读且位置不被改写。

## 屏幕故事

- 首屏四步：①挪 ②存 ③再挪 ④读
- 青圈=现在，绿幽灵=存档点，灰圈=不进档临时侦察
- 右侧复用通用存档面板（零拷贝）
