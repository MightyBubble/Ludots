相机 Rig：锚点 · 摇臂 · 镜体

锚点 Pivot摇臂 Arm镜体 Lens瞄准层 AimLayer探测 Probe

命名只用引擎自己的字段语言。外来词（Shoulder/Boom/Socket）不进词表——映射关系见下方括号。

① 锚点层（跟随的根）
红色球 = 锚点，钉在被跟随实体上
字段：TargetCm + TargetHeightCm + RigPivotOffsetCm（枢轴偏移）

谁写它：sim tick 里跟随目标（读实体 WorldPositionCm）。20Hz 步进，渲染帧做 Previous→Current 插值。

② 摇臂层（这条大梁）
绿线 = 摇臂：yaw / pitch / distance 三自由度
字段：Yaw / Pitch / DistanceCm（带上下限）

挂在摇臂上的行为积木：DragRotate（拖转）、Zoom、Grounding（贴地）。摇臂的"阻尼"（arm lag）= 渲染帧连续积分的指数趋近——不挂在 20Hz tick 上，这正是抖动修复的核心约束。

· 面向采信 facingMode: followTarget：角色转向时摇臂随转（拖拽期间完全让位给玩家）
· 指针捕获：look 模式时隐藏+锁定光标（出窗不断流），随 seat 的活动上下文走
③ 镜体层（出画面的眼睛）
蓝色锥框 = 镜体视锥，挂摇臂末端
字段：FovYDeg + RigCameraOffsetCm（镜体偏移，不参与摇臂阻尼——"冷端"）

取代外来词的那两个：枢轴偏移（热端，吃阻尼）、镜体偏移（冷端，最后叠加）——刻度一冷一热是刻意设计。

④ 瞄准层 AimLayer（开镜）
橙色 = 瞄准权重驱动的参数差，不是第二台相机

一层 = 一组 {FovYDeg 收窄，镜体横移，灵敏度系数}。硬约束：权重混合前后，屏幕中心必须指向同一世界点（否则准星飘）。多档位（肩射→机瞄→镜瞄）= 这张表的行数组。

⑤ 探测 Probe（防穿）
紫色 = 沿摇臂的探测球，被挡则把镜体拉近

参数形状：探测半径 + 距离上限 + 进/出不对称阻尼（撞进去快、弹回来慢是手感关键）。

⑥ 时钟模型（为什么会抖、怎么治）

sim 20Hz 写 TargetCm（右面板"sim 步进"打开可见角色幽灵按 50ms 跳）；渲染帧用 α = 累积器/固定步长 在 Previous→Current 之间插值。修复前：宿主每渲染帧把 Previous 覆写回 Current → 插值被清零 → 相机 20Hz 裸步进（走路剧烈抖）。修复后：插值对只在 sim tick 内推进。

控件都在右侧面板。灰白幽灵球 = sim 真值（20Hz 步进），实心球 = 渲染插值后的角色。
