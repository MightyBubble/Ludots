# 万户账本 — 1 页大纲

*三国大战略 · 速查卡片 02 · hahaboard*

## 核心规则

> **聚合单位 = 万户（5 万人）。状态 = 3 职业 + 1 临时态。需求 = 饱 / 安 / 望。**
> 玩家不操作单个人，群体按状态机迁移。

## 状态机

```
   ┌─── 太平/屯田 ───→ 耕 ◀─── 限豪强 ───┐
   │                  ↑↑                  │
   │                  ││ 招抚/安饱        │
   │                  ││                  │
   │              流民（临时态）           │
   │                  ││                  │
   │                  │↓ 强征/武将高 Clout │
   │                  战 ──── 战乱/重税 ───┘
   │                  ↑
   │           武将军头 Clout 高
   │
   └── 黄巾（极端态）── 长期饱/安/望不足
```

## 状态定义

| 状态 | 占比参考 | 核心属性 | 关键迁移去向 |
|---|---|---|---|
| **耕**（自耕农+佃农）| 60-70% | 户数、亩产、徭役负担 | 流民（失衡）/ 豪强（望↑ + 限豪强未生效）|
| **战**（士兵+武将私兵）| 10-20% | 兵员、士气、补给依赖 | 豪强私兵（世袭）/ 解散归耕（和平期）|
| **豪强**（士族+大地主+部曲）| 5-15% | 部曲数、田庄、门生 | 耕（限豪强）/ 战（被召）|
| **流民**（临时态）| 0-20% 浮动 | 无 | 耕（屯田）/ 战（强征）/ 黄巾（极端）|

## 三需：饱 / 安 / 望

| 需求 | 满足来源 | 长期不足后果 | 派系关联 |
|---|---|---|---|
| **饱** | 亩产 × 田亩 − 徭役消耗 | 饿殍 → 流民 → 黄巾 | 自耕农-黄巾链条 |
| **安** | 治安机构 + 战事压力 − 战乱波及 | 流民 → 逃户 → 州郡空壳 | 武将军头负向 |
| **望** | 政策公平 + 派系平衡 + 人物德望 | 派系暴动 → 战争 | 士族-儒生链条 |

V3 的 14 needs 对这个尺度是过度设计。三国农业社会 = 三种根本张力。

## 状态迁移规则

```json
{
  "耕 → 流民": ["饱<阈值 持续 2 季", "战<0（被战乱波及）", "徭役>阈值 1 季"],
  "流民 → 耕":  ["屯田生效", "安>阈值 且 饱>阈值", "黄巾<阈值"],
  "流民 → 战":  ["强征生效", "武将 Clout≥高", "安<阈值（强征阻力低）"],
  "流民 → 黄巾": ["饱<0.3 持续 3 季", "安<0.3", "望<0.3"],
  "耕 → 豪强":  ["望>阈值 + 限豪强未生效 + 3 季累积"],
  "豪强 → 耕":  ["限豪强生效 + 皇权 Clout≥极高"],
  "豪强 → 战":  ["武将 Clout≥极高 + 战时（私兵征召）"]
}
```

## 数字量级（与真实汉代对照）

| 维度 | 数字 | 来源 |
|---|---|---|
| 单万户 | 5 万人 | 汉代户口制标准 |
| 三国总人口 | ~3000 万口 | 公元 200 年合计 |
| 东汉峰值 | ~5600 万口 | 公元 150 年 |
| 人口损耗 | 46% | 200 年 vs 150 年 |
| 一个州郡万户数 | 30-100 万户不等 | 豫州 > 凉州 |
| 一户口数 | 5-7 人 | 汉代户均 |

```

```
