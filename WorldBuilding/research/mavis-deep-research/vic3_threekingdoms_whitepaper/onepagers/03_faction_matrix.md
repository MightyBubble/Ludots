# 6 政治派系 Clout 牵制 — 1 页大纲

*三国大战略 · 速查卡片 03 · hahaboard*

## 核心规则

> **6 大派系相互牵制，3 组天然敌对 + 3 组天然张力 + 1 组转化链。**
> 玩家通过政策 + 人物化身间接影响 Clout，平衡派系是中心张力的来源。

## Clout 计算公式

```
Clout(p) = 基础权重 × (1 + 人口占比修正 + 政策效应 + 人物加成) × 事件触发修正
```

| 因子 | 说明 |
|---|---|
| 基础权重 | 上表 |
| 人口占比修正 | 派系对应人口 / 总人口 |
| 政策效应 | 上一季政策对派系的 `clout_modifiers` 累计 |
| 人物加成 | 派系化身的"个人能力" 1-10 级，每级 +0.02 |
| 事件触发 | 派系事件临时修正 ±0.10~0.30 |

## 3 组关键牵制对

### ① 士族门阀 vs 儒生清流（**根本轴**）
**皇权 vs 门阀**。决定"九品中正制"何时确立。
- 士族 Clout 高 + 儒生 Clout 低 → 九品中正制（上品无寒门）
- 儒生 Clout 高 + 士族 Clout 低 → 察举制仍主流
- 限豪强政策 + 皇权 Clout 极高 → 强制平衡

### ② 武将军头 vs 士族门阀（**兵权轴**）
**兵为国有 vs 兵为将有**。赤壁后变剧烈。
- 武将 Clout 高 + 世袭领兵制度 → 武将拥兵自重（董卓/吕布型）
- 士族 Clout 高 + 武将 Clout 低 → 兵为国有的理想状态
- 武将 Clout≥极高 + 豪强 Clout≥中 → 部曲制（私兵合法化）

### ③ 自耕农 ↔ 黄巾底层（**民怨轴**）
**黄巾是自耕农饿殍化后的极端态**。这是一对"潜在转化"关系。
- 饱<0.3 持续 3 季 → 自耕农 → 黄巾（太平道渗透）
- 屯田政策 + 安>0.5 → 黄巾 → 自耕农
- 自耕农 Clout<0.10 + 调徭役 3 季 → 黄巾事件触发

## 派系事件触发

| 事件 | 触发条件 | 系统反应 |
|---|---|---|
| **黄巾起义** | 自耕农 Clout<0.10 + 调徭役 3 季 + 黄巾 Clout>0.15 | 触发"太平道"事件链；多个州郡同时响应 |
| **士族叛乱** | 限豪强生效 + 士族 Clout<0.20 持续 2 季 | 士族化身可"清君侧"；触发内战选项 |
| **武将拥兵** | 武将 Clout≥极高 + 世袭领兵制度 + 战时 | 武将化身转化为"独立军阀"实体 |
| **商人联盟** | 商人 Clout≥中 + 士族 Clout≥中 | 兴盐铁政策效果 +50% 但望-0.10 |
| **儒生朝议** | 儒生 Clout≥高 + 皇权 Clout≥中 | 触发"政策合法性"判定；某些政策需先过朝议 |
| **察举招贤** | 儒生 Clout≥中 + 察举征辟政策 | 招到 1 个儒生化身（诸葛亮/荀彧/司马懿等模板）|

## 人物化身（派系 Clout 节点）

| 类型 | 存在方式 | 影响 |
|---|---|---|
| **武将化身** | 武将军头派系 Clout 节点 | 节点能力 1-10，每级 +0.02；阵亡 = 派系 Clout 暴跌 |
| **儒生化身** | 儒生清流派系 Clout 节点 | 归隐/出仕 = 派系 Clout 变化 |
| **门阀化身** | 士族门阀派系 Clout 节点 | 同上 |
| **事件化身** | 临时（黄巾渠帅、外族首领）| 触发事件，不持续影响 |

**关键设计点**：人物不能独立指挥军队，军队是州郡派系+补给的延伸。关羽败走麦城 = 武将军头派系 Clout 暴跌 + 派系事件触发，不是"关羽这个角色死亡"。

## 中心循环中的位置

```
[季初] 6 派系 Clout 重算（含基础权重 + 政策 + 人物 + 事件）
[玩家] 选 1-2 政策（受约束图限制，见 01）
[群体反应] 万户迁移（见 02）+ 派系 Clout 按政策效果修正
[季末] 派系事件触发（黄巾/叛乱/拥兵/联盟/朝议/招贤）
```
