这一页记录「已经查出来、但本轮没修完」的问题，防止审计结果丢失。

## 一、平台覆盖偏斜（最大的内容缺口）

唯一动作按平台统计：键鼠 151、主机 12、触控 6。

也就是说「同一套交互在主机 / 键鼠 / 触控的不同实现」目前只有 6 组真正做到了分 tab：

| 编号 | 动作 | 已有平台 |
|------|------|----------|
| UX-001 | 拖指示器松手放技能 | 键鼠 · 触控 |
| UX-002 | 点选一个单位 | 键鼠 · 触控 |
| UX-003 | 相对镜头方向行走 | 主机 · 键鼠 |
| UX-004 | 移瞄分离移动射击 | 主机 · 键鼠 |
| UX-005 | 长按出上下文菜单 | 键鼠 · 触控 |
| UX-142 | 转动视角准星 | 主机 · 键鼠 |

**待办**：下列动作在主机/触控上确实存在对应实现，但图鉴只写了键鼠那一版，需要补平台变体
（不是补一段文字，是补该平台自己的设备输入、逻辑判定、画面反馈三段 + 分镜）：

- 冲刺 / 跑步（UX-024）：手柄是按下左摇杆或 B 键，且常带「推满即跑」
- 变身整栏替换（UX-034）、同键换动词（UX-041）：复刻目标本来就是手柄为主的动作游戏
- 技能格面板点选（UX-081）：平板上是直接点触技能格，和鼠标点面板是两种手感
- 框选一群单位（UX-087）：主机上是「圈选光标 + 扩圈」，触控上是双指框
- 近战连段（UX-091 系列）：主机才是主场

## 二、该合并成同一编号的重复动作

多路评审独立指出的重复，按共识强度排序。改编号会牵动 `player_action_ux_action_index.py`
的编号体系，建议单独一轮做，并同步更新 CHECKPOINT。

1. **右键语境指令一族**：UX-007（RA2 右键随兵种）、UX-009（SC2 右键随选中）、
   UX-038（右键地面对比对象）、UX-039（右键敌人下令攻击）、UX-040（右键智能指令）
   —— 五条讲的是同一件事：右键没有固定含义，结果由「选中了谁 × 点到了什么」决定。
   建议保留一条总纲，RA2 / SC2 作为同一编号下的复刻目标示例。
2. **临时追加技能键一族**：UX-159（限时叠加）、UX-162（饰品主动）、UX-163（骑乘技）、
   UX-023（偷来/复制）—— 都是「条件成立→技能栏多几颗键→用掉→收回」。
   注意「替换整栏」（UX-034 变身、UX-146 载具）是另一种心智，不要并进来。
3. **上车 / 上炮位一族**：UX-013（上车变载具手感）、UX-146（座位整套替换）、
   UX-161（靠近载具解锁上车）—— 同一个流程被切成三段，应合成一条四拍流程：
   靠近解锁 → 不可上（满员/走远）→ 上车换套 → 下车还原。
4. **近战攻击与衔接窗一族**：UX-144（轻攻击连段）、UX-147（近战点一下）、
   UX-145（轻重混按分支）、UX-158（闪避后接攻击）、UX-091（按住/连点连段）
   —— 同一个操作模型，应合成：单发 → 连段推进 → 重击分支 → 闪避派生 → 错过窗口中断。
5. **技能瞄准流程**：UX-148（进入技能瞄准）+ UX-116（瞄准中取消）
   —— 各自拿走了同一流程的一半，合起来才是「进入 / 调整 / 确认 / 取消」四拍。
6. **目标不合法拒绝**：UX-139（超距遮挡）T1 + UX-160（雾中/类型不对）
   —— 同一体验，区别只是拒绝原因的文字。UX-137（资源不足）讲自身状态，保持独立。
7. **智能施法**：UX-103（智能施法打准星下单位）并入 UX-102（智能施法 vs 先瞄后放）T1。
8. **按住持续开火**：UX-092（按住扫射/喷火）作为 UX-107（枪械点射/扫射）的主机变体。

## 四、缺关键拍（多数是缺「失败 / 被拒绝 / 对照」那一拍）

- UX-143 软锁定：缺「挣脱」拍 —— 不补的话和硬锁在画面上没有任何区别
- UX-155 钩索：缺「甩空了会怎样」
- UX-144 / UX-091 连段：缺「错过衔接窗 → 从第一段重来」
- UX-017 交易窗：缺「一方改报价 → 双方确认被清空」（这是交易窗最重要的防骗机制）
- UX-156 镜头模式：标题承诺「锁定 / 自由转 / 拉远」，缺滚轮拉远那一拍
- UX-157 闪避中转向射击：标题是疑问句，只给了「能」这一半，缺「不能」的对照设计
- UX-019 侧移与后撤：缺「前进」作为速度基准拍，否则「更慢」在画面上无从成立
- UX-030 双击技能变体：缺「单击」基准拍，否则「变体」没有对照对象
- UX-032 捏合缩放：缺「缩放前」的对照，一张静止图看不出「变化」
- UX-108 槽位拖放：summary 承诺「替换要看得见谁被挤走」，一拍都没有
- UX-129 菜单确认后入队：立意是防误触，却没讲「点了取消会怎样」
- UX-115 环境位姿解锁：三拍全在讲提示亮/灭，没有一拍画「按下去真的翻过去了」
- UX-119 只操控自己 / UX-113 点地只指挥自己：要成立必须画出旁边有别人且它们没被选中/没动
- UX-100 教学逼迫输入：已补「按错」拍 ✅（本轮修完）
