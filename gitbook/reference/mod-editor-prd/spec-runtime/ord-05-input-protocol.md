# ord-05 runtime spec · 输入协议

> 引擎实现任务书。第一性需求见 [ord-05 PRD](../prd/ord-05-input-protocol.md)；现状见 [reference](../reference/ord-05-input-protocol.md)。

## 1. 概述
时间轴只保留事件门；玩家输入在下令前由交互上下文收集完，随施法命令进入。

## 2. 设计
- 门流程：进门记等待标记与可选截止；每帧扫本帧事件，命中或到期放行。
- 加载校验：未知步骤类型启动失败，报能力 id 与步骤序号。
- 目标来源唯一：执行实例的目标和目标上下文只来自施法命令，时间轴内没有改写入口。

## 3. 精确语义与不变量
- 门只认本帧事件，不回看历史帧。
- 截止为 0 时不超时。
- 放行后清空等待标记与截止，不影响后续门。

## 4. 迁移与治理
已删除 `InputGate`、`TargetCollectionGate`、能力输入请求/应答队列和应答系统。需要"先选目标再放技能"的玩法，改在交互上下文的图里完成。
