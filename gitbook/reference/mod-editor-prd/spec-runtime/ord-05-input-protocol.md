# ord-05 runtime spec · 输入协议

> 引擎实现任务书。第一性需求见 [ord-05 PRD](../prd/ord-05-input-protocol.md)；现状见 [reference](../reference/ord-05-input-protocol.md)。

## 1. 概述
问答应答合同：请求-响应按号配对、门上目标回填、事件门超时放行。

## 2. 设计
- 协议结构保持：请求（请求号/标记/源/目标/上下文/双载荷）与响应同构对偶；请求环形队列、响应按请求号消费。
- 门流程保持：进门构造请求（请求号 = payloadA 非零优先，否则订单号）入队置等待；处理期按等待号取响应，命中且目标存活回填目标与上下文；事件门标记命中或到期放行。
- 加载校验保持：InputGate 必须显式 payloadA。
- 文档收口：仓库尚无 InputGate 真实用例——首例落地时回写本篇示例（见 reference）。

## 3. 精确语义与不变量
- 请求号配对唯一：等待者只消费自己的号，串号忽略。
- 回填不复活死目标：目标消亡则不回填。
- 响应消费后即从缓冲移除，不重复消费。

## 4. 迁移与治理
现状即基线，无新增设计项。
