# tag-01 runtime spec · Tag 表示与状态

> 引擎实现任务书。第一性需求见 [tag-01 PRD](../prd/tag-01-basics.md)；现状见 [reference](../reference/tag-01-basics.md)。

## 1. 概述

tag 状态层合同：位图在场集 + 层数 + 定时 + 有效缓存 + 脏管道。

## 2. 设计

- 统一操作入口（加/减/查），规则事务与效果授予全部经此；操作带快照回滚。
- 有效视角：规则禁用表解析结果缓存，规则变更时失效重建。
- 定时缓冲按到期 tick 退层，时钟域可逐条目指定。

## 3. 精确语义与不变量

- 容量（种类/计数/定时）超限即失败，见事实页数值。
- 变化事件必在下一拍可见（帧序不变量，tag-03）。

## 4. 迁移与治理

现状即基线，无新增设计项。
