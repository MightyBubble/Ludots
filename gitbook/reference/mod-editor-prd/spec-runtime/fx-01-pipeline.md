# fx-01 runtime spec · 效果执行管线总览

> 引擎实现任务书。第一性需求见 [fx-01 PRD](../prd/fx-01-pipeline.md)；现状见 [reference](../reference/fx-01-pipeline.md)。

## 1. 概述

效果主循环的阶段机、切片预算与事务边界合同。

## 2. 设计

- 阶段机四段固定：提案应用 → 存活 → 存活后提案应用 → 完成；提案段子阶段循环消化（pass 上限见事实页），队列无后续才进存活段，第三段消化存活期新请求；切片双预算=工作单元数与毫秒并行（毫秒 ≤0 视 1、计时器逐子系统传递，超耗抛错），每片首重置扇出根预算、根预算表三子系统共享。
- 三子系统职责保持：提案（出队、响应窗口、内联或实体化、监听器暂存）、应用（入容器、相位事务、FanOut 发布、监听器回放）、存活（周期、过期、tag 回收、容器移除销毁）。
- 事务合同保持：提交顺序结构回放→属性→tag/容器/状态/黑板/监听器/关系→外部写→dirty→请求→Spawn→表现→事件→根预算→销毁；失败四段回滚。

## 3. 精确语义与不变量

- 提案段未清空不进存活段；pass 数与切片预算不超事实页上限；事务要么全落地要么零落地，子系统不得绕过事务直写世界。

## 4. 迁移与治理

现状即基线，无迁移项。
