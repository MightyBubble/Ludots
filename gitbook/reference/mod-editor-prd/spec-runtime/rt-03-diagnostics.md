# rt-03 runtime spec · 诊断与错误码

> 引擎实现任务书。第一性需求见 [rt-03 PRD](../prd/rt-03-diagnostics.md)；现状见 [reference](../reference/rt-03-diagnostics.md)。

## 1. 概述

结构化诊断合同：九系统域 × 指标命名值、四要素事件、fail-fast 诊断缓冲；错误码命名法集中化。

## 2. 设计

- 九域枚举与指标命名值保持；指标编号的保留空号（5、6）在枚举注释中显式说明"缺号保留，勿补"，工具按命名值消费。
- 诊断缓冲保持默认容量与满抛语义——诊断通道自身 fail-fast 不变。
- **治理项 R2**：错误码无集中字典——32 族 165 个 `GAS.*.ERR.*` 字面量散布约 40 个文件（最大族 GAS.GRAPH.ERR×43，单文件最多 GasGraphRuntimeApi.cs 25 处）。方向：建单一错误码注册表（常量类或生成清单），抛出点引用注册表；字面量格式保持不变（对外合同），仅收敛定义位置，供编辑器字典与文档同源消费。
- 指标→人话解释表与错误码注册表同源生成，供 DataPlane 暴露。

## 3. 精确语义与不变量

- 帧首清零；只发布非零计数；事件四要素齐全。
- 诊断 Publish 满即抛（带容量与帧号）。
- 错误码字面量一经发布不改义；新增码只增不改。

## 4. 迁移与治理

现状即基线；R2 处置入 TODO（见 todo/runtime.md），迁移以"先集中定义、后逐文件替换引用"两步走，每步可独立验收。
