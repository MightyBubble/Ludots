# map-02 runtime spec · 地图触发器

> 引擎实现任务书。第一性需求见 [map-02 PRD](../prd/map-02-triggers.md)；现状见 [reference](../reference/map-02-triggers.md)。

## 1. 概述

触发器装载合同：类型名反射解析、并集注册、事件分发。

## 2. 设计

- 解析顺序：类型名先在工作区已装载程序集中解析；解析不到即失败（fail-fast），不继承基类的类型跳过并记录。
- **治理设计**：声明式触发器（数据定义条件与动作，走效果/订单组合）作为代码触发器的补充通道——降低"改一句剧情也要写代码"的门槛；与组合优先红线一致。

## 3. 精确语义与不变量

- 同一类型多片段启用只注册一次。
- 触发器执行异常不静默：报事件与类型名。

## 4. 迁移与治理

现状即基线；声明式触发器为新增设计项，随战役包场景需求立项。
