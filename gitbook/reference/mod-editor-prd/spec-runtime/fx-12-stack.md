# fx-12 runtime spec · 堆叠

> 引擎实现任务书。第一性需求见 [fx-12 PRD](../prd/fx-12-stack.md)；现状见 [reference](../reference/fx-12-stack.md)。

## 1. 概述

堆叠策略合并、溢出处理与授予标签差量联动合同。

## 2. 设计

- 策略保持：三策略作用于剩余时长，合并后到期时点置零下帧重算；RemoveOldest 换新不增层数、RejectNew 拒收；新实体首层=1；仅声明策略且非即时的效果参与合并，按模板身份在目标容器定位。
- 授予联动保持：差量=新贡献−旧贡献经标签操作落地，失败先回滚堆叠与效果实体再上抛；三对方法全量回滚；标签层数溢出抛错并计预算。

## 3. 精确语义与不变量

- 层数与授予标签贡献同事务，不存在"层数变了、标签没跟上"的中间态；上限内层数单调不减（除移除/过期）。

## 4. 迁移与治理

治理项 E3/E4（todo/effect.md）：E3——limit 无正值校验、0/负值按无上限意外放行，loader 增加 limit≥1 校验并同步编辑器，落地属行为收紧需发布说明；E4——图公式 loader 即拒、其后图解析分支为死代码，删除死分支（接通图公式须先评审）。
