# fx-12 runtime spec · 目标查询

> 引擎实现任务书。第一性需求见 [fx-11 PRD](../prd/fx-09-target-query.md)；现状见 [reference](../reference/fx-09-target-query.md)。

## 1. 概述

五形状互斥矩阵、原点语义、动态查询与查询中心解析合同。

## 2. 设计

- 互斥矩阵保持：五形状各字段必填与正数约束、环内径闭开区间、原点二值；GraphProgram 时九个空间字段全禁、图 id 必填。
- 查询中心解析保持：锥/线/矩形偏施法者；其余先目标点、再施法者兜底。

## 3. 精确语义与不变量

- 查询块只产出候选，不做敌我与数量裁剪（裁剪序@@fx9@@）；同一形状边界字段组合非法即拒绝，不存在缺省补零。

## 4. 迁移与治理

治理项 E2（todo/effect.md）：空间查询描述符上的敌我/排除/数量/层四字段是双路径残留、loader 从不填充——删除四字段，过滤参数唯一正路为 targetFilter 块；删除前文档与编辑器不得引导写入查询块。
