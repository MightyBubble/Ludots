# attr-06 runtime spec · 属性事件

> 引擎实现任务书。第一性需求见 [attr-06 PRD](../prd/attr-06-events.md)；现状见 [reference](../reference/attr-06-events.md)。

## 1. 概述

两条通知面的语义合同：映射表封闭、一帧延迟、表现位全覆盖。

## 2. 设计

- 玩法面链路保持：属性脏位→延迟触发收集（比对快照得 Old/New 入队并更新快照）→处理系统查映射发布 GameplayEvent；未映射直接返回。
- 表现面链路保持：写入权威与聚合器打变化位→表现投影产出属性值变化事件→清位系统消费即移除。
- **治理项 A13**：映射注册入口生产零调用、无配置文件——补配置入口（GAS 域表）或特性门禁后显式标注实验。
- **治理项 A14**：冻结后 Register 的错误信息不指向真因——改为带注册时机与正解。
- **治理项 A15**：两面对比（机制、OldValue 语义、消费方）以手册 attr-06 对比表为准同源进架构文档。

## 3. 精确语义与不变量

- 映射表 64 槽直查、启动填充、冻结封闭，越界查询返回无效 id 即不发布；变化位消费即清，一帧内不重复发布；玩法面与表现面互不派生。

## 4. 迁移与治理

现状即基线；A13-A15 见 todo/attribute.md。A13 是先决决策：入口立项后面板（attr-06 editor spec）才可编辑。
