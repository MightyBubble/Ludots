# fx-08 runtime spec · 八相位执行

> 引擎实现任务书。第一性需求见 [fx-07 PRD](../prd/fx-05-phases.md)；现状见 [reference](../reference/fx-05-phases.md)。

## 1. 概述

八相位三槽执行序、监听器后置与确定性种子的执行合同。

## 2. 设计

- 相位与槽保持：八相位 id 有序；每相位 Pre→Main→Post；Main 权威在模板图，无 Main 且未 SkipMain 才回落 preset 默认；绑定步上限=8×3（事实页常量推导）。
- 执行序保持：①监听器先行收集+预检（Pre 图之前）②三槽依次执行 ③Post 后按优先级降序执行已收集监听器；来源目标缓冲→施法者缓冲→全局注册表；超容量抛错不丢弃。
- 确定性保持：相位随机种子 FNV 混合派生；config 作用域包裹相位执行。

## 3. 精确语义与不变量

- 监听器永远在本相位三槽之后执行（先收集后执行，看到的是相位结果）；执行序只由优先级决定，与来源路数无关。

## 4. 迁移与治理

现状即基线；监听器收集注释的语义治理@@fx7@@ spec（E6）。
