# ord-01 runtime spec · 订单类型

> 引擎实现任务书。第一性需求见 [ord-01 PRD](../prd/ord-01-types.md)；现状见 [reference](../reference/ord-01-types.md)。

## 1. 概述
订单类型加载合同：三段重建、双模式编号、引用许可序、必备类型底线校验。

## 2. 设计
- 三段加载时序保持：Clear 两注册表 → 键注册 → 两遍式编号（整数先行、语义按字典序取最小空闲）→ 类型 → 规则。
- 语义编号语义收紧：语义串必须与条目 key 逐字相同——这不是别名机制，外部 key 映射不做（现状即如此，文档同步收口）。
- **治理项**：`OrderTypeConfig` 类默认值不可达（加载器逐字段显式赋值）且不一致（`QueuedModeMaxSize` 默认 16 超加载器上限 8、黑板键默认非 -1）——清理为与加载器一致的合法缺省或改由加载器统一提供（O1）。
- 必备类型校验保持 fail-fast：常量声明 ∩ 注册表对账，错误信息带常量路径。

## 3. 精确语义与不变量
- 编号空间 >0 且 <256；整数编号互不重复；语义编号分配与加载顺序无关（字典序决定）。
- 三键组键 id 在类型注册前全部已注册；`none` 归一为 -1。
- 五键组存在当且仅当 `instantComplete=true`。

## 4. 迁移与治理
现状即基线；O1 默认值清理入 TODO，不影响数据格式。
