# ent-01 runtime spec · 实体模板

> 引擎实现任务书。第一性需求见 [ent-01 PRD](../prd/ent-01-templates.md)；现状见 [reference](../reference/ent-01-templates.md)。

## 1. 概述

模板实例化合同：组件名→类型的装配、实例覆盖语义、出生效果时点。

## 2. 设计

- 装配：模板 components 逐名映射到引擎组件类型（组件注册表）；值经组件自身解析器物化。
- 覆盖：实例 Overrides 逐组件写入（同名组件整体替换该组件的值块）。
- 出生效果：实例化完成、组件就绪后施放；效果失败不回滚实体（报错并保留）。

## 3. 精确语义与不变量

- 模板表注册后冻结（随表体系规则）。
- 组件名不在注册表即失败，无宽容跳过。

## 4. 迁移与治理

现状即基线，无新增设计项。
