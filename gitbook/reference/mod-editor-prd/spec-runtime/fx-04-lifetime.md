# fx-04 runtime spec · 生命周期与时长

> 引擎实现任务书。第一性需求见 [fx-04 PRD](../prd/fx-04-lifetime.md)；现状见 [reference](../reference/fx-04-lifetime.md)。

## 1. 概述

三值寿命、duration 矩阵、周期惰性首拍与过期条件的执行合同。

## 2. 设计

- 内联条件保持：模板 Instant 且无周期才同帧内联，其余实体化。
- 周期首拍惰性初始化保持：仅 After/Infinite 且周期>0 参与；首拍偏移 = FNV 混合(RootId/模板/周期/源/目标/目标上下文) 对周期取模再加一；周期≤1 固定加一；未达 Committed 不参与；时钟取运行时当前值。
- 到期保持惰性计算：到时点=now+总时长；先判取消（走移除相位），再求值过期条件；过期与移除各自暂存展示事件；Infinite 不参与自然过期清理；Turn 时钟写法保持拒绝。

## 3. 精确语义与不变量

- 同一效果实例的首拍偏移与到时点确定性可复现；过期路径固定为到期→（取消 或 过期条件）→移除，不存在跳过移除相位的出口。

## 4. 迁移与治理

现状即基线，无迁移项。
