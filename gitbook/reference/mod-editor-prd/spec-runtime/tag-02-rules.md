# tag-02 runtime spec · Tag 规则

> 引擎实现任务书。第一性需求见 [tag-02 PRD](../prd/tag-02-rules.md)；现状见 [reference](../reference/tag-02-rules.md)。

## 1. 概述

规则引擎合同：编译为掩码快查、添加期事务、级联预算。

## 2. 设计

- 规则表编译：六类规则 → 六组掩码 + 标志（现状即此）。
- 事务：防环处理集 + 步数预算；连带目标自身过前置/互斥校验。
- 热替换：整表替换走安全帧（工作台通道），新身份仍重启级。

## 3. 精确语义与不变量

- 每类规则 ≤8、事务步数与处理集上限见事实页。
- 拒绝与回滚必须可观察（错误码/遥测）。

## 4. 迁移与治理

现状即基线，无新增设计项。
