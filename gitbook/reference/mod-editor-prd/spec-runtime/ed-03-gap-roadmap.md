# ed-03 runtime spec · 编辑器缺口与路线图

> 引擎实现任务书。第一性需求见 [ed-03 PRD](../prd/ed-03-gap-roadmap.md)；现状见 [reference](../reference/ed-03-gap-roadmap.md)。

## 1. 概述

四缺口的引擎侧处置：文档投影源（生产实现）、会话撤销栈、图编辑器承载、冷编辑流——按供血优先排序。

## 2. 设计

- **治理项 R5（路线图 #1，最高优先）**：文档投影源缺生产实现——ILiveSkillWorkbenchDocumentSource 的唯一实现是测试桩；ModEntry 启动时服务未注入即无文档，UI 目录树默认空。方向：实现生产投影源，从"配置文件 + 运行注册表"合成目录树文档（效果/技能/图/tag/属性五类，注册表枚举 + 配置出处回链），随快照发布；注入路径保持可选，缺源仍走空态而非报错。
- **会话撤销栈（#2）**：LiveEditSession 增补修订历史（操作级 undo/redo，Discard 清栈），快照暴露栈深；不可用清单动态摘除 undo/redo 项。
- **图编辑器（#3）**：引擎侧只需保证图文档（gr-04）与热替换（ed-02 图通道）往返无损——编辑器本体不在引擎侧立项。
- **冷编辑流（#4）**：与配置重载触发器（backlog T1）合并裁决——同属"改动如何进运行时"的接线问题，不建平行机制。
- 不可用清单生成保持动态（按绑定状态），LSWUI 码保持稳定。

## 3. 精确语义与不变量

- 不可用清单与绑定状态逐帧一致；清单内动作调用必得码。
- 投影源产出的目录树与注册表/配置零出入（同源合成，不做第二事实源）。
