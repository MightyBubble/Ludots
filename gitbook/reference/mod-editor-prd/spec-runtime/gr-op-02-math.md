# gr-op-02 runtime spec · 节点：数学与比较

> 引擎实现任务书。第一性需求见 [gr-op-02 PRD](../prd/gr-op-02-math.md)；现状见 [reference](../reference/gr-op-02-math.md)。

## 1. 概述

算术与判定族的描述符合同：双目求值、类型闭合、纯度边界。

## 2. 设计

- 双目/变形节点保持"读一次值线、写一次目的寄存器"的零分配执行形态。
- 引脚类型检查与描述符引脚列同源；Int/Float 无转换指令，混接在编译期拒绝。
- RandomFloat01 是本族唯一非纯节点：不做缓存、不做种子暴露；需要可复现随机的图不得依赖它。
- **治理项**：Int↔Float 换算节点空档——跨类型公式只能两端手工改写；若补节点，走新 op 注册而非隐式转换。

## 3. 精确语义与不变量

- 全族（除 RandomFloat01）对相同输入产出相同结果。
- SelectEntity 两分支实体都读，不做惰性求值。
- 除法语义跟随引擎浮点约定，不额外抛错。

## 4. 迁移与治理
