# ord-04 runtime spec · 订单黑板

> 引擎实现任务书。第一性需求见 [ord-04 PRD](../prd/ord-04-blackboard.md)；现状见 [reference](../reference/ord-04-blackboard.md)。

## 1. 概述
黑板合同：四缓冲容量与操作面、键注册纪律、存储目标三态、瞬时单闭环。

## 2. 设计
- 四缓冲操作面保持：Int/Entity/Spatial 有移除，Float 补齐移除接口消除不对称（O5）；实体三元组校验与空间点序列保持。
- **治理项**：`Cast.AbilityId`（113）为死键——定义注册但核心无读取方；接通消费方或从内置表移除（O6）。
- 存储目标保持三态（Entity/Point/HexCell）；Hex 缺世界点按六角坐标推导的规则保持并文档化。
- 瞬时单闭环保持：构造收集 → 提交存储目标 → 完成通知，三步在提交调用内完成。

## 3. 精确语义与不变量
- 键必须先注册后使用；内置键集合启动后不变。
- 实体+空间目标并存即提交失败（目标歧义），不静默择一。
- 各缓冲写入受容量守卫，拒绝可观察。

## 4. 迁移与治理
现状即基线；O5 接口补齐、O6 死键处置入 TODO，均不动数据格式。
