# fx-07 runtime spec · 相位监听器

> 引擎实现任务书。第一性需求见 [fx-07 PRD](../prd/fx-08-phase-listeners.md)；现状见 [reference](../reference/fx-08-phase-listeners.md)。

## 1. 概述

相位监听器的契约校验、宿主注册回放与按宿主清理合同。

## 2. 设计

- 契约保持：动作恰为三种合法组合；执行图⇔图 id>0、发布事件⇔事件标签>0；纯相位禁发布事件；loader 与执行计划双重校验不合并。
- 注册保持：模板编译写 0 宿主 id；运行期以宿主效果实体 id 注册、应用事务内延迟回放；移除阶段按宿主清理并压缩缓冲。
- 寿命约束保持：即时模板禁携监听器，运行期再遇持久监听需求同样抛跨帧寿命错。

## 3. 精确语义与不变量

- 监听器所有权唯一（一个监听器只属一个宿主效果实体）；收集与执行分离，序不变（fx-04）。

## 4. 迁移与治理

治理项 E6（todo/effect.md）：监听器收集处注释称"超预算截断丢弃"、实现是 dropped>0 即抛——统一为抛错语义并修正注释。
