# tag-03 runtime spec · Tag 变化与事件

> 引擎实现任务书。第一性需求见 [tag-03 PRD](../prd/tag-03-changed-events.md)；现状见 [reference](../reference/tag-03-changed-events.md)。

## 1. 概述

变化管道合同：脏收集 → 快照对比 → 触发 → 事件（双缓冲）→ 反应分发。

## 2. 设计

- 三类触发（加入/退出/层数变）与属性变化触发共用管道；事件负载带旧/新值。
- 事件总线双缓冲：发布写次缓冲，分拍换入；同帧等待者读当前缓冲（现状语义，保持）。
- 反应绑定：事件到达即按槽尝试激活，激活失败按技能失败语义上报。

## 3. 精确语义与不变量

- 一拍延迟恒定：本帧变化最早下一拍被跨帧消费者看见。
- 队列/缓冲容量见事实页；超限失败不丢弃。

## 4. 迁移与治理

现状即基线，无新增设计项。
