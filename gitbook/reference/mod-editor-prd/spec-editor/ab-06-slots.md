# ab-06 editor spec · 槽位系统

> 编辑器实现任务书。编辑器需求见 [ab-06 UXD](../uxd/ab-06-slots.md)；引擎侧见 [runtime spec](../spec-runtime/ab-06-slots.md)。

## 1. 概述

槽位视图实现：四层合并解析、覆盖栈、场景模拟、槽号引用索引。

## 2. 设计

- **合并解析**：编辑器侧调用引擎 AbilitySlotResolver（同源），输入为"模板 + 装备组合 + 形态场景"的编辑器沙盒状态。
- **覆盖栈**：按层缓冲逐层投影该槽条目与来源；胜者判定即解析序本身。
- **引用索引**：扫描输入映射、UI 档案、上下文组中的槽号引用，保存时增量更新。

## 3. 精确语义与不变量

- 场景模拟结果与运行期解析逐字一致（同一解析器）。
- 槽冲突胜者显示顺序 = 解析序，不另立规则。

## 4. 依赖接口与验收
- 消费：AbilitySlotResolver、模板/物品/形态配置读取、装备同步规则。
- 验收：构造四层各占同槽的用例，模拟结果与实测一致；引用索引发现全部槽号使用处。
