# gr-05 editor spec · 函数库 FuncLib

> 编辑器实现任务书。编辑器需求见 [gr-05 UXD](../uxd/gr-06-funclib.md)；引擎侧见 [runtime spec](../spec-runtime/gr-06-funclib.md)。

## 1. 概述

函数库面板实现：入库向导、纯度预检、被调索引。

## 2. 设计

- 纯度预检在编辑器侧运行同一可达性算法（引擎校验器导出），入库前即给路径级结果。
- 撞名判定同时查函数与动作两个目录（引擎命名空间规则同源）。
- 被调索引由全图 functionName 扫描维护，保存时增量更新。

## 3. 精确语义与不变量

- 编辑器纯度判定与装载校验结论一致；违规路径一致。
- 面板入库产物与手写 func_lib 条目等价（同 schema）。

## 4. 依赖接口与验收

- 消费：函数目录、图注册表、纯度校验器、动作目录（撞名）。
- 验收：构造含可达挂起/环/悬空引用三例，编辑器与引擎判定一致；入库往返无损。
