# rt-03 editor spec · 诊断与错误码

> 编辑器实现任务书。编辑器需求见 [rt-03 UXD](../uxd/rt-03-diagnostics.md)；引擎侧见 [runtime spec](../spec-runtime/rt-03-diagnostics.md)。

## 1. 概述

诊断中心实现：诊断流镜像、指标解释、错误码字典。

## 2. 设计

- **流镜像**：订阅 GasDiagnosticEventBuffer 服务投影，逐帧对齐帧号；暂停即停止消费并计数（同 tag-03 查看器模式）。
- **指标解释**：由枚举源生成的映射表（域/指标/默认容量/一句话解释）；缺号在生成期记录、渲染期跳过。
- **错误码字典**：正源为引擎错误码注册表（R2 交付物）；过渡期由构建脚本扫描 `GAS.*.ERR.*` 字面量生成静态字典，含字面量、抛出文件、出现次数；版本 diff 非空时在界面警示。
- **导出**：流快照导出为带错误码原文的清单（工单可直接粘贴）。

## 3. 精确语义与不变量

- 流序 = 引擎发布序；不做跨帧重排。
- 字典条目与扫描结果一一对应；未知码如实标注不猜。

## 4. 依赖接口与验收

- 消费：GasDiagnosticEventBuffer、System/Metric 枚举、错误码注册表（R2 后）或扫描产物（过渡期）。
- 验收：注入单根超限后流内出现对应域/指标条目；任一字面量检索 ≤ 1 跳到抛出点；缺号指标不产生空条目。
