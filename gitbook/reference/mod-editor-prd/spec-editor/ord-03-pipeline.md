# ord-03 editor spec · 订单流水

> 编辑器实现任务书。编辑器需求见 [ord-03 UXD](../uxd/ord-03-pipeline.md)；引擎侧见 [runtime spec](../spec-runtime/ord-03-pipeline.md)。

## 1. 概述
观测台实现：水位监控、事件流聚合、实体缓冲切面、原因码词典。

## 2. 设计
- **水位**：订阅各缓冲占用与容量快照，阈值渲染与事实页数值联动。
- **事件流**：合并准入结果区、拒绝区、终态账本三源，按代际对齐成统一时间线；过滤与导出在编辑器侧建索引。
- **实体切面**：按实体投影 OrderBuffer 的 active/pending/队列与排序键。
- **原因码词典**：以引擎枚举（提交结果、失败原因）为源生成，禁止编辑器自造文案表。

## 3. 精确语义与不变量
- 事件流条目与缓冲快照一一对应，无编辑器侧合成事件。
- 词典覆盖全部枚举值（编译期对账）。

## 4. 依赖接口与验收
- 消费：各缓冲占用/快照接口、终态账本读取、枚举定义。
- 验收：制造一次队满拒绝，观测台 3 次交互内定位原因码与命中规则。
