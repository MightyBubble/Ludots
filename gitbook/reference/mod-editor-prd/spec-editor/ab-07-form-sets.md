# ab-07 editor spec · 形态路由

> 编辑器实现任务书。编辑器需求见 [ab-07 UXD](../uxd/ab-07-form-sets.md)；引擎侧见 [runtime spec](../spec-runtime/ab-07-form-sets.md)。

## 1. 概述

形态路由编辑器实现：路由卡、八槽对照盘、匹配预览、同分与冲突先拦。

## 2. 设计

- **路由卡视图模型**：routes 投影；条件选择器与 ab-05 tag 门控件复用同组件。
- **对照盘**：slotOverrides 覆盖在单位底座槽（ab-06 视图共享数据源）之上；拖入即建 override，编辑器侧先拦重复槽号与未注册 id。
- **匹配预览**：调用与 MatchesRoute 同源的判定件；胜者优先级判定同引擎（严格更大才替换）。
- **同分检测**：静态扫描可同时匹配且 priority 相等的路由对，先于运行给出提示。

## 3. 精确语义与不变量

- 编辑器可产出的路由形状 = 加载器接受的形状（同源校验）。
- 预览胜者与运行期每帧路由结果逐槽一致。

## 4. 依赖接口与验收
- 消费：路由表加载器校验、MatchesRoute 判定件、底座槽视图（ab-06）。
- 验收：重复槽号/越界/悬空引用在编辑器被拦截；双形态切换预览与实测一致。
