# ord-01 editor spec · 订单类型

> 编辑器实现任务书。编辑器需求见 [ord-01 UXD](../uxd/ord-01-types.md)；引擎侧见 [runtime spec](../spec-runtime/ord-01-types.md)。

## 1. 概述
订单类型面板实现：编号占用视图、参数表单、落点联动、底线检查。

## 2. 设计
- **编号控件**：双模式输入；整数模式查重与范围校验、语义模式本地重放"字典序取最小空闲"分配算法，与加载器同源。
- **落点联动**：选择器数据源为 orderBlackboardKeys 注册视图；"＋建键"写同文件键段，避免跨文件时序。
- **底线检查**：读游戏配置常量与类型注册表做差集，作为保存阻断条件。

## 3. 精确语义与不变量
- 编号预览与加载器分配结果逐字一致（同源算法）。
- 表单可产生的类型形状 = 加载器接受的形状（同源校验）。

## 4. 依赖接口与验收
- 消费：类型/键注册表枚举、加载器校验规则、常量表。
- 验收：语义编号预览与启动实际分配一致；缺必备类型时保存被阻断；被规则引用的类型删除被拒。
