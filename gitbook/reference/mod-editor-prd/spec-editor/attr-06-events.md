# attr-06 editor spec · 属性事件

> 编辑器实现任务书。编辑器需求见 [attr-06 UXD](../uxd/attr-06-events.md)；引擎侧见 [runtime spec](../spec-runtime/attr-06-events.md)。

## 1. 概述

属性事件面板：映射清单只读透视与变化诊断视图。

## 2. 设计

- **投影**：映射注册表（现状恒空）→ 只读清单；运行时表现变化位与属性脏位 → 双列诊断。
- **数据源**：会话查询接口（变化位组件、快照组件）；事件 tag 枚举为新增映射预留。
- **同源不变量**：诊断判定（有无变化位）与表现投影消费判定同源；两面对比文案与 attr-06 配置说明对比表同文。

## 3. 精确语义与不变量

- 新增映射控件在玩法面入口（A13）落地前禁用并说明原因。
- 首帧伪基线（无快照 Old=0）在诊断中显式标注（A5 联动）。

## 4. 依赖接口与验收

- 消费：表现变化位查询、属性快照查询、事件映射注册表枚举、事件 tag 枚举。
- 验收：任一属性写入后一帧内，诊断能同时回答两面状态；映射清单与注册表逐条一致。
