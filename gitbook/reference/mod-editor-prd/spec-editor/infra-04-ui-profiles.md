# infra-04 editor spec · 界面档案

> 编辑器实现任务书。编辑器需求见 [infra-04 UXD](../uxd/infra-04-ui-profiles.md)；引擎侧见 [runtime spec](../spec-runtime/infra-04-ui-profiles.md)。

## 1. 概述

HUD 档案编辑器实现：三表统一编辑、预览画布、封闭表达式选择。

## 2. 设计

- **档案模型**：三表投影；聚合条目与面板条目两类编辑器；新建一律落本 mod。
- **表达式选择**：groupBy 数据源为引擎内建表达式清单的只读投影（封闭下拉）。
- **预览画布**：编辑器侧渲染面板布局；技能槽图标来自 GAS 注册表 + 表现资产（pres-02）。
- **热键捕获**：槽位热键用按键捕获控件，写入档案条目。

## 3. 精确语义与不变量

- 预览分组结果与引擎聚合器对同样输入的输出一致。
- 能力引用下拉与 GAS 能力注册表实时一致。

## 4. 依赖接口与验收

- 消费：三表注册表投影、内建表达式清单、能力注册表、表现资产索引。
- 验收：新建甲板档案产物通过引擎加载；预览与运行期面板一致。
