# cfg-02 editor spec · 虚拟文件系统

> 编辑器实现任务书。编辑器需求见 [cfg-02 UXD](../uxd/cfg-02-vfs.md)；引擎侧见 [runtime spec](../spec-runtime/cfg-02-vfs.md)；第一性需求见 [cfg-02 PRD](../prd/cfg-02-vfs.md)。

## 1. 概述

编辑器侧的地址服务：统一解析通道、挂载点树投影、地址输入控件。目标是与引擎看到同一份文件，不建平行寻址。

## 2. 设计

- **解析通道单例**：一切地址→物理路径换算消费引擎文件系统的解析接口，编辑器不自建映射表。
- **挂载树投影**：按当前工作区的已挂载点枚举目录树，作为资产浏览器与路径补全的数据源；挂载变化（打开/关闭 mod）时增量刷新。
- **地址控件**：挂载点前缀 + 相对路径两段输入；前缀来自投影，路径段实时校验（存在性、越界）。

## 3. 精确语义与不变量

- 编辑器内任何磁盘访问都经解析通道——不允许拼接物理路径的旁路。
- 地址校验结果与引擎加载结果同源（同一挂载状态）。

## 4. 依赖接口与验收

- 消费：挂载/卸载通知、枚举、解析接口。
- 验收：移动 mod 目录后浏览器与引用不失效；越界地址在输入时即红；拖拽生成的地址可被引擎直接加载。
