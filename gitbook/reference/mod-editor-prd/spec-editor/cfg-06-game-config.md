# cfg-06 editor spec · 游戏配置

> 编辑器实现任务书。编辑器需求见 [cfg-06 UXD](../uxd/cfg-06-game-config.md)；引擎侧见 [runtime spec](../spec-runtime/cfg-06-game-config.md)；第一性需求见 [cfg-06 PRD](../prd/cfg-06-game-config.md)。

## 1. 概述

项目设置页实现：字段元数据驱动表单、容量约束前置校验、最小覆盖保存。

## 2. 设计

- **字段元数据单一来源**：分组/类型/默认/约束（含交叉约束表达式）由元数据生成，与运行配置对象同步演进。
- **约束校验复用**：容量的正数/有限/交叉校验调用引擎同一校验器，表单内即时。
- **最小覆盖保存**：只序列化用户改过的字段路径；两份骨架（默认引用 + 项目覆盖）由向导生成。

## 3. 精确语义与不变量

- 表单校验与启动校验同源；预填默认值来自引擎基线解析结果。
- 保存的最小覆盖与引擎深合并结果等价于表单当前态。

## 4. 依赖接口与验收

- 消费：运行配置对象与校验器、引擎基线文件。
- 验收：随机改字段循环保存后，启动合并结果与表单态一致；交叉约束冲突在表单内报出且与启动报错同文案。
