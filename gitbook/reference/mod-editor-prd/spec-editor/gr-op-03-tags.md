# gr-op-03 editor spec · 节点：标签

> 编辑器实现任务书。编辑器需求见 [gr-op-03 UXD](../uxd/gr-op-03-tags.md)；引擎侧见 [runtime spec](../spec-runtime/gr-op-03-tags.md)。

## 1. 概述

单节点族的目录条目与 tag 符号选择器；为 G8 重立节点预留通用表绑定通道。

## 2. 设计

- **目录条目**：描述符表扫描，本族当前一行；已删 op 名维护在"拒绝清单"，手输即时报"已随 ADR #876 删除"。
- **tag 选择器**：数据源 = tag 注册表投影 + 通用用户表；专表不进候选（G8 重立时的硬约束）。
- **选择器写回**：只写节点 `tag` 字符串字段，不做 id 内联（id 由编译期解析）。

## 3. 精确语义与不变量

- 选择器候选集合与 tag 注册表投影一致；不缓存过期快照。
- 拒绝清单与描述符表互补：描述符表没有且清单在列的 op 名，报"已删除"而非"未知"。

## 4. 依赖接口与验收

- 消费：描述符表、tag 注册表投影、通用用户表枚举。
- 验收：手输 `SelectTagInMask` 得到已删除提示；选中的 tag 名编译期通过符号解析。
