# ord-04 editor spec · 订单黑板

> 编辑器实现任务书。编辑器需求见 [ord-04 UXD](../uxd/ord-04-blackboard.md)；引擎侧见 [runtime spec](../spec-runtime/ord-04-blackboard.md)。

## 1. 概述
键总账实现：键注册视图、读写方索引、运行期窥视、五键组表单。

## 2. 设计
- **键清单**：键注册表投影；内置键标记来源只读；自定义键写同文件键段。
- **读写方索引**：全配置扫描（类型三键组、五键组、校验图引用）+ 代码消费点清单（随引擎版本维护），保存时增量更新。
- **窥视**：会话期订阅黑板快照接口，按实体分组渲染，不做写入。

## 3. 精确语义与不变量
- 索引集合与加载器解析结果一致（同源扫描）。
- 内置键集合与引擎常量同源，禁止编辑器侧手抄清单。

## 4. 依赖接口与验收
- 消费：键注册表、四缓冲快照、类型/图配置解析结果。
- 验收：新建键保存后启动即注册；孤儿键在总账可见；窥视值与运行调试输出一致。
