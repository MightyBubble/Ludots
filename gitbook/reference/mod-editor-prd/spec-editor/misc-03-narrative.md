# misc-03 editor spec · 叙事与任务

> 编辑器实现任务书。编辑器需求见 [misc-03 UXD](../uxd/misc-03-narrative.md)；引擎侧见 [runtime spec](../spec-runtime/misc-03-narrative.md)。

## 1. 概述

剧情编辑器实现：对话节点画布、过场步骤带、任务阶段列、变量面板与试播。

## 2. 设计

- **画布**：节点/边视图模型（对话=节点、选项/nextNodeId=边）；序列化产出 dialogues 结构；悬空检测编辑期先验。
- **参数化表单**：动作/条件 kind 驱动动态参数（schema 来自引擎枚举投影）；变量/相机/任务/台词/过场引用全下拉封闭。
- **步骤带**：过场时间线控件；durationSeconds 默认 0.75 预填。
- **试播**：编辑器侧推进模拟器（条件求值 + 动作应用到沙盒变量存储），与引擎枚举同源。

## 3. 精确语义与不变量

- 画布序列化与手写 JSON 等价；内插变量在试播用沙盒值渲染。
- 引用下拉与各注册表实时一致。

## 4. 依赖接口与验收

- 消费：四表投影、条件/动作枚举、变量存储、相机/属性/信号注册表。
- 验收：一段三节点带分支对话产物通过启动校验；试播推进序列与运行期一致。
