# gr-05 editor spec · 执行模型

> 编辑器实现任务书。编辑器需求见 [gr-05 UXD](../uxd/gr-05-execution.md)；引擎侧见 [runtime spec](../spec-runtime/gr-05-execution.md)。

## 1. 概述

图调试视图：游标快照消费、预算与挂起可视化。

## 2. 设计

- 调试会话调用引擎切片入口逐片驱动，游标/步数/调用栈直接取执行快照，不复制状态。
- 入口选择器映射两种引擎入口；错误呈现透传引擎原文。
- 宿主政策表投影用于"可挂宿主"提示（gr-07 同源）。

## 3. 精确语义与不变量

- 调试器步数与宿主内执行步数同源同值。
- 调试视图不得改变执行语义（只读驱动）。

## 4. 依赖接口与验收

- 消费：切片执行入口、游标快照接口、宿主政策表、上限常量投影。
- 验收：挂起循环逐帧续跑可视化正确；预算耗尽呈现与引擎异常一致。
