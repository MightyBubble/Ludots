# attr-02 editor spec · 修改器

> 编辑器实现任务书。编辑器需求见 [attr-02 UXD](../uxd/attr-02-modifiers.md)；引擎侧见 [runtime spec](../spec-runtime/attr-02-modifiers.md)。

## 1. 概述

效果表单内的修改器行编辑器：属性选择、运算切换、数值热调。

## 2. 设计

- **投影**：效果模板 modifiers 块与行列表双向映射；落点徽标（即时/聚合）由 presetType 推导，判定与引擎同源。
- **数据源**：属性下拉取注册表枚举（attr-01 面板同源）；容量上限读事实页。
- **保存管线**：修改器数值与增删行走效果表热替换，下次施放生效。

## 3. 精确语义与不变量

- 未注册属性、超容量在编辑器侧即拦截，判定与加载器同源；落盘前必过校验。
- 行顺序即声明序，保存往返不重排。

## 4. 依赖接口与验收

- 消费：效果条目模型、属性注册表枚举、事实页容量、工作台热替换管线。
- 验收：造价数值热调后下次施放生效；超上限条目保存被拒并定位到行。
