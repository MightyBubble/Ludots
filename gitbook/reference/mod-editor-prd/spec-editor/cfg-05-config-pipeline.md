# cfg-05 editor spec · 合并管线

> 编辑器实现任务书。编辑器需求见 [cfg-05 UXD](../uxd/cfg-05-config-pipeline.md)；引擎侧见 [runtime spec](../spec-runtime/cfg-05-config-pipeline.md)；第一性需求见 [cfg-05 PRD](../prd/cfg-05-config-pipeline.md)。

## 1. 概述

合并预览与覆盖审计的实现。原则：预览数据来自引擎合并产物与冲突报告，编辑器不实现第二套合并。

## 2. 设计

- **预览数据源**：片段链与 id 级赢家消费冲突报告；字段级胜出消费字段级溯源（依赖 runtime spec 的字段级冲突溯源任务）。
- **顺序呈现**：最终生效顺序取自启动计划，逐 mod 标注。
- **覆盖审计**：给定（上游 mod，下游集合），输出下游覆盖点清单（条目、字段、值差异）；升级前触发。
- **两义删除写回**：物理删除作用于本 mod 文件行；屏蔽生成规范布尔删除标记的分片条目。

## 3. 精确语义与不变量

- 预览裁决与引擎合并同源——预览显示的赢家必须等于启动后注册表内容。
- 字段级溯源缺失时，预览降级为 id 级并明示，不猜测字段归属。

## 4. 依赖接口与验收

- 消费：冲突报告（片段/赢家/删除）、字段级溯源（待交付）、计划顺序。
- 验收：预览赢家与启动注册表逐条一致；审计输出与手动 diff 一致；屏蔽写回可被引擎接受。
