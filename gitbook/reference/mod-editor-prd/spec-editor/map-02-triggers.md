# map-02 editor spec · 地图触发器

> 编辑器实现任务书。编辑器需求见 [map-02 UXD](../uxd/map-02-triggers.md)；引擎侧见 [runtime spec](../spec-runtime/map-02-triggers.md)。

## 1. 概述

触发器页实现：类型扫描、勾选写回、并集呈现。

## 2. 设计

- **类型扫描**：分析工作区已装载程序集，列出继承触发器基类的类型（含来源 mod、事件签名）；扫描结果缓存随构建刷新。
- **写回**：勾选生成 TriggerTypes 条目写入本 mod 地图片段（规范化）。
- **并集呈现**：消费地图合并结果标注逐项来源。

## 3. 精确语义与不变量

- 扫描类型集与引擎可解析类型集同源（同一程序集装载状态）。
- 类型缺失判定与引擎解析失败判定一致。

## 4. 依赖接口与验收

- 消费：程序集装载状态、触发器基类元数据、地图合并器。
- 验收：勾选保存后试玩地图，触发器注册数与并集提示一致；移除代码类后编辑器红条先于启动失败出现。
