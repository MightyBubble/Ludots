# ab-09 editor spec · Targeting 与组合命令

> 编辑器实现任务书。编辑器需求见 [ab-09 UXD](../uxd/ab-09-targeting.md)；引擎侧见 [runtime spec](../spec-runtime/ab-09-targeting.md)。

## 1. 概述

射程面板与沙盘实现：表单校验、射程圈渲染、走近路径同源预演。

## 2. 设计

- **表单**：两必填字段 + 自动目标联动标注；impactEffect 选择器与效果编辑器双向跳转。
- **沙盘**：射程圈按地图比例尺渲染；锚点与路径线调用与计划器同源的锚点求解（方向×距离差），不另立公式。
- **预演状态**：排队开关切换原点（当前/预计位置），判定复用同一求解。

## 3. 精确语义与不变量

- 沙盘锚点/判定与运行期计划器逐点一致（同一锚点求解）。
- 表单可产出的 targeting 形状 = 加载器接受的形状。

## 4. 依赖接口与验收
- 消费：targeting 编译校验、锚点求解接口、提交模式枚举。
- 验收：三档目标位置（圈内/边缘/圈外）预演与实测一致；旧字段粘贴被拦截。
