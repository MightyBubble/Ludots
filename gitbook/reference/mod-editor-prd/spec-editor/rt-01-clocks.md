# rt-01 editor spec · 时钟系统

> 编辑器实现任务书。编辑器需求见 [rt-01 UXD](../uxd/rt-01-clocks.md)；引擎侧见 [runtime spec](../spec-runtime/rt-01-clocks.md)。

## 1. 概述

时钟面板实现：三域读数投影、步进挡位控制、实体变速命令。

## 2. 设计

- **域状态**：订阅运行实例时钟快照与步进策略版本，逐 tick 镜像；固定 tick 毫秒由 FixedHz 换算（同引擎公式）。
- **挡位控制**：mode/scale 走引擎运行时策略入口；步进间隔改动标注重启级并生成配置写回计划（走保存管线，不直改运行时）。
- **实体变速**：复用即时属性命令通道写 time.scale_permille；无该属性的实体禁用控件并说明。
- **单步**：Manual 态请求一步，同步高亮本次步进产生的事件/效果条目（与 ed-01 效果链时间线联动）。

## 3. 精确语义与不变量

- 读数与引擎 tick 同源同帧；挡位切换后下一 tick 生效。
- 变速值校验与引擎五连校验同语义——编辑器先拦（同规则），引擎失败原文透传。

## 4. 依赖接口与验收

- 消费：时钟快照、步进策略读写入口、即时属性命令通道。
- 验收：Manual 单步恰产生一步与一条回合事件；非法 scale_permille 被拦且原因与引擎一致；未连接态不误报 tick。
