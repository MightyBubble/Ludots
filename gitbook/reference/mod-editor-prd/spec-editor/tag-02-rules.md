# tag-02 editor spec · Tag 规则

> 编辑器实现任务书。编辑器需求见 [tag-02 UXD](../uxd/tag-02-rules.md)；引擎侧见 [runtime spec](../spec-runtime/tag-02-rules.md)。

## 1. 概述

规则编辑器实现：六槽卡片、连锁图、模拟器。

## 2. 设计

- **六槽卡片**：写规则表分片（一主体一文件）；槽值选择器数据源为 tag 注册表。
- **连锁图**：规则间引用关系图（主体→attached/removed/disabled 目标），环检测复用引擎事务判定。
- **模拟器**：调用运行时事务的干跑接口（无副作用），结果与拒绝原因同源。

## 3. 精确语义与不变量

- 卡片可产生的规则形状 = 加载器接受的形状（同源校验）。
- 模拟器判定与引擎实际事务逐字一致。

## 4. 依赖接口与验收

- 消费：规则表加载器、tag 注册表、事务干跑接口。
- 验收：六槽配置保存后启动即生效；模拟器与实测一致；环在图上先于运行报错出现。
