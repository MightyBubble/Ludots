# gr-03 editor spec · 六种 Kind

> 编辑器实现任务书。编辑器需求见 [gr-03 UXD](../uxd/gr-03-kinds.md)；引擎侧见 [runtime spec](../spec-runtime/gr-03-kinds.md)。

## 1. 概述

kind 决策向导与白名单过滤：编辑器侧节点可见性判定与引擎策略同源。

## 2. 设计

- 白名单过滤直接消费引擎策略表投影（kind × op → 允许/拒绝+原因），不维护第二份规则。
- kind 锁定体现为视图模型字段只读；"改 kind"引导走新建图 + 挂点重挂。
- 保留槽（E0/E1/E2、各 kind 返回槽）在 pinRegister 编辑器里显式排除。

## 3. 精确语义与不变量

- 面板可见性、粘贴校验、导入校验三路用同一策略表，判定结果一致。
- 编辑器拒掉的节点组合，引擎装载同样拒绝；反之亦然。

## 4. 依赖接口与验收

- 消费：kind 策略表投影、返回槽/保留槽常量、图名注册表。
- 验收：六 kind 各建一图，越权路径三路全拦；挂点拖拽的 kind 校验与引擎挂接一致。
