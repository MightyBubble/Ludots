# ord-02 editor spec · 订单规则与打断

> 编辑器实现任务书。编辑器需求见 [ord-02 UXD](../uxd/ord-02-rules.md)；引擎侧见 [runtime spec](../spec-runtime/ord-02-rules.md)。

## 1. 概述
规则编辑器实现：双表卡、命令关系图、裁决模拟器。

## 2. 设计
- **双表卡**：写 `orderRules` 段（与类型表同文件）；选择器数据源为类型注册表，容量与去重同源校验。
- **关系图**：双表边构建有向图；提供"谁打断我"反向视图；互打断环只提示不阻断。
- **模拟器**：调用提交裁决干跑接口（无副作用），输出结果码与最终去向，判定与引擎同源。

## 3. 精确语义与不变量
- 卡片可产生的规则形状 = 加载器接受的形状。
- 模拟器裁决与引擎提交路径逐字一致。

## 4. 依赖接口与验收
- 消费：规则表加载器、类型注册表、裁决干跑接口。
- 验收：双表配置保存后启动即生效；模拟器与实测一致；悬空引用在保存前被拦截。
