# gr-03 editor spec · 编译与校验

> 编辑器实现任务书。编辑器需求见 [gr-03 UXD](../uxd/gr-04-compilation.md)；引擎侧见 [runtime spec](../spec-runtime/gr-04-compilation.md)。

## 1. 概述

诊断面板实现：同源预编译、码义字典、画布定位联动。

## 2. 设计

- 预编译直接调用引擎编译器（只编译不注册），诊断流原样消费，不自建规则。
- 码义字典与修复建议由诊断码字典投影生成，随引擎字典演进。
- 定位映射：诊断携带的图/节点/边 id 直接驱动画布选中与相机跳转。

## 3. 精确语义与不变量

- 编辑器诊断与引擎装载诊断逐码逐条一致（同一编译器、同一文档）。
- G3 约定落地前，缺省 value 边的 HaltReturnInt 编辑器给软提示（非错误）。

## 4. 依赖接口与验收

- 消费：编译器"只编译"入口、诊断码字典投影、糖 SSOT。
- 验收：对 21 码各构造一例，编辑器全部呈现并定位；多错文档一次列全。
