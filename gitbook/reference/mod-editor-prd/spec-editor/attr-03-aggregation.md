# attr-03 editor spec · 聚合管线

> 编辑器实现任务书。编辑器需求见 [attr-03 UXD](../uxd/attr-03-aggregation.md)；引擎侧见 [runtime spec](../spec-runtime/attr-03-aggregation.md)。

## 1. 概述

聚合透视面板：运行时会话的重算过程可视化与数值验证。

## 2. 设计

- **投影**：效果容器+属性缓冲的运行时组件投影为叠加栈与数值瀑布；瀑布按重算步序（复位→叠加→派生）逐条模拟。
- **数据源**：工作台会话的实体查询接口；效果条目反查效果表模板。
- **同源不变量**：叠加资格判定（存活+提交+未取消+聚合标志）与引擎逐条同判，瀑布序=存活序。

## 3. 精确语义与不变量

- 假想剔除只在编辑器模拟层，不触碰运行时状态。
- Cap/Current 双轨展示与缓冲语义一致：聚合写动 Cap、直改动 Current。

## 4. 依赖接口与验收

- 消费：会话实体查询（效果容器、属性缓冲、派生绑定）、效果表模板解析。
- 验收：瀑布值与引擎同帧输出一致；未提交条目不计入。
