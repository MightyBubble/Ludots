# fx-18 editor spec · 视野揭示

> 编辑器实现任务书。编辑器需求见 [fx-18 UXD](../uxd/fx-19-vision.md)；引擎侧见 [runtime spec](../spec-runtime/fx-19-vision.md)。

## 1. 概述

效果表单的视野揭示通用区块：注册表选择、层上限约束、现状可执行性警示。

## 2. 设计

- **区块复用**：作为可挂任意 preset 的通用区块组件，随生命周期联动校验（After 需正周期）。
- **选择器**：scope 与 layers 分别绑定作用域注册表与迷雾层注册表；层上限取运行时常量（与事实页同源）。
- **可执行性警示**：消费计划编译器的认证集合（同源判定）出示常驻警示，不硬拦保存。

## 3. 精确语义与不变量

- 校验集合与 loader 一致（radius 正、层 1..上限、强度 0..255、TTL 非负）。
- 警示判定与启动期 fail-closed 判定同源，不手抄状态。

## 4. 依赖接口与验收

- 消费：作用域注册表、迷雾层注册表、计划编译认证结果、保存管线。
- 验收：勾选第上限+1 层被禁用；scope 悬空阻保存；警示条在启用区块即出现。
