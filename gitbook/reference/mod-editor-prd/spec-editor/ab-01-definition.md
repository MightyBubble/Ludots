# ab-01 editor spec · 技能定义骨架

> 编辑器实现任务书。编辑器需求见 [ab-01 UXD](../uxd/ab-01-definition.md)；引擎侧见 [runtime spec](../spec-runtime/ab-01-definition.md)。

## 1. 概述

技能编辑器首页实现：清单、块卡表单、同源校验条。

## 2. 设计

- **清单与视图模型**：分片合并视图投影 abilities.json；重复 id 检测与 mod 来源标注在保存时增量更新。
- **块卡表单**：每顶层块一卡，未声明块折叠；引用选择器数据源为效果模板/图/属性/进度需求注册表与文案目录。
- **校验**：保存前跑与加载器同源的编译校验（含旧字段拦截与 token 校验），错误映射到字段路径。

## 3. 精确语义与不变量

- 表单可产出的技能形状 = 加载器接受的形状（同源校验，不另立规则）。
- 引用选择器只列已注册名，与注册表枚举一致。

## 4. 依赖接口与验收
- 消费：AbilityExecLoader 编译入口（干跑）、各注册表枚举、文案目录查询。
- 验收：含旧字段的历史 JSON 粘贴被拦截并指明替代写法；保存的条目启动编译零错误。
