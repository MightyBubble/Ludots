# gr-op-02 editor spec · 节点：数学与比较

> 编辑器实现任务书。编辑器需求见 [gr-op-02 UXD](../uxd/gr-op-02-math.md)；引擎侧见 [runtime spec](../spec-runtime/gr-op-02-math.md)。

## 1. 概述

数学分组目录与引脚类型约束从描述符表生成，连线合法性用值类型表在线判定。

## 2. 设计

- **目录条目**：描述符表扫描，子分组（四则/极值/变形/比较/整数/选择）由编辑器侧的分组映射维护，映射键为 op 名。
- **引脚渲染**：输入引脚 = 描述符引脚列；类型徽标 = 该引脚在值类型表中的列类型。
- **连线判定**：拖线落点即时查"源输出类型 + 目标引脚类型"相等性；不等则弹回。
- **公式摘要**：对纯算术链做局部表达式折叠显示（只读投影，不写回图）。

## 3. 精确语义与不变量

- 连线判定与编译器类型检查同一张值类型表，编辑器通过的连线编译不再报类型错。
- 公式摘要只是展示，不改变节点存储形态。

## 4. 依赖接口与验收

- 消费：描述符表、值类型表、纯度标记。
- 验收：Float 接 Int 引脚当场弹回；Query 图中除 CompareEqEntity 外置灰；AddFloat 链摘要与手算一致。
