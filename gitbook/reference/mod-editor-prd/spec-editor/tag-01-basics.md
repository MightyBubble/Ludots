# tag-01 editor spec · Tag 表示与状态

> 编辑器实现任务书。编辑器需求见 [tag-01 UXD](../uxd/tag-01-basics.md)；引擎侧见 [runtime spec](../spec-runtime/tag-01-basics.md)。

## 1. 概述

tag 总账与运行检视的实现：全工程扫描索引 + 运行时实体面板。

## 2. 设计

- **扫描索引**：遍历工作区配置构建 授予/消费 交叉索引；保存时增量更新。
- **运行检视**：连接运行实例时读实体 tag 状态（在场/层数/定时/有效），离线隐藏。
- **用量计数**：与启动注册同源（同一扫描规则）。

## 3. 精确语义与不变量

- 索引的注册集合与引擎启动注册一致；孤儿/撞名判定同源。

## 4. 依赖接口与验收

- 消费：配置扫描（各表 schema）、运行时 tag 查询接口。
- 验收：授予改动后索引即时反映；运行检视层数与引擎一致。
