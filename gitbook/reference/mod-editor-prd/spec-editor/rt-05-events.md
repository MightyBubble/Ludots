# rt-05 editor spec · 事件总线与帧延迟

> 编辑器实现任务书。编辑器需求见 [rt-05 UXD](../uxd/rt-05-events.md)；引擎侧见 [runtime spec](../spec-runtime/rt-05-events.md)。

## 1. 概述

事件时序查看器实现：双缓冲泳道投影、消费去向标注、响应链遥测流。

## 2. 设计

- **泳道投影**：逐拍镜像当前/次缓冲与交换事件；条目为事件 tag、实体、来源系统。
- **消费去向**：订阅反应/技能执行/延迟触发的消费结果（与 tag-03 查看器同源通道），按事件 id 关联。
- **遥测流**：消费响应链遥测缓冲（六事件+结果枚举），按窗口 id 聚合为一条时间线；丢弃计数常显。
- **语义标注**：主道溢出错误与遥测丢弃计数在 UI 分色（红/黄）并各带一句话语义。

## 3. 精确语义与不变量

- 泳道推进与引擎组序同源；延迟渲染为恰好一拍，不引入编辑器侧缓冲延迟。
- 遥测丢弃计数与引擎计数一致（同源投影，不清零不重算）。

## 4. 依赖接口与验收

- 消费：事件总线只读视图、交换时机通知、消费结果通道、响应链遥测缓冲。
- 验收：受击→反击链路在泳道呈"写入拍→交换→消费拍"三段且恰一拍；遥测窗口六事件完整成链；两种溢出语义分色不混。
