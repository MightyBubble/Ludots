# rt-02 editor spec · 预算与容量

> 编辑器实现任务书。编辑器需求见 [rt-02 UXD](../uxd/rt-02-budgets.md)；引擎侧见 [runtime spec](../spec-runtime/rt-02-budgets.md)。

## 1. 概述

预算监视器实现：丢弃计数镜像、单根用量 top-N、订单水位与容量读数。

## 2. 设计

- **计数镜像**：订阅诊断通道（GasDiagnosticEventBuffer 投影），按 System×Metric 归位九丢弃与水位指标；每帧对齐帧号。
- **单根用量**：消费引擎侧单根记账表快照接口（待引擎暴露——列为本篇依赖缺口）；无快照时该区隐藏而非估算。
- **容量读数**：读 game.json（事实页同源）+ 引擎常量表；单根上限与表容量分区渲染并带一句话职责说明（R1 同源）。
- **趋势**：连续非零丢弃做帧间聚合（编辑器侧状态，不回写引擎）。

## 3. 精确语义与不变量

- 九类计数与引擎发布序一致；帧号对齐，不跨帧平均。
- 单根上限/表容量两个数字在模型层就是两个字段，禁止合并显示。

## 4. 依赖接口与验收

- 消费：诊断事件通道、gasRuntimeCapacity 配置、单根记账表快照接口（新增依赖）。
- 验收：构造连锁召唤使单根达上限——监视器显示拒绝计数与 top-N 根；水位回退注入后红条可见；两数字渲染不混淆。
