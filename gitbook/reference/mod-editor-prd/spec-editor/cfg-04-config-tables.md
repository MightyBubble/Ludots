# cfg-04 editor spec · 配置表体系

> 编辑器实现任务书。编辑器需求见 [cfg-04 UXD](../uxd/cfg-04-config-tables.md)；引擎侧见 [runtime spec](../spec-runtime/cfg-04-config-tables.md)；第一性需求见 [cfg-04 PRD](../prd/cfg-04-config-tables.md)。

## 1. 概述

表清单投影、分片保存、引用校验、审批流。原则：表能力地图与引擎目录同源，表单 schema 由加载器合同生成。

## 2. 设计

- **表清单投影**：消费配置目录（含分片字段）与逐表条目计数；挂载点变化时刷新。
- **分片保存**：新建/修改条目 upsert 到对应分片文件（文件名 = id 尾段规范化）；主文件只读呈现。
- **引用校验服务**：以加载顺序链为知识来源，校验跨表引用的存在性与方向合法性；编辑期即时。
- **审批流**：新表三件套（登记行 + 挂接声明 + 策略）生成审批件，落盘前走治理确认。

## 3. 精确语义与不变量

- 投影与引擎目录同源：不允许编辑器维护第二份表清单。
- 分片写回的条目必须能被引擎加载器原样接受（同一严格校验）。
- 引用校验的方向判定与引擎加载链一致。

## 4. 依赖接口与验收

- 消费：目录加载结果、逐表注册表枚举、严格反序列化选项。
- 验收：新建条目落分片后引擎启动即可见；越权引用（前表引后表）编辑期报出；审批产物三件齐备。
