# ed-03 editor spec · 编辑器缺口与路线图

> 编辑器实现任务书。编辑器需求见 [ed-03 UXD](../uxd/ed-03-gap-roadmap.md)；引擎侧见 [runtime spec](../spec-runtime/ed-03-gap-roadmap.md)。

## 1. 概述

能力状态面板与空态系统实现：不可用清单消费、占位渲染、解锁指引。

## 2. 设计

- **清单消费**：UnavailableActions 直渲染快照字段（id/名称/原因），不前端增删；LSWUI 码透传可复制。
- **空态系统**：目录树空态（文档投影源未注入）与 Inspector"尚未接入"区为两个独立空态组件，文案与路线图序号同源常量。
- **解锁指引**：码→步骤映射表随构建生成（与运行时原因字段同源）；码未知时显示原文并引导上报。
- **路线图条**：静态四步（投影源/撤销重做/图编辑器/冷编辑流），完成态由清单推导（对应项消失即打勾）。

## 3. 精确语义与不变量

- 灰按钮的禁用态与后端调用拒绝一一对应——前端不禁而引擎拒（或反之）即为缺陷。
- 空态不渲染任何占位假数据（空目录 ≠ 假目录）。

## 4. 依赖接口与验收

- 消费：快照 UnavailableActions 字段、LSWUI0001-0009 码表、文档投影源注入状态。
- 验收：未绑定管线时预检/应用灰显且点击得码；挂载保存目标后清单实时摘项；目录树空态文案正确且无假节点；路线图完成态与清单一致。
