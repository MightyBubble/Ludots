# fx-08 · 八相位执行

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/fx-05-phases.md)；编辑器需求见 [UXD](../uxd/fx-05-phases.md)；引擎实现见 [runtime spec](../spec-runtime/fx-05-phases.md)；editor spec 见 [editor spec](../spec-editor/fx-05-phases.md)；现状见 [reference](../reference/fx-05-phases.md)。

## 1. 定位

八相位是效果的行为节拍：从提案、计算、命中到周期、过期、移除，每个时刻该发生什么由相位图与监听器共同回答。

## 2. 产品承诺

- **相位序固定**：提案→计算→裁决→命中→应用→周期→过期→移除，顺序不可配置。
- **一相位三槽**：每相位分前置、主、后置三个槽位；主槽权威在模板图，无图才回落 preset 默认处理器。
- **监听器后置执行**：监听器先收集并预检，在本相位三槽走完后按优先级从高到低执行；超容量报错不丢弃。
- **确定性**：相位内随机由确定性种子派生——同配置同输入同结果。
- **可跳过主槽**：显式声明跳过主槽即不执行默认处理器；跳过与提供主图互斥。

## 3. 运行行为

监听器来源三路：目标实体、施法者实体、全局注册表；执行时按声明优先级降序。模板每相位绑定步数有界（相位数乘槽数）。

## 4. 异常承诺

主槽与跳过同写、监听器超容量、绑定步超上限——启动或运行期报错，不静默降级。
