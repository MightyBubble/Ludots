# rt-01 · 时钟系统

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/rt-01-clocks.md)；编辑器需求见 [UXD](../uxd/rt-01-clocks.md)；引擎实现见 [runtime spec](../spec-runtime/rt-01-clocks.md)；editor spec 见 [editor spec](../spec-editor/rt-01-clocks.md)；现状见 [reference](../reference/rt-01-clocks.md)。

## 1. 定位

GAS 的时间分三层：固定帧（引擎节拍，恒速）、步进（玩法时间轴，可暂停/手动/变速）、实体本地（每实体一个变速影子）。一切效果时长、周期、冷却都以步进计。

## 2. 产品承诺

- **三域正交**：固定帧与步进是全局域；实体本地不是全局域——每实体独立累加本地步数，不参与全局交换。
- **步进三态**：Auto 按固定 tick 累计消费步数（由步进间隔与千分比速度共同决定）；Manual 只走显式请求的步；Paused 停走。
- **手动步才是回合事件**：TurnAdvanced 脚本事件只随手动步发出，自动步不发。
- **实体变速即属性**：`time.scale_permille`（1000=与全局同步）驱动实体本地步进；缺属性、非有限、非整数千分比、负值、超上限——一律失败并指明实体，不静默夹取。
- **换算确定**：一个固定 tick 的时长由引擎固定帧率决定；步进速率=固定帧率÷步进间隔；作者写 duration ticks 时以步进为单位。

## 3. 运行行为

每固定 tick：先推进固定帧域，再按策略消费零到多个步进；实体本地步进=本轮已消费全局步×本地千分比，按 1000 阈值累加进本地步数。步进速率作为下游系统（订单缓冲等）的节拍参数在启动期换算一次。

## 4. 异常承诺

时钟配置缺字段、非规范拼写、步进间隔小于 1——启动失败并指明字段。实体缺属性缓冲或 scale_permille 非法——运行失败并指明实体与属性名。
