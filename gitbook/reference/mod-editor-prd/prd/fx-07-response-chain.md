# fx-06 · 响应链

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/fx-07-response-chain.md)；编辑器需求见 [UXD](../uxd/fx-07-response-chain.md)；引擎实现见 [runtime spec](../spec-runtime/fx-07-response-chain.md)；编辑器实现见 [editor spec](../spec-editor/fx-07-response-chain.md)；现状见 [reference](../reference/fx-07-response-chain.md)。

## 1. 定位

响应链是效果的可对抗层：效果提案后、落地前，目标与其响应者在窗口内以钩子、修正、连锁、请求输入四种动作回应。

## 2. 产品承诺

- **参与是门槛**：只有声明参与响应的效果才开窗口；验证未过的提案不开。
- **四动作语义固定**：钩子直接否决；修正在提案数值上改写；连锁派生新提案；请求输入转入等待交互。
- **窗口有界**：深度、数量、步数均有上限（见事实页）；步数熔断即整窗作废，不让死循环拖垮帧。
- **裁决从尾向前**：连锁产生的链从最后一级向前裁决，非根项可被剩余否决票否决。
- **根预算独立**：单个根效果引发的扇出受独立预算表约束，事务内可回滚；无根标识的内部请求不占预算。

## 3. 运行行为

窗口状态为关→收集→等输入→裁决四态；修改动作即时改写窗口数值，连锁动作可再触发连锁；连续空转即关窗。等待期交互与订单请求原子发布。

## 4. 异常承诺

响应超容量、连锁超深、根预算超限、步数熔断——报错或作废并指明根效果，不静默截断。
