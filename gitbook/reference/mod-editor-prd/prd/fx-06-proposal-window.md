# fx-05 · 提案窗口与 Instant 内联

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/fx-06-proposal-window.md)；编辑器需求见 [UXD](../uxd/fx-06-proposal-window.md)；引擎实现见 [runtime spec](../spec-runtime/fx-06-proposal-window.md)；编辑器实现见 [editor spec](../spec-editor/fx-06-proposal-window.md)；现状见 [reference](../reference/fx-06-proposal-window.md)。

## 1. 定位

提案窗口是效果的准入关卡：验证图先答"能不能发生"，纯计算再答"按什么数值发生"，通过后效果才被允许实体化或内联。

## 2. 产品承诺

- **纯相位契约**：提案与计算两个相位只做纯计算——验证图、计算图与监听图里出现副作用一律编译期拒绝，不留运行期侥幸。
- **验证语义固定**：验证图以结果寄存器播种"否"，图内显式写"是"才通过；拒绝在窗口内粘滞，本窗口不再翻案。
- **外部原子独占**：激活窗口若调用外部原子（位移、进度、订单三类），必须恰一个、必须是最后一步、且不与修改器等组合——保证可回滚边界清晰。
- **Instant 内联**：即时效果满足内联条件时同帧走完提案与应用，不产生实体。
- **空相位放行**：未挂图的验证相位视为通过，不阻塞缺省写法。

## 3. 运行行为

四个相位窗口（激活、周期、过期、移除）各自编译完成才允许模板进入运行；运行期在监听器预检发现独占律冲突时立即拒绝。

## 4. 异常承诺

纯相位带副作用、监听图调用内建或读配置、外部原子组合违例——编译期或运行期立即拒绝并指明模板与窗口。
