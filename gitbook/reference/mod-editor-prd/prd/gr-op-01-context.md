# gr-op-01 · 节点：常量与上下文

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/gr-op-01-context.md)；编辑器需求见 [UXD](../uxd/gr-op-01-context.md)；引擎实现见 [runtime spec](../spec-runtime/gr-op-01-context.md)；编辑器实现见 [editor spec](../spec-editor/gr-op-01-context.md)；现状见 [reference](../reference/gr-op-01-context.md)。

## 1. 定位

图里一切"值从哪来"的入口：常量三件、施法者与显式目标、上下文三件、观众、事件载荷与击落点坐标。全部是无输入、只出值的叶子节点。

## 2. 产品承诺

- **常量即字面量**：Bool/Int/Float 三个常量节点把字面值送上值线；Int 常量可钉住寄存器槽，做 Script 图的循环变量。
- **固定实体槽**：施法者、显式目标、观众分别落编译期保留的实体寄存器槽 E0/E1/E2；作者与编译器都不可挪作他用。
- **上下文按挂接点注入**：源/目标/目标上下文三件读宿主（效果相位、订单校验、AI 打分）注入的上下文实体——同一张图挂不同挂接点，读到的实体不同。
- **载荷与落点可读**：事件载荷按槽位读整型或浮点；击落点坐标以厘米整数读出。

## 3. 运行行为

常量在编译期折进指令立即数；实体加载从宿主上下文取句柄写入固定槽或目标寄存器；事件载荷与落点由宿主在图执行前注入环境，节点只做搬运。

## 4. 异常承诺

载荷槽位越界、钉住的寄存器槽撞保留槽或超容量——编译失败并指明节点与槽位。上下文实体缺位时节点产出无效实体句柄，由消费方的判空语义接管。
