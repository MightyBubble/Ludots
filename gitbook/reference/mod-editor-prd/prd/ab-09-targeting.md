# ab-09 · Targeting 与组合命令

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ab-09-targeting.md)；编辑器需求见 [UXD](../uxd/ab-09-targeting.md)；引擎实现见 [runtime spec](../spec-runtime/ab-09-targeting.md)；editor spec 见 [editor spec](../spec-editor/ab-09-targeting.md)；现状见 [reference](../reference/ab-09-targeting.md)。

## 1. 定位

targeting 块回答"这个技能要离多近才能放"；组合命令回答"不够近时怎么办"——超射程时把"走近 + 施放"拼成一张计划，单位自己走到射程边缘开火。

## 2. 产品承诺

- **射程即声明**：castRangeCm 一项声明施法距离，0 表示自施（不吃距离）；超射程的施放不被静默丢弃，而是进入组合计划。
- **自动走近**：目标在射程外时生成移动锚点——停在射程边缘而非贴脸；到达后自动施放。
- **续单成链**：移动单与施放单构成续单链，键是移动单的订单号；链条容量有界，满了明确拒绝。
- **取消会传播**：移动单被取消或失败，续的施放单以对应原因拒绝——不留下"走一半忘了干嘛"的单位。
- **自动目标与排队**：带自动目标策略的技能不进组合计划（目标现选、绕射程）；排队模式按移动完成后的预计位置判定，不等真正走到。

## 3. 运行行为

组合计划器在订单提交时裁剪：不适用则直通原单；适用则先提交移动单、挂续单；移动单终态为完成后释放施放续单。

## 4. 异常承诺

不满足裁剪条件的命令不改写；续单队列满明确拒绝；批量命令部分不可行时整批报错拆分，不部分执行。
