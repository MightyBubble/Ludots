# cfg-06 · 游戏配置

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/cfg-06-game-config.md)；编辑器需求见 [UXD](../uxd/cfg-06-game-config.md)；引擎实现见 [runtime spec](../spec-runtime/cfg-06-game-config.md)；编辑器实现见 [editor spec](../spec-editor/cfg-06-game-config.md)；现状见 [reference](../reference/cfg-06-game-config.md)。

## 1. 定位

游戏实例级运行配置：这台机器这次怎么跑——窗口、启动地图、本地玩家、帧率、仿真预算、运行时容量。与"游戏里有什么"（内容配置）是两回事。

## 2. 产品承诺

- **一份深合并**：不走配置目录，全部来源深合并成单一运行配置——对象递归、标量与数组后到者覆盖。
- **表现必填**：表现运行时配置缺失即拒绝启动。
- **容量是性能合同**：全部容量必须为正（工作预算项另须有限），交叉约束不满足即拒绝启动并指明字段。
- **启动即生效**：合并一次定形，修改为重启级。
- **基线与定制分离**：引擎默认一份是基线，各 mod 按需覆盖——两者从文件上就分得清。

## 3. 运行行为

启动期合并为单一配置对象；常量表（订单号、属性名、通用值）随之一并就绪供引擎与 mod 查询。

## 4. 异常承诺

表现缺失、容量非正/无限、交叉约束不满足、字段类型错误——一律启动失败并指明字段路径。
