# fx-11 · 相位监听器

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/fx-08-phase-listeners.md)；编辑器需求见 [UXD](../uxd/fx-08-phase-listeners.md)；引擎实现见 [runtime spec](../spec-runtime/fx-08-phase-listeners.md)；editor spec 见 [editor spec](../spec-editor/fx-08-phase-listeners.md)；现状见 [reference](../reference/fx-08-phase-listeners.md)。

## 1. 定位

相位监听器是宿主外挂的行为钩子：按标签、效果、相位、视角四元组匹配，在匹配相位走完后执行一张图或发布一个事件。

## 2. 产品承诺

- **匹配即声明**：听什么（标签/效果 id，可通配）、何时（八相位之一）、从谁看（目标或施法者视角）——四元组齐全才有效。
- **动作二选一可双选**：执行图、发布事件、或两者都做；声明与动作一一对应，不存在空动作监听器。
- **随宿主清理**：监听器登记在效果实体名下，宿主效果移除即一并清理，不留孤儿。
- **纯相位禁事件**：提案与计算相位里的监听器不得发布事件。
- **容量即红线**：单宿主监听器数量有上限（见事实页），超限报错不丢弃。

## 3. 运行行为

模板携带的监听器在宿主效果应用时以宿主实体 id 注册、延迟回放；收集先于相位执行、执行晚于相位三槽（fx-07）。即时效果不得携带监听器。

## 4. 异常承诺

动作组合非法、声明与动作不对应、纯相位发布事件、超容量、即时效果携带——加载或运行期报错并指明模板。
