# ed-02 · 热应用白名单与边界

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ed-02-hot-apply.md)；编辑器需求见 [UXD](../uxd/ed-02-hot-apply.md)；引擎实现见 [runtime spec](../spec-runtime/ed-02-hot-apply.md)；editor spec 见 [editor spec](../spec-editor/ed-02-hot-apply.md)；现状见 [reference](../reference/ed-02-hot-apply.md)。

## 1. 定位

热应用是"哪些改动可以在运行中的对局里生效"的白名单合同：四条通道、精确到字段；白名单之外的一切都是重载级或重启级，不存在降级生效。

## 2. 产品承诺

- **数值三字段热改**：效果模板的时长、周期、首个修改器数值可在运行中替换——模板身份不变，进行中的效果实例按模板新值走后续周期。
- **弹道引用热改**：仅弹道预设模板的三个子效果引用（命中/落点/表现）可热替换。
- **授予 tag 定槽热改**：效果模板槽 0 的固定授予 tag 可热替换（无槽则追加）。
- **图程序整体替换**：同 id 同 kind 的图程序可热替换，替换失败恢复原程序——不产生半新半旧。
- **tag 规则集替换**：仅已注册 tagId 的规则集可替换；新 tag 身份是重启级。
- **属性约束替换**：三边界——属性已注册、旧约束非空、新约束非空。
- **拒绝即指路**：白名单外字段被拒时说明需要重进地图还是重启，不猜不降级。
- **可回滚**：每条热替换自带快照恢复；多通道批量提交失败逆序回滚。

## 3. 运行行为

热替换只经工作台流水线（ed-01）在安全帧内提交；模板身份字段（id、preset 身份、效果间身份扩张）永不可热改；同字段等价写法归一处理。

## 4. 异常承诺

未注册模板/图、身份变更、非白名单字段、槽缺失、约束边界不满足——拒绝并带原因；提交中途失败回滚到提交前状态。
