# ed-01 · 实时技能工作台编辑基座

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ed-01-workbench-base.md)；编辑器需求见 [UXD](../uxd/ed-01-workbench-base.md)；引擎实现见 [runtime spec](../spec-runtime/ed-01-workbench-base.md)；编辑器实现见 [editor spec](../spec-editor/ed-01-workbench-base.md)；现状见 [reference](../reference/ed-01-workbench-base.md)。

## 1. 定位

实时技能工作台是运行中改技能的编辑基座：暂存会话隔离改动、三段流水线分级应用、保存回写 mod 文件。它是热应用（ed-02）与缺口路线图（ed-03）的宿主。

## 2. 产品承诺

- **先验证后入暂存**：非法编辑带诊断码被拒，不污染暂存区；会话修订号单调递增，丢弃清空且递增。
- **三来源一模型**：手动工作台、文件变更、AI 草稿三种入口暂存进同一补丁模型。
- **永不清空重注册**：提交走字段级替换，不是清表重载——运行中的对局不因编辑而中断重置。
- **四级应用分级**：预检结论四选一（立即命令/下次施放生效/需重进地图/需重启），不存在"未分类"终态。
- **安全帧原子提交**：下次施放级变更只在安全帧窗口提交，按固定顺序、失败逆序回滚——注册表永不见半提交状态。
- **立即命令 fail-closed**：未选中实体、实体死亡、缺属性缓冲、未知属性——拒绝并报错，不猜目标。
- **保存先出计划**：保存前出预览（立即属性命令不落盘、显式列为排除项），确认后按计划 upsert 回 mod 文件。
- **效果链有界可追溯**：环形时间线记录施法→效果→属性/tag 的链路，溢出以显式丢弃事件可见，不静默丢。
- **AI 草稿是结构化补丁**：草稿即补丁操作序列；生成器未配置时显式拒绝，不产假数据。

## 3. 运行行为

暂存（Stage）→ 分类（Classify）→ 提交（Commit）三段；编辑经 DataPlane 主题命令进入，状态以最新胜出快照发布；诊断码贯穿三段，编辑器可逐步定位失败原因。

## 4. 异常承诺

暂存非法值、图编译失败、身份变更、非热字段、缺安全帧、提交失败回滚——每类失败有独立诊断码与可恢复路径；回滚失败是最高级错误，显式报码并要求停止编辑会话。
