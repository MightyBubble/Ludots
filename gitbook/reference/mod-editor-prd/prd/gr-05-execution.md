# gr-05 · 执行模型

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/gr-05-execution.md)；编辑器需求见 [UXD](../uxd/gr-05-execution.md)；引擎实现见 [runtime spec](../spec-runtime/gr-05-execution.md)；editor spec 见 [editor spec](../spec-editor/gr-05-execution.md)；现状见 [reference](../reference/gr-05-execution.md)。

## 1. 定位

编译产物在寄存器机上的执行语义：一口气跑到停，或切成片跨帧推进；挂起由宿主政策裁决。

## 2. 产品承诺

- **两种入口语义明确**：run-to-halt 不允许挂起（逢挂起即错）；可挂起的图只走切片执行。
- **挂起归宿主管**：四种宿主各自声明是否允许挂起；装载期对不允许的宿主做可达挂起校验，不留运行期惊喜。
- **预算树共享**：跨图调用整棵树共享指令预算，嵌套不重置；预算内没跑完就挂起为可恢复状态，不是失败。
- **深度封顶**：跨图调用深度有硬上限，超限即失败。
- **零堆分配**：单次执行不在堆上分配寄存器、目标表与调用栈。

## 3. 运行行为

执行入口由宿主选择；挂起状态持久化后可在后续帧恢复续跑；跨图调用目标必须是 Script 且被调子图不得含挂起。

## 4. 异常承诺

预算耗尽、深度超限、在不允许挂起的入口遇到挂起——执行失败并指明图；掉队指令指针一律按越界处理。
