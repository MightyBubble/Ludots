# attr-06 · 属性事件

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/attr-06-events.md)；编辑器需求见 [UXD](../uxd/attr-06-events.md)；引擎实现见 [runtime spec](../spec-runtime/attr-06-events.md)；editor spec 见 [editor spec](../spec-editor/attr-06-events.md)；现状见 [reference](../reference/attr-06-events.md)。

## 1. 定位

属性事件是"数值变了"的两条通知面：玩法面（属性变化发布 GameplayEvent，供触发器与图消费）与表现面（变化位供演出层消费）。两面并行，互不替代。

## 2. 产品承诺

- **玩法面可声明**：属性到事件 tag 的映射在启动期声明；声明的属性每次变化经延迟触发器发布事件，载荷带新值。
- **一帧延迟**：玩法面事件在变化后的处理帧发布——同帧读写不串（延迟语义同 tag-03）。
- **表现面全覆盖**：一切属性写入（含聚合重算）都打表现变化位；表现层按位产出属性值变化事件，消费即清。
- **两面语义不混**：玩法面带 Old/New 与一帧延迟；表现面只陈述"本帧变了"，不带 Old——手册与编辑器并排给出对比。
- **未声明即安静**：没有映射的属性不发布玩法事件；这是选择，不是丢失。

## 3. 运行行为

任意属性写打属性脏位；延迟触发收集逐位比对快照得 Old/New 入队并更新快照；表现位并行打点，表现投影消费后清位。

## 4. 异常承诺

映射注册超上限或重名——启动失败并指明属性与 tag；冻结后注册——失败并指明正确注册时机。
