# cfg-02 · 虚拟文件系统

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/cfg-02-vfs.md)；编辑器需求见 [UXD](../uxd/cfg-02-vfs.md)；引擎实现见 [runtime spec](../spec-runtime/cfg-02-vfs.md)；编辑器实现见 [editor spec](../spec-editor/cfg-02-vfs.md)；现状见 [reference](../reference/cfg-02-vfs.md)。

## 1. 定位

寻址层：mod 的一切文件用地址引用，永不写磁盘路径。它让"文件在哪"与"文件叫什么"解耦。

## 2. 产品承诺

- **地址两段式**：`挂载点:相对路径`，按第一个冒号切分。
- **挂载点封闭且唯一**：引擎资产根挂 `Core`，每个 mod 的根目录挂它的名字；mod 名全局唯一因此挂载点唯一。
- **位置无关**：同一份 mod 目录挪到磁盘任何位置，全部地址不变。
- **逃逸禁止**：相对路径不得越出挂载根。
- **随装卸灭**：mod 卸载即挂载移除，其地址立即失效。

## 3. 运行行为

装配期建立挂载；配置收集、分片目录枚举、代码取资源、编辑器寻址全部经此层。目录枚举顺序稳定。

## 4. 异常承诺

未挂载与文件不存在报同型异常（消息可区分归属），路径越界报访问拒绝异常——三种情况均可定位。
