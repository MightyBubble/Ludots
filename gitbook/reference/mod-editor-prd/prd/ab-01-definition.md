# ab-01 · 技能定义骨架

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ab-01-definition.md)；编辑器需求见 [UXD](../uxd/ab-01-definition.md)；引擎实现见 [runtime spec](../spec-runtime/ab-01-definition.md)；编辑器实现见 [editor spec](../spec-editor/ab-01-definition.md)；现状见 [reference](../reference/ab-01-definition.md)。

## 1. 定位

技能是单位可被下单执行的行动单元：一条必填的执行时间轴，加若干各管一事的可选声明——冷却、激活门、开关、目标、表现、输入。技能表是技能侧唯一的声明面。

## 2. 产品承诺

- **身份与身体**：技能名全局扁平命名空间（同名后加载覆盖）；执行时间轴必填——空时间轴也要显式声明。
- **一块一事**：每个可选块只声明一个侧面；块之间不重复职责、不互相兜底。
- **旧字段必须报错指路**：已删除字段与旧字段名不接受也不忽略——启动失败并写明替代写法。
- **文案走目录**：表现文案 token 必须已在文案目录注册且有当前语言模板；兜底键不得入库。
- **单条失败即整体失败**：一条技能编译不过，启动聚合报错并终止，不降级加载其余。

## 3. 运行行为

加载期按 id 排序后注册进技能注册表；引用许可序要求效果模板与图先于技能加载，技能先于形态路由与上下文组。

## 4. 异常承诺

时间轴缺失、item 超上限、引用未注册的效果模板/图/属性/进度需求名、使用已删除或已改名旧字段、未知交互模式键、文案 token 未注册——一律启动失败，指明技能 id、文件与字段路径。
