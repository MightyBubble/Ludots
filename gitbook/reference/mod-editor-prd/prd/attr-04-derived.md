# attr-04 · 派生属性图

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/attr-04-derived.md)；编辑器需求见 [UXD](../uxd/attr-04-derived.md)；引擎实现见 [runtime spec](../spec-runtime/attr-04-derived.md)；编辑器实现见 [editor spec](../spec-editor/attr-04-derived.md)；现状见 [reference](../reference/attr-04-derived.md)。

## 1. 定位

派生属性图把"这个属性是算出来的"声明为一张 Derived 图：实体模板按图名绑定，聚合完成后执行，结果写回宿主自己的属性。当前生产内容零使用（状态标注见 config 与 reference）。

## 2. 产品承诺

- **公式即图**：派生关系复用图编程模型——节点、校验、预算全部继承；创作与执行限定 Derived 种类。
- **按名绑定**：实体模板用图名声明绑定；图名解析失败启动即败，数字 id 是内部物禁止书写。
- **原子提交**：一次派生执行的全部写入整体生效或整体丢弃；执行中异常不留半程状态。
- **只写宿主**：图只能改绑定宿主自己的属性；对他人写、加属性、发事件一律拒绝并报错。
- **当帧纯算**：被派生图写过的属性当帧不恢复持久值——派生即真相。

## 3. 运行行为

派生图在聚合重算后逐绑定执行；执行期读写走暂存缓冲，提交才写回；重复进入写作用域即错。

## 4. 异常承诺

未知图名、绑定超容、非 Derived 图——启动或执行失败并指明模板与图；写作用域内副作用调用——执行失败并指明图与节点。
