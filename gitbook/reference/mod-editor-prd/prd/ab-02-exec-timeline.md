# ab-02 · 执行时间轴

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ab-02-exec-timeline.md)；编辑器需求见 [UXD](../uxd/ab-02-exec-timeline.md)；引擎实现见 [runtime spec](../spec-runtime/ab-02-exec-timeline.md)；editor spec 见 [editor spec](../spec-editor/ab-02-exec-timeline.md)；现状见 [reference](../reference/ab-02-exec-timeline.md)。

## 1. 定位

执行时间轴是技能的身体：一串按时间排布的条目挂在一条独立时钟上，从起播到终态一次性消费——持续物、瞬发物、等待点、收束点。

## 2. 产品承诺

- **四类条目**：Clip 持续一段时间（效果、自身 tag、目标 tag）；Signal 到点即发（效果、事件、tag 增删）；Gate 等待外部响应（玩家输入、事件、目标收集）；End 收束。
- **节奏与顺序**：整轴一条基准时钟（单条目可换），刻度是 tick 不是秒；条目按 tick 逐个到点触发，End 或耗尽即完成。
- **打断即取消**：命中打断 tag 或订单被替换，时间轴立即终止为取消，已开的 Clip 由到期体系回收。
- **终态映射订单**：完成/取消/失败一一映射订单终态与失败原因，不带原因的终态是缺陷。
- **容量先行**：效果发布前先占队列容量，占不到就失败——不出现"看起来施放成功、效果丢失"。

## 3. 运行行为

起播时把槽位与目标写入黑板（多点取首点为原点、末点为目标）；每帧按当前时钟推进到点条目；Gate 挂起等待响应或超时；同帧内完成后再扫描承接续单，有轮数上限。

## 4. 异常承诺

条目超上限启动失败；黑板槽缺失、效果队列容量不足、Gate 队列满——技能失败并给出对应订单失败原因。
