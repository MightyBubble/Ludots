# fx-12 · 堆叠

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/fx-12-stack.md)；编辑器需求见 [UXD](../uxd/fx-12-stack.md)；引擎实现见 [runtime spec](../spec-runtime/fx-12-stack.md)；editor spec 见 [editor spec](../spec-editor/fx-12-stack.md)；现状见 [reference](../reference/fx-12-stack.md)。

## 1. 定位

堆叠让同类效果共居一个目标：时长策略回答"再上一个怎么算时间"，溢出策略回答"满了怎么办"。

## 2. 产品承诺

- **策略作用于剩余时长**：刷新、累加、保持三义——改的是剩余寿命，不是原始寿命。
- **溢出两义**：拒收新层，或挤掉最旧层换新——层上限内绝不凭空加层。
- **不声明即独立**：无堆叠声明的同类效果各自成实体并存，互不干扰。
- **首层即一**：新效果实体首次应用层数为一，此后按策略合并。
- **授予联动原子**：堆叠变化引起的授予标签增减走差量更新，失败先回滚堆叠再报错——层数与标签永不脱钩。

## 3. 运行行为

只有声明了堆叠策略且非即时的效果参与合并；合并按模板身份在目标容器内定位既有实例。到期时点在合并后重算。

## 4. 异常承诺

三字段缺一即失败；层数上限非正值当前按"无上限"放行——属已知陷阱，治理中（todo/effect.md E3）。
