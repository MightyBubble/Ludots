# ord-04 · 订单黑板

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ord-04-blackboard.md)；编辑器需求见 [UXD](../uxd/ord-04-blackboard.md)；引擎实现见 [runtime spec](../spec-runtime/ord-04-blackboard.md)；编辑器实现见 [editor spec](../spec-editor/ord-04-blackboard.md)；现状见 [reference](../reference/ord-04-blackboard.md)。

## 1. 定位

订单黑板是命令参数的落脚处与技能执行的取数处：实体上挂着整数、浮点、实体、空间四种小缓冲，订单按类型声明的键落参数，能力执行系统按键取参数。

## 2. 产品承诺

- **键先注册后使用**：全部黑板键在订单类型表声明（内置全集固定，自定义键即声明即用）；使用未注册键在启动期失败。
- **四种缓冲各司其职**：整数承载槽位与参数、浮点承载朝向类标量、实体承载目标（带身份三元组校验，拒绝陈旧引用）、空间承载目标点序列。
- **目标的三种形态**：持久化存储目标区分实体、点、六角格三态；一格只能是一种形态，实体与点并存是配置错误。
- **瞬时单的闭环**：瞬时完成类型提交即收集参数、写存储目标、发完成通知，一步到位。

## 3. 运行行为

订单激活把参数按类型三键组写入黑板；能力执行与目标解析按键读取；实体值在读取时按身份三元组重建校验；瞬时单在提交步内完成写入与通知。

## 4. 异常承诺

使用未注册键、存储目标五键组残缺或与瞬时完成绑定非法、实体与空间目标并存、缓冲容量耗尽——一律拒绝并指明键名与订单类型。
