# map-01 · 地图定义

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/map-01-definition.md)；编辑器需求见 [UXD](../uxd/map-01-definition.md)；引擎实现见 [runtime spec](../spec-runtime/map-01-definition.md)；编辑器实现见 [editor spec](../spec-editor/map-01-definition.md)；现状见 [reference](../reference/map-01-definition.md)。

## 1. 定位

地图是一次对局的世界容器：棋盘（空间基底）、初始实体布阵、队伍与玩家、初始相机、地形与碰撞资产引用。

## 2. 产品承诺

- **进游戏的入口**：游戏配置的启动地图指向一张地图；地图经自己的资产管线加载（不走配置目录）。
- **跨 mod 合并**：多个 mod 可向同一张地图贡献内容——实体/队伍/玩家**追加**、棋盘**按名覆盖**、相机**后到者赢**、触发器类型**并集**。
- **地图可继承**：子地图经父地图派生，公共布阵不重复维护。
- **布阵即数据**：初始实体 = 模板引用 + 实例覆盖（位置/队伍/属性初值），不放行为。
- **难度可修饰**：不改原地图文件，用另一个 mod 的片段追加内容、覆盖棋盘与相机。

## 3. 运行行为

进地图时：合并片段 → 解析继承 → 实例化布阵实体 → 建棋盘 → 启用触发器 → 设相机。重进地图重新走资产管线（不触发配置重载）。

## 4. 异常承诺

地图缺失、布阵引用不存在的模板、继承环——加载失败并指明位置。
