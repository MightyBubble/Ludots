# ord-06 · 输入映射

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ord-06-input-mappings.md)；编辑器需求见 [UXD](../uxd/ord-06-input-mappings.md)；引擎实现见 [runtime spec](../spec-runtime/ord-06-input-mappings.md)；编辑器实现见 [editor spec](../spec-editor/ord-06-input-mappings.md)；现状见 [reference](../reference/ord-06-input-mappings.md)。

## 1. 定位

输入映射是按键到订单的翻译层：哪个动作触发哪个订单类型、带什么参数、对哪个演员集合生效——玩家意图进入订单系统的唯一正门。

## 2. 产品承诺

- **一动作一映射**：动作标识全局唯一；一次触发一次裁决。
- **两种路由**：直连一个订单类型，或按演员逐个匹配候选（能力标签、槽位、技能名）择单——同一按键对坦克是移动、对兵营是设集结点。
- **参数随行**：整数与浮点参数槽随映射下发，落到订单黑板。
- **交互模式分层**：全局交互模式六选一，单条映射可覆盖；生效模式决定按键的取目标方式。
- **偏好可持久、编队可展开**：用户覆写开关与落盘路径可配，玩家改键不进 mod 数据；框选群体的落点可按编队格展开。

## 3. 运行行为

每帧按"生效模式 = 映射覆盖，无则全局"分派；分派经命令意图仲裁决定当前帧路由意图，再逐演员提交订单（见 input-01/02）。

## 4. 异常承诺

动作标识重复、直连与候选路由并存、技能映射缺优先级参数、自动与光标目标策略并存或范围非法、编队格参数非法——一律启动失败并指明映射。
