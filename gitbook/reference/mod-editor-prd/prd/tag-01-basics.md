# tag-01 · Tag 表示与状态

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/tag-01-basics.md)；编辑器需求见 [UXD](../uxd/tag-01-basics.md)；引擎实现见 [runtime spec](../spec-runtime/tag-01-basics.md)；编辑器实现见 [editor spec](../spec-editor/tag-01-basics.md)；现状见 [reference](../reference/tag-01-basics.md)。

## 1. 定位

Tag 是实体上最轻的状态原语：一个名字标记实体"处于什么状态"（眩晕、燃烧、隐身），带层数与时效。技能、效果、AI 全靠它对话。

## 2. 产品承诺

- **在场与层数**：一个 tag 要么不在实体上，要么有 1..N 层；加减层数即加退状态。
- **生命周期外置**：tag 自己不知道也不管理时效——加退完全由控制器管理：能力时间轴的 TagClip 项（持续 N tick，到期由能力执行系统退层）与效果的存续期授予（效果移除即回收层数）。"5 秒沉默"是能力时间轴上的一个 TagClip 项，不是 tag 的属性。
- **名字即声明**：tag 名在配置里首次出现即注册（上限见事实页），无中心声明文件；命名分层靠约定（`State.*`、`Event.*`、`Cooldown.*`）。
- **两种可见性**：在场（位图直读）与有效（被规则禁用的 tag 不可见）——消费方自选视角。
- **变化可观察**：tag 的增减与层数变化都会变成事件（下一拍），供反应与 AI 消费。

## 3. 运行行为

tag 操作即时生效于在场集；变化先记脏，帧末对比快照生成变化事件（下一拍可见）；能力时间轴的 TagClip 到期退层。

## 4. 异常承诺

超出容量（种类/计数/定时条目）即操作失败并报错，不静默丢弃。
