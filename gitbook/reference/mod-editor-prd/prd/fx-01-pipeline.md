# fx-01 · 效果执行管线总览

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/fx-01-pipeline.md)；编辑器需求见 [UXD](../uxd/fx-01-pipeline.md)；引擎实现见 [runtime spec](../spec-runtime/fx-01-pipeline.md)；editor spec 见 [editor spec](../spec-editor/fx-01-pipeline.md)；现状见 [reference](../reference/fx-01-pipeline.md)。

## 1. 定位

效果管线是技能与战斗的执行主干：一个效果请求从入队到消失，在固定的阶段机里走完提案、应用、存活、清理。

## 2. 产品承诺

- **阶段序固定**：提案与应用先行，随后存活推进，存活引发的新请求当帧消化完毕才收帧；提案段内循环消化直到队列无新增——同帧引发的连锁效果同帧收敛。
- **预算切片**：每帧效果处理同时受工作单元数与毫秒预算约束（上限见事实页）；预算尽则本帧让位、下帧续跑，请求不丢。
- **事务原子**：相位副作用一律经事务提交，失败整体回滚——效果要么完整落地，要么从未发生。
- **两种归宿**：即时效果同帧内联完成，不落实体；持久效果实体化进目标容器，由存活段周期推进直至过期或移除。

## 3. 运行行为

三个子系统接力：提案处理消化请求并决定内联或实体化，应用系统提交入容器并发布扇出与表现，存活系统驱动周期与过期。每帧切片开始时重置扇出根预算，三子系统共享同一预算表。

## 4. 异常承诺

子系统超耗时间预算、事务提交失败——立即报错并整体回滚，不静默吞掉任何请求。
