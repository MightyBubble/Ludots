# rel-01 · 关系目录

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/rel-01-catalog.md)；编辑器需求见 [UXD](../uxd/rel-01-catalog.md)；引擎实现见 [runtime spec](../spec-runtime/rel-01-catalog.md)；editor spec 见 [editor spec](../spec-editor/rel-01-catalog.md)；现状见 [reference](../reference/rel-01-catalog.md)。

## 1. 定位

关系目录是关系系统的词表：类型、度量、旗标、档位、原因、回调、协同、知识授予、姿态九块——图的关系节点族与姿态判定都引用这里的 id。

## 2. 产品承诺

- **九块各司其职**：类型定关系的形状（对称与否），度量/旗标/档位定数值画像，原因/回调/协同定行为反应，知识授予定可见性，姿态定默认敌我。
- **声明一次全局引用**：目录 id 是关系域的命名空间；图节点、AI 姿态、关系操作全部按 id 引用，装载期解析。
- **跨 mod 覆盖合并**：九块按 id 合并——mod 只写自己要新增或覆盖的条目；姿态块整体替换。
- **缺省可运行**：目录可以为空骨架（只留姿态缺省），系统按缺省值运行。

## 3. 运行行为

目录在关系系统装配前加载（DeepObject 合并）；姿态缺省参与敌我判定；图节点的关系符号引用在此解析。

## 4. 异常承诺

未知字段、引用不存在的目录 id——装载失败并指明块与条目。
