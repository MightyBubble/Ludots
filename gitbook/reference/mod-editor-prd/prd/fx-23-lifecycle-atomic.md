# fx-23 · 生命周期原子操作

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/fx-23-lifecycle-atomic.md)；编辑器需求见 [UXD](../uxd/fx-23-lifecycle-atomic.md)；引擎实现见 [runtime spec](../spec-runtime/fx-23-lifecycle-atomic.md)；editor spec 见 [editor spec](../spec-editor/fx-23-lifecycle-atomic.md)；现状见 [reference](../reference/fx-23-lifecycle-atomic.md)。

## 1. 定位

DeployConsumeSource 效果执行一次原子变形：源单位在场地上物化目标形态、迁移身份与属性、然后消费自身——基地车展开、幼虫化茧的通用底座。

## 2. 产品承诺

- **专属组合**：必须 Instant；必配三件参数：目标实体模板、属性取值来源（Base/Current）、至少一条属性键（容量见事实页）。
- **六步原子链**：物化模板 → 拷身份组件 → 拷属性切片 → 清活跃效果 → 转稳定 id → 消费源实体；任一步失败回滚已物化目标，世界回到执行前。
- **身份延续**：稳定 id 从源迁移到目标，表现层可无缝接管。
- **源消费语义**：源走表现销毁挂起，不做立即销毁；放置点由目标点解析决定；事务不可嵌套、不可对挂起销毁的源执行。
- **现状边界**：预设默认图含未认证生命周期内建，无法通过启动计划编译；原子链经测试直连执行器验证（治理见 spec E15）。

## 3. 运行行为

事务开始时捕获源快照并按配置组装事务态；六步依序执行；属性切片按配置键与取值来源拷贝。

## 4. 异常承诺

缺任一必配参数、取值来源非法、无属性键——启动失败并指明键名；源已死或挂起销毁、目标点不可解析、嵌套事务、模板键不可解析——执行期抛生命周期错误。
