# ab-08 · Toggle 技能

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ab-08-toggle.md)；编辑器需求见 [UXD](../uxd/ab-08-toggle.md)；引擎实现见 [runtime spec](../spec-runtime/ab-08-toggle.md)；editor spec 见 [editor spec](../spec-editor/ab-08-toggle.md)；现状见 [reference](../reference/ab-08-toggle.md)。

## 1. 定位

Toggle 技能是有"开/关"两态的技能：激活时间轴播完即开——挂上形态/状态 tag、向自己挂最多四个无限时长效果；再次激活即关。光环、姿态、形态切换的基础件。

## 2. 产品承诺

- **开关同键**：同一槽位再按一次即关；关闭不经过冷却与激活门——开着的状态永远关得掉；已开再开不重复挂效果。
- **开 = tag + 效果**：开启挂 toggleTag（形态路由与规则系统的输入），并把声明的效果按无限时长挂到自己身上。
- **关 = 摘 tag + 清效果**：关闭摘除 toggleTag，效果随身份 tag 消失由效果生命周期过期清理；可声明关断时间轴做收尾演出。
- **容量先行**：开启效果发布前先占队列容量，占不到宁可起播失败——不出现"开着的光环丢了一半"。
- **两段时间轴**：激活时间轴与关断时间轴各自独立，互不共享条目。

## 3. 运行行为

激活时间轴到达终态"完成"时开启（在订单收尾与表现事件之前完成容量检查）；再次激活在激活门之前走关闭分支；有声明关断时间轴则播完再收，未声明瞬时完成。

## 4. 异常承诺

toggleTag 缺失、activeEffects 超上限——启动失败；开启时效果队列不足——起播失败并报容量错误，不给玩家假成功。
