# ab-06 · 槽位系统

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ab-06-slots.md)；编辑器需求见 [UXD](../uxd/ab-06-slots.md)；引擎实现见 [runtime spec](../spec-runtime/ab-06-slots.md)；editor spec 见 [editor spec](../spec-editor/ab-06-slots.md)；现状见 [reference](../reference/ab-06-slots.md)。

## 1. 定位

槽位是单位持有技能的方式：八个编号格子，输入与订单用槽号点技能。一格放什么由四层来源叠出——临时授予、物品、形态、底座。

## 2. 产品承诺

- **八格定容**：槽号 0-7，越界一律无效，不存在第九个技能位。
- **四层解析有序**：临时授予 > 物品授予 > 形态路由 > 底座，逐层短路——上层占了的格子里底座说了不算。
- **来源可回收**：按来源批量回收——来源 tag 消失、装备卸下、形态切换，授予的格子成批让出，不需要逐格清理。
- **形态层每帧重算**：形态覆盖不持久，随单位状态实时进出（ab-07）；其余三层增量维护。
- **槽号是稳定接口**：输入映射、命令面板、AI 引用槽号而非技能名——换技能不换键位。

## 3. 运行行为

底座槽在实体出生时由模板落定；物品层由装备同步系统维护；形态层由路由系统每帧重算；读取时四层按序短路解析出当前生效技能。

## 4. 异常承诺

槽号越界解析失败（非崩溃）；无任何来源的空槽解析为无技能；模板底座槽超 8 条启动失败。
