# ab-10 · 上下文组

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ab-10-context-groups.md)；编辑器需求见 [UXD](../uxd/ab-10-context-groups.md)；引擎实现见 [runtime spec](../spec-runtime/ab-10-context-groups.md)；编辑器实现见 [editor spec](../spec-editor/ab-10-context-groups.md)；现状见 [reference](../reference/ab-10-context-groups.md)。

## 1. 定位

上下文组回答"指着这个东西时该出哪个技能"：一个根技能（上下文动作）带一组候选技能，每个候选按距离、朝向、悬停、前置与打分图竞争，得分最高者成为右键动作。智能上下文菜单的规则面。

## 2. 产品承诺

- **一组一裁决**：每组以一个根技能为入口、一个搜索半径圈定候选范围；组内候选逐个打分，最高者胜。
- **打分可编程**：基础优先级起步，距离与朝向贡献加权，悬停加成，再叠前置图过滤与打分图——复杂品味写进图。
- **需目标与不需目标两形**：需要目标的候选必须声明距离/角度硬过滤与权重；不需目标的候选只用基础优先级与图。
- **裁决确定**：平分先比实体 id 再比槽号——同样输入永远同样结果。
- **声明即校验**：组、候选、图引用在启动期校验；候选图未通过校验的组不进游戏。

## 3. 运行行为

根技能被激活时：按搜索半径做空间查询并过视野门，逐候选硬过滤（距离、朝向）→ 软打分（权重、悬停、打分图）→ 排序取首；前置图不通过的候选直接出局。

## 4. 异常承诺

组缺根技能/半径/候选、候选缺必填项、图未注册——启动失败；运行期候选图执行异常按图执行语义失败，不拖垮整组。
