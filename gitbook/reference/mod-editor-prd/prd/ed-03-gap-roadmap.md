# ed-03 · 编辑器缺口与路线图

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/ed-03-gap-roadmap.md)；编辑器需求见 [UXD](../uxd/ed-03-gap-roadmap.md)；引擎实现见 [runtime spec](../spec-runtime/ed-03-gap-roadmap.md)；editor spec 见 [editor spec](../spec-editor/ed-03-gap-roadmap.md)；现状见 [reference](../reference/ed-03-gap-roadmap.md)。

## 1. 定位

本篇是编辑器能力的诚实清单：哪些已可用、哪些缺生产实现、按什么顺序补齐。缺口不是缺陷藏起来，而是一等公民写在界面上。

## 2. 产品承诺

- **不可用即声明**：每个不可用动作显式列出并带原因——撤销/重做（会话栈未接入）恒在清单；未绑定流水线则预检/应用不可用；未绑定生成器则 AI 草稿不可用；未配保存根则保存不可用。
- **占位即说明**：缺生产实现的区域（目录树空态、Inspector"尚未接入"区）渲染缺口说明而非空白或假数据。
- **缺口有诊断码**：UI 层不可用动作各带 LSWUI 码，可检索可上报。
- **路线图有序**：文档投影源（目录树的供血者）→ 会话撤销栈 → 图编辑器 → 冷编辑流——先供血、再可悔、再扩面、最后离线。

## 3. 运行行为

不可用清单由运行时按绑定状态动态生成并随快照发布；文档投影源是可选注入服务，注入失败仅日志、UI 进入空态。

## 4. 异常承诺

对不可用动作的任何调用尝试返回对应 LSWUI 诊断码与解锁条件；缺口不产生静默降级——没有"假装成功"。
