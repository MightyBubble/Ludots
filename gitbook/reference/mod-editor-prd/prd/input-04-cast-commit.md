# input-04 · 施法提交档案

> 第一性需求 · 已冻结。配置写法见 [配置说明](../config/input-04-cast-commit.md)；编辑器需求见 [UXD](../uxd/input-04-cast-commit.md)；引擎实现见 [runtime spec](../spec-runtime/input-04-cast-commit.md)；editor spec 见 [editor spec](../spec-editor/input-04-cast-commit.md)；现状见 [reference](../reference/input-04-cast-commit.md)。

## 1. 定位

施法提交档案决定技能槽激活那一刻发生什么：压入或弹出交互帧、提交订单、参数从光标或帧指针取值——技能的扣扳机行为，无状态机。

## 2. 产品承诺

- **两种触发面**：槽激活即执行一段操作序列；已压帧期间指定输入动作触发帧内操作（帧在顶才生效）。
- **三种操作**：压帧、弹帧、提交订单——序列即行为，不再有别的形态。
- **参数值源注入**：订单参数槽在提交时从值源（光标世界坐标、帧指针）取值，不写死坐标。
- **玩家偏好分层**：全局、模板、形态集、单槽四层偏好，窄层优先；锁可封死指定作用域，被封的改不进。
- **空档案合法**：引擎默认无档案无锁，技能不声明即无提交定制。

## 3. 运行行为

技能槽激活按档案序列执行；压帧操作可携带交互上下文档案（input-03）；帧内动作在帧顶期间被注册表拦截执行。

## 4. 异常承诺

未知操作或值源、超出三种字段的声明——启动失败；对被锁作用域的偏好写入被拒绝且返回明确失败。
