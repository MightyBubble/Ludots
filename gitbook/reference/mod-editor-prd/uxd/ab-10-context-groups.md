# ab-10 UXD · 上下文组的编辑器需求

> ab-10 的编辑器需求（高保真规格）。第一性需求见 [ab-10 PRD](../prd/ab-10-context-groups.md)；配置写法见 [ab-10 配置说明](../config/ab-10-context-groups.md)；编辑器实现见 [editor spec](../spec-editor/ab-10-context-groups.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

上下文组编辑器是候选竞技场：左候选榜按预期得分排序，右沙盘拖一个目标即时看到每个候选的硬过滤与得分构成。

## 2. 布局线框

```text
┌─ 上下文组：interaction_arcweaver_action ─────────────────────────┐
├─ 组头：root [ActionContext ▾]  searchRadiusCm [900]               │
├─ 左：候选榜 ──────────┬─ 右：选中候选 + 沙盘 ──────────────────────┤
│ 1 ArcDash   40+30+10+8│ basePriority 40  距离 (≤900,×30)           │
│ 2 DuelBolt  36+18+4+12│ 角度 (≤110°,×10)  悬停 +8                  │
│ 3 NovaPulse 10        │ 前置图 [—] 打分图 [—] ▾                    │
│ ▸ ＋候选              │ 沙盘：◎单位 ·目标(拖动) → 各候选得分实时    │
├─ 底：裁决预览 [胜者 ArcDash] 平分规则提示 ─────────────────────────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| root 选择器 | 技能注册表 | 只列已注册；显示该根被哪些组引用 |
| 候选榜 | candidates + 实时打分 | 排序显示当前沙盘下的胜者 |
| 候选编辑器 | 单候选字段 | requiresTarget 开关切换两形字段组 |
| 图选择器 | graphs 注册表 | 前置图只列 Validation、打分图只列 Score |
| 沙盘 | 空间查询与打分同源接口 | 拖目标即时重算全部候选得分 |

## 4. 关键交互流：给根技能加一个候选

1. 候选榜"＋候选"选技能 NovaPulse。
2. requiresTarget 关 → 距离/角度/悬停字段收起，只留 basePriority。
3. basePriority 填 10；沙盘即时显示它在无目标场景胜出。
4. 保存 → 表分片落盘。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 全员出局 | 沙盘目标使所有候选硬过滤失败 | "无可用动作"占位 + 出局原因列表 |
| 图 kind 迟到 | 图注册为非要求 kind | 黄条"运行期才校验，启动不拦"（如实标注现状） |
| 平分 | 两候选总分相同 | 显示 tie-break 顺序（实体 id → 槽号） |

## 6. 易用性验收口径

- 加一个不需目标的候选 ≤ 3 次交互。
- 沙盘胜者与运行期裁决同源一致。
