# fx-14 UXD · 目标过滤的编辑器需求

> 目标过滤的编辑器需求（高保真规格）。第一性需求见 [fx-12 PRD](../prd/fx-10-target-filter.md)；配置写法见 [fx-12 配置说明](../config/fx-10-target-filter.md)；编辑器实现见 [editor spec](../spec-editor/fx-10-target-filter.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

过滤器表单是候选裁决的开关板：四项过滤一字排开，配合查询预览实时显示"过滤后剩谁"。

## 2. 布局线框

```text
┌─ 过滤器表单 ────────────────────────────────────────────────────────┐
│ 敌我 [Hostile ▾]   排除施法者 [✓]   数量上限 [12 ▸0=不限]            │
│ 层掩码 [☑地面 ☑空中 ☐建筑]（缺省=不滤层）                            │
├─ 预览联动（fx-11 画布只读叠加）─────────────────────────────────────┤
│   候选 ●●●●● → 过滤后 ●●（敌对且≤12，己方变灰）                     │
├─ 底部：过滤序提示 [排除源→内径→层→敌我→数量→根预算] ─────────────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 敌打下拉 | 六值枚举 | 必填无空值 |
| 排除施法者开关 | 布尔 | 必填；预览中施法者着灰 |
| 数量上限 | 数值输入 | 0 显示"不限量"徽标 |
| 层掩码多选 | 层注册表 | 空选=不滤层 |
| 过滤序提示 | 固定顺序说明 | 只读 |

## 4. 关键交互流：把群伤改成对空无效

1. 打开技能效果的过滤器表单。
2. 层掩码取消"空中"，预览中空中候选变灰。
3. 敌我确认为 Hostile、排除施法者勾选、上限 12 不变。
4. 保存；下次施放生效（热级同 fx-11 参数）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 必填缺失 | 敌我/排除源未填 | 保存禁用 |
| 无阵营候选 | 候选缺 Team | 预览标"将按敌我滤除" |
| 不限量 | 上限为 0 | 徽标提示数量由根预算兜底 |

## 6. 易用性验收口径

- 过滤后的候选数在预览中实时可见，不必进游戏试。
- 六值敌我语义有悬停释义（含"缺阵营=滤除"规则）。
