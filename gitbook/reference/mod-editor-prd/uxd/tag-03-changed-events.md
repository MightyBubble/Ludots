# tag-03 UXD · Tag 变化与事件的编辑器需求

> tag-03 的编辑器需求（高保真规格）。第一性需求见 [tag-03 PRD](../prd/tag-03-changed-events.md)；配置写法见 [tag-03 配置说明](../config/tag-03-changed-events.md)；编辑器实现见 [editor spec](../spec-editor/tag-03-changed-events.md)；容量以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

事件流查看器 + 反应绑定编辑：让"谁动了哪个 tag、触发了什么"可见、可配、可回放。

## 2. 布局线框

```text
┌─ 事件流查看器（连接运行实例）───────────────────────────────────┐
├─ 时间线（最近 N 条，环形缓冲同容量）─────────────────────────────┤
│ t1024  Event.Damaged   实体#17  ±1   → 反应槽2 技能尝试          │
│ t1024  State.Burning   实体#23  层1→2                            │
│ t1025  Event.Dispel    实户#23  → 规则自清 State.Stealth          │
├─ 过滤器 [tag 前缀▾] [实体▾] [只看反应]  ▶暂停  ⏬导出             │
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 时间线 | 运行实例事件流（环形缓冲投影，容量=事实页） | 实时滚动；条目点开看负载（旧/新值、源） |
| 过滤器 | tag 前缀、实体 id | 组合过滤 |
| 反应绑定编辑 | 实体模板 ReactionBuffer + 技能槽表 | 事件 tag→槽 下拉绑定（离线可配） |

## 4. 关键交互流：排查"为什么没触发反击"

1. 过滤 `Event.Damaged` → 时间线显示伤害事件正常发布。
2. 条目展开：实体#17 的反应槽 2 指向的技能未出现在激活尝试里。
3. 跳转该技能 → 发现 blockTags 含冷却 tag；再过滤冷却 tag 确认在场。
4. 修配置（冷却缩短）→ 热应用 → 时间线复测。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未连接 | 无运行实例 | 占位说明 + 连接按钮 |
| 缓冲溢出提示 | 环形缓冲覆盖旧条目 | 时间线头部警示计数 |
| 暂停 | 手动 | 冻结视图，新事件计数 |

## 6. 易用性验收口径

- 任一事件的"发布→消费/未消费原因"≤ 2 跳可达。
- 时间线序与引擎事件序一致（同源投影）。
