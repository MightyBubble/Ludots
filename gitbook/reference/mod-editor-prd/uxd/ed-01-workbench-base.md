# ed-01 UXD · 实时技能工作台的编辑器需求

> ed-01 的编辑器需求（高保真规格）。第一性需求见 [ed-01 PRD](../prd/ed-01-workbench-base.md)；配置写法见 [ed-01 配置说明](../config/ed-01-workbench-base.md)；编辑器实现见 [editor spec](../spec-editor/ed-01-workbench-base.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

工作台主界面：左目录、中表单、右链路、底暂存条——一屏完成"选对象→改字段→预检→应用→保存"。

## 2. 布局线框

```text
┌─ 实时技能工作台 ──────────────────────────────────────────────────┐
├─ 左：目录树 ────┬─ 中：Inspector ─────────┬─ 右：效果链时间线 ───┤
│ ▸ 技能          │ Effect.Fireball        │ #t88 Cast ▸ Effect   │
│   ▸ 火球术 ⬤选中│ duration [120]→[180]⏳  │   ▸ Attr Δ-35        │
│ ▸ 效果          │ damage    [-35]→[-50]⏳ │ #t89 … 丢弃 0        │
│ ▸ 图/Tag/属性   │ （只读字段 🔒）          │                      │
├─ 底：暂存条 ──────────────────────────────────────────────────────┤
│ 暂存 2 项 修订 r14 [预检] [应用▾立即/下次施放] [保存计划] [丢弃]   │
│ 预检结论：下次施放生效 ×2                                  ▸诊断 0 │
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 目录树 | 文档投影源（配置+注册表合并视图；现状缺口见 ed-03） | 选中即拉 Inspector；空态如实显示 |
| Inspector 表单 | 字段描述符（只读/min/max/枚举） | 编辑即暂存（先验证后入）；只读字段锁显 |
| 应用级别徽章 | 预检分类结果四级（立即/下次施放/重进地图/重启） | 每暂存项与整单各显级别；重启级红徽 |
| 效果链时间线 | 效果链追踪环形缓冲（容量默认 256，溢出显式丢弃事件） | 按 trace 聚合七相位；可刷新 |
| 暂存条 | 会话快照（修订号、暂存数、脏标记） | 修订号单调显示；丢弃需确认 |
| 诊断面板 | LSW 诊断码流（LSW0001-0021） | 码+人话+失败阶段；点击定位字段 |

## 4. 关键交互流：改伤害并下次施放生效

1. 目录树选火球术 → Inspector 改 damage −35→−50（即时暂存，r14）。
2. 点预检 → 结论"下次施放生效"（热字段，见 ed-02）。
3. 点应用到下次施放 → 引擎在安全帧提交；徽章转"已应用"。
4. 游戏内放一次火球 → 效果链时间线出现新 trace，Attr Δ-50 可见。
5. 满意 → 保存计划 → 确认 → upsert 回 mod 文件（立即属性命令被列为排除项）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未预检 | 暂存后未跑预检 | 应用按钮禁用 + 提示先预检 |
| 预检四级结论 | 预检完成 | 徽章：立即（绿）/下次施放（蓝）/重进地图（橙）/重启（红） |
| 提交回滚 | 安全帧提交失败 | 红条"已回滚"，暂存区保留可改后重试 |
| 保存目标未配置 | 无挂载目标 | 保存按钮灰 + 解锁路径说明 |
| 效果链溢出 | 环形覆盖 | 时间线头部"丢弃 N"计数 |

## 6. 易用性验收口径

- "选对象→改字段→应用生效"≤ 4 步且全程不离开本屏。
- 任一暂存项的应用级别徽章常显；任何时刻可解释"为什么不立即生效"。
- 诊断码出现时 ≤ 2 跳到人话解释与修正路径。
