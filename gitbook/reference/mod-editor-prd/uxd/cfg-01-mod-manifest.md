# cfg-01 UXD · mod 数据的编辑器需求

> cfg-01 的编辑器需求（高保真规格）。第一性需求见 [cfg-01 PRD](../prd/cfg-01-mod-manifest.md)；配置写法见 [cfg-01 配置说明](../config/cfg-01-mod-manifest.md)；编辑器实现见 [editor spec](../spec-editor/cfg-01-mod-manifest.md)；数值取值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

作者在编辑器里对 mod 数据的全部操作：新建 mod、编辑身份字段、维护依赖。用户的第一个动作（"新建一个 mod"）从这里开始，演示场景的每一段也从这里起步。

## 2. 布局线框

```text
┌─ 工作区栏 ────────────────────────────────────────────────────┐
│ [CncRtsBaseMod ▾] [Ra2SkinMod ▾] [＋新建]  ⚠ 2 个待重启变更    │
├─ 左：依赖图（占 40%）────────┬─ 右：身份表单（占 60%）────────┤
│   ┌─────┐                    │  名称    [RtsRedAlertLikeShowcaseMod] ✓│
│   │Core ├─┬─► InputMod       │  版本    [1.0.0]                       │
│   └──┬──┘ │   └─► EntityPanel│  依赖    [Core ^1.0.0 ×] [＋添加依赖]  │
│      ▼    ▼                   │  代码入口 [bin/net9.0/….dll] [清除]   │

```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 工作区栏 mod 下拉 | 工作区已打开 mod 清单 | 切换当前编辑目标；重名项红标 |
| 名称输入框 | 现值 + 全局注册名集合 | 输入即时校验唯一性；重名红框 + 提示"挂载点冲突" |
| 版本输入框 | 现值 | 三段格式校验；失焦解析 |
| 依赖列表 | 本清单 dependencies + 工作区可选 mod | 每行：名称 + 范围编辑（`^ ~ >= <= > < = *` 下拉 + 输入）；删除即移除键 |
| 代码入口 | main 字段；文件选择器经地址空间（cfg-02） | 可清空（纯数据 mod）；路径必须落在本 mod assets/bin 下 |
| 排序值 | priority | 数字输入；旁注固定文案"不影响正常启动顺序" |
| 保存 | — | 规范化写回；身份变更后置"待重启"标记并广播工作区 |

## 4. 关键交互流：新建 mod 向导

1. **命名**：输入名称 → 即时查重（工作区 + 引擎挂载点）→ 下一步可用。
2. **选依赖**：从工作区已打开 mod 勾选（或跳过）；每勾一项显示"你将可以覆盖它的配置"。
3. **代码骨架**：三选一——纯数据 / 空入口类型 / 复制现有入口；默认纯数据。
4. **预览产物**：目录树预览（mod.json + assets/ 域目录 + 可选 bin 入口），version 默认 `1.0.0`、priority 默认 `0`。
5. **完成**：落盘 + 打开工作区 + 进入空资产浏览器；产物必须一次通过解析校验。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空工作区 | 首次启动 | 引导卡："新建你的第一个 mod"（一步进向导） |
| 重名冲突 | 命名/打开时 | 输入框红 + 冲突对象链接 |
| 依赖环 | 图中出现环 | 环边标红 + "查看环路"定位按钮 |
| 版本不满足 | 依赖范围与实际不符 | 依赖行黄标 + 双值对照 |
| 保存冲突 | 磁盘清单被外部修改 | 加载最新 + 差异对照后合并保存 |
| 待重启 | 身份字段变更已保存 | 工作区栏常驻 ⚠ 计数；点开列受影响运行配置 |

## 6. 易用性验收口径

- 从启动编辑器到新建一个可启动的空 mod，不超过 5 次点击。
- 任何身份字段的修改，其生效级别（重启）在保存前可见。
- 依赖图的每种错误（环/缺失/版本）都能一键定位到边与节点。
