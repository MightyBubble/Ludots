# gr-op-12 UXD · 节点：放置校验的编辑器需求

> gr-op-12 的编辑器需求（高保真规格）。第一性需求见 [gr-op-12 PRD](../prd/gr-op-12-placement.md)；配置写法见 [gr-op-12 配置说明](../config/gr-op-12-placement.md)；编辑器实现见 [editor spec](../spec-editor/gr-op-12-placement.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

落点手感件：地图叠层预览是核心——拉回圈、吸附候选、路网边都要看得见。

## 2. 布局线框

```text
┌─ 节点面板 · 分组：放置校验 ──────────────────────────────────────┐
│ ▸ ClampTargetToRange（拉回射程 ⚠改落点）                          │
│ ▸ IsPointInCircle（圈内判定）                                     │
│ ▸ SnapToNearestInCollection / SnapToNearestGraphEdge（⚠改落点）  │
├─ 地图叠层预览 ───────────────────────────────────────────────────┤
│   ○ 拉回圈（射程 b）   ◉ 吸附候选（集合成员）                     │
│   ━ 路网边最近点        ✕ 原落点 → ➜ 校正后落点                   │
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 集合键选择器 | ConfigKeyRegistry 投影 | 只列已登记集合 |
| 有效口命名 | `validOutput` 字段 | 自动建议名，可改 |
| 副作用徽标 | 编辑器静态标注 | Clamp/吸附卡常驻"改落点" |
| 叠层预览 | 地图渲染 + 节点参数 | 拉回圈/候选点/边投影实时画 |

## 4. 关键交互流：给下单位加吸附

1. Validation 图拖 SnapToNearestInCollection，集合键选建造点集合。
2. `value` 接 ConstFloat 200（吸附半径）；叠层显示候选点高亮。
3. 有效口命名保留建议值 `snapValid`；输出口接 JumpIfFalse 门（gr-op-14）。
4. 保存编译；预览中拖动落点看吸附跳变。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 校验图副作用 | Validation 图含改落点节点 | 图级提示条（一次性说明） |
| 吸附无候选 | 集合空/半径外 | 预览灰显 + 有效口假说明 |
| 键未注册 | 手输集合键错名 | 红字 + 注册指引 |

## 6. 易用性验收口径

- 四件的叠层预览与参数改动同步刷新。
- 校验图副作用的说明在校验图首次保存时必现一次。
