# infra-04 UXD · 界面档案的编辑器需求

> infra-04 的编辑器需求（高保真规格）。第一性需求见 [infra-04 PRD](../prd/infra-04-ui-profiles.md)；配置写法见 [infra-04 配置说明](../config/infra-04-ui-profiles.md)；编辑器实现见 [editor spec](../spec-editor/infra-04-ui-profiles.md)；目录计数以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

HUD 档案编辑器：作者选择归组维度、摆放命令甲板与生产总览条目，用预览画布看面板长相。两张空根表意味着这里的一切内容都属于某个 mod。

## 2. 布局线框

```text
┌─ HUD 档案编辑器 ──────────────────────────────────────────────────┐
├─ 左：档案类型 ─────┬─ 中：预览画布 ────────┬─ 右：检查器 ──────────┤
│ ▸ 技能聚合 (2)     │  ┌─ 命令甲板 ───────┐ │ 聚合: groupBy        │
│ ▸ 命令甲板 (空⚠D3) │  │ [Q][W][E] [R]    │ │  [template.id ▾]     │
│ ▸ 生产总览 (空⚠D3) │  └──────────────────┘ │ 甲板: 条目列表        │
│   ＋新建档案(入本mod)│  ┌─ 生产总览 ──────┐  │  槽位/热键/技能引用  │
│                    │  │ 兵营▮ 工厂▮      │ │                      │
└────────────────────┴──┴──────────────────┴────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 档案类型树 | 三表注册表投影 | 空表显示"内容在 mod"说明（D3） |
| groupBy 下拉 | 内建表达式清单（封闭） | 只列可编译表达式 |
| 预览画布 | 档案数据 + 技能图标（GAS 注册表） | 拖摆即时反映 |
| 槽位编辑器 | profiles 条目 | 技能引用下拉来自能力注册表；热键捕获输入 |
| 归组预览 | 聚合档案 + 样例实体 | 按当前 groupBy 演示分组结果 |

## 4. 关键交互流：给皮肤 mod 配命令甲板

1. 档案类型树选命令甲板 → "新建档案（写入本 mod）"。
2. 预览画布拖入技能槽，槽位绑定能力（下拉搜索）。
3. 捕获热键。
4. 预览归组效果（聚合档案选 by_template）。
5. 保存到本 mod 的 `UI/command_deck_profiles.json`。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空根表 | 命令甲板/生产总览无内容 | 类型树徽标"空·内容在 mod"（D3） |
| 表达式未知 | groupBy 非内建 | 下拉外值不可输入 |
| 能力引用失效 | 技能 id 未注册 | 槽位红标 |
| 待重启 | 保存后 | 状态栏"重启生效" |

## 6. 易用性验收口径

- 拖摆一个技能槽到看见预览变化 ≤ 2 步。
- 空根表的"内容在 mod"语义在界面一处可见，不需读文档。
