# fx-23 UXD · 生命周期原子操作的编辑器需求

> fx-23 的编辑器需求（高保真规格）。第一性需求见 ；配置写法见 ；编辑器实现见 ；上限数值以  为准。

## 1. 界面定位

DeployConsumeSource 效果编辑页的部署表单：目标形态、属性切片、六步链预览，配现状可执行性警示。

## 2. 布局线框

```text
┌─ 效果编辑页 · 部署变形 ────────────────────────────────────────┐
│ 目标   _ep.targetEntityTemplate [GraphOps.Ally ▾]              │
│ 切片   取值来源 (·)Current ( )Base                              │
│        属性键 [✔Health ☐Energy ☐… ]（≤ 4·事实页）              │
│ 链路   ①物化 ②拷身份 ③拷属性 ④清效果 ⑤转稳定id ⑥消费源        │
│        ↳ 任一步失败 = 整体回滚（只读示意）                      │
│ ⚠ 本预设现状未通过启动认证：保存可写，启动校验将拒绝             │
└─────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 模板选择器 | 实体模板注册表 | 只列已注册模板；选中展示模板摘要 |
| 取值来源单选 | Base/Current | 二选一，内联说明差异 |
| 属性键多选 | 属性注册表 | 至少 1 项、至多 4 项（常量与事实页同源） |
| 链路示意 | 六步静态序列 | 只读，标注回滚边界 |

## 4. 关键交互流：基地车展开成建筑

1. 新建 DeployConsumeSource 效果 → 部署表单。
2. 模板选基地建筑模板；取值来源 Current（按当前血量迁移）。
3. 属性键勾选 Health；链路示意确认六步与回滚。
4. 确认警示条后保存，挂到展开技能的施放链。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 属性键为空 | 全部取消勾选 | 红条"至少一条"，保存禁用 |
| 勾选第 5 个属性 | 超容量 | 复选禁用并提示上限 |
| 模板悬空 | 模板表条目被删 | 选择器标"未注册"并阻保存 |
| 现状不可执行 | 表单任意启用 | 常驻黄条（与启动错误同源） |

## 6. 易用性验收口径

- "哪一步失败会回滚到哪"在链路示意中一跳可见。
- 取值来源 Base 与 Current 的差异（拷基线还是拷当前值）内联说明一跳可见。
