# pres-03 UXD · 动画配置的编辑器需求

> pres-03 的编辑器需求（高保真规格）。第一性需求见 [pres-03 PRD](../prd/pres-03-animation.md)；配置写法见 [pres-03 配置说明](../config/pres-03-animation.md)；编辑器实现见 [editor spec](../spec-editor/pres-03-animation.md)；目录计数以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

动画编辑器三视图：状态机画布（控制器）、剪辑库（平台寻址）、档案映射表。作者在这里定义"单位怎么走、怎么跑"。

## 2. 布局线框

```text
┌─ 动画编辑器 ──────────────────────────────────────────────────────┐
├─ [状态机] [剪辑库] [档案] ─────────────────────────────────────────┤
│ ┌─ 状态机画布 ────────────┬─ 右：转移检查器 ─────────────────────┐ │
│ │  (101 idle) ──▶ (102 walk) │ 条件 [FloatGreaterOrEqual ▾]     │ │
│ │     ▲  ◀── speed≤0.10 ──┤ 参数 [core.hero.locomotion.speed]  │ │
│ │  默认 [101 ●]            │ 阈值 [0.20] 混合 [0.08s]          │ │
│ └─────────────────────────┴──────────────────────────────────┘ │
│  底部：试播条 [▶] 速度滑杆 [0.0──0.5] 状态高亮                     │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 状态机画布 | animator_controllers 注册表 | 节点=packedStateIndex；转移=边；默认态双环标记 |
| 转移检查器 | transitions 数组 | conditionKind 封闭下拉；参数名自动补全 |
| 剪辑库 | animation_clips + host 落地索引（pres-02） | locator 按 backendId 分行；assetRef 文件选择 |
| 档案映射表 | animation_profiles | 状态索引下拉 ← 控制器；剪辑下拉 ← 剪辑库 |
| 试播条 | 画布状态机 + 参数滑杆 | 参数驱动转移即时演示 |

## 4. 关键交互流：加一个跑动状态

1. 状态机画布拖入新状态（分配 packedStateIndex）。
2. 画 idle→新状态转移，条件 FloatGreaterOrEqual、阈值 0.5。
3. 剪辑库登记 run 剪辑（raylib locator）。
4. 档案映射表给新状态绑 run 剪辑。
5. 保存；试播验证转移。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空状态机 | states 为空 | 画布引导"拖入第一个状态"；保存禁用 |
| 无默认态 | defaultStateIndex 缺失 | 默认态选择器红标 |
| 剪辑未落地 | locator 的 assetRef 文件缺失 | 剪辑行红标 + 重定位 |
| 档案缺映射 | 控制器状态无 clip | 映射表黄格"该状态无剪辑" |
| 待重启 | 保存后 | 状态栏"重启生效" |

## 6. 易用性验收口径

- 新增一个带转移的状态并配好剪辑，不手写 JSON。
- 状态机上任意转移的参数与阈值 ≤ 2 跳可达检查器。
- builtin_clips 旧键在编辑器中无法产生（键不存在于表单模型）。
