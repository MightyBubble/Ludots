# fx-14 UXD · 参数化的编辑器需求

> fx-14 的编辑器需求（高保真规格）。第一性需求见 ；配置写法见 ；编辑器实现见 ；上限数值以  为准。

## 1. 界面定位

效果编辑页的"参数"区块：模板默认值的具名槽位，供施放侧覆盖；保留键在此显示语义用途。

## 2. 布局线框

```text
┌─ 效果编辑页 · 参数区块 ────────────────────────────────────────┐
│ [＋ 添加参数]                            用量 [5 / 上限·见事实页]│
├─ 参数表 ──────────────────────────────────────────────────────┤
│ 键                     类型 [Float ▾]   值 [250]                │
│ _ep.forceXAttribute    [保留·力]        (数值框)                │
│ _ep.forceXTargetAttrId [保留·力]  Attr  [Physics.ForceRequestX ▾]│
│ showcase.config.power  [自定义]   Float [40]                   │
├─ 覆盖预览 ── caller 同键 → 新值；异键 → 追加 ──────────────────┤
└─────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 键输入 | 自由命名；`_ep.` 前缀识别 | 保留键锁定为选择而非自由输入 |
| 类型下拉 | 七类型 | 切换后值控件随类型变形 |
| 值控件 | 数值框 / 引用选择器（对应注册表） | 引用类型只允许选已注册名 |
| 保留键徽标 | `_ep.` 键→消费域注释 | 显示用途（力/弹道/生命周期等） |
| 用量条 | 参数条数 vs 上限（事实页） | 预警 |

## 4. 关键交互流：给力效果配保留参数

1. ApplyForce2D 效果 → 参数区块 → 添加参数。
2. 键选保留键 `_ep.forceXAttribute`（徽标"力"），类型 Float，值 250。
3. 添加 `_ep.forceXTargetAttrId`，类型 Attribute，选择 `Physics.ForceRequestX`。
4. 覆盖预览勾选"模拟 caller 覆盖"→ 显示合并结果；保存。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 引用名不存在 | 选择器搜索无果 | 引导去对应声明面（或提示首现注册语义） |
| 保留键类型不符 | 类型切换 | 红条列出该键合法类型 |
| 容量将满 | 剩 2 槽 | 用量条变色；满则添加禁用 |
| caller 覆盖冲突 | 覆盖预览 | 同键行显示"模板值 → caller 值" |

## 6. 易用性验收口径

- 七类型的"值该写什么"一跳可见（类型旁内联提示）。
- 任一保留键的"键名 + 用途 + 消费分篇"≤ 2 跳可达。
