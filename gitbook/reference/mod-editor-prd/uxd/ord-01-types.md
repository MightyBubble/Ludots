# ord-01 UXD · 订单类型的编辑器需求

> ord-01 的编辑器需求（高保真规格）。第一性需求见 [ord-01 PRD](../prd/ord-01-types.md)；配置写法见 [ord-01 配置说明](../config/ord-01-types.md)；编辑器实现见 [editor spec](../spec-editor/ord-01-types.md)；键编号以 [事实与取值表](../facts.md) 关联页为准。

## 1. 界面定位

订单类型面板是命令物种的总账：全部类型、编号来源、排队参数、黑板落点、被谁引用。

## 2. 布局线框

```text
├─ 左：类型清单 ────────┬─ 右：类型详情 ──────────────────────────────┤
│ ▸ castAbility  #100 ⚓ │ 编号 [#100|语义]  label [Cast Ability]      │

```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 类型清单 | 类型注册表 | 编号徽标（整数/语义两态）；⚓ 标必备类型（不可删） |
| 编号输入 | 编号占用表 | 双模式：整数（查重+范围）或语义串（预览将分到的最小空闲编号） |
| 排队/窗口表单 | 类型配置字段 | 数值步进与枚举下拉；≤0 窗口旁挂"永不过期"标注 |
| 落点选择器 | orderBlackboardKeys 注册视图 | 补全含 `none`；未注册名即时红条 |
| 五键组区 | 存储目标键组 | 仅 instantComplete 开启时展开 |
| 底线检查 | 游戏配置常量 ∩ 注册表 | 缺任一必备类型即整页红条（重启级） |

## 4. 关键交互流：新建一个可打断的自定义命令

1. 左栏 ＋新建 → 输入 key `rallyPoint`，编号选语义 → 预览显示 #4。
2. 排队卡：same 选 `Replace`，canInterruptSelf 开。
3. 落点 spatial 选已有键或"＋顺带声明键"（同时写入键段）；保存 → 类型表落盘，清单出现语义徽标条目。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 编号冲突 / 键未注册 | 整数编号已被占用 / 落点引用缺失 | 红框+占用者链接 / 红条+一键建键提案 |
| 必备缺失 | 底线检查失败 | 保存阻断，指明常量来源 |
| 规则引用 | 该类型被 orderRules 引用 | 详情页引用计数，点击跳转 |

## 6. 易用性验收口径

- 任一类型"参数+落点+规则引用"≤ 2 跳可达。
- 语义编号输入框当场预览分配结果，无需保存试探。
- 删除被规则引用的类型前必须先解除引用（阻断并指路）。
