# ed-03 UXD · 编辑器缺口与路线图的编辑器需求

> ed-03 的编辑器需求（高保真规格）。第一性需求见 [ed-03 PRD](../prd/ed-03-gap-roadmap.md)；配置写法见 [ed-03 配置说明](../config/ed-03-gap-roadmap.md)；编辑器实现见 [editor spec](../spec-editor/ed-03-gap-roadmap.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

能力状态面板 + 空态系统：不可用动作灰显带因、缺供血区域占位说明、路线图一屏可读——让作者对"现在能干什么"零误解。

## 2. 布局线框

```text
┌─ 能力状态（工作台侧栏）───────────────────────────────────────────┐
├─ 不可用动作 ─────────────────────────────────────────────────────┤
│ ↩撤销   灰 · 会话撤销栈尚未接入            [LSWUI0003]           │
│ ↪重做   灰 · 会话重做栈尚未接入            [LSWUI0004]           │
│ 💾保存   灰 · 保存目标 Mod 根目录尚未配置   [LSWUI0001] ▸如何解锁 │
├─ 空态占位 ───────────────────────────────────────────────────────┤
│ 目录树：暂无文档——文档投影源尚未接入生产实现（路线图 #1）          │
│ Inspector：此区"尚未接入"——等待图编辑器（路线图 #3）              │
├─ 路线图 ─────────────────────────────────────────────────────────┤
│ ①文档投影源 ▸ ②撤销重做 ▸ ③图编辑器 ▸ ④冷编辑流                 │
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 不可用动作清单 | 运行时快照 UnavailableActions（id/名称/原因） | 灰按钮 + 原因 + LSWUI 码；随绑定状态动态增减 |
| 空态占位 | 目录树/Inspector 的缺供血判定 | 渲染缺口说明与路线图序号，不渲染假数据 |
| 解锁指引 | 码→解锁条件映射（与运行时原因同源） | 点击展开步骤 |
| 路线图条 | 本篇四步顺序 | 静态展示，完成项打勾 |

## 4. 关键交互流：从"保存灰了"到解锁

1. 作者点保存——灰，原因"保存目标 Mod 根目录尚未配置"+码。
2. 点"如何解锁"——挂载能力演示 mod 的步骤说明。
3. 挂载后快照刷新——保存项从清单消失，按钮变实。
4. 其余恒灰项（撤销/重做）保留并链接路线图条目。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 清单为空 | 全部能力可用 | 面板收起为一行"全部可用" |
| 恒不可用 | 会话栈未接入类 | 灰显 + 路线图链接（不提供假入口） |
| 空态目录树 | 文档投影源未注入 | 占位说明 + 路线图 #1 高亮 |
| 部分解锁 | 绑定状态变化 | 清单逐项动态消失，无残影

## 6. 易用性验收口径

- 任一灰按钮 ≤ 1 跳得到原因、码、解锁路径。
- 空态页面永不出现无解释的空白或假数据。
- 不可用清单与实际调用行为零出入（点灰必得码）。
