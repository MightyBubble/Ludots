# cfg-06 UXD · 游戏配置的编辑器需求

> cfg-06 的编辑器需求。第一性需求见 [cfg-06 PRD](../prd/cfg-06-game-config.md)；配置写法见 [cfg-06 配置说明](../config/cfg-06-game-config.md)；编辑器实现见 [editor spec](../spec-editor/cfg-06-game-config.md)。

## 1. 界面定位

编辑器"项目设置"页的数据源——这台机器这次怎么跑；与内容编辑完全分区。

## 2. 界面功能

- **分组表单**：按字段表分组渲染（启动/窗口/帧率/仿真/世界/物理/容量/表现/常量）。
- **容量预算页**：全部容量项（以事实页为准）展示含义与交叉约束，改动前提示影响面；约束冲突表单内即红。
- **两份骨架**：新建项目生成"引擎默认 + 项目覆盖"两份，基线与定制从第一天分清。
- **启动地图选择器**：`startupMapId` 从工作区地图清单下拉选择（联动 map-01）。

## 3. 数据存储

项目覆盖只写用到的字段（深合并语义下的最小覆盖）；写回规范化。

## 4. 易用性设计

- 修改即标注生效级别（全部重启级），保存时汇总提示。
- 常量表可搜索；订单号/属性名表与对应配置表互链。
