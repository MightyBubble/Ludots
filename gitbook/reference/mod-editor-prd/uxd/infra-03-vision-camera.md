# infra-03 UXD · 视野与相机的编辑器需求

> infra-03 的编辑器需求（高保真规格）。第一性需求见 [infra-03 PRD](../prd/infra-03-vision-camera.md)；配置写法见 [infra-03 配置说明](../config/infra-03-vision-camera.md)；编辑器实现见 [editor spec](../spec-editor/infra-03-vision-camera.md)；目录计数以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

相机实验室：预设列表 + 实时视口调参（改距离立刻看到画面变化）；迷雾层设置是其中一页小表单。演示场景"皇室战争玩法"的观感从这里调。

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 预设列表 | virtual_cameras 注册表（含 mod 覆盖标记） | 选中即视口切换 |
| 骨架下拉 | rigKind 枚举 | 决定参数面板分组 |
| 距离/俯仰/视场滑杆 | 现值 + min/max 边界 | 拖动实时反映到视口 |
| 边界成对输入 | min/max 字段 | 倒置红标，保存拦截 |
| 交互模式下拉 | panMode/rotateMode/followMode 枚举 | 边缘平移参数仅 EdgePan 类模式启用 |
| 视口试操作 | 当前预设交互参数 | 作者在视口里直接试平移/缩放/跟随 |
| 迷雾层表单 | fog_layers | cellSizeCm/updateHz 带正数守卫 |

## 4. 关键交互流：调一台 RTS 相机

1. 预设列表选 Rts（或复制为新预设）。
2. 拖距离滑杆到舒适值；视口同步。
3. 开 KeyboardAndEdge 平移、调边缘余量与速度；视口边缘热区可视化验证。
4. 设缩放边界 min/max；滑杆范围随之收窄。
5. 保存（本 mod 覆盖该预设的改动字段）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 边界倒置 | min > max | 成对输入红标 |
| 依赖覆盖 | 预设字段来自依赖 mod | 字段灰显"继承"，改写后转常态 |
| 迷雾参数非法 | 非正数 | 输入红框 |
| 待重启 | 保存后 | 状态栏"重启生效" |

## 6. 易用性验收口径

- 任一参数改动到视口反馈 < 1 帧感知延迟。
- 七台底座预设的"继承/覆盖"状态逐字段可见。
