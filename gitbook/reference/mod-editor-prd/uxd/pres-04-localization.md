# pres-04 UXD · 本地化的编辑器需求

> pres-04 的编辑器需求（高保真规格）。第一性需求见 [pres-04 PRD](../prd/pres-04-localization.md)；配置写法见 [pres-04 配置说明](../config/pres-04-localization.md)；编辑器实现见 [editor spec](../spec-editor/pres-04-localization.md)；目录计数以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

文案工作台：一张 token 总表 + 每语言一列的翻译矩阵。作者在这里补语言、改文案、查漏译。

## 2. 布局线框

```text
┌─ 文案工作台 ──────────────────────────────────────────────────────┐
├─ 工具条: [语言列 ▾ en-US ✔ zh-CN ✔ ＋加语言] [漏译筛选] [导出核对] ┤
├─ token 矩阵 ──────────────────────────────────────────────────────┤
│ id                │ argCount │ en-US        │ zh-CN               │
│ hud.combat.delta  │ 1        │ {0}          │ {0}          ✓      │
│ genreinfo.genre.* │ …        │ (从依赖继承)  │ ── 漏译 ── ⚠        │
│ ＋新建 token（按域命名）                                           │
├─ 底部: 预览条 [当前语言 ▾] "示例渲染：42/50"     使用处: HUD×3       │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| token 矩阵 | text_tokens × text_locales 联结视图 | 继承值灰显、本 mod 值常态 |
| 语言列 | locales 键集合 | 新语言整列生成空模板 |
| argCount | token 行 | 位次参数数变更时校验各语言模板 |
| 漏译筛选 | 矩阵扫描 | 只列缺失/参数不符的格 |
| 预览条 | 当前语言模板 + 样例实参 | 位次参数即时渲染 |
| 使用处索引 | 全配置扫描（HUD/WorldHud/面板/能力） | 点击跳转 |

## 4. 关键交互流：给皮肤 mod 补一种语言

1. 工具条"加语言"→ 选 locale 键 → 整列空模板生成。
2. 漏译筛选逐格填写（继承值可一键复制再改）。
3. 预览条逐 token 核对参数位次。
4. 保存到本 mod 的 `text_locales.json`（DeepObject 合并只动本语言键）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 漏译 | 语言列存在空格 | 格黄标 + 漏译清单计数 |
| 参数不符 | 模板位次参数数 ≠ argCount | 格红标，保存拦截 |
| 能力校验失败 | 启动反馈未注册 token | 错误定位到能力引用处 |
| 待重启 | 保存后 | 状态栏"重启生效" |

## 6. 易用性验收口径

- 漏译总数与逐格定位一键可达。
- 新增语言全程不手写 JSON，产物只含本 mod 写到的键。
