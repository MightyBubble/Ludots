# cfg-07 UXD · 合并案例的编辑器需求

> cfg-07 的编辑器需求。第一性需求见 [cfg-07 PRD](../prd/cfg-07-merge-rules.md)；配置写法见 [cfg-07 配置说明](../config/cfg-07-merge-rules.md)；编辑器实现见 [editor spec](../spec-editor/cfg-07-merge-rules.md)。

## 1. 界面定位

把十种案例变成编辑器的**操作语义**：作者选"我要改这一个元素"时，编辑器按合同安全地完成整组重写，而不是让作者踩坑。

## 2. 界面功能

- **差异分类呈现**：合并预览按五类渲染——新增 / 覆盖标量 / 扩展对象 / 整组替换 / 删除。
- **替换预警**：危险数组字段上的编辑给"将替换对方 N 项"确认框，展示将被替换的元素。
- **屏蔽复活提示**：写删除标记时提示"更晚加载的 mod 写同名会复活"。
- **安全改组**：改数组内单个元素时，自动载入合并结果整组、改该元素、整组写回。

## 3. 数据存储

危险字段清单由字段元数据驱动（类型为数组且未登记可追加），不手抄列表。

## 4. 易用性设计

- 案例集即帮助系统：每类差异可跳"为什么"解释（链到本篇对应案例行）。
