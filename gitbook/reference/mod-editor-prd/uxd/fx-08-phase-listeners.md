# fx-08 UXD · 相位监听器的编辑器需求

> 相位监听器的编辑器需求（高保真规格）。第一性需求见 [fx-08 PRD](../prd/fx-08-phase-listeners.md)；配置写法见 [fx-08 配置说明](../config/fx-08-phase-listeners.md)；编辑器实现见 [editor spec](../spec-editor/fx-08-phase-listeners.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

监听器编辑器是"听什么→做什么"的构建器：匹配条件左侧拼装，动作右侧二选一可双选，容量即时可见。

## 2. 布局线框

```text
┌─ 监听器编辑器 ──────────────────────────────────────────────────────┐
├─ 左：监听器清单（宿主模板内）─┬─ 右：监听器表单 ─────────────────────┤
│ ① 听 MysticShotHit    ⚡    │ 听：效果 [MysticShotHit ▾] 标签[通配] │
│ ② 听 ArcaneShiftBolt   ⚡   │     相位 [OnApply ▾]  视角 [Target ▾] │
│ ③ 听 TrueshotBarrage   ⚡   │ 做：[✓]执行图 [PopEssenceFlux ▾]      │
│ ＋新建监听器                 │     [ ]发布事件（纯相位时禁用）        │
│                              │ 优先级 [100]                          │
├─ 底部：容量 [3 / 上限·事实页] · 宿主寿命提示（Instant 禁挂）────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 效果选择器 | 效果注册表 | 选定即非通配；可清空回通配 |
| 相位/视角下拉 | 八相位 / 两视角 | 纯相位时事件动作禁用 |
| 动作双选 | 图注册表 / 事件标签表 | 勾选与必填联动 |
| 容量条 | 已用槽位 vs 事实页上限 | 接近上限变色 |

## 4. 关键交互流：给标记 Buff 加连监听

1. 打开标记 Buff 的监听器清单，点"＋新建监听器"。
2. 听：选效果 id=MysticShotHit，相位 OnApply，视角 Target。
3. 做：勾"执行图"选 PopEssenceFlux；优先级 100。
4. 保存；容量 +1；Instant 宿主会在此入口直接拦截。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 通配监听 | 效果与标签都不选 | 黄色提示"将响应所有效果" |
| 动作缺失 | 双选均未勾 | 保存禁用 |
| Instant 宿主 | 宿主寿命为即时 | 入口置灰 + 原因提示 |

## 6. 易用性验收口径

- 新建监听器全程无自由文本 id 手打（选择器化）。
- 容量与纯相位限制在编辑期可见，不靠运行报错发现。
