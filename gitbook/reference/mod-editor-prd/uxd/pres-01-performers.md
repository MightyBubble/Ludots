# pres-01 UXD · 表现器档案的编辑器需求

> pres-01 的编辑器需求（高保真规格）。第一性需求见 [pres-01 PRD](../prd/pres-01-performers.md)；配置写法见 [pres-01 配置说明](../config/pres-01-performers.md)；编辑器实现见 [editor spec](../spec-editor/pres-01-performers.md)；表上限与分片清单以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

表现器编辑器是"换皮"的工作台：作者在这里给一类实体组装外观——参数、资产行为、动画挂点。演示场景的 RA2 / Dune 皮肤 mod 从这里开始。

## 2. 布局线框

```text
┌─ 表现器编辑器 ────────────────────────────────────────────────────┐
├─ 左：档案清单 ────────┬─ 右：档案详情 ──────────────────────────────┤
│ ▸ entity_health_bar   │ id [entity_health_bar]  剔除 [OwnerCull]    │
│ ▸ demo.unit.body      │ 距离剔除 [5000] cm                          │
│ ▸ ＋新建表现器        │ ── 绑定参数 ──  ── 行为槽 ──                 │
│   分片：presenters/   │ slot[body] kind[AssetBinding] ▸资产面板      │
│   ⚠3 片未认领         │ activeByDefault ✔                           │
├─ 底部：预览 [3D 视口] ── 引用方：模板×2 ────────────────────────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 档案清单 | presenters 注册表（主文件+分片合并视图） | 分片来源打徽标 |
| 剔除策略下拉 | 引擎剔除枚举 | 只列白名单值 |
| 绑定参数表 | bindings 数组 | paramKey 自动补全；source=constant 展常量框 |
| 行为槽编辑 | behaviors 数组 + kind 白名单 | slot 冲突即时红标；kind 决定后续表单 |
| 资产选择器 | pres-02 资产注册表 | 按 assetKind 过滤；未注册资产红标 |
| 引用方索引 | 全配置扫描 | 点击跳实体模板 |

## 4. 关键交互流：给单位换皮

1. 复制底座表现器为新 id（皮肤 mod 内）。
2. 行为槽 `body` → 资产选择器换 mesh/material（pres-02 注册表）。
3. 预览视口实时渲染（读资产注册表）。
4. 保存到皮肤 mod 的 `Presentation/presenters.json`；实体模板引用不变，重进地图生效。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空表 | 无任何档案 | 引导卡"新建第一个表现器" |
| 槽位冲突 | 同 slot 多行为 | 槽位红标 + 冲突对象链接 |
| 资产缺失 | assetBinding 指向未注册资产 | 红标 + "去 pres-02 注册"跳转 |
| 待重启 | 保存后 | 状态栏标注"重启生效" |

## 6. 易用性验收口径

- 从复制表现器到看到换皮预览，不超过 3 次点击。
- 任一行为的资产引用"定义+资产面板"≤ 2 跳可达。
- kind 白名单外的值不可输入（下拉封闭）。
