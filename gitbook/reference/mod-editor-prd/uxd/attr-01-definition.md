# attr-01 UXD · 属性定义与约束的编辑器需求

> attr-01 的编辑器需求（高保真规格）。第一性需求见 [attr-01 PRD](../prd/attr-01-definition.md)；配置写法见 [attr-01 配置说明](../config/attr-01-definition.md)；编辑器实现见 [editor spec](../spec-editor/attr-01-definition.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

属性面板是数值体系的总账：全部属性、类型、约束、被谁用。

## 2. 布局线框

```text
┌─ 属性面板 ───────────────────────────────────────────────────────┐
├─ 左：属性清单 ────────┬─ 右：属性详情 ────────────────────────────┤
│ ▸ Health   [血条] ⚡12 │ Health                    [血条型]        │
│ ▸ Credits  [血条] ⚡8  │ clampToBase ✔  min [0]  max [—]           │
│ ▸ MoveSpeed [普通] ⚡3 │ 使用处：修改器×8 模板×4 绑定×0             │
│ ▸ ＋新建属性（治理）   │                                            │
├─ 底部：用量条 [种类 5 / 上限·见事实页] ────────────────────────────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 属性清单 | 注册表 + 约束合并视图 | 血条/普通徽标；引用计数 |
| 约束表单 | 约束表 | min/max 编辑；clampToBase 仅对无约束属性可首开（热更边界标注） |
| 使用处索引 | 全配置扫描 | 点击跳转 |
| 用量条 | 种类 vs 上限（事实页） | 预警 |

## 4. 关键交互流：给新单位配血条

1. 属性面板确认 `Health` 存在（血条型）。
2. 实体模板 → `AttributeBuffer` 表单 → base/current 填初值。
3. 保存 → 引用计数 +1。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 无约束属性 | 只在修改器出现 | "Current 无钳制"提示 |
| 冻结冲突 | 会话中新增属性名 | 红条"重启级" |
| 上限预警 | 种类接近上限 | 用量条变色 |

## 6. 易用性验收口径

- 任一属性"定义+全部使用处"≤ 2 跳可达。
- 新建属性明确标注重启级与命名空间规则。
