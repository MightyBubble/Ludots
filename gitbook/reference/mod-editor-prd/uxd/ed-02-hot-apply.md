# ed-02 UXD · 热应用白名单与边界的编辑器需求

> ed-02 的编辑器需求（高保真规格）。第一性需求见 [ed-02 PRD](../prd/ed-02-hot-apply.md)；配置写法见 [ed-02 配置说明](../config/ed-02-hot-apply.md)；编辑器实现见 [editor spec](../spec-editor/ed-02-hot-apply.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

应用级别标注系统：每个字段自带生效级别徽章，预检结论汇总——作者永远知道"这改动什么时候生效"，白名单不靠记忆。

## 2. 布局线框

```text
┌─ Inspector（含级别标注）──────────────────────────────────────────┐
│ Effect.Fireball.Damage                                   r14      │
│ duration.durationTicks [120→180]  ⏳下次施放                        │
│ duration.periodTicks     [30]     ⏳下次施放                        │
│ modifiers.0.value        [-35→-50] ⏳下次施放                        │
│ presetType              [Damage]   🔒重启（身份字段）                │
│ id                      […]       🔒只读                            │
│ grantedTags[0]           [Burning] ⏳下次施放                        │
│ targetQuery.shape       [Cone]    🔄重进地图                         │
├─ 底部：整单预检 ──────────────────────────────────────────────────┤
│ 3 项可下次施放 · 1 项需重进地图 · 0 项需重启      [分级应用…]      │
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 字段级徽章 | 预检分类项（操作×字段→四级） | 静态预估（编辑时）+预检确认；hover 出白名单依据 |
| 身份字段锁 | 字段描述符只读标记 + 身份字段清单 | 禁改并注明重启级 |
| 整单预检条 | 预检报告聚合 | 按级别分组计数；只应用可热项，其余生成重载/重启待办 |
| 白名单速查 | 热字段清单（与引擎分类器同源） | 侧栏一屏速查四通道 |

## 4. 关键交互流：混合级别改动

1. 改三处热字段 + 一处 targetQuery.shape（重进地图级）。
2. 预检：4 项分两组——3 蓝（下次施放）1 橙（重进地图）。
3. 选择"只应用可热项"→ 安全帧提交 3 项成功。
4. 剩余 1 项自动进"重启待办"清单，附带"重进地图后生效"说明与触发按钮。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未预检 | 编辑未跑预检 | 徽章为静态预估样式（浅色） |
| 预检确认 | 预检完成 | 徽章转实色，可点应用 |
| 部分可热 | 混合级别 | 分组呈现 + 只应用可热项 |
| 提交回滚 | 批量失败 | 红条"全部回滚"（逆序），逐项可查原因 |
| 白名单外尝试 | 直接改非热字段 | 字段级拒绝提示 + 级别说明（不静默接受） |

## 6. 易用性验收口径

- 任一字段的生效级别 ≤ 1 跳可见（徽章常显）。
- 白名单四通道速查一屏呈现，与引擎判定零出入。
- 混合级别改动永不"部分静默生效"。
