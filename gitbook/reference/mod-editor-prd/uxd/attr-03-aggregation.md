# attr-03 UXD · 聚合管线的编辑器需求

> attr-03 的编辑器需求（高保真规格）。第一性需求见 [attr-03 PRD](../prd/attr-03-aggregation.md)；配置写法见 [attr-03 配置说明](../config/attr-03-aggregation.md)；编辑器实现见 [editor spec](../spec-editor/attr-03-aggregation.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

聚合透视面板回答一个问题：这个单位当前的数值是怎么算出来的。数值验证与 Buff 调试的总入口。

## 2. 布局线框

```text
┌─ 聚合透视 · 选中单位 ─────────────────────────────────────────────┐
├─ 左：叠加栈（存活序）─┬─ 右：数值瀑布 ──────────────────────────────┤
│ ▸ Base           —   │ MoveSpeed                 Current 5.25      │
│ ▸ Buff·增益 ×1.5  ▲  │ Base 3.5                                     │
│ ▸ Buff·减速 ×0.8  ▼  │ ├ ×增益   5.25   ← 当前                       │
│ ▸ Derived·图名    ◆  │ ├ ×减速   4.20   ← 增益过期后                 │
│                     │ Cap=聚合结果 · 持久 Current 另列               │
├─ 底部：重算序 复位→叠加→派生 · 派生接管属性当帧不回持久值 ──────────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 叠加栈 | 运行时会话的效果容器投影（存活+已提交+聚合标志） | 点条目跳效果模板 |
| 数值瀑布 | 重算步序的逐效果模拟（Base→逐条叠加→Cap/Current） | 假想条目静默可剔除 |
| 派生徽标 | 派生图绑定（attr-04） | 标注"本帧纯重算" |
| 持久值栏 | 属性缓冲的 Cap/Current 双轨 | 聚合写只动 Cap 的可视化 |

## 4. 关键交互流：验证 Buff 叠乘顺序

1. 场景中选中单位，打开聚合透视。
2. 叠加栈依序展示增益、减速；数值瀑布按同序演算。
3. 拖走增益条目（假想剔除），瀑布即时给出过期后的值。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空栈 | 无活跃聚合效果 | "Current=Base"占位 |
| 派生接管 | 属性被派生图写过 | 徽标"当帧不回持久值" |
| 未提交效果 | 提案窗口内条目 | 灰显，不计入瀑布 |

## 6. 易用性验收口径

- 任一 Current 的构成（Base+每条叠加）≤3 跳可见。
- 瀑布演算结果与引擎同帧输出一致。
