# attr-04 UXD · 派生属性图的编辑器需求

> attr-04 的编辑器需求（高保真规格）。第一性需求见 [attr-04 PRD](../prd/attr-04-derived.md)；配置写法见 [attr-04 配置说明](../config/attr-04-derived.md)；编辑器实现见 [editor spec](../spec-editor/attr-04-derived.md)；上限数值以 [事实与取值表](../facts.md) 与 reference 源码常量为准。

## 1. 界面定位

实体模板编辑器的派生绑定区：给一类单位声明"哪些属性由图算出"；带实验特性徽标（当前无生产样例）。

## 2. 布局线框

```text
┌─ 实体模板表单 · 派生绑定区 ◆实验 ─────────────────────────────────┐
│ #  派生图                            用途属性        ▲▼ ✕           │
│ 1  Derived.Example.MoveSpeed… ▾      MoveSpeed ×1                  │
│ 2  ＋ 添加派生图（仅 Derived kind）                                 │
├─ 底部：用量条 [绑定 1 / 上限·见 reference] · 执行序=聚合后·原子提交 ─┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 图选择器 | 图注册表投影，过滤 kind=Derived | 只列可绑定图；空态给"先在图编辑器建 Derived 图"引导 |
| 绑定列表 | 模板组件 graphs 数组 | 容量上限校验（见 reference） |
| 用途属性列 | 图内写属性静态扫描 | 提示"这些属性当帧不回持久值" |
| 实验徽标 | 生产实例计数=0 | 常显，链到 attr-04 config 状态标注 |

## 4. 关键交互流：给单位模板挂派生图

1. 图编辑器创建 Derived 图并保存（gr-04 流程）。
2. 实体模板表单 → 派生绑定区 → 图选择器选中该图。
3. 用途属性列展示写入面；保存 → 重启生效（模板结构变更）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 无可绑图 | 图表无 Derived kind | 引导创建，禁手输 |
| 超容 | 绑定数达上限 | ＋按钮禁用、用量条红 |
| 图被删 | 引用悬空 | 红条"启动将失败"，链到删除处 |

## 6. 易用性验收口径

- 非 Derived 图在选择器中不可见也不可选。
- 绑定写坏（未知图名）在保存前被拦截并定位模板。
