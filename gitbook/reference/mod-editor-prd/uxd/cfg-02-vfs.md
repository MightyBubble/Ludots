# cfg-02 UXD · 虚拟文件系统的编辑器需求

> cfg-02 的编辑器需求。第一性需求见 [cfg-02 PRD](../prd/cfg-02-vfs.md)；配置写法见 [cfg-02 配置说明](../config/cfg-02-vfs.md)；编辑器实现见 [editor spec](../spec-editor/cfg-02-vfs.md)。

## 1. 界面定位

编辑器里作者看到、输入、复制的一切文件引用都是地址形态；地址与磁盘位置的换算对作者不可见。

## 2. 界面功能

- **资产浏览器**：按挂载点分组的文件树（`Core` 一棵、每个打开的 mod 一棵），浏览、搜索、复制地址。
- **地址输入**：所有要求填文件引用的表单字段用地址控件（挂载点前缀下拉 + 路径补全），杜绝手写越界路径。
- **落盘透明**：保存、导出、外部工具唤起时自动完成地址到物理路径的换算。

## 3. 数据存储

- 编辑器自身不存地址→物理路径映射；每次换算经同一解析通道，磁盘移动后无需刷新缓存。

## 4. 易用性设计

- 地址可读性即文档性：`Mod名:路径` 一眼可看出归属，浏览器树与地址互为导航。
- 拖拽资产到表单字段自动生成地址；从地址反查定位到浏览器树节点。
