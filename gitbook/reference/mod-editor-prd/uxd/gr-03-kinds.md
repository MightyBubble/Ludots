# gr-03 UXD · 六种 Kind 的编辑器需求

> gr-03 的编辑器需求（高保真规格）。第一性需求见 ；配置写法见 ；编辑器实现见 ；上限数值以  与 gr-01 reference 为准。

## 1. 界面定位

kind 是建图第一决策：新建向导一次讲清六种的返回约定与能写什么，建后锁定不可改。

## 2. 布局线框

```text
┌─ 新建图 ────────────────────────────────────────────────────────────┐
│ id [Graph.Ability.Gate            ]                                 │
│ ┌─Effect──┐ ┌─Query──┐ ┌─Score───┐ ┌─Validation┐ ┌─Derived┐ ┌Script┐│
│ │做事不返回│ │目标列表│ │分值 F[0]│ │判定 B[0]  │ │直写属性│ │返回整数││
│ │全节点   │ │outputs │ │纯读为主 │ │先清零    │ │唯一写 │ │控制流 ││
│ └─────────┘ └────────┘ └─────────┘ └───────────┘ └────────┘ └──────┘│
│        ▸ 主线实例数（实时统计）        [取消] [创建]                  │
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| kind 卡片 | 六值 + 白名单摘要（引擎同源策略表） | 选中即预览可用节点族 |
| id 输入 | 图名注册表 | 撞名即时提示 |
| 节点面板过滤 | kind 白名单 | 越权节点不出现（而非灰显误导） |
| 保留槽提示 | E0/E1/E2 与返回槽表 | pinRegister 撞保留槽即时拒绝 |
| 实例计数 | 主线资产扫描 | 每 kind 显示真实存量 |

## 4. 关键交互流：建一张能力前置图

1. 新建图 → 选 Validation → 命名。
2. 画布只出现纯读节点 + 判定收尾；控制流糖不出现。
3. 保存 → 预编译零诊断 → 挂到能力前置（gr-08），kind 校验通过。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| kind 锁定 | 图已注册 | 头部徽标只读；改 kind 提示走新建替换 |
| 挂点不符 | 拖图到不收该 kind 的挂点 | 拒绝并说明挂点只收哪些 |
| 越权粘贴 | 从 Script 图复制节点进 Validation | 粘贴拒绝，列出越权节点 |

## 6. 易用性验收口径

- 建 kind 决策所需信息（返回约定、白名单、实例数）一屏读完。
- 编辑器内不可能出现越权节点（面板、粘贴、导入三路全部拦截）。
