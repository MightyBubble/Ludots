# fx-10 UXD · 目标派发的编辑器需求

> 目标派发的编辑器需求（高保真规格）。第一性需求见 [fx-10 PRD](../prd/fx-11-target-dispatch.md)；配置写法见 [fx-10 配置说明](../config/fx-11-target-dispatch.md)；编辑器实现见 [editor spec](../spec-editor/fx-11-target-dispatch.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

派发映射编辑器用三支箭头讲清"谁打谁"：三个角色槽各自指向四类实体之一，预设一键填充。

## 2. 布局线框

```text
┌─ 派发映射编辑器 ────────────────────────────────────────────────────┐
│ 映射来源：( )预设 [SourceToResolved ▾]  (•)显式映射   （互斥）       │
│ ┌─ 角色槽图 ─────────────────────────────────────────────────────┐ │
│ │ 载荷施法者 ──▶ [原施法者 ▾]                                     │ │
│ │ 载荷目标   ──▶ [解析实体 ▾]   预览：●●● → 每候选发一箭           │ │
│ │ 目标上下文 ──▶ [原目标   ▾]                                     │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│ 载荷效果 [Effect.Champion.Garen.JudgmentHit ▾]（注册表校验）        │
├─ 底部：扇出预估 = 过滤后候选数（联动 fx-09 预览）────────────────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 映射来源单选 | 预设/显式 | 互斥切换 |
| 预设下拉 | 派发预设表 | 选中即填充三槽（只读展示） |
| 角色槽下拉 ×3 | 槽值域四值 | 显式模式下可改 |
| 载荷效果选择器 | 效果注册表 | 未注册 id 不可选 |
| 扇出预估 | 过滤后候选数联动 | 只读 |

## 4. 关键交互流：把命中伤害改为"以命中者为新源"

1. 打开派发映射编辑器，映射来源切"显式映射"。
2. 载荷施法者槽改选"解析实体"（即被命中者）。
3. 扇出预估随查询/过滤联动刷新；载荷效果不变。
4. 保存；三槽组合合法即通过（槽值域外无法选择）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 默认映射 | 预设与映射均空 | 三槽灰显"默认"并标等价预设 |
| 互斥冲突 | 两来源同写 | 单选组红条 |
| 载荷悬空 | payloadEffect 被删 | 选择器红 + 跳转被引用处 |

## 6. 易用性验收口径

- 三槽语义不看文档可懂（每槽有四值悬停释义）。
- 默认映射与等价预设的关系一屏可见。
