# attr-06 UXD · 属性事件的编辑器需求

> attr-06 的编辑器需求（高保真规格）。第一性需求见 [attr-06 PRD](../prd/attr-06-events.md)；配置写法见 [attr-06 配置说明](../config/attr-06-events.md)；编辑器实现见 [editor spec](../spec-editor/attr-06-events.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

属性事件面板管两条通知面的可见性：玩法面映射声明（入口待立项，先给只读透视）与表现面变化诊断。

## 2. 布局线框

```text
┌─ 属性事件面板 ◆玩法面休眠 ─────────────────────────────────────────┐
├─ 左：映射清单（只读）─┬─ 右：变化诊断（本帧/最近帧）─────────────────┤
│ ▸ Health → Event.X  —│ 属性        玩法面    表现面                  │
│ ▸ （空——无映射）     │ Health      —（无映射）●变了                  │
│                     │ Credits     —         ●变了                  │
├─ 底部：[两面对比] 玩法面=Old/New·延迟一帧 ｜ 表现面=只报变了·消费即清 ┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 映射清单 | 事件映射注册表投影 | 现状恒空；标注"配置入口待立项（A13）" |
| 新增映射 | 属性枚举 × 事件 tag 枚举 | 玩法面入口落地前禁用并说明 |
| 变化诊断 | 运行时表现变化位 + 脏位投影 | 双列显示两面各自去向 |
| 两面对比条 | 手册对比表（config） | 常驻页脚 |

## 4. 关键交互流：排查"血条没动"

1. 选中实体，打开变化诊断。
2. 表现面列 Health 无变化位 → 数值根本没写，转 attr-03 聚合透视。
3. 表现面有位、演出未刷新 → 问题在表现层，链到 rt-04。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 玩法面休眠 | 映射表空且无入口 | 面板级徽标＋指引（A13） |
| 映射空 | 无任何声明 | "未声明即安静"说明 |
| 首帧伪基线 | 实体首帧变化 | Old 列标注"快照缺失按 0"（A5） |

## 6. 易用性验收口径

- 任一属性变化能在一屏内回答"玩法面发不发、表现面报没报"。
- 两面语义差异（Old/延迟）在界面常驻可见，无需翻文档。
