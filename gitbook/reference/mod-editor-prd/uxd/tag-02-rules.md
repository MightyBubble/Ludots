# tag-02 UXD · Tag 规则的编辑器需求

> tag-02 的编辑器需求（高保真规格）。第一性需求见 [tag-02 PRD](../prd/tag-02-rules.md)；配置写法见 [tag-02 配置说明](../config/tag-02-rules.md)；编辑器实现见 [editor spec](../spec-editor/tag-02-rules.md)；容量以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

规则编辑器：以主体 tag 为中心的六槽规则卡片；配一条规则当场可见连锁图。

## 2. 布局线框

```text
┌─ 规则编辑器：Status.Stealth ────────────────────────────────────┐
├─ 左：规则主体清单 ────┬─ 中：六槽规则卡 ─────────────────────────┤
│ ▸ Status.Stunned ⚡  │ 前置(requiredAll) [State.CanStealth ×]   │
│ ▸ Status.Stealth ●  │ 互斥(blockedAny)  [Status.Revealed ×]    │
│ ▸ ＋新建（选 tag 名）│ 连带授予(attached) [Status.Evasive ×] ＋  │
│                      │ 连带移除(removed) [Status.Noise ×] ＋     │
│                      │ 条件禁用/自清 …（折叠区）                 │
├─ 底部：连锁图 [Stealth ─授→ Evasive]  ▶模拟器 ──────────────────┤
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 主体清单 | 规则表全部条目 | 点选编辑；无规则的 tag 可一键建 |
| 六槽 tag 选择器 | tag 注册表（tag-01 总账） | 每槽多值（≤8），补全来自注册名 |
| 连锁图 | 规则间引用关系（主体↔attached/disabled 目标） | 节点可点跳转；环高亮 |
| 模拟器 | 运行时事务干跑接口 | 输入一组在场 tag → 演示事务结果/拒绝原因 |

## 4. 关键交互流：配"隐身附带闪避"

1. 新建规则 → 主体选 `Status.Stealth`。
2. 连带授予槽加 `Status.Evasive`。
3. 连锁图即时出现 `Stealth ─授→ Evasive`。
4. 模拟器在场集输入隐身 → 结果显示隐身+闪避。
5. 保存 → 规则表分片落盘。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 规则环 | 连锁图检测环 | 环路高亮 + 事务预算提示 |
| 槽满 | 单类 8 条上限 | 添加钮禁用 + 计数 |
| 热替换冲突 | 规则被下游 mod 覆盖 | 双值对照 + 来源 |

## 6. 易用性验收口径

- 配一条含连带的规则 ≤ 4 次交互且即时见连锁图。
- 模拟器结果与引擎事务一致（同源）。
