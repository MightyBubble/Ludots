# ab-09 UXD · Targeting 与组合命令的编辑器需求

> ab-09 的编辑器需求（高保真规格）。第一性需求见 [ab-09 PRD](../prd/ab-09-targeting.md)；配置写法见 [ab-09 配置说明](../config/ab-09-targeting.md)；编辑器实现见 [editor spec](../spec-editor/ab-09-targeting.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

射程面板是小而关键的表单加一台沙盘：改 castRangeCm 即时看到射程圈与"超射程自动走近"的路径预演。

## 2. 布局线框

```text
┌─ 射程面板：ArcaneShift ──────────────────────────────────────────┐
├─ 表单 ────────────────────────────────────────────────────────────┤
│ castRangeCm [440] (0=自施)   impactEffect [ArcaneShift ▾]          │
│ 自动目标 [NearestEnemyInRange ▾] 半径 [760] → 组合计划: 绕过       │
├─ 沙盘预演 ────────────────────────────────────────────────────────┤
│      ·目标            射程圈 (440cm)                               │
│   ◎单位 ──────▶█锚点(射程边缘) ─Cast                               │
│ ☑ 排队模式（按移动后预计位置判定）                                  │
├─ 底：与 impactEffect 双向跳转  旧字段粘贴拦截 ─────────────────────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| castRangeCm 输入 | 数值（≥0） | 0 显示"自施"徽标；沙盘射程圈同步 |
| impactEffect 选择器 | 效果模板注册表 | 只列已注册；双向跳转效果编辑器 |
| 自动目标策略选择器 | input 块枚举 | 非 None 时沙盘标注"组合计划绕过" |
| 沙盘预演 | 地图比例尺 + 组合计划同源判定 | 拖动目标点即时算锚点与路径线 |
| 排队模式开关 | 提交模式枚举 | 切换原点（当前位置/预计位置）对照 |

## 4. 关键交互流：调射程并验证走近行为

1. castRangeCm 从 440 改 600 → 射程圈放大，锚点外推。
2. 沙盘把目标拖到圈外 → 出现"移动→施放"路径线与锚点标记。
3. 切排队模式 → 原点切换为预计位置，判定结果即时更新。
4. 保存 → 下次施放生效（表单热替换）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 自施 | castRangeCm=0 | 射程圈隐藏；"不吃距离"标注 |
| 旧字段粘贴 | 含 targeting.range / indicator 的 JSON | 红条指路新写法 |
| 队列满预演 | 续单队列占用接近上限（facts 页） | 沙盘警示 RejectedQueueFull |

## 6. 易用性验收口径

- 改一次射程 ≤ 2 次交互且沙盘即时反映。
- 走近锚点位置预演与运行期实测一致（同源判定）。
