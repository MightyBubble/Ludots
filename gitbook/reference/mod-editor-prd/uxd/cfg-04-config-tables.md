# cfg-04 UXD · 配置表体系的编辑器需求

> cfg-04 的编辑器需求。第一性需求见 [cfg-04 PRD](../prd/cfg-04-config-tables.md)；配置写法见 [cfg-04 配置说明](../config/cfg-04-config-tables.md)；编辑器实现见 [editor spec](../spec-editor/cfg-04-config-tables.md)。

## 1. 界面定位

"我能配什么"的完整答案：表清单是编辑器的配置能力地图；新建条目是编辑器最高频动作。

## 2. 界面功能

- **表清单视图**：按域分组的全部已登记表（路径、策略、去重字段、分片目录、条目数、来源）。
- **新建条目默认落分片**：一文件一条，文件名取 id 尾段；空表也保得住。
- **引用检查前移**：表文件路径对得上登记、条目引用对得上已加载注册表——编辑期即时报错，不等启动。
- **新表审批流**：新增登记 = 新条目 + 加载器挂接 + 策略选择三件同批，做成显式审批；审批前引导用已有表组合。

## 3. 数据存储

- 新建/改条目写分片文件（规范化 JSON），不鼓励直接编辑大表文件。
- 表清单为只读投影，不落编辑器侧副本。

## 4. 易用性设计

- 每张表在清单里可一键"新建条目"，表单 schema 由该表加载器合同驱动。
- 严格性翻译成人话：未知字段报错显示"该表不接受此字段"+ 最近似合法字段建议。
