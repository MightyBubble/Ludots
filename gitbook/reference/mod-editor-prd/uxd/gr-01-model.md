# gr-01 UXD · 图编程模型的编辑器需求

> gr-01 的编辑器需求（高保真规格）。第一性需求见 ；配置写法见 ；编辑器实现见 ；上限数值以  与 gr-01 reference 为准。

## 1. 界面定位

图编辑器是全部可编程面的工作台：一张画布写图，一套诊断保装载，卷 8 其余篇的面板（函数库、动作库、挂接、输出）都挂在它下面。

## 2. 布局线框

```text
┌─ 图编辑器 ──────────────────────────────────────────────────────────┐
├─ 左：节点面板 ──┬─ 中：画布 ─────────────────────┬─ 右：节点检查器 ────┤
│ ▸ 常量          │  ┌──────┐   ┌──────────┐      │ ConstInt           │
│ ▸ 数学          │  │c 常量│──▶│h 返回 Int│      │ intValue [7]       │
│ ▸ 属性   过滤▾  │  └──────┘   └──────────┘      │ pinRegister [—]    │
│ ▸ 控制流        │  kind: Script  ▶运行  ⏸挂起    │                    │
├─ 底部：诊断 0 · 预算 [指令 2/·见事实页] · 目标 0/· · 调用 0/· ──────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 节点面板 | 节点目录表 + kind 白名单（gr-03） | 按 kind 过滤；不可用节点灰显并注明原因 |
| 画布 | 图文档（gr-02 格式） | 连线即校验端口与值类型 |
| 节点检查器 | 节点字段表（gr-02） | 符号字段带引用补全（tag/attribute/图名） |
| 诊断条 | 编译器诊断码（gr-04） | 点击定位节点/边 |
| 预算仪表 | 编译产物统计 vs 上限（事实页 / gr-01 reference） | 接近上限变色 |

## 4. 关键交互流：从零建一张图

1. 新建图 → 选 kind（gr-03 六卡片）→ 命名 id。
2. 节点面板拖 ConstInt、HaltReturnInt 入画布，连线（next、value）。
3. 保存 → 编辑器预编译零诊断 → 写入 graphs.json 分片 → 预算仪表更新。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空图 | 无节点 | 画布引导：选 entry 节点 |
| 带诊断 | 预编译有错误 | 诊断条红色计数，画布节点标角标 |
| 接近预算 | 指令/寄存器用量近上限 | 仪表预警色 |
| 只读 | 会话外冻结视图 | 画布锁定并注明 |

## 6. 易用性验收口径

- 新图从新建到装载通过 ≤ 3 步操作。
- 任一诊断 ≤ 2 跳定位到对应节点或边。
- 编辑器预编译通过的文档，引擎装载必零诊断（同源验收）。
