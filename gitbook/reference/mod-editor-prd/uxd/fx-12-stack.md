# fx-12 UXD · 堆叠的编辑器需求

> 堆叠的编辑器需求（高保真规格）。第一性需求见 [fx-12 PRD](../prd/fx-12-stack.md)；配置写法见 [fx-12 配置说明](../config/fx-12-stack.md)；编辑器实现见 [editor spec](../spec-editor/fx-12-stack.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

堆叠表单管"层怎么算"，堆叠视图管"现在几层"：前者静态规则，后者运行观测。

## 2. 布局线框

```text
┌─ 堆叠表单（模板内）────────┐  ┌─ 堆叠视图（运行会话）─────────────┐
│ 层数上限 [ 3 ]（须>0 ⚠E3）│  │ 目标：敌方坦克                     │
│ 策略 [RefreshDuration ▾]  │  │  ├ WMark      ×1  ▓▓▓▓░░ 剩120t  │
│ 溢出 [RemoveOldest ▾]     │  │  ├ 腐蚀       ×3  ▓▓░░░░ 剩 90t  │
│ 预估：满层再施加→换最旧    │  │  └ 护盾       ×2  ▓▓▓░░░ 剩200t  │
└────────────────────────────┘  └────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 层数上限 | 数值输入 | ≤0 即红条（E3 语义：不允许无上限写法） |
| 策略下拉 | 三值 | 悬停给"剩余时长"示意 |
| 溢写下拉 | 两值 | 与上限联动展示满层行为 |
| 堆叠视图 | 目标容器运行时快照 | 层数、剩余时长条、模板跳转 |

## 4. 关键交互流：把标记改成可叠三层

1. 打开标记 Buff 的堆叠表单。
2. 上限改 3；策略保持 RefreshDuration；溢出选 RejectNew。
3. 预估行更新为"第 4 次施加将被拒"。
4. 会话内施加验证：堆叠视图层数 1→2→3 后不再增长。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 非正值上限 | limit ≤0 | 红条 + 现状语义提示（E3） |
| 无声明 | 模板未写 stack | 表单折叠，提示"同类各自独立实体" |
| Instant 宿主 | 寿命为即时 | 提示"内联即完成，不参与合并" |

## 6. 易用性验收口径

- 三策略对"剩余时长"的作用一图可懂（悬停示意）。
- 运行会话中任一目标的层数与剩余时长实时可见。
