# fx-23 UXD · 兑换的编辑器需求

> fx-23 的编辑器需求（高保真规格）。第一性需求见 [fx-23 PRD](../prd/fx-20-exchange.md)；配置写法见 [fx-23 配置说明](../config/fx-20-exchange.md)；编辑器实现见 [editor spec](../spec-editor/fx-20-exchange.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

Exchange 效果编辑页的兑换区块：选操作、配作用域，并透视操作本体的输入/输出摘要。

## 2. 布局线框

```text
┌─ 效果编辑页 · 兑换 ────────────────────────────────────────────┐
│ 操作   _ep.exchangeOperationId [gold_market.buy_relic ▾]       │
│        输入: Gold×5(AttributeCost/Source)                      │
│        输出: gold_market_relic×1(CreateItem/Stash)             │
│ 作用域 _ep.exchangeScopeKey [— 可选 ▾]                          │
│ ⚠ 本 preset 处理器现状未通过启动认证：保存可写，启动校验将拒绝   │
└─────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 操作选择器 | 兑换操作注册表 | 选中即展示输入/输出摘要（只读透视） |
| 摘要面板 | 操作表条目投影 | 点击跳操作表编辑处（跨域跳转） |
| 作用域选择 | 作用域注册表 | 可空 |

## 4. 关键交互流：商店技能买遗物

1. 新建 Exchange 效果 → 兑换区块。
2. 操作选 `gold_market.buy_relic`，摘要显示 金 5 → 遗物 1。
3. 作用域留空；确认警示条后保存，挂到商店技能的施放链。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 操作悬空 | 操作表条目被删 | 选择器标"未注册"并阻保存 |
| 运行期兑换失败 | 诊断回流 | 效果实例标"兑换失败（已记录）"，无红错 |
| 现状不可执行 | 区块任意启用 | 常驻黄条（与启动错误同源） |

## 6. 易用性验收口径

- 选中操作后的"进什么、出什么"一跳可见，无需打开操作表。
- "失败不炸效果"的语义在区块提示中一跳可见。
