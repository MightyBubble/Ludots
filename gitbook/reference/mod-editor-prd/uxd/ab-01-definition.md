# ab-01 UXD · 技能定义骨架的编辑器需求

> ab-01 的编辑器需求（高保真规格）。第一性需求见 [ab-01 PRD](../prd/ab-01-definition.md)；配置写法见 [ab-01 配置说明](../config/ab-01-definition.md)；编辑器实现见 [editor spec](../spec-editor/ab-01-definition.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

技能编辑器是技能侧的首页：左侧技能清单，右侧一块一卡的声明表单，时间轴与各专块入口由此分发。

## 2. 布局线框

```text
┌─ 技能编辑器 ─────────────────────────────────────────────────────┐
├─ 左：技能清单 ────────┬─ 右：声明卡组 ────────────────────────────┤
│ ▸ BuildPowerPlant ●  │ [id] Ability.Rts.RedAlert.BuildPowerPlant │
│ ▸ BuildRefinery      │ [exec] 时间轴 16 槽 ▶ 进 ab-02 编辑器      │
│ ▸ TrainRhino  ⚡3 引用│ [cooldown] ▸ ab-04   [blockTags] ▸ ab-05  │
│ ▸ ＋新建技能          │ [toggleSpec] ▸ ab-08 [targeting] ▸ ab-09  │
│                      │ [presentation] 表单  [input] 表单          │
│                      │ [useRequirement ▾] [showRequirement ▾]     │
├─ 底部：校验条 [✔ 可启动 | ✘ 2 错误 ▶ 定位] ───────────────────────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 技能清单 | abilities.json 全量条目（分片合并视图） | 显示 catalogTags 徽标；重复 id 高亮"后加载覆盖" |
| 声明卡组 | 单条技能 JSON 顶层块 | 每块一卡；未声明块折叠为一行"添加" |
| 引用选择器 | 效果模板/图/属性/进度需求注册表 | 只列已注册名；键入新名即预警启动失败 |
| token 字段 | 文案目录（PresentationTextCatalog） | 补全 + 校验"已注册且有模板" |
| 校验条 | 与加载器同源的编译校验 | 错误点击跳到对应字段 |

## 4. 关键交互流：新建一个技能

1. 清单点"＋新建" → 输入 id（命名空间查重提示）。
2. exec 卡自动生成最小骨架：clockId 默认 FixedFrame、空 items。
3. 按需展开 presentation 填名字/图标/提示；token 字段从目录补全。
4. 保存 → 分片落盘 → 校验条全绿。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 覆盖冲突 | 同 id 条目多来源 | 双值对照 + 来源 mod 标注 |
| 旧字段 | 粘贴的历史 JSON 含已删字段 | 红条指明替代写法，可一键改写 |
| 引用缺失 | 引用未注册名 | 字段级红标 + "启动将失败" |

## 6. 易用性验收口径

- 新建一个可启动的空技能 ≤ 3 次交互。
- 任何启动失败错误都能从校验条一次点击定位到字段。
