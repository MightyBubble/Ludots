# rt-03 UXD · 诊断与错误码的编辑器需求

> rt-03 的编辑器需求（高保真规格）。第一性需求见 [rt-03 PRD](../prd/rt-03-diagnostics.md)；配置写法见 [rt-03 配置说明](../config/rt-03-diagnostics.md)；编辑器实现见 [editor spec](../spec-editor/rt-03-diagnostics.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

诊断流查看器 + 错误码字典：九域过滤的事件流、指标人话解释、错误码全文检索——从"一个码"到"什么意思、在哪抛的"一跳。

## 2. 布局线框

```text
┌─ 诊断中心 ────────────────────────────────────────────────────────┐
├─ 流（最近 N 帧）──────────────────────────────────────────────────┤
│ f1042  OrderAdmission  OrderRejectedByRule        ×5   cap 4096   │
│ f1043  ResponseChain   ResponseCreatesDropped     ×2   cap 256/根  │
│ f1044  GameplayEventBus GameplayEventBusDropped   ×1   cap 4096   │
├─ 过滤器 [域▾ 九选一] [指标▾] [只看非零]  ▶暂停  ⏬导出            │
├─ 错误码检索 [GAS.______________] 🔍                                │
│ ▸ GAS.GAMEPLAY_EVENT_BUS.ERR.CapacityExceeded  事件总线发布满抛    │
│   抛出点：GameplayEventBus.Publish   含义：单帧事件超容量          │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 诊断流 | 诊断缓冲镜像（逐帧，容量=引擎默认） | 实时滚动；条目含帧号/域/指标/容量/计数 |
| 域与指标过滤 | System 九值 × Metric 命名值（以枚举为准，缺号如实显示） | 组合过滤；缺号在筛选器中跳过不占位 |
| 指标解释 | 指标→人话映射表（编辑器侧维护，与枚举同源生成） | 悬停即出 |
| 错误码检索 | 错误码字典（引擎侧集中表为正源；过渡期编辑器扫描生成，见 R2） | 前缀模糊匹配；命中显示抛出点与含义 |

## 4. 关键交互流：从错误码定位配置

1. 测试报告里拿到 `GAS.ROOT_BUDGET.ERR.RollbackCapacityExceeded`。
2. 诊断中心检索框粘贴——命中：单根预算回滚槽超限，抛出点 RootBudgetTable。
3. 关联跳转 rt-02 预算监视器——查看当时单根表事务状态。
4. 结论：某效果事务在回滚路径上创建数超表容量——改配置规避。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未连接 | 无运行实例 | 错误码字典仍可用（静态数据），流区占位 |
| 空流 | 本帧无非零指标 | "无诊断——一切在预算内" |
| 检索无命中 | 码不在字典 | 显示原文 + "未知码，可能来自旧版本"，引导上报 |
| 字典漂移提示 | 扫描生成与上版 diff 非空 | 字典页头警示（R2 治理过渡期） |

## 6. 易用性验收口径

- 任一错误码 ≤ 1 跳得到含义与抛出点。
- 流内任一指标 ≤ 2 跳得到人话解释与关联配置篇。
- 指标缺号不产生空行或错误计数。
