# ab-03 UXD · CallerParams 参数池的编辑器需求

> ab-03 的编辑器需求（高保真规格）。第一性需求见 [ab-03 PRD](../prd/ab-03-caller-params.md)；配置写法见 [ab-03 配置说明](../config/ab-03-caller-params.md)；编辑器实现见 [editor spec](../spec-editor/ab-03-caller-params.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

参数池是时间轴旁边的提词板：四格池 + 条目到格子的连线，让"哪个效果用哪组数值"一眼可读。

## 2. 布局线框

```text
┌─ 参数池（嵌于时间轴编辑器侧栏） ─────────────────────────────────┐
├─ 池格 ────────────────┬─ 引用视图（回连轨道） ────────────────────┤
│ [0] damage 30         │ #0 ← E0(t0 Nova) · E2(t30 Nova 小)        │
│     radiusCm 120      │ [1] damage 90                             │
│     radiusCm 260      │ #1 ← E1(t30 Nova 大)                      │
│ [2] ＋组（≤4）        │ 未引用组灰显                              │
├─ 底：键名查重（全局键命名空间） 空间注入提示 [T/O 四键自动] ──────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 池格 | exec.callerParams 数组 | 组内键值行编辑；删除组重排索引并警示下游引用 |
| 引用视图 | items.callerParamsIdx 反向索引 | 条目点击跳轨道；未引用组提示清理 |
| 条目参数下拉 | 池组列表 + "无" | 时间轴条目属性面板入口（ab-02） |
| 键名补全 | 参数键注册表（与效果 configParams 共用） | 同名键跨用提示 |
| 用量计数 | 单组条目数 vs 上限（facts 页） | 接近上限预警 |

## 4. 关键交互流：给两个 Nova 条目配不同伤害

1. 池格 [0] 已有 damage 30；点"＋组"建组 [1]。
2. 组 [1] 键入 damage 90（键名补全自注册表）。
3. 轨道选中第二个 Nova 条目 → 参数下拉选组 [1]。
4. 引用视图即时出现连线；保存落盘。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 悬空引用 | 条目 callerParamsIdx 指向未声明组 | 红标"运行期读空组"（现状语义如实标注） |
| 键冲突 | 池键与模板 configParams 键同名 | 蓝标"调用方将覆盖模板值" |
| 池满 | 4 组上限 | "＋组"禁用 |

## 6. 易用性验收口径

- 建组并绑到条目 ≤ 3 次交互；引用关系双向可达。
- 覆盖语义（同键调用方胜）在冲突提示中直接可见。
