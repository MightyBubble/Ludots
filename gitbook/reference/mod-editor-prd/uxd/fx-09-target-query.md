# fx-12 UXD · 目标查询的编辑器需求

> 目标查询的编辑器需求（高保真规格）。第一性需求见 [fx-11 PRD](../prd/fx-09-target-query.md)；配置写法见 [fx-11 配置说明](../config/fx-09-target-query.md)；编辑器实现见 [editor spec](../spec-editor/fx-09-target-query.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

查询编辑区是空间手感的设计面：形状参数在俯视小地图上实时画出命中范围，字段与图形双向绑定。

## 2. 布局线框

```text
┌─ 查询编辑区 ────────────────────────────────────────────────────────┐
├─ 左：参数 ──────────────┬─ 右：范围预览（俯视）───────────────────────┤
│ kind [BuiltinSpatial ▾] │        ◠◠◠◠◠                              │
│ shape [Cone ▾]          │      ╱  300 ╲      ▲施法者                │
│ radius    [ 300 ]       │     ╱  ±40°  ╲    ▸朝向                   │
│ halfAngle [  40 ]       │     ╲        ╱                            │
│ origin [Default ▾]      │      ╲______╱   候选高亮 ●●                │
│ ▸ 切换 GraphProgram…    │                                          │
├─ 底部：单位换算 cm（cellSize 见事实页）· 过滤去 fx-12 ───────────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 形状下拉 | 五形状 | 切换即换字段集与预览 |
| 边界数值输入 | 形状互斥矩阵 | 非法值即时标红 |
| 原点下拉 | Default/Source | 预览中心随动 |
| GraphProgram 切换 | 图注册表（查询类） | 切换后空间字段折叠禁用 |
| 范围预览 | 形状参数投影 | 拖拽手柄反写数值 |

## 4. 关键交互流：调一个锥形斩击

1. 打开技能效果的查询编辑区，形状切到 Cone。
2. 拖预览手柄把半径拉到 300、半角 40；字段同步。
3. 预览高亮候选（含敌我着色，来自 fx-12 联动只读）。
4. 保存；互斥矩阵违例（如 Cone 缺半角）无法离开字段。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 边界违例 | 半径 ≤0、环内径 ≥半径 | 字段红 + 预览虚线 |
| 动态查询 | kind=GraphProgram | 空间字段全禁 + "由图产出"提示 |
| 无目标回退 | 预览原点缺目标 | 中心自动示施法者回退位 |

## 6. 易用性验收口径

- 五种形状均能"改字段见图形、拖图形改字段"。
- 互斥矩阵违例不允许保存；环内径边界用预览直接可感。
