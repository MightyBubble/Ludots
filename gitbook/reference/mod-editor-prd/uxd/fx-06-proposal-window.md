# fx-06 UXD · 提案窗口与 Instant 内联的编辑器需求

> 提案窗口与 Instant 内联的编辑器需求（高保真规格）。第一性需求见 [fx-06 PRD](../prd/fx-06-proposal-window.md)；配置写法见 [fx-06 配置说明](../config/fx-06-proposal-window.md)；编辑器实现见 [editor spec](../spec-editor/fx-06-proposal-window.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

提案窗口检查器是纯相位图的守门视图：验证图的行为、独占律冲突、内联判定结果集中呈现。

## 2. 布局线框

```text
┌─ 提案窗口检查器 ────────────────────────────────────────────────────┐
├─ 上：窗口判定 ──────────────────────────────────────────────────────┤
│ OnPropose  [Graph.Example.CorrosiveValidate] → 模拟运行：✓通过/✗拒绝 │
│ OnCalculate[Graph.Example.CorrosivePotency ] → 输出预览（纯计算）    │
│ 内联判定：Instant 且无周期 → 同帧内联（badge）                       │
├─ 下：独占律面板 ────────────────────────────────────────────────────┤
│ 外部原子：☐无 ☑位移 ☐进度 ☐订单   位置：[最后一步 ✓]               │
│ 组合冲突：modifiers ☐ grantedTags ☐ listenerSetup ☐（勾选即冲突）   │
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 窗口判定行 | 执行计划四窗口编译产物 | 显示每窗口 finalized 状态 |
| 验证图模拟 | 图 VM 试运行（纯图可离线跑） | 展示通过/拒绝与寄存器终值 |
| 独占律面板 | 窗口编译的组合检查 | 任一冲突项勾选即整窗标红 |
| 内联 badge | 寿命+周期推导 | 只读 |

## 4. 关键交互流：排查一个永不生效的效果

1. 作者反馈"效果没发生"，打开该模板的提案窗口检查器。
2. 验证图模拟显示拒绝，展开寄存器终值定位到判定节点。
3. 修图后模拟转通过；独占律面板无冲突。
4. 保存触发重编译，下次施放生效。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 拒绝粘滞 | 模拟中验证拒绝 | 面板标"本窗口不再翻案" |
| 独占冲突 | 外部原子+组合块并存 | 冲突行红条 + 编译错误码 |
| 空相位 | 未挂验证图 | 显示"空相位直接通过"灰提示 |

## 6. 易用性验收口径

- 验证图的通过/拒绝可以在编辑器内离线模拟，不必进游戏。
- 独占律冲突在编辑期可视化，错误信息能指到具体块。
