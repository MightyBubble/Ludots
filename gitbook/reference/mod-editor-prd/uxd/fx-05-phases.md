# fx-08 UXD · 八相位执行的编辑器需求

> 八相位执行的编辑器需求（高保真规格）。第一性需求见 [fx-07 PRD](../prd/fx-05-phases.md)；配置写法见 [fx-07 配置说明](../config/fx-05-phases.md)；编辑器实现见 [editor spec](../spec-editor/fx-05-phases.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

相位编辑视图把一个模板的全部相位绑定摊成时间带：哪一相位哪一槽挂了什么图、监听器排在哪，一屏可见。

## 2. 布局线框

```text
┌─ 相位编辑视图 ──────────────────────────────────────────────────────┐
│      相位： 提案 计算 裁决 命中 应用 周期 过期 移除                   │
│ pre  │     │    │    │    │  ▢  │     │  ▢  │     │                 │
│ main │  V  │  E │  E │  E │ [图]│ [图]│ ⤼跳 │ [图]│  ← 槽位格       │
│ post │     │    │    │    │  ▢  │     │ [图]│     │                 │
│ 监听 │  ·  │  · │  · │  · │ ●3  │  ·  │  ·  │  ●1 │  ← 优先级轨道  │
├─ 底部：绑定步 7 / 上限·事实页推导 · 纯相位只读提示（fx-08）─────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 槽位格 | phaseGraphs 投影 | 点击选图（图选择器按相位过滤 kind） |
| 跳过开关 | skipMain | 与 main 互斥，冲突即红 |
| 监听轨道 | 相位监听器注册（fx-10） | 只读计数，跳监听器编辑器 |
| 绑定步计数 | 已用槽位数 | 接近上限预警 |

## 4. 关键交互流：给 DoT 的周期拍加图

1. 打开模板的相位编辑视图，定位"周期"列。
2. 点 post 槽，图选择器过滤为 Effect kind，选中目标图。
3. 底部绑定步 +1；保存后执行计划重编译提示"下次施放生效"。
4. main 槽保持空——继续回落 preset 的 ApplyModifiers。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 主槽互斥冲突 | main 与 skipMain 同写 | 两格标红 + 顶部红条 |
| 纯相位限制 | 提案/计算列操作 | 列头标注"仅 Validation/纯图"（fx-08） |
| 步数预警 | 绑定步接近上限 | 计数变色 |

## 6. 易用性验收口径

- 八相位三槽的占用情况一屏可见；空 main 槽能看到"将回落到哪个 preset 处理器"。
- 互斥与 kind 违例在拖图入格时即报。
