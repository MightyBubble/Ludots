# fx-03 UXD · Preset 类型系统的编辑器需求

> Preset 类型系统的编辑器需求（高保真规格）。第一性需求见 [fx-03 PRD](../prd/fx-03-preset-types.md)；配置写法见 [fx-03 配置说明](../config/fx-03-preset-types.md)；编辑器实现见 [editor spec](../spec-editor/fx-03-preset-types.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

preset 类型面板是效果原型的字典页：每种原型一屏看全相位、寿命、默认处理器与消费者。

## 2. 布局线框

```text
┌─ Preset 类型面板 ───────────────────────────────────────────────────┐
├─ 左：原型清单 ────────┬─ 右：原型详情 ──────────────────────────────┤
│ ▸ InstantDamage   ⚡9 │ InstantDamage                     [内建]    │
│ ▸ Buff            ⚡6 │ 组件：modifiers（提示性，不校验）           │
│ ▸ Search          ⚡5 │ 活跃相位：OnApply → [OnResolve] → …         │
│ ▸ ＋新建原型（mod）   │ 允许寿命：Instant                          │
│                      │ 默认处理器：builtin ApplyModifiers           │
│                      │ 消费者：CostPowerPlantStep 等 9 个模板       │
├─ 底部：id 段用量 [mod 原型 0 / 上限·见 reference] ──────────────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 原型清单 | preset 类型注册表 | 内建/mod 徽标；被引用计数 |
| 相位带 | 原型 activePhases | 高亮活跃相位（八相位底图） |
| 消费者索引 | 效果表反向扫描 | 点击跳模板 |
| 新建原型表单 | 分片表 schema | handler 二选一（builtin 下拉 / graph 选择器） |

## 4. 关键交互流：注册一个自定义原型

1. 清单点"＋新建原型"，填 id（校验与内建枚举不撞名）。
2. 勾选活跃相位与允许寿命，为每相位选默认处理器。
3. 保存写入 mod 的 `assets/GAS/preset_types.json` 分片，重启生效。
4. 新原型出现在效果编辑器 presetType 下拉。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 零消费者原型 | 无效果引用 | 计数 0 灰显，提示核对拼写 |
| 冻结冲突 | 会话中新建原型 | 红条"重启级" |
| 字段缺失 | 任一字段未填 | 保存禁用，逐字段标红 |

## 6. 易用性验收口径

- 任一原型的"声明 + 全部消费者"≤2 跳可达。
- 新建原型不需要查 loader 规则——表单只呈现合法形态。
