# rt-02 UXD · 预算与容量的编辑器需求

> rt-02 的编辑器需求（高保真规格）。第一性需求见 [rt-02 PRD](../prd/rt-02-budgets.md)；配置写法见 [rt-02 配置说明](../config/rt-02-budgets.md)；编辑器实现见 [editor spec](../spec-editor/rt-02-budgets.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

预算监视器：把"这帧什么被预算拦了"变成一屏可见——九类丢弃、单根用量、订单水位；并区分"碗多大"与"一勺多大"。

## 2. 布局线框

```text
┌─ 预算监视器（连接运行实例）──────────────────────────────────────┐
├─ 帧丢弃计数（九类，非零高亮）─────────────────────────────────────┤
│ ResponseCreates ✓0   ResponseDepth ✓0   StepFused ✓0  QueueOvf ✓0 │
│ TagOvf ✓0  EffectAttach ⚠3  ListenerReg ✓0  ListenerDisp ✓0  Bus ✓0│
├─ 单根扇出 top-N ─────────┬─ 订单准入水位 ────────────────────────┤
│ root#412  254/256 ▸99%   │ backlog 118  高水位 4096  溢出 ✓0      │
│ root#398  190/256 ▸74%   │ 拒绝原因分布：QueueFull×2 Rule×5 …     │
├─ 底部：容量读数（碗）与单根上限（勺）分列，互不混排 ────────────────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 九类丢弃 | 诊断通道九个丢弃指标（按系统/指标，见 rt-03） | 每帧刷新；非零高亮；点击跳该系统的解释页 |
| 单根用量 | 单根记账表投影（需引擎快照接口） | top-N 排序；接近单根上限变色（上限见事实页） |
| 订单水位 | 订单准入 backlog/高水位/溢出 + 八种拒绝原因分布 | 溢出非零红显；计数回退红显"异常" |
| 容量读数 | game.json gasRuntimeCapacity（事实页）+ 单根上限 | 两数分列展示并标注职责差异 |

## 4. 关键交互流：排查"效果没生成"

1. 预算监视器看到 ResponseCreatesDropped 非零——根创建被拦。
2. 单根用量 top-N：root#412 已达单根上限——某技能的连锁召唤爆了。
3. 跳到该根的效果模板 → 发现 fan-out 目标数设置过大。
4. 调小 → 热应用（ed-02）→ 计数复测归零。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未连接 | 无运行实例 | 占位 + 连接按钮 |
| 全零 | 本帧无丢弃 | 九类淡显 ✓0 |
| 持续丢弃 | 连续多帧非零 | 计数器闪烁 + 聚合趋势条 |
| 计数回退 | 溢出计数减小 | 红条"引擎异常，请上报" |

## 6. 易用性验收口径

- 任一非零丢弃 ≤ 2 跳到达"哪个系统、什么原因、对应什么配置"。
- 单根上限与表容量在界面任何位置不混排为同一概念。
- 水位异常（回退）一定能被肉眼发现。
