# ord-04 UXD · 订单黑板的编辑器需求

> ord-04 的编辑器需求（高保真规格）。第一性需求见 [ord-04 PRD](../prd/ord-04-blackboard.md)；配置写法见 [ord-04 配置说明](../config/ord-04-blackboard.md)；编辑器实现见 [editor spec](../spec-editor/ord-04-blackboard.md)。

## 1. 界面定位

黑板键总账：全部键、类型归属、读写双方索引、运行期值窥视——参数链路的对账中心。

## 2. 布局线框

```text
┌─ 黑板键总账 ────────────────────────────────────────────────────────┐
├─ 左：键清单 ─────────┬─ 右：键详情 ─────────────────────────────────┤
│ ▸ Cast.SlotIndex  🔒 │ 类型 [整数]  编号 110  内置                   │
│   Int #110          │ 写方：castAbility 类型三键组 · argsTemplate    │

│ ▸ ＋新建键           │                                             │

└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 键清单 | 键注册表（内置 + 自定义） | 内置 🔒 只读；类型徽标（Int/Float/Entity/Spatial） |
| 读写方索引 | 全配置扫描（类型三键组、五键组、图节点、代码消费点） | 点击跳转声明处 |
| 实时值窥视 | 运行会话黑板快照 | 按实体分组展示当前值；离线会话隐藏 |
| 缓冲水位 | 四缓冲占用（容量为引擎常量） | 预警色阶 |

## 4. 关键交互流：为自定义订单加目标实体参数

1. 键总账 ＋新建键 → 输入 `Rally.Entity` → 类型选 Entity。
2. 写入订单类型 `rallyPoint` 的 `entityBlackboardKey`（跳转类型面板完成）。
3. 回到键详情，读写方索引出现新写方；无人读取时提示"暂无读方"。
4. 保存 → 键段与类型表同文件落盘。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 孤儿键 | 声明后无任何读写方 | 灰条 + 清理建议 |
| 内置误改 | 试图编辑内置键 | 只读锁 + 说明 |
| 五键组残缺 | 瞬时类型键组缺项 | 红条 + 补全表单 |

## 6. 易用性验收口径

- 任一键"声明+全部读写方"≤ 2 跳可达。
- 新建键到被类型引用 ≤ 4 次交互，且同文件保存。
