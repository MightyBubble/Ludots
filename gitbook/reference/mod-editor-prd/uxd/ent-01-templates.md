# ent-01 UXD · 实体模板的编辑器需求

> ent-01 的编辑器需求（高保真规格）。第一性需求见 [ent-01 PRD](../prd/ent-01-templates.md)；配置写法见 [ent-01 配置说明](../config/ent-01-templates.md)；编辑器实现见 [editor spec](../spec-editor/ent-01-templates.md)；组件清单以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

实体编辑器是"造单位"的地方：组件堆叠 + 出生效果挂接。地图编辑器的模板库、造单位效果的选择器都消费这里的产物。

## 2. 布局线框

```text
┌─ 实体编辑器：rts_ra_rifleman ──────────────────────────────────┐
├─ 左：模板列表 ────┬─ 中：组件堆叠面板 ─────────┬─ 右：出生效果 ──┤
│ ▸ rts_ra_rifleman│ ▾ AttributeBuffer           │ 效果：[无 ▾]   │
│ ▸ rts_ra_refinery│   base: Health [100]        │ (Effect 表下拉) │
│ ▸ ＋新建         │   current: Health [100]     │ 挂接预览       │
│                  │ ▾ Team  Id [1]              │                │
│                  │ ＋添加组件（引擎清单）        │                │
├─ 底部：继承提示 [底座模板，被 Ra2SkinMod 覆盖 2 个字段] ─────────┤
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 模板列表 | 模板表合并结果（逐条来源标注） | 点选编辑；被下游覆盖的字段标"被覆盖" |
| 添加组件 | 引擎组件清单（组件注册表投影） | 按组件 schema 生成初值表单 |
| 组件表单 | 该组件的解析 schema（字段/类型/默认） | 编辑写回本 mod 分片；数值经深合并预览最终值 |
| 出生效果 | 效果表（卷 5）已注册模板 | 下拉选择；只列合法 preset 的建议项 |

## 4. 关键交互流：调一个单位属性

1. 模板列表搜 `rifleman` → 点选。
2. 组件堆叠展开 `AttributeBuffer` → 改 base Health 100→120。
3. 底部提示"写入本 mod 分片；底座值 100 被覆盖"。
4. 保存 → 分片落盘；切到地图编辑器摆一个该模板实体。
5. 试玩 → 血量 120 生效。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空模板 | 新建 | 引导：选 1-2 个起步组件（位置/队伍/属性） |
| 组件缺失 | 引擎组件名不存在 | 组件卡红 + 名称 |
| 值不合 schema | 组件初值解析失败 | 字段级红 + 期望类型 |
| 被覆盖 | 下游 mod 覆盖了本字段 | 双值对照（基线 → 生效）+ 来源链接 |

## 6. 易用性验收口径

- 新建可用单位模板（位置+队伍+属性）≤ 4 次交互。
- 组件表单全部由 schema 生成，无裸 JSON 编辑兜底。
- 每个字段可见"基线值/生效值/覆盖来源"。
