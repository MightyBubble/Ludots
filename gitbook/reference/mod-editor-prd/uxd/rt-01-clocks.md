# rt-01 UXD · 时钟系统的编辑器需求

> rt-01 的编辑器需求（高保真规格）。第一性需求见 [rt-01 PRD](../prd/rt-01-clocks.md)；配置写法见 [rt-01 配置说明](../config/rt-01-clocks.md)；编辑器实现见 [editor spec](../spec-editor/rt-01-clocks.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

时钟面板：让"时间怎么走"可见、可控——三域读数、步进挡位（暂停/单步/自动）、实体变速调试。

## 2. 布局线框

```text
┌─ 时钟面板（连接运行实例）──────────────────────────────────────┐
├─ 域状态 ────────────────────────────────────────────────────────┤
│ FixedFrame  tick 1042 ▸ 50ms/帧                                 │
│ Step        tick 1042 ▸ mode [Auto▾] scale [1000‰] 步进间隔 [1]  │
│ EntityLocal #17  localStep 1027 ▸ time.scale_permille [1000‰]   │
├─ 控制 ──────────────────────────────────────────────────────────┤
│ ⏸暂停  ⏭单步×1  速度 [500|1000|2000]‰   适用：全局策略/选中实体  │
└─────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 域状态行 | 运行实例时钟快照 + 步进策略投影 | 每 tick 刷新；固定 tick 毫秒由 FixedHz 换算显示 |
| mode/scale/步进间隔 | 步进策略当前值（配置基线来自 GAS/clock.json） | mode 与速度运行中可调；步进间隔改动标注重启级 |
| 单步按钮 | 仅 Manual 态可用 | 请求一步；Manual 之外禁用并提示 |
| 实体变速 | 选中实体 AttributeBuffer 的 time.scale_permille | 即时属性命令生效；无该属性的实体显示"不参与本地时钟" |

## 4. 关键交互流：手动单步调试回合技能

1. 面板切 mode=Manual，游戏画面冻结在当前步。
2. 点单步×1——恰好一个步进、一条 TurnAdvanced 事件。
3. 效果链时间线（见 ed-01）观察该步内的效果相位推进。
4. 调试完切回 Auto。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未连接 | 无运行实例 | 占位说明 + 连接按钮 |
| 单步不可用 | mode ≠ Manual | 按钮禁用 + "切 Manual 后可用" |
| 实体变速非法 | scale_permille 校验失败 | 红条带引擎错误原文（不夹取不代填） |
| 非全局域提示 | 查看 EntityLocal | 说明"实体本地不是全局域" |

## 6. 易用性验收口径

- 三域读数与引擎 tick 严格一致（同源投影）。
- 改一个实体的变速 ≤ 2 跳（选中→面板改值）。
- 非法变速值一定看到失败原因，无静默生效。
