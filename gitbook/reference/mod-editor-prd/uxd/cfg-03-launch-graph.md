# cfg-03 UXD · 启动计划的编辑器需求

> cfg-03 的编辑器需求。第一性需求见 [cfg-03 PRD](../prd/cfg-03-launch-graph.md)；配置写法见 [cfg-03 配置说明](../config/cfg-03-launch-graph.md)；编辑器实现见 [editor spec](../spec-editor/cfg-03-launch-graph.md)。

## 1. 界面定位

编辑器里的"运行"体验：选组合、看顺序、一键启动。计划对作者是透明产物——界面上呈现的是组合与顺序，不是 JSON。

## 2. 界面功能

- **组合预览**：勾选根 mod 即见依赖闭包与最终顺序，DAG 呈现；环、缺失依赖、版本不满足在图上标红定位。
- **运行按钮**：走与命令行同一条计划生成链路再启动；运行配置（选哪个预设/哪些根 mod）随项目保存。
- **预设与绑定编辑**：绑定表与预设表的可视化编辑（别名、扫描根、选择器组、适配器）。
- **新鲜度错误呈现**：陈旧计划类拒绝启动错误翻译为"配置已变，请重新生成计划"并给出变化项。

## 3. 数据存储

- 运行配置存为项目级设置（选择器 + 根 mod 集合），不含推导结果。
- 绑定表与预设表写回保持规范化（字段序稳定）。

## 4. 易用性设计

- **顺序可解释**：预览图上任意 mod 可问"为什么排在这"——高亮它的依赖来源。
- 皮肤切换场景一条路径：预设下拉切换（底座+RA2 / 底座+Dune），所见即跑。
