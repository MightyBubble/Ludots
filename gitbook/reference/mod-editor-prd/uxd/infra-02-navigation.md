# infra-02 UXD · 导航配置的编辑器需求

> infra-02 的编辑器需求（高保真规格）。第一性需求见 [infra-02 PRD](../prd/infra-02-navigation.md)；配置写法见 [infra-02 配置说明](../config/infra-02-navigation.md)；编辑器实现见 [editor spec](../spec-editor/infra-02-navigation.md)；目录计数以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

导航设置页 + 地图编辑器的导航工具：作者声明体型与选路人格，在地图上烘网格、看覆盖、调代价。

## 2. 布局线框

```text
┌─ 导航设置 ────────────────────────────────────────────────────────┐
├─ [体型档案] [Agent 类型] [网格烘焙] ───────────────────────────────┤
│ ▸ 体型: id [Small] r[30] h[180] clearance[40] draft[0] beam[0]    │
│         mass[1.0] layer[0]        覆盖预览: (顶视小人图)          │
│ ▸ 类型: id [Humanoid] profile[Small ▾]                            │
│         选路 [PreferMesh ▾] 图权[1.0] 网格权[1.0]                 │
│         面积代价: Default[1.0] Mud[3.0]＋                          │
│ ▸ 烘焙: recast·offline  爬高[40] 坡度[45°] 增量预算[1/步]          │
├─ 底部: [在当前地图试烘] 覆盖率 92% ▓▓▓▓▓▓▓▓░░  [保存·重启级]      │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 体型表单 | agent_profiles | 厘米字段带单位后缀；清空表禁止保存（至少一档案） |
| profile 下拉 | 档案注册表 | agent 类型必绑 |
| 选路模式下拉 | selection.mode 枚举 | 权重输入随模式启用 |
| 面积代价编辑 | navmesh areas 声明 | 只可选已声明面积 |
| 烘焙参数 | navmesh profiles | 按 profileId 分组 |
| 试烘按钮 | 当前地图 + 烘焙参数 | 编辑器侧调烘焙器，展示覆盖 |

## 4. 关键交互流：给载具加宽通道

1. 新建体型 `Truck`：beamCm 加大、质量提高。
2. 在 navmesh 烘焙 profiles 加 Truck 组（爬高/坡度按载具调）。
3. 试烘：地图视图高亮 Truck 可通行区域（比 Small 窄）。
4. 新建 agent 类型绑 Truck、选路 PreferMesh。
5. 保存；重启后生效。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空档案表 | 删除最后一体型 | 阻止 + "至少保留一个体型档案" |
| 引用悬空 | profileId/areaId 失效 | 红标 + 重选 |
| 覆盖不足 | 试烘覆盖率低 | 覆盖条红 + 不可通行区域高亮 |
| 待重启 | 保存后 | 状态栏"重启生效" |

## 6. 易用性验收口径

- 体型字段全部带单位可见（cm/kg/度），无裸数字歧义。
- 试烘到参数调整的往返 ≤ 2 跳。
