# gr-op-03 UXD · 节点：标签的编辑器需求

> gr-op-03 的编辑器需求（高保真规格）。第一性需求见 [gr-op-03 PRD](../prd/gr-op-03-tags.md)；配置写法见 [gr-op-03 配置说明](../config/gr-op-03-tags.md)；编辑器实现见 [editor spec](../spec-editor/gr-op-03-tags.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

节点面板"标签"分组：单节点族。tag 选择器的体验重于节点数量。

## 2. 布局线框

```text
┌─ 节点面板 · 分组：标签 ──────────────────────────────────────────┐
│ ▸ HasTag   （判定 · 六类图通用）                                  │
├─ 画布节点卡 ─────────────────────────────────────────────────────┤
│ ┌ HasTag ────────────────────────────┐                          │
│ │ tag [State.Sandbox.Marked      ▾]  │                          │
│ │ source ●──────────────────── ● Bool │                          │
│ └────────────────────────────────────┘                          │
│  选择器数据：tag 注册表 + 通用用户表                                │
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| tag 选择器 | tag 注册表投影 + 通用用户表 | 搜索、层级树、显示已用计数（上限见事实页） |
| source 引脚 | Entity 值线 | 补全只推 Entity 源 |
| 用量预警 | 本图/全项目 tag 种类 vs 上限（事实页） | 接近上限变色 |

## 4. 关键交互流：给效果门加 tag 条件

1. JumpIfFalse 前插 HasTag，`source` 接 LoadExplicitTarget。
2. tag 选择器输入 `State.` 前缀，树定位到 Sandbox.Marked，回车选中。
3. Bool 值线接 JumpIfFalse 的 `condition`；保存即编译。
4. 若 tag 名未注册，选择器标红并给出"首现注册"提示（惰性注册语义，见 tag-01）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| tag 未注册 | 名字手输不在注册表 | 红字 + 惰性注册说明 |
| 专表误绑 | 未来重立"选 tag"节点时绑到专表 | 禁止连线并提示走通用表 |
| 上限预警 | tag 种类接近上限 | 选择器顶部预警条 |

## 6. 易用性验收口径

- 从拖入 HasTag 到选中一个既有 tag ≤ 3 步。
- 选择器搜索按点分层级匹配（输全名或尾段都能命中）。
