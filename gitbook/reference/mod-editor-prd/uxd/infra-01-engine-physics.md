# infra-01 UXD · 引擎与物理配置的编辑器需求

> infra-01 的编辑器需求（高保真规格）。第一性需求见 [infra-01 PRD](../prd/infra-01-engine-physics.md)；配置写法见 [infra-01 配置说明](../config/infra-01-engine-physics.md)；编辑器实现见 [editor spec](../spec-editor/infra-01-engine-physics.md)；实配数值以仓库资产与 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

项目设置里的"引擎/物理"页：少数但高危的底层旋钮。目标是让作者改之前知道影响、改的时候有守卫。

## 2. 布局线框

```text
┌─ 项目设置 → 引擎与物理 ───────────────────────────────────────────┐
├─ 引擎时钟 ────────────────────────────────────────────────────────┤
│ 固定步频 FixedHz        [20] Hz     ⓘ实配；代码缺省不同(D2)         │
├─ 物理 2D ─────────────────────────────────────────────────────────┤
│ 物理步频 PhysicsHz      [60]  每固定步补步上限 [8]                  │
│ 宽相策略 [SortAndSweep ▾]  网格尺寸 [100] cm（仅 UniformGrid 可用） │
│ ── 求解器 ── 迭代 [12] 位置修正 [1.0] 休眠 [4.0]s 碰撞对 [4096]    │
│ ── 运动学容量（必填，无默认）──                                     │
│ 刚体容量 [4096] 事件队列 [4096] 发射层 [（空）＋]                   │
├─ 底部：影响预览 "1 引擎步 = 3 物理步；预算 ~x ms/步"  [保存·重启级] ┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| FixedHz | Engine/clock.json | 数字输入，下限 1；显示实配值与代码缺省差异提示 |
| PhysicsHz / 补步上限 | Physics2D/clock.json | 下限 0 / 1；补步×步频超预算给黄条 |
| 宽相策略下拉 | 封闭枚举 | 选 UniformGrid 才启用 CellSizeCm（≥1） |
| 求解器四项 | solver.json | 迭代/修正比带区间守卫；修正比滑杆 0-1 |
| 容量三项 | kinematic.json | 空值即红（必显式）；发射层选择器来自层注册表 |
| 影响预览 | 派生计算（步频比、粗略预算） | 改值即时更新 |

## 4. 关键交互流：把物理从默认调到跟手

1. 打开项目设置 → 引擎与物理。
2. 读影响预览确认当前 1 引擎步 = N 物理步。
3. 调 PhysicsHz 与补步上限；预览黄条时回退或提预算说明。
4. 保存 → 标注"重启生效"；下次启动新参数生效。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 缺省差异 | 实配 ≠ 代码缺省 | ⓘ 提示"代码缺省 X，本项目实配 Y"（D2） |
| 越界 | 数值出区间 | 输入红框 + 具体界限；保存拦截 |
| 容量缺失 | kinematic 字段空 | 红"必填，引擎无默认注入" |
| 待重启 | 保存后 | 页面顶部常驻条 |

## 6. 易用性验收口径

- 每个字段的合法区间在输入处可见，越界不可保存。
- "代码缺省 vs 实配"差异在本页可见，无需读源码。
