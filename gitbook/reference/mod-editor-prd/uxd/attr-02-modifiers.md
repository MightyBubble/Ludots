# attr-02 UXD · 修改器的编辑器需求

> attr-02 的编辑器需求（高保真规格）。第一性需求见 [attr-02 PRD](../prd/attr-02-modifiers.md)；配置写法见 [attr-02 配置说明](../config/attr-02-modifiers.md)；编辑器实现见 [editor spec](../spec-editor/attr-02-modifiers.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

修改器编辑器嵌在效果模板表单里，是"这个效果动了谁的什么数"的唯一声明面。

## 2. 布局线框

```text
┌─ 效果表单 · 修改器区 ──────────────────────────────────────────────┐
│ #  属性            运算          数值                              │
│ 1  Credits         Add ▾         [-62.5 ]      ▲▼ ✕                │
│ 2  ＋ 添加修改器                                                   │
├─ 底部：用量条 [条数 1 / 上限·见事实页] · 落点徽标 [即时｜聚合·随 preset] ┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 属性选择器 | 属性注册表枚举（attr-01 面板同源） | 只允许已注册名；手输未知名即时报错 |
| 运算下拉 | Add / Multiply / Override | 切换即更新行内示意公式 |
| 数值框 | 有限数 | 负数标注"扣减" |
| 落点徽标 | 效果 presetType 推导 | Buff=聚合（链接 attr-03），其余即时 |
| 用量条 | 条数 vs 上限（事实页） | 接近上限预警 |

## 4. 关键交互流：强化兵种热调造价

1. 效果表单打开 `Effect.Rts.RedAlert.CostPowerPlantStep`。
2. 修改器行 1 数值 -62.5 改 -50，表单校验通过。
3. 保存 → 走工作台热管线，下次施放生效。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 容量将满 | 条数=上限 | ＋按钮降权、用量条红 |
| 未注册属性 | 手输新名 | 行内红"重启级：先在属性面板注册" |
| 聚合落点 | Buff 预设 | "随 Buff 过期消退"说明行 |

## 6. 易用性验收口径

- 任一修改器"属性+运算+数值"一眼可读，无嵌套展开。
- 超上限在编辑期即被拦截，不落盘。
