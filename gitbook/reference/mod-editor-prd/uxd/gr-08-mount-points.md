# gr-08 UXD · 挂接点总表的编辑器需求

> gr-08 的编辑器需求（高保真规格）。第一性需求见 ；配置写法见 ；编辑器实现见 。

## 1. 界面定位

挂接导航回答两张问题：这张图能挂到哪；这个挂点能收哪些图。

## 2. 布局线框

```text

│ │OnPropose:││同相位+  ││Derived  ││Validation││Validation││Score │   │
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 挂点卡片 | 挂接点表 × kind 合同（引擎同源） | 显示只收 kind 与消费时机 |
| 当前图过滤器 | 图 kind（gr-03） | 高亮可挂点、灰显不可挂点 |
| 挂点详情 | 挂点注册信息 | 已挂图清单 + 跳转各域配置 |
| 次要挂点组 | 次要挂点五项 | 展开呈现（含 Query 两项 → gr-09） |

## 4. 关键交互流：给 Validation 图找挂点

1. 选中一张 Validation 图 → 挂接导航自动过滤。
2. 可挂点三处高亮（效果相位提案、能力前置、订单校验）。
3. 点"能力前置" → 跳转该域挂接编辑（ab-05），按名引用完成挂接。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 无可挂点 | kind 与全部挂点不符 | 空态提示换 kind |
| 挂点拥挤 | 同一挂点图数量异常多 | 计数提示（性能预算提醒） |
| 悬空挂接 | 挂点引用的图未注册 | 行级红条（各域配置页联动） |

## 6. 易用性验收口径

- 任一图"能挂到哪"一屏读完；反向任一挂点"收什么"同屏可查。
- 导航的 kind 过滤与引擎终检判定一致。
