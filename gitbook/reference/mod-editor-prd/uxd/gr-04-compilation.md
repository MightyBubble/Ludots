# gr-04 UXD · 编译与校验的编辑器需求

> gr-04 的编辑器需求（高保真规格）。第一性需求见 ；配置写法见 ；编辑器实现见 。

## 1. 界面定位

诊断面板是装载失败的唯一解释入口：一次报全、逐条可定位、码义可查。

## 2. 布局线框

```text
┌─ 诊断面板 ──────────────────────────────────────────────────────────┐
│ ⚠ 3 · Graph.X：GASG0008 不可达节点「h」          [定位] [为什么?]    │
│ ⚠ 2 · Graph.X：GASG0015 BranchBool 缺 condition  [定位] [为什么?]   │
│ ⚠ 1 · Graph.Y：GASG0018 未定义读「r3」← 节点「m」 [定位] [为什么?]   │
├─ 详情：GASG0018 · 值边来源不存在；建议连一条值边或先写寄存器 ───────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 诊断列表 | 引擎编译器诊断流（同源） | 按图分组、按节点/边定位画布 |
| 码义详情 | 诊断码字典投影（21 码） | 含义 + 修复建议 |
| 保存预编译 | 编辑器内嵌编译器 | 保存即跑，一次报全 |
| 预算预警 | 编译产物 vs 上限（事实页） | GASG0009 前置预警 |

## 4. 关键交互流：修复一处数据流错误

1. 保存 → 诊断面板列出 GASG0018（未定义读 r3）。
2. 点击定位 → 画布跳到读节点并高亮缺失入边。
3. 补值边 → 再保存 → 该诊断消失，其余诊断保留可见。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 干净 | 预编译零诊断 | 绿勾 + 可装载标识 |
| 多错并存 | ≥2 条诊断 | 全量列表，不因首错中断 |
| 预算临界 | 指令数接近上限 | 预警色 + 建议拆图 |
| 跨图符号未决 | functionName 待二次 patch | 提示装 func_lib 后再验 |

## 6. 易用性验收口径

- 任一诊断从出现到定位 ≤ 1 跳。
- 编辑器诊断集合与引擎装载诊断完全一致（同源验收）。
