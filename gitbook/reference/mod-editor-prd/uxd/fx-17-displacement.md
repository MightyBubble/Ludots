# fx-21 UXD · 位移的编辑器需求

> fx-20 的编辑器需求（高保真规格）。第一性需求见 [fx-20 PRD](../prd/fx-17-displacement.md)；配置写法见 [fx-20 配置说明](../config/fx-17-displacement.md)；编辑器实现见 [editor spec](../spec-editor/fx-17-displacement.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

Displacement 效果编辑页的位移表单：方向模式、距离时长、导航接管，配"叠加即替换"语义提示。

## 2. 布局线框

```text
┌─ 效果编辑页 · 位移 ────────────────────────────────────────────┐
│ 方向  mode [ToTarget ▾]                                        │
│       Fixed 时： fixedDirectionDeg [90]                         │
│ 距离  totalDistanceCm [520]   时长 totalDurationTicks [2]       │
│       速度 ≈ 260 cm/tick（派生展示）                            │
│ 导航  [✔ overrideNavigation 压制移动输入]                       │
│ ℹ 同一目标再命中位移 = 替换当前段，不叠加                        │
└─────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 方向下拉 | ToTarget/AwayFromSource/TowardSource/Fixed | Fixed 时展开角度输入；其余隐藏 |
| 角度输入 | 整数度 | 仅 Fixed 可编辑 |
| 距离/时长 | 正整数 | <=0 即时红条；派生速度随动 |
| 导航开关 | 布尔 | 提示"位移期间压制移动输入" |

## 4. 关键交互流：把闪现改成击退

1. 打开 BlinkStep 效果 → 位移表单。
2. 方向切 AwayFromSource（角度输入自动收起并从落盘清除）。
3. 距离 350、时长 12；速度派生显示。
4. 保存；语义提示确认"连续命中会替换不叠加"。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 非 Fixed 残留角度 | 模式切换 | 字段隐藏且校验面板提示"将不保存" |
| 距离/时长非正 | 输入 0 或负 | 红条，保存禁用 |
| 叠加疑问 | 悬停提示 | 说明替换合同与写权窗口语义 |

## 6. 易用性验收口径

- "这个位移有多快"无需手算：派生速度一跳可见。
- 方向模式切换后的可见字段集与合法集一致。
