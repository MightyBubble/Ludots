# ab-07 UXD · 形态路由的编辑器需求

> ab-07 的编辑器需求（高保真规格）。第一性需求见 [ab-07 PRD](../prd/ab-07-form-sets.md)；配置写法见 [ab-07 配置说明](../config/ab-07-form-sets.md)；编辑器实现见 [editor spec](../spec-editor/ab-07-form-sets.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

形态路由编辑器是技能组的换装台：左边一组形态卡，右边八槽对照盘，选状态组合即时预览换组结果。

## 2. 布局线框

```text
┌─ 形态路由：champion_skill_sandbox_jayce_forms ───────────────────┐
├─ 左：路由卡 ────────┬─ 右：八槽对照盘 ────────────────────────────┤
│ ▸ 锤形态 ● priority │ 槽 [0 ToTheSkies][1 LightningField]        │
│   requiredAll ⚡1   │    [2 ThunderingBlow][3 Transform.Cannon]   │
│   blockedAny —      │    [4·底座]…[7·底座]                        │
│ ▸ ＋新路由          │ 预览条件 [☑ State.Hammer ☐ …] ▶匹配        │
├─ 底：优先级排序条 [锤 100]  冲突检查 [✔ 无同分] ──────────────────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 路由卡列表 | 表项 routes 数组 | 卡片显示条件徽标与优先级；拖动改不了优先级语义（数值编辑） |
| 条件选择器 | tag 注册表 | requiredAll 多选、blockedAny 多选（ab-05 同语义控件） |
| 八槽对照盘 | slotOverrides + 单位底座槽 | 覆盖格高亮形态层徽标；空格可拖入技能 |
| 技能拖入 | 技能清单（ab-01） | 拖到槽格生成 override；重复槽号即时拦截 |
| 预览条件 | 状态沙盒（与 ab-06 场景模拟共享） | 勾选状态即时显示匹配结果与胜者 |
| 优先级排序条 | routes 的 priority | 同分高亮"先出现者胜"提示 |

## 4. 关键交互流：给新英雄配双形态

1. "＋新路由"建"炮形态"卡：requiredAll 选 `State.NewHero.Cannon`，priority 100。
2. 技能清单把炮形态四技能拖入槽 0-3。
3. 预览条件勾 `State.NewHero.Cannon` → 对照盘即时换组。
4. 保存 → 表分片落盘，校验全绿。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 路由同分 | 两条路由 priority 相等且可同时匹配 | 黄条"平分先出现者胜，建议拉开" |
| 槽号冲突 | 同路由内重复 slotIndex | 拖入即拦（先于启动报错） |
| 悬空引用 | abilityId 未注册 | 槽格红标 |
| 无形态缓冲 | 目标单位模板缺组件 | 预览顶部提示"此单位不参与形态路由" |

## 6. 易用性验收口径

- 建一条四槽路由 ≤ 5 次交互（含拖入技能）。
- 预览匹配结果与运行期路由逐槽一致（同源）。
