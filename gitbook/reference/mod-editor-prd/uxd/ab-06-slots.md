# ab-06 UXD · 槽位系统的编辑器需求

> ab-06 的编辑器需求（高保真规格）。第一性需求见 [ab-06 PRD](../prd/ab-06-slots.md)；配置写法见 [ab-06 配置说明](../config/ab-06-slots.md)；编辑器实现见 [editor spec](../spec-editor/ab-06-slots.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

槽位视图是单位侧的技能收纳检查器：八个格子按四层来源叠放显示，谁在覆盖谁一目了然。

## 2. 布局线框

```text

├─ 八格条 ──────────────────────────────────────────────────────────┤

├─ 底：解析模拟 [场景 ▾ 默认|锤形态|装备满配] ▶四层解析 ─────────────┤
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 八格条 | 单位模板四层来源合并解析结果 | 格徽标显示生效层；被覆盖层灰显角标 |
| 覆盖栈 | 各层缓冲的该槽条目 | 逐层显示来源（模板/物品/形态/临时） |
| 场景模拟 | 形态 route 集与物品装备组合 | 切换场景即时重算八格 |
| 槽号引用索引 | 输入映射/面板/上下文组的槽号引用扫描 | 显示谁在用这个槽号 |
| 占用计数 | 各层非空槽数 vs 8 | 预警 |

## 4. 关键交互流：查"装备后技能没换"

1. 槽位视图切场景"装备满配"。
2. 八格条槽 4 出现物品层角标但仍显示底座技能——提示"物品授予未生效"。
3. 覆盖栈展开：该物品 abilityGrants.slotIndex=4 与另一物品冲突，先装者胜。
4. 点击跳转物品定义修改槽号。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 槽冲突 | 多来源争同槽 | 按解析序标注胜者与被覆盖者 |
| 满格 | 底座 8/8 且有授予欲进 | 冲突预警（授予将覆盖底座） |
| 引用悬空 | 输入映射引用的槽无技能 | 黄标"空槽" |

## 6. 易用性验收口径

- 任一槽的四层来源与胜者 ≤ 2 次交互可见。
- 场景模拟结果与运行期解析同源一致。
