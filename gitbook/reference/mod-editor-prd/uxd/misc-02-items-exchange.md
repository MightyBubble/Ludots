# misc-02 UXD · 物品与兑换的编辑器需求

> misc-02 的编辑器需求（高保真规格）。第一性需求见 [misc-02 PRD](../prd/misc-02-items-exchange.md)；配置写法见 [misc-02 配置说明](../config/misc-02-items-exchange.md)；编辑器实现见 [editor spec](../spec-editor/misc-02-items-exchange.md)；目录计数以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

物品工坊：形状画板（画占格）、容器布局画板（画格子）、物品卡编辑器（形状+堆叠+效果+技能）、兑换公式表。四张空根表意味着这里从零开始属于每个玩法 mod。

## 2. 布局线框

```text
┌─ 物品工坊 ────────────────────────────────────────────────────────┐
├─ [形状] [布局] [物品] [兑换] ──────────────────────────────────────┤
│ ▸ 形状画板:  ┌·X·┐  rotatable ☐(4旋转预览↻)                      │
│              └───┘  占格 2/9                                    │
│ ▸ 物品卡:    [缩略图] 造型[supply_1x1 ▾] 堆叠[99]                │
│              tags[＋] 槽位限定[＋] 装备效果[fx-选择器] 技能[ab-选择器]│
│ ▸ 兑换公式:  门槛: TradePact✔  投入: Gold×5  产出: Supply×1       │
│              试算: ▸(选样例单位) 可执行 ✓                        │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 形状画板 | shapes.rows 掩码 | 点格切换占/空；行数列数即掩码维度 |
| 旋转预览 | rotatable 派生 | 展示 4 旋转占格 |
| 布局画板 | layouts | blockedRows/namedSlots 直接在格上画 |
| 物品卡表单 | definitions | 形状/槽位下拉封闭；maxStack ≤0 显示"将归 1" |
| 效果/技能选择器 | GAS 效果与能力注册表 | equipEffects/abilityGrants 引用 |
| 兑换公式表 | operations | 投入/产出行编辑；门槛下拉来自 Relationship 目录 |
| 试算 | 样例单位 + 操作定义 | 预检关系/投入是否满足 |

## 4. 关键交互流：造一个可购买的补给箱

1. 形状画板画 1×1 掩码，命名保存。
2. 物品卡：选形状、堆叠、tags。
3. 布局已有 Stash 容器（或新建）。
4. 兑换公式：挂 TradePact 门槛，投入 Gold×5，产出选新物品、purpose=Stash。
5. 试算通过 → 保存（本 mod）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空根表 | 四表无内容 | 引导卡"内容在 mod（D3）" |
| 引用悬空 | 形状/物品/关系失效 | 下拉红标 |
| 堆叠非法 | maxStack ≤0 | 输入提示"保存时归 1" |
| 兑换不可试算 | 门槛/投入不满足 | 试算结果红 + 原因 |

## 6. 易用性验收口径

- 画一个异形形状到用于物品定义 ≤ 3 步。
- 兑换公式的"门槛/投入/产出"三段在视口内同时可见。
