# rt-04 UXD · 表现事件的编辑器需求

> rt-04 的编辑器需求（高保真规格）。第一性需求见 [rt-04 PRD](../prd/rt-04-presentation.md)；配置写法见 [rt-04 配置说明](../config/rt-04-presentation.md)；编辑器实现见 [editor spec](../spec-editor/rt-04-presentation.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

表现事件流查看器：让"逻辑发了什么回执、表现接没接"可见——施法漏斗、失败原因分布、事件负载明细。

## 2. 布局线框

```text
┌─ 表现事件流（连接运行实例）───────────────────────────────────────┐
├─ 施法漏斗（最近 N tick）──────────────────────────────────────────┤
│ Started 128 ▸ Committed 96 ▸ Finished 88 | Interrupted 6         │
│ Failed 32 ▸ OnCooldown×18 BlockedByTag×9 NoTarget×3 …            │
├─ 事件流 ─────────────────────────────────────────────────────────┤
│ f1042 CastStarted   技能#7 槽1 施法者#17 → 目标#23                │
│ f1042 EffectApplied 模板#41 施法者#17 属性 Health Δ-35            │
├─ 过滤 [种类▾ 九选一] [技能▾] [实体▾]  ▶暂停  ⏬导出               │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 施法漏斗 | 事件流聚合（Started/Failed/Committed/Finished/Interrupted） | 实时比例条；失败原因按枚举七值分布 |
| 事件流 | 表现事件缓冲投影（每 tick，容量=事实页 presentation 配置） | 实时滚动；条目点开看全负载（Actor/Target/槽/技能/模板/属性/增量/失败原因） |
| 过滤器 | 种类九值、技能 id、实体 id | 组合过滤 |
| 负载跳转 | AbilityId/EffectTemplateId → 定义面板 | 点击跳转对应配置 |

## 4. 关键交互流：排查"技能放了没动画"

1. 表现事件流过滤该技能——看到 CastStarted 与 EffectApplied 都在（逻辑回执正常）。
2. 结论收敛到表现侧：表现器档案没绑该技能/模板 → 跳 pres-01 表现器配置。
3. 反向场景：流里只有 CastStarted 没有 Committed——跳 ed-01 效果链时间线查逻辑侧断点。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未连接 | 无运行实例 | 占位 + 连接按钮 |
| 空流 | 本 tick 无事件 | "无施法/效果活动" |
| 缓冲满错误 | 引擎抛容量错误 | 红条透传错误原文 + 直达容量配置项（cfg-06） |
| 失败集中 | Failed 占比高 | 漏斗高亮 + 首要原因置顶 |

## 6. 易用性验收口径

- 任一事件的"逻辑回执→表现配置"≤ 2 跳。
- 九种事件与七种失败原因全部有筛选入口与人话标签。
- 容量错误出现时给出改容量的直达路径。
