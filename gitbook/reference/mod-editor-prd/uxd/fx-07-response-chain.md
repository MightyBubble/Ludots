# fx-06 UXD · 响应链的编辑器需求

> 响应链的编辑器需求（高保真规格）。第一性需求见 [fx-06 PRD](../prd/fx-07-response-chain.md)；配置写法见 [fx-06 配置说明](../config/fx-07-response-chain.md)；编辑器实现见 [editor spec](../spec-editor/fx-07-response-chain.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

响应链调试视图把不可见的对抗过程摊开：窗口状态、回应序列、否决链、根预算四件套一屏追踪。

## 2. 布局线框

```text
┌─ 响应链调试视图 ────────────────────────────────────────────────────┐
├─ 顶：窗口状态机 [关]→[收集 ▶]→[等输入]→[裁决] · 根 = Judgment #812 ─┤
├─ 中：回应序列（按优先级）──────────────────────────────────────────┤
│ ① Modify  天赋甲   +15%    → 窗口数值 62.5 → 71.9                  │
│ ② Hook    护盾乙   取消    → 非根项否决标记 ✗                       │
│ ③ Chain   反伤丙   → 新提案 Effect.X #815（深度 2/上限·事实页）      │
├─ 底：根预算 [###–––––] 3/上限·事实页 · 步数 214/上限·事实页 ────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 状态机指示 | 窗口状态投影 | 四态高亮 |
| 回应序列 | 窗口内已收集回应 | 按优先级排序；类型徽标 |
| 连锁树 | 链式提案父子关系 | 展开/折叠各级 |
| 根预算与步数 | 根预算表与步数计数 | 接近上限变色 |

## 4. 关键交互流：追一个被改写的伤害

1. 触发技能后暂停，打开响应链调试视图。
2. 状态机停在裁决，定位根提案。
3. 回应序列里看到 Modify 行：数值 62.5→71.9，点击跳到该回应来源。
4. 连锁树确认无 Hook 否决；裁决结果与预期一致。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未参与 | 根模板未声明参与 | 空态"此效果不开窗" |
| 等输入 | 存在 PromptInput | 状态机高亮等输入 + 待办提示 |
| 熔断 | 步数超上限 | 整窗标红"已作废"并显示根效果 |

## 6. 易用性验收口径

- 任一裁决结果能回溯到"哪些回应以什么顺序参与了改写"。
- 熔断与预算超限的错误能定位到根效果。
