# ord-03 UXD · 订单流水的编辑器需求

> ord-03 的编辑器需求（高保真规格）。第一性需求见 [ord-03 PRD](../prd/ord-03-pipeline.md)；配置写法见 [ord-03 配置说明](../config/ord-03-pipeline.md)；编辑器实现见 [editor spec](../spec-editor/ord-03-pipeline.md)；容量数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

订单流水观测台：实时回答"我的命令卡在哪一步"——队列水位、准入拒绝流、实体缓冲切面、终态账本。

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 水位条 | 各缓冲容量与占用（事实页） | 阈值变色；拒绝区非零即 ⚠ |
| 实体切面 | 指定实体的 OrderBuffer 快照 | 展示 active/pending/类型队列及排序键 |
| 事件流 | 准入结果区 + 拒绝区 + 终态账本流 | 按代际对齐；拒绝与终态带原因码悬停解释 |
| 原因码词典 | 失败原因/提交结果枚举全表 | 每码一句人话 + 常见处置 |

## 4. 关键交互流：排查"点了没反应"

1. 观测台过滤该实体 → 事件流定位最近一次提交。
2. 结果为拒收 → 悬停原因码（如 RejectedByRule）→ 弹出规则解释与命中边。
3. 结果为接受但无终态 → 实体切面看卡在哪（pending 未提升/队列积压）。
4. 步进观察下一逻辑步换代后的去向；导出该实体全程事件。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 溢出 | 任一水位越阈 | 水位红 + 对应容量字段直达链接 |
| 终端故障 | 拒绝区满触发停机 | 全屏横幅 + 复现步骤导出 |
| 空转 | 无提交的会话 | 骨架水位 + 引导文案 |

## 6. 易用性验收口径

- 任一提交从"点了"到"去向明确"≤ 3 次交互。
- 每个原因码都有人话解释；事件流可按实体/结果码过滤导出。
