# gr-08 UXD · 执行模型的编辑器需求

> gr-06 的编辑器需求（高保真规格）。第一性需求见 [gr-06 PRD](../prd/gr-05-execution.md)；配置写法见 [gr-06 配置说明](../config/gr-05-execution.md)；编辑器实现见 [editor spec](../spec-editor/gr-05-execution.md)；上限数值以 [事实与取值表](../facts.md) 与 gr-02 reference 为准。

## 1. 界面定位

图调试视图：跑一张图看得见游标、预算与挂起——执行模型对作者不再是黑盒。

## 2. 布局线框


## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 游标高亮 | 执行游标快照（指令位置） | 实时标出当前节点 |
| 步数仪表 | 游标步数 vs 上限（事实页 / gr-02 reference） | 递增条 + 临界变色 |
| 挂起徽标 | 游标状态五态 | Yielded/BudgetSuspended 区分呈现 |
| 宿主政策提示 | 宿主×挂起允许表（gr-09） | 图含 Yield 时提示可挂宿主 |
| 入口切换 | run-to-halt / 切片 | 选错入口时呈现引擎同款错误 |

## 4. 关键交互流：调一次挂起循环

1. 打开图调试 → 选切片入口 → 逐片步进。
2. 游标停在 Yield 节点 → 徽标变"挂起中"，预算条冻结。
3. 下一帧续跑 → 循环回到分支节点，步数继续累计（树共享）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 运行中 | 游标 Running | 节点流动高亮 |
| 挂起 | Yielded / BudgetSuspended | 冻结高亮 + 原因 |
| 预算耗尽 | run-to-halt 抛出 | 红条 + 定位嫌疑环 |
| 深度超限 | 跨图调用超上限 | 红条 + 调用链展开 |

## 6. 易用性验收口径

- 挂起原因与恢复点一屏可见。
- 预算条与引擎实测步数一致（同源）。
