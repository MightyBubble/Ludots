# map-01 UXD · 地图定义的编辑器需求

> map-01 的编辑器需求（高保真规格）。第一性需求见 [map-01 PRD](../prd/map-01-definition.md)；配置写法见 [map-01 配置说明](../config/map-01-definition.md)；编辑器实现见 [editor spec](../spec-editor/map-01-definition.md)；数值取值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

地图编辑器是"看见游戏"的地方：棋盘画布上摆实体、设相机、接触发器。演示场景的战役包与难度修正两段都在这里发生。

## 2. 布局线框

```text
┌─ 工具栏：[选择] [放置实体] [相机预览] [棋盘设置] ▶试玩 ──────────┐
├─ 左：实体模板库 ─┬─ 中：棋盘画布（网格/宏观格切换）──┬─ 右：属性面板 ┤
│ ▸ rts_ra_rifleman│   [实体图标@位置]  [队伍色边框]   │ 实例 rts_ra_… │
│ ▸ rts_ra_refinery│   相机视锥预览                    │ 模板：▾ 选择  │
│ ▸ 搜索…          │                                  │ 覆盖：组件表单│
│                  │                                  │ 棋盘：64×64   │
├─ 底部：片段来源条 [底座 ✓] [难度修正 +2 实体] [仅看本 mod] ──────┤
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 实体模板库 | 工作区全部 `Entities/templates.json` 合并结果 | 拖入画布即创建布阵条目（Template + 自动 InstanceId） |
| 棋盘画布 | Boards（名字/类型/尺寸） | 网格渲染；点选实体；坐标读写 `WorldPositionCm` 覆盖 |
| 片段来源条 | 当前地图全部来源片段（地址列表） | 切换"合并视图 / 单片段视图"——难度修正段的审计入口 |
| 相机预览 | DefaultCamera | 拖动视锥实时改参数；支持虚拟相机 id 选择 |
| 覆盖表单 | 选中实例的 Overrides + 模板组件 schema | 只显示被覆盖组件 + "添加覆盖组件"来自模板组件清单 |

## 4. 关键交互流：放置一个敌方单位

1. 模板库搜索 `rifleman` → 拖到画布目标格。
2. 属性面板自动展开：位置已填（落点），队伍待选。
3. 选队伍（下拉来自 Teams）→ 覆盖表单按模板组件渲染（属性初值等）。
4. 保存 → 写入本 mod 的地图片段（追加一条 Entities；InstanceId 冲突即时报）。
5. 片段来源条高亮"本 mod +1"，一键切合并视图看总布阵。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空地图 | 新建 | 引导：先建棋盘（尺寸/格宽表单，默认值取事实页） |
| 模板缺失 | 布阵引用未注册模板 | 实体图标灰 + 缺失名 + 模板库直达 |
| InstanceId 冲突 | 合并视图检测重复 | 两端高亮，冲突名提示 |
| 片段只读 | 查看非本 mod 片段 | 画布锁定编辑，提示"在本 mod 片段中追加" |
| 试玩中 | ▶ | 内嵌运行预览（走启动链路，cfg-03 UXD） |

## 6. 易用性验收口径

- 从新建空地图到摆上一个单位 ≤ 3 次交互。
- 合并/单片段视图一键切换；追加与覆盖的归属颜色区分。
- 相机参数改动实时反映到画布视锥。
