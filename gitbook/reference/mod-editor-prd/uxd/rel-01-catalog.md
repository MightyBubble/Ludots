# rel-01 UXD · 关系目录的编辑器需求

> rel-01 的编辑器需求（高保真规格）。第一性需求见 [rel-01 PRD](../prd/rel-01-catalog.md)；配置写法见 [rel-01 配置说明](../config/rel-01-catalog.md)；编辑器实现见 [editor spec](../spec-editor/rel-01-catalog.md)。

## 1. 界面定位

关系目录编辑器：九块词表的分页账本——声明一次，图节点与姿态判定按名引用。

## 2. 布局线框

```text
┌─ 关系目录 ──────────────────────────────────────────────────────────┐
│ [类型 3] [度量 0] [旗标 0] [档位 0] [原因 0] [回调 0] [协同 0] [知识 0] [姿态] │
│ ▸ Owns      非对称   被 2 处引用            [定位引用]               │
│ ▸ Controls  非对称   被 1 处引用            [定位引用]               │
│ ▸ MemberOf  非对称   被 0 处引用            [定位引用]               │
│ ── ＋新增类型    姿态缺省: Neutral · 同域 Friendly · 同队 Friendly   │
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 九块页签 | 目录九块 + 计数 | 空块引导新增 |
| 条目表单 | 各块字段与缺省（度量 -100..100 等） | 缺省值预填 |
| 引用计数 | 图节点关系符号扫描（gr-03 字段族） | 点击定位引用图 |
| 姿态编辑 | stance 词表与三个缺省 | 整对象替换提示（合并语义） |
| 合并预览 | 跨 mod DeepObject 合并结果 | 显示引擎默认 vs mod 覆盖 |

## 4. 关键交互流：加一种关系类型

1. 类型页签"新增" → 填 id（命名空间提示）与对称性。
2. 保存 → 写入本 mod 的 `Relationships/catalog.json`。
3. 图节点引用计数更新；合并预览显示引擎默认三条之上新增一条。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空块 | 计数 0 | 引导示例（不自动写入） |
| 被引用条目改名 | id 变更将断引用 | 红条 + 受影响图清单 |
| 姿态覆盖 | 多 mod 改 stance | 后到者整对象替换的醒目提示 |

## 6. 易用性验收口径

- 任一条目"定义+全部引用"≤ 2 跳。
- 改名/删除前能看到受影响引用清单。
