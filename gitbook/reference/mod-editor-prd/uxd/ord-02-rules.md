# ord-02 UXD · 订单规则与打断的编辑器需求

> ord-02 的编辑器需求（高保真规格）。第一性需求见 [ord-02 PRD](../prd/ord-02-rules.md)；配置写法见 [ord-02 配置说明](../config/ord-02-rules.md)；编辑器实现见 [editor spec](../spec-editor/ord-02-rules.md)。

## 1. 界面定位

规则编辑器以类型为中心的阻止/打断双表；配一条规则当场可见命令关系图与裁决模拟。

## 2. 布局线框

```text
┌─ 订单规则编辑器：stop ────────────────────────────────────────────┐
├─ 左：类型清单 ────────┬─ 中：双表卡 ────────────────────────────────┤
│ ▸ castAbility   ⚡1  │ 阻止表(blocked) [— 空 —] ＋                 │
│ ▸ moveTo        ⚡1  │ 打断表(interrupts) [castAbility ×]          │
│ ▸ stop          ●   │                     [moveTo ×]              │
│ ▸ myPing        —   │                     [attackTarget ×] ＋     │
├─ 右：关系图 ─────────┴──────────────────────────────────────────────┤
│   moveTo ⇢stop⇢ castAbility   （⇢=可打断；虚线=阻止边）             │
├─ 底部：裁决模拟器 [新单▾ × 活动单▾ ▶运行] → Activated/Rejected… ────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 类型清单 | 类型注册表 + 规则表 | 有规则的类型标 ⚡ 与计数；无规则可一键建 |
| 双表选择器 | 类型注册表（除主体自身） | 每表 ≤8；重复项即时拒绝 |
| 关系图 | 全部规则的双表边 | 节点可点跳转；反向边（谁打断我）切换视图 |
| 裁决模拟器 | 提交裁决干跑接口 | 输入新单+活动单组合 → 输出结果码与落点（排队/激活/拒收） |

## 4. 关键交互流：让停止命令打断一切普通命令

1. 左栏选 `stop`（已有规则直接进编辑）。
2. 打断表补 `castAbility`/`moveTo`/`attackTarget`。
3. 关系图即时出现三条 ⇢ 边；切"谁打断我"确认无意外反向边。
4. 模拟器选新单 `stop` × 活动单 `castAbility` → 结果 Activated（被打断）。
5. 保存 → 规则段随类型表落盘。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 表满 | 单表 8 条上限 | 添加钮禁用 + 计数 |
| 互打断环 | A⇢B 且 B⇢A | 环高亮 + 说明（后到者胜，非错误） |
| 引用悬空 | 规则引用的类型被删 | 红条 + 跳转类型面板 |

## 6. 易用性验收口径

- 配一条含打断的规则 ≤ 4 次交互且即时见关系图。
- 模拟器输出与引擎提交裁决逐字一致（同源）。
