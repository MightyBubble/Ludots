# misc-03 UXD · 叙事与任务的编辑器需求

> misc-03 的编辑器需求（高保真规格）。第一性需求见 [misc-03 PRD](../prd/misc-03-narrative.md)；配置写法见 [misc-03 配置说明](../config/misc-03-narrative.md)；编辑器实现见 [editor spec](../spec-editor/misc-03-narrative.md)；目录计数以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

剧情编辑器：对话节点画布、过场步骤带、任务阶段列、变量面板四视图联动。战役地图包 mod 的主工作区。

## 2. 布局线框

```text
┌─ 剧情编辑器 ──────────────────────────────────────────────────────┐
├─ [对话] [过场] [任务] [变量] ─────────────────────────────────────┤
│ ┌─ 对话画布 ───────────────┬─ 节点检查器 ─────────────────────┐   │
│ │ ●briefing_intro          │ 说话人 [elder] 名 [Warden Mirelle]│   │
│ │   ├─▶ lore_reply         │ 相机 [Narrative.Intro.Elder ▾]   │   │
│ │   └─▶ accept             │ 选项[lore]: ▸动作 AddVariable     │   │
│ │ ●(end)                   │      条件: trust ≥ 1 (灰)         │   │
│ └─────────────────────────┴─────────────────────────────────┘   │
│ 底部: 变量监视 [trust=0 lore=0] ▶试播（从选中节点起）              │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 对话画布 | dialogues 节点图 | 节点=对话、边=nextNodeId/选项；悬空边红 |
| 节点检查器 | 节点字段 | 相机下拉来自虚拟相机注册表（infra-03）；文本框支持 {变量} 内插提示 |
| 动作/条件下拉 | 封闭枚举（5 条件/11 动作） | 参数表单随 kind 切换；变量下拉来自 variables 表 |
| 过场步骤带 | cinematics.steps | 时间线拖排；durationSeconds/requiresAdvance 行内编辑 |
| 任务阶段列 | quests.stages | 台词/过场引用下拉；requiredSignals 标签编辑 |
| 变量面板 | variables | 类型决定默认值控件 |
| 试播 | 画布 + 变量监视 | 从选中节点模拟推进，变量变更实时显示 |

## 4. 关键交互流：写一段带分支的简报对话

1. 对话画布新建入口节点，填说话人与相机位。
2. 加两个选项，其一挂 AddVariable 动作（lore +1）。
3. 画后继节点连线；悬空边即时红。
4. 试播：选分支看变量监视变化。
5. 保存（本 mod 的 dialogues.json）。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 悬空后继 | nextNodeId 无着落 | 边红 + 定位按钮 |
| 未知动作/条件 | 枚举外值（导入旧数据） | 检查器红标，保存拦截 |
| 相机引用失效 | cameraId 未注册 | 下拉红 |
| 空根表 | 四表无内容 | 引导卡"内容在 mod"（D3） |
| 待重启 | 保存后 | 状态栏"重启生效" |

## 6. 易用性验收口径

- 对话任意节点到其检查器/试播起点 ≤ 1 跳。
- 变量内插（{player}/{lore}）在编辑器有实参预览。
- 悬空引用全部有清单视图一键定位。
