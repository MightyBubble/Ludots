# ab-05 UXD · 激活门的编辑器需求

> ab-05 的编辑器需求（高保真规格）。第一性需求见 [ab-05 PRD](../prd/ab-05-activation-gates.md)；配置写法见 [ab-05 配置说明](../config/ab-05-activation-gates.md)；编辑器实现见 [editor spec](../spec-editor/ab-05-activation-gates.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

激活门检查器是技能的安检模拟台：把六关排成一条链，选一组单位状态干跑，看在哪一关被拦。

## 2. 布局线框

```text
┌─ 激活门检查器：Ability.Ex.Gated ─────────────────────────────────┐
├─ 关卡链（订单起播序） ────────────────────────────────────────────┤
│ 1 存活 ✔ → 2 目标校验 ✔ → 3 槽位 ✔ → 4 toggle 关闭检查 —          │
│ → 5 tag 门 [requiredAll ⚡1 | blockedAny ⚡1] ✔ → 6 进度需求 ✔     │
│ → 7 前置图 [Graph.Ex.CanCastNuke ▸] ✔ → 起播 ✔                    │
├─ 左：单位状态沙盒 ────┬─ 右：拒绝详情 ─────────────────────────────┤
│ ☑ Status.Stunned     │ 拒于关卡 5：blockedAny 命中 Status.Stunned │
│ ☐ State.Ex.Stance    │ 影响面：本技能在命令面板置灰（原因悬浮）     │
│ 目标 [实体 ▾ 存活]    │                                           │
├─ 底：▶干跑（同源判定）  差异提示 [直启入口判序不同 ▸spec] ──────────┤
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 关卡链 | 技能定义的门块 + 固定判序 | 每关展开对应编辑器（tag 选择器/图选择器/进度需求选择器） |
| 单位状态沙盒 | tag 注册表、属性、进度状态 | 勾选即重算整链 |
| 拒绝详情 | 干跑结果 + 失败原因码 | 显示命中的 tag/需求/图；复制失败原因 |
| 前置图跳转 | graphs 注册表 | 点击进图编辑器（gr-08 挂点） |
| 差异提示 | 两入口判序差异（spec） | 悬浮展示对照，不误导 |

## 4. 关键交互流：排查"技能按了没反应"

1. 打开检查器，沙盒勾上实际战斗中可疑 tag（如 Cooldown/Stunned）。
2. 关卡链即时显示在第 5 关被拦、命中哪个 tag。
3. 点击命中 tag 跳转其来源（时间轴 TagClip/效果授予）。
4. 修复后重跑干跑全绿。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 无门技能 | 三门皆未声明 | 链压缩为"存活+目标+槽位"三关 |
| 延迟评估 | 进度需求遇目标门 | 关卡 6 标"等门回填后判"徽标 |
| 图缺失 | validationGraph 未注册 | 关卡红标 + 启动失败预警 |

## 6. 易用性验收口径

- 任一拒绝原因 ≤ 2 次交互定位到源头字段。
- 干跑判定与引擎实测逐字一致（同源）。
