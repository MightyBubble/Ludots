# rt-05 UXD · 事件总线与帧延迟的编辑器需求

> rt-05 的编辑器需求（高保真规格）。第一性需求见 [rt-05 PRD](../prd/rt-05-events.md)；配置写法见 [rt-05 配置说明](../config/rt-05-events.md)；编辑器实现见 [editor spec](../spec-editor/rt-05-events.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

事件时序查看器：把一拍延迟画出来——双缓冲泳道、发布→交换→消费的对角线、响应链遥测流。

## 2. 布局线框

```text
┌─ 事件时序查看器（连接运行实例）───────────────────────────────────┐
├─ 泳道 ───────────────────────────────────────────────────────────┤
│ 拍 f1042 │ next(写入)  Event.Damaged×2  Event.Dispel×1            │
│   帧末   │ ⇄ 交换                                                │
│ 拍 f1043 │ current(读取) ─→ 反应#17槽2 尝试 ─→ 延迟触发入队        │
├─ 响应链遥测 ──────────────────────────────────────────────────────┤
│ w#88 WindowOpened ▸ PromptRequested ▸ OrderConsumed ▸ Proposal×3  │
│   ▸ Resolved(CreatedEffect) ▸ WindowClosed        溢出计数 0      │
├─ 过滤 [tag▾] [实体▾] [只看反应]  ▶暂停  ⏬导出                    │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 双缓冲泳道 | 事件总线当前/次缓冲投影（容量=事实页引擎常量） | 逐拍推进；交换点显式画出 |
| 消费去向 | 反应系统/技能执行/延迟触发的消费结果 | 每事件标注"谁消费、结果如何" |
| 响应链遥测流 | 遥测缓冲投影（六事件+六种结果） | 按窗口聚合；结果枚举人话标签 |
| 溢出计数 | 遥测 DroppedSinceClear/DroppedTotal | 非零黄条，并标注"遥测溢出=计数丢弃（与主道 fail-fast 不同）" |

## 4. 关键交互流：验证反应的一拍延迟

1. 触发一次受击——泳道显示本拍写入 Event.Damaged。
2. 帧末交换线亮起——事件移入 current。
3. 下一拍：反应#17 的尝试条目出现——延迟恰一拍，与合同一致。
4. 若作者以为"当拍就该反击"——查看器截图即教学材料。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 未连接 | 无运行实例 | 占位 + 连接按钮 |
| 空拍 | 本拍无事件 | 泳道空白帧 |
| 主道溢出 | 发布抛错 | 红条透传（这是设计错误，需减事件量） |
| 遥测溢出 | 遥测丢弃计数非零 | 黄条 + 计数 + 语义差异说明（治理项 R3） |

## 6. 易用性验收口径

- 任一事件的"发布→消费/未消费原因"≤ 2 跳可达。
- 泳道延迟永远是恰好一拍——若引擎行为不符即为回归。
- 两种溢出语义（主道抛错/遥测计数）在 UI 上不可混淆。
