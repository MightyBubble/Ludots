# tag-01 UXD · Tag 表示与状态的编辑器需求

> tag-01 的编辑器需求（高保真规格）。第一性需求见 [tag-01 PRD](../prd/tag-01-basics.md)；配置写法见 [tag-01 配置说明](../config/tag-01-basics.md)；编辑器实现见 [editor spec](../spec-editor/tag-01-basics.md)；容量数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

Tag 管理页：全工程 tag 名的总账（谁声明、谁授予、谁消费），加运行时的实体 tag 检视。

## 2. 布局线框

```text
┌─ Tag 管理页 ────────────────────────────────────────────────────┐
├─ 左：tag 名清单（按前缀分组）────┬─ 右：选中详情 ────────────────┤
│ ▾ State.* (12)                  │ State.Burning                │
│   ✔ State.Burning  ⚡3 处授予   │ 授予：Effect.Burn(L1/层) 等 3 │
│ ▾ Cooldown.* (8)                │ 消费：HasTag ×2、规则 ×1      │
│ ▸ 搜索…  [重命名(治理)]          │ 时效：Cooldown.MyMod.Q 300t   │
├─ 底部：用量条 [种类 45/上限·见事实页] ────────────────────────────┤
└──────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| tag 清单 | 全工程配置扫描的注册结果 | 按前缀分组；未消费的孤儿标灰 |
| 详情面板 | 授予方（grantedTags/TagClip）与消费方（HasTag/规则/AI）交叉索引 | 点击跳转对应配置 |
| 用量条 | 当前种类数 vs 上限（事实页） | 接近上限预警 |

## 4. 关键交互流：查一个状态为什么没生效

1. 搜 `State.Burning` → 详情显示"授予 3 处、消费 2 处、规则 1 条"。
2. 规则行提示"`DisabledIf Status.Wet`"→ 疑似被禁用。
3. 跳转规则（tag-02 页）确认；再开运行检视（实体面板）看有效集。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 孤儿 tag | 无任何消费方 | 灰 + "仅授予未消费" |
| 撞名 | 两 mod 同名不同义 | 警示（命名空间全局扁平） |
| 容量预警 | 种类接近上限 | 用量条变色 |

## 6. 易用性验收口径

- 任一 tag 的授予/消费全链路 ≤ 2 跳可达。
- 清单计数与启动注册数一致（同源）。
