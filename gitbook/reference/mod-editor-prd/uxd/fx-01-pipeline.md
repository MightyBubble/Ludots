# fx-01 UXD · 效果执行管线总览的编辑器需求

> 效果执行管线总览的编辑器需求（高保真规格）。第一性需求见 [fx-01 PRD](../prd/fx-01-pipeline.md)；配置写法见 [fx-01 配置说明](../config/fx-01-pipeline.md)；编辑器实现见 [editor spec](../spec-editor/fx-01-pipeline.md)；上限数值以 [事实与取值表](../facts.md) 为准。

## 1. 界面定位

效果管线面板是工作台的运行观测页：回答"这一帧效果走到哪、预算还剩多少、谁被回滚"。

## 2. 布局线框

```text
┌─ 效果管线面板 ──────────────────────────────────────────────────────┐
├─ 顶：阶段带 [提案·应用 ▶] [存活] [消化] [完成] · 帧 1204 ───────────┤
├─ 中左：请求队列 ─────────┬─ 中右：预算 ─────────────────────────────┤
│ #812 Judgment    Search  │ 工作单元 [####––––] 37%                  │
│ #813 WMark       Buff    │ 毫秒     [##––––––] 1.2/4ms             │
│ …（滚动）                │ 扇出根   [###–––––] 3 根 / 上限·事实页   │
├─ 底：事务日志（提交 ✓ / 回滚 ✗ + 原因）─────────────────────────────┤
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 控件与数据源

| 控件 | 数据源与取值 | 行为 |
|---|---|---|
| 阶段带 | 阶段机当前态投影 | 只读；帧步进时高亮 |
| 请求队列 | 请求缓冲快照 | 行点击跳效果模板详情 |
| 预算表 | 切片预算与根预算用量 | 超 80% 用量条变色 |
| 事务日志 | 提交/回滚事件流 | 回滚行展开原因 |

## 4. 关键交互流：定位一帧卡顿

1. 会话运行中打开面板，暂停在目标帧。
2. 阶段带确认停在提案段，读工作单元与毫秒用量。
3. 队列中找占用最大的请求，点击跳到模板。
4. 在模板详情热改字段，恢复运行对比下一帧用量。

## 5. 状态设计

| 状态 | 触发 | 呈现 |
|---|---|---|
| 空闲 | 本帧无请求 | 队列空态"本帧无效果" |
| 让位 | 预算尽、本帧未完 | 阶段带加"续跑"角标 |
| 回滚 | 事务失败 | 日志红行，源请求行标回滚 |

## 6. 易用性验收口径

- 任一暂停帧 ≤2 跳答出"阶段、剩余预算、未消化请求数"。
- 回滚必须可见原因，不允许请求静默消失。
