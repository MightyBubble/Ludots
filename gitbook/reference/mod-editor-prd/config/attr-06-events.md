# attr-06 配置说明 · 属性事件

> 配置写法与行为。第一性需求见 [attr-06 PRD](../prd/attr-06-events.md)；编辑器需求见 [UXD](../uxd/attr-06-events.md)；现状见 [reference](../reference/attr-06-events.md)。

## 1. 示例配置

**状态标注：玩法面链路休眠**——属性→事件映射注册入口在生产代码零调用、无配置文件，当前内容下永不发布（A13）。以下为目标写法（教学骨架，配置入口待立项）：

```json
[ { "attribute": "Health", "eventTag": "Event.Attribute.HealthChanged" } ]
```

表现面零配置：变化位对一切属性写入自动生效。

## 2. 两条通知链对比

| | 玩法面（属性→GameplayEvent） | 表现面（变化位→表现投影） |
|---|---|---|
| 触发条件 | 属性已声明映射 | 一切属性写入，自动 |
| 时序 | 延迟一帧发布 | 当帧打位、表现消费即清 |
| 载荷 | Old/New 数值 | 只含"变了"事实与属性 id |
| 消费方 | 触发器、图（事件总线） | 表现层演出 |
| 现状 | 休眠（无映射则直接返回） | 常开 |

映射字段（目标写法）：`attribute` 已注册属性名；`eventTag` 事件 tag 名。Old 取自上次快照；实体首帧无快照时 Old=0（已知伪基线，A5）。

## 3. 文件结构

现状无独立文件；映射属启动期代码注册。配置入口立项后归属 GAS 域表（A13 决策）。

## 4. 运行时加载效果

映射表为 64 槽直查结构，启动期填充、冻结后封闭；运行期按属性 id 直查，未映射返回无效 id 即不发事件。快照由实体模板创建与批量生成路径预置。

## 5. 异常处理

| 异常情形 | 系统响应 |
|---|---|
| 映射越界查询 | 返回无效 id，即不发布 |
| 冻结后注册 | 失败（错误信息现状不指向真因，A14） |
