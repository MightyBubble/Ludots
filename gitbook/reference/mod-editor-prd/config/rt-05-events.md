> 配置写法与行为。第一性需求见 [rt-05 PRD](../prd/rt-05-events.md)；编辑器需求见 [UXD](../uxd/rt-05-events.md)；现状见 [reference](../reference/rt-05-events.md)。

## 1. 示例配置

事件总线无独立配置文件。作者要"发事件"靠 tag 变化（规则写法见 tag-02 配置说明）；要"消费事件"靠实体模板组件（教学骨架）：

```json
"ReactionBuffer": { "entries": [ { "tag": "Event.Damaged", "slot": 2 } ] }
```

```csharp
// EventGate 节点：等待事件 tag，下一拍到达即放行（可设 deadline）
```

## 2. 作者可配什么与在哪配

| 想控制什么 | 在哪 | 说明 |
|---|---|---|
| 发什么事件 | tag 规则表与效果授予（见 tag-01/02/03） | 事件即 tag 变化，发布是自动的 |
| 谁消费 | 实体模板 ReactionBuffer、技能 EventGate、延迟触发 | 一拍后送达；绑定写法见 tag-03 |
| 缓冲容量 | 无入口（引擎常量，见事实页 MAX_GAMEPLAY_EVENTS_PER_FRAME） | 双缓冲各一倍该容量；满即抛错 |

规则表——一拍链时序（作者据此排反应先后）：

| 拍 | 发生什么 |
|---|---|
| 本拍 | tag/属性变化 → 事件写入次缓冲；效果事务可回滚本拍已写事件 |
| 帧末 | 双缓冲交换；丢弃计数结算 |
| 下一拍 | 反应系统/技能执行/延迟触发读当前缓冲并行动 |

## 3. 文件结构

无独立表：事件 tag 散布于授予方与消费方（tag-01 注册规则）；反应绑定在实体模板组件；等待节点在技能图。

## 4. 运行时加载效果

引擎装配期构造双缓冲总线并注册；每帧按组序（技能激活→效果处理→事件分发）推进；帧末交换后下一拍分发。响应链遥测缓冲并行记录窗口六事件（开启/请求输入/订单消费/提案加入/提案裁决/窗口关闭）。

## 5. 异常处理

| 异常情形 | 系统响应 |
|---|---|
| 单帧事件超容量 | 发布抛错（带容量与 tag id）——减事件量，无配置项可调 |
| 事务回滚后仍见事件 | 不发生——写检查点随事务回滚 |
| 遥测缓冲溢出 | 现状计数丢弃（静默）——仅影响编辑器观测面，不影响玩法（治理中） |
