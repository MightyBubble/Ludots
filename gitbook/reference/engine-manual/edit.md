# 编辑场景

场景不只是"看"——播放器内置**编辑态**：左键点选实例、拖三色轴柄移动、Ctrl+S 保存回场景文件。改的是纯数据（JSON），全程不碰代码。

## 进编辑态

两种方式：

- 运行播放器进场景后按 **E**（检视↔编辑随时切）；
- 启动直入：加 `--edit` 参数（`--scene composition --edit`）。

编辑态的检视相机改为**右键旋转**（左键让位给拾取与拖拽）。

## 挑选与拖动

1. **左键点击**场景里的静态网格实例（石头阵任意一块）→ 选中：亮黄色线框 + 属性面板（右侧）显示它的节点/组件/实例号、位置、尺寸、朝向；
2. 选中后实例中心出现**三色轴柄**：红=X（东西）、绿=Y（上下）、蓝=Z（南北）；
3. **左键按住轴柄拖** → 实例沿该轴移动，属性面板实时刷新；
4. 松手完成一次编辑（**内存态**，尚未写盘）；
5. **Ctrl+S** 保存：原子写回 scene.json（自动 `.bak` 备份；若文件在编辑期间被外部程序改过，保存拒绝并报错——重新打开场景再改）。

## 编辑态的规矩

- **编辑器是 scene.json 唯一写入方**：拖动只改内存，Ctrl+S 才落盘；预览/运行态永不写盘；
- 保存是**最小 diff**：只改被拖动实例 position 数组的数字行，其余一个字符不动（字节级 round-trip 合同测试守卫）；
- 预览（普通播放）从文件快照重建世界，退出即丢——编辑数据永远不会被运行态污染。

## 属性面板字段

| 显示 | 含义 |
|---|---|
| node / component / instance | 该实例在场景 JSON 里的三层地址 |
| position | 实例中心世界坐标（米） |
| halfsize | 半尺寸（缩放的一半） |
| yaw | 绕竖轴的朝向角 |
| unsaved | 是否有未保存的编辑 |

## 验收

编辑链有无头自证：`--edit-selftest composition` 模拟拾取→移动→保存→重装载→diff 校验，CI 可跑，输出 PASS/FAIL。改动写回的正确性由三条合同测试锁死：22 场景 no-op 字节稳定、单实例编辑只动 position 数字行、外部修改后保存拒写。
