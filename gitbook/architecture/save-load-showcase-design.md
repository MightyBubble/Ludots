# 存档读档 showcase 设计

## 一句话与目标用户

把巡逻兵挪走、存一档、再挪远，读档后他会弹回存档点——给没读过存档代码的人看。

## 主循环

谁改变世界：玩家用 WASD / 屏幕方向键挪「巡逻兵」。  
用户看到什么变：地上青色圈跟着兵走；存档后多一个绿色幽灵圈钉在存档点；读档后兵弹回绿圈。  
惊喜时刻：兵已经走出老远，一点「读档回来」，绿圈里归位——屏幕上写清「回来了」。

## 消融对照

同一场景一键切：
- **无存档重置**：丢掉进度，兵回到出厂摆位（营地旁）；
- **有存档恢复**：读刚写下的槽，兵回到你存档时站的地方。

一眼看出：存档解决的是「我挪过的进度丢了」，不是多一个按钮。

## 解释层

- 首屏大字：「挪兵 → 存档 → 再挪 → 读档」四步；
- 当前步高亮（第几步）；
- 巡逻兵坐标（厘米）+ 存档点坐标；读档后绿字「归位成功」或红字失败；
- 落盘路径常显；
- 地上：青=现在，绿幽灵=存档点，灰=故意不进档的临时侦察；
- 图例钉在面板底。

## 旋钮清单

| 旋钮 | 范围 | 演示什么 |
|------|------|----------|
| 槽位选择（右侧通用面板） | 多 manual 槽 | 槽位互不覆盖 |
| autosave 保留数 | 1–5 | 轮换只删自动档 |
| 篡改槽位 | 一键弄坏文件 | 校验失败，世界不偷偷改 |
| 排除临时侦察 | 开/关 | 灰圈单位不进档 |

## 场景结构

- 主演示：岸线小地图 + 一名「巡逻兵」演员 + 右侧 `SavePanelMod`（零拷贝）；
- 子故事：冷启动读档、篡改拒读、排除实体；
- 首屏：「用方向挪巡逻兵 → 点存这一档 → 再挪远 → 点读档回来看绿圈归位。」

## Cucumber UAT

```gherkin
Feature: 巡逻兵挪走还能读回来
  Scenario: 挪兵、存档、再挪、读档归位
    Given 我打开存档演示，看到巡逻兵站在营地旁
    When 我把巡逻兵往前挪了几步
    And 我点「存这一档」
    And 我再把巡逻兵挪得更远
    And 我点「读档回来」
    Then 巡逻兵回到存档点，地上绿圈里写着归位成功

  Scenario: 无存档重置 vs 有存档恢复
    Given 我已经挪过兵并存过档，又继续挪远了
    When 我点「无存档重置」
    Then 兵回到出厂营地旁，不是存档点
    When 我点「有存档恢复」
    Then 兵回到存档点

  Scenario: 弄坏档时读档失败可见
    Given 已有完整槽位
    When 我点「弄坏这一档」再读档
    Then 面板用红色说明校验失败，巡逻兵位置不被悄悄改写
```
