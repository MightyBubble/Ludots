# 确定性回放 showcase 设计

## 一句话与目标用户

同一段操作再播一遍，世界演化得一模一样——给关心「能不能复现」的作者看。

## 主循环

谁改变世界：玩家录制一段移动/攻击；之后由权威输入帧驱动回放。  
用户看到什么变：时间线进度、录制时 vs 回放时的世界指纹并排滚；一致绿、分叉红。  
惊喜时刻：回放到一半乱按键——输入被拒绝，轨迹不被污染。

## 消融对照

并排含义（同场景切换）：
- **确定性回放**：从检查点按权威输入一帧帧走，证明过程确定；
- **快照跳终点**：直接读档到终点，只证明终点，不证明过程。

## 解释层

- 录制区间、总帧数、当前 tick、播放头；
- 录制 digest vs 回放 digest 并排（归一化镜头口径）；
- 回放资产路径与格式版本常显；
- 图例：绿=一致，红=分叉，灰=输入隔离中。

## 旋钮清单

| 旋钮 | 范围 | 演示什么 |
|------|------|----------|
| 播放速度 | 慢/正常/快 | 快慢不影响确定性 |
| 逐帧步进 | 一帧一帧 | tick 级演化可见 |
| 跳到中途检查点 | 从中段续播 | 任意中途点仍一致 |
| 播放中注入输入 | 开/关尝试 | 回放不被污染 |

## 场景结构

- 主演示：录制 → 停 → 播 → 终点对比；
- 子场景：逐帧、中途跳转、输入隔离拒收；
- 首屏：「先录一段，再播。看两条指纹并排；播放中乱按应被拒绝。」

## 门户资产

- 封面取「指纹分叉变红 / 或输入被拒」那一帧；
- 配置与 HUD 同源。

## Cucumber UAT

```gherkin
Feature: 同一段操作，重放一模一样
  Scenario: 录制后回放终点指纹一致
    Given 我从检查点开始录制若干帧并停止
    When 我从同一检查点播放到终点
    Then 回放终点世界指纹与录制终点一致，并显示为绿色

  Scenario: 播放中注入输入被拒绝
    Given 回放正在进行且输入隔离已打开
    When 我注入实时操作
    Then 系统拒绝该输入，回放轨迹不被改写

  Scenario: 中途检查点续播仍一致
    Given 一段完整录制
    When 我跳到中途检查点再播到终点
    Then 中途与终点的对比结果都可读且一致为绿
```
