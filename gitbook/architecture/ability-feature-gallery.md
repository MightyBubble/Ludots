# Ability 词条画廊

技能这边按图节点画廊同一套规矩收：一场短剧只讲一个技能合同，不把英雄整栏、冷却、瞄准、换姿态塞进同一间房。

本页是技能词条层的入口。图能力总账仍只认 [图能力唯一入口](graph-capability-status.md)。引擎渲染词条仍只认 [Raylib 引擎能力标准化 Showcase](engine-capability-showcases.md)。

## 1. 概述

打开启动器，每个还能运行的技能合同自己一间短剧。字幕只讲这一场的动词。作者页只给这一场的写法。

旧的英雄技能沙盒还在，那是把多招串成一栏的组合戏，不再当技能词条的入口。

本轮只收 `abilities.json` 里已经接通、并且这场能真跑起来的合同：时间轴条目、激活门、开关、派发对象、形态换栏。配置册上写了但加载器不收的 `cooldown` 块、还没有生产写入的临时授招槽、技能自带触发图，不进画廊，也不假装能玩。

## 2. 结构

```text
词条    一场短剧只讲一个技能合同
专项    热改工作台、配置分片、超级武器瞄准、自动施放、进度解锁
剧情    英雄技能沙盒、夜袭、各品类演示
```

词条共用一个宿主，薄入口只改开场地图。词条正文在 `Vignettes/{Feature}.json`。启动器条目、登记表和 Wiki 由生成器写出，不要手改。

## 3. 详情

### 3.1 玩家怎么进

启动绑定：`capability_standard_ability_feature_{Feature}`

```text
scripts/run-mod-launcher.cmd cli launch $capability_standard_ability_feature_EffectSignal --adapter raylib
```

Wiki： [技能词条画廊](../reference/ability-feature-wiki/README.md)

### 3.2 一场短剧里有什么

舞台上能看见施法者和木桩，头顶有血条。短剧自己出手，不用先学键位。字幕点名这一场的结果：掉血、挂印、放不出、再按一次关掉。

作者页从这场真实技能表摘写法，链回手册分册 `ab-01` 到 `ab-10`。

### 3.3 本轮词条

时间轴：点一下就打中、火还在烧、自己身上挂一阵印、给对面挂一阵印、瞬间给自己打上印、瞬间给对面打上印、出手那一下敲响铃、等你点头才打出去、铃响了才打出去、名单齐了才打出去、被晕就停手、同一招两波不同力道。

门：身上有禁招印就放不出、没有姿态印就放不出、残血才打得中、没解锁就放不出、没解锁栏上就没有。

开关与附属：再按一次关掉、关掉时补一刀收尾、这一刀打回自己、换姿态换一栏招。

技能自带触发图这轮不进：开招瞬间的名字不在事件名册里；写进名册又会把开招瞬间带着的载荷判成非法。挂得上，但这场玩不真。

### 3.4 不进这轮词条的

- `cooldown` 配置块：加载器不收，实战冷却走「自己挂印 + 禁招印」。
- 临时授招槽：还没有生产写入。
- 走位够得着再出手、智能锁敌、单招改施法手感：订单/输入层，已有订单合同与英雄沙盒。
- 装备授招、情境选招：已有物品专项与交互专项。

看见旧本子还把英雄沙盒写成技能能力总入口，听本页的。

## 4. 场景

1. 新人打开启动器。每个技能合同自己一间房。没有把整栏英雄技能塞进同一场的大杂烩。
2. 我走进「点一下就打中」。不用按键。施法者出手，木桩血条掉一截，字幕只讲这一下。
3. 我走进「身上有禁招印就放不出」。第一下挂上禁招印，第二下字幕说放不出。
4. 我打开英雄技能沙盒。那是组合戏，不是词条。

## 5. 边界

- 一场短剧只证明一个合同。冷却拆成「自己挂印」和「禁招印」两间房，不在第三间再演一遍。
- 名单门只把当前目标换成名单里的第一个；远处那根木桩在场上，是为了让人看见名单有两个人，这场不挨打。
- 技能自带触发图这轮不进画廊。开招瞬间的名字不在事件名册里；写进名册会把开招瞬间带着的载荷判成非法。
- 被晕停手只停还没打出去的时间轴，不假装把已经挂上的火掐灭。
- 词条不新造技能枚举、效果预设或平行时间轴。
- 表上写「测过了」，就必须真跑到那个合同。
- 录像还没采之前，Wiki 可以先出页，但必须写明还没有录像；不能拿截图冒充已拍。

## 6. UAT

```gherkin
Feature: 每个技能合同单独一场能看懂的短剧

  Scenario: 新玩家点开「点一下就打中」
    Given 玩家从画廊进入 capability_standard_ability_feature_EffectSignal
    And 舞台上能看见施法者和木桩，头顶有血条
    When 短剧开始出手
    Then 字幕只讲这一下打中了
    And 木桩血条往下掉
    And 这场里看不到换姿态或冷却的完整剧情

  Scenario: 覆盖表里的每个已接通合同都能单独进
    Given 覆盖表里有一个 status=covered 的技能合同
    Then 画廊里有且仅有一场以它为主角的短剧
    And 启动器能单独打开这一场
    And 这一场有自己的验收

  Scenario: 英雄技能沙盒不再当词条入口
    Given 玩家在画廊导览里找技能词条
    Then 导览把词条指向 capability_standard_ability_feature_* 
    And 英雄技能沙盒标成组合戏
```
