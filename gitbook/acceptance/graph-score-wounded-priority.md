# 残血的分更高

## 1. 概述

场上同时站着满血木桩和残血木桩。队友手里拿的是一张**打分图**：谁缺的血更多，谁的分更高，然后自动打分高的那个。

这间短剧只验收一件事：打分走正式图链路，玩家能看见「字幕点名残血，分来自这一刀的决策，残血掉血，满血不动」。

## 2. 结构

```text
两根木桩（满血 / 残血）
        ↓
打分图读当前血，用图里的满血常数减去，得到缺口分
        ↓
队友按分数选人
        ↓
正式出手，残血木桩掉血，满血木桩不动
```

启动入口：`capability_standard_graph_score`  
地图：`capability_standard_graph_score`  
打分图：`Graph.GraphScore.MissingHealth`（`Score`）  
选人输入：Utility `GraphScore`

## 3. 详情

- 满血木桩开场满血，残血木桩开场更残，两人离队友一样远。
- 打分图只读不写：先点名眼前这个人，读他的血，再算缺口分。满血常数写在打分图里（今天没有读生命上限的节点）。
- 字幕写出两个人的血、点名谁挨打、以及这一刀的分。分只读决策痕迹，不再另跑一遍打分图。
- 出手走技能和伤害效果，不在短剧代码里直接改血。

## 4. 场景

玩家打开这间展厅，不用点技能。看字幕，看谁挨打。

## 5. 边界

- 打分图不能写血、不能挂效果、不能发事件。
- 两根木桩距离相同，不能靠「谁比较近」混过去。
- 满血木桩这一刀不能掉血。
- 缺图、缺分、缺人时直接失败，不许当成 0 分继续演。
- 字幕和验收不得另开打分执行门。

## 6. UAT

```gherkin
Feature: 残血的分更高

  Scenario: 玩家看见残血木桩被点名
    Given 我走进「残血的分更高」
    And 场上站着会打分的队友、满血木桩和残血木桩
    And 残血木桩比满血木桩更残
    When 我站着看完第一刀
    Then 字幕点名残血木桩
    And 字幕写出这一刀的分
    And 这一刀打向残血木桩
    And 残血木桩的血往下掉
    And 满血木桩的血不动
```
