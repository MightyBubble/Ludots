# 贡献与开发

本章节定义 Ludots 的正式开发规范。所有开发者和 AI Agent 都应先读这里，再进入具体代码与深度材料。

## 核心原则

- 先搜索，再阅读，再编码，再自检。
- 新代码必须挂靠现有 Registry、Pipeline、SystemGroup 和 Mod 机制。
- 文档、代码、测试在同一提交或同一 PR 内同步更新。
